# مسار .NET — رحلة TeamBoard

منهج عربي للمبرمج الذي يريد الاندماج في فريق .NET. موقع React داكن برئيسية مفتوحة، لقطة واحدة للدراسة، محاكاة تفاعلية، حفظ محلي ودفتر. المشروع الوحيد TeamBoard API، مبني بمنافذ وأطراف: Domain / Application / Infrastructure / Api / Tests.

## الموقع

```sh
cd curricula/web/dotnet/site
npm install --workspaces=false
npm run dev
```

الرابط المحلي: http://127.0.0.1:5186/ . للبناء: `npm run build`.

## المصادر

- `content/`: الدروس، أسئلة مع تغذية راجعة، تمارين وتلميحات وحلول ومراجع رسمية.
- `project/`: المرجع الكامل القابل للبناء والاختبار.
- `journey/`: محطات تعديل نفس المشروع؛ تعليمات وملفات مرجعية وفروق.
- `scripts/package-journey.py`: توليد البداية وحزم المحطات والحل المرجعي.
- `AUTHORING.md`: قواعد التأليف والتصميم الخاصة بهذا المنهج.
- `VALIDATION.md`: ما تم التحقق منه وحدود التحقق.

لإعادة توليد الحزم: `python3 curricula/web/dotnet/scripts/package-journey.py` من جذر المستودع، ثم بناء الموقع. الملفات القابلة للتنزيل في public/ مولدة من المصادر وليست نسخة مستقلة للتأليف. توجيهات Claude تُستعمل كمراجع اختيارية بحسب طلب المستخدم.
