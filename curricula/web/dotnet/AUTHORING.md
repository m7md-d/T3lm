# قواعد تأليف مسار .NET

هذه اختيارات لهذا المنهج، مستمدة من طلب المستخدم وخبرته المذكورة في خطته، لا قواعد إلزامية من ملفات Claude. لا نفترض ذاكرة شخصية خارج ما قاله المستخدم. أحدث توجيه للمستخدم مقدم على هذا المستند.

## المنتج

موقع React عربي، دارك مود افتراضي ثابت، ورئيسية تفتح كل المحطات. لا أقفال ولا اشتراط إنهاء درس للوصول إلى آخر. المسار المتسلسل اقتراح للفهم، لا ترتيب واجهة ملزم.

## مشروع واحد

TeamBoard API هو الرحلة. كل محطة تربط المفهوم بتغيير فيه، مع ملفات جاهزة جزئيًا، تكليف محدد، تلميح عند الطلب، حل مقارنة، وعلامة نجاح عملية. الحزم المرحلية ليست مشاريع مستقلة: تتراكب ملفاتها على نفس مجلد المتعلم. لا تضف console app أو تطبيقًا نهائيًا آخر لكل فصل.

الهيكل السداسي: Domain وApplication في الداخل؛ المنافذ في Application؛ EF وHTTP adapters في Infrastructure؛ Api مدخل ومكان تركيب؛ الاختبارات مدخل آخر. لا EF/HTTP types في Application، ولا DbContext في controllers. لا نعلّم six-folders myth. لا CQRS/MediatR/microservices/DDD framework.

PostgreSQL قاعدة المشروع. Adapter ذاكرة يمهد ويوضح الاستبدال؛ SQLite داخل integration tests فقط، مع ذكر حدود اختلاف provider. الإشعار best effort بعد commit؛ لا نعد بتسليم مضمون.

## خفض حمل البداية

الفكرة والشرح ودليلها في لقطة واحدة، والفعل التالي واضح. يظل المورد أو الطلب نفسه مستمرًا بين اللقطات. لا نسب إنجاز كلية في واجهة الدراسة، ولا عد تنازلي ولا streak أو نقاط أو مواعيد قسرية. تعرض الرئيسية خيارات حقيقية؛ الخريطة والوقت الإجمالي في موضع اختياري. حفظ آخر موضع ودفتر محلي وواجهة إكمال هادئة. التلميح والحل والمرجع مطويان، والانتقال لا يقفل على الاختبار.

التقطيع، خفض تشتيت الانتباه، الأمثلة المحلولة وتلاشي السقالة تدريجيًا اختيارات مستنيرة بأدبيات التعلم. لا ندعي أرقامًا مثلى أو تأثيرًا علاجيًا مثبتًا لهذا الشخص. حدود كلمات اللقطة إن استعملت هي قرارات تحرير، لا سعة ذاكرة مقيسة. نستند إلى .claude/philosophy/foundations.md و.evidence/open.md لفهم القرارات وحدودها، دون تحويلها إلى ضمان فعالية.

## المظهر من الموضوع

اللون يشرح مسؤولية أو نتيجة داخل TeamBoard، ولا يصبغ النصوص والبطاقات للزينة. الأسطح فحمية باردة والنصوص محايدة متدرجة السطوع. أربع عائلات دلالية كحد تصميمي، وليست حدًا بيولوجيًا مثبتًا:

| العائلة | معناها الثابت | موضعها والقناة الثانية |
|---|---|---|
| الكهرماني | القلب: قرار العمل الذي نحميه من تفاصيل الخارج | Application / Domain في الرسمين؛ اسم المسؤولية بجواره |
| السماوي | التعامل مع الخارج: المنافذ والأطراف والمدخل التفاعلي | HTTP / Test / IBoardStore / IAssignmentNotifier؛ اسم المنفذ أو الفعل |
| الأخضر | نتيجة تحقق ناجحة | الإجابة الصحيحة والإنجاز وقرار 200؛ نص النتيجة أو علامة تحقق |
| الوردي | رفض أو تفسير غير صحيح | الإجابة غير الصحيحة و401/403؛ سبب الرفض مكتوب |

لا تلوّن كل محطة بلون مختلف، ولا تلوّن معلومة عامة بالأخضر قبل تحققها. النافذة والكود والنص الطويل والخلفيات لا تحمل صبغة العائلة. لا تجمع اللون مع مؤشرات زخرفية متكررة. تظل المسؤولية والنتيجة مفهومتين دون تمييز اللون. الكلمات التقنية في النثر محايدة؛ لا تُصبغ جميعها لمجرد أنها كود.

مصدر الحقيقة البصري `site/src/styles/tokens.css`. لا قيم لونية حرفية في CSS المكونات؛ دليل المحطات وfavicon وtheme-color يولدون من نفس المصدر عبر package-journey.py. لا تستخدم filter/hue-rotate لتغيير لوحة الموقع.

مرجع القرار: `.claude/philosophy/foundations.md` §11 و`.claude/evidence/findings.md` §8 وقسم اللون في `.claude/skills/curriculum-site-design/SKILL.md`. هذه الملفات نفسها تنبه إلى أن الأسانيد التجريبية لبعض الأرقام لم تحدد؛ لا نحوّل القواعد إلى وعد بتحسن تعلم مقيس.

القلب السداسي حالة استخدام؛ الأطراف adapters يمكن تبديلها. العربية بخط عربي متصل دون letter-spacing. الكود والأسماء المعزولة LTR مع unicode-bidi:isolate؛ monospace للكود فقط. افحص الجوال والكمبيوتر ولوحة المفاتيح وقابلية القراءة.

## ملكية المحتوى

content/ مصدر الدروس والمحطات. project/ مرجع C# الكامل. scripts/package-journey.py يصنع حزم المراحل ودليلها من نفس المرجع. لا تعدل zip أو guide HTML يدويًا؛ أعد توليدها. site/src/ يملك العرض والتفاعلات، ولا يحمل شرح الدروس الأساسي.

## التحقق

بعد تعديل C#: build/tests مناسبة، وفحص migrations على PostgreSQL عندما تتغير. بعد تعديل generator: ابنِ snapshots المرجعية وتأكد من أن files-to-copy + إزالة الملفات المعلنة تنتج المرحلة نفسها بعد إكمال TODO. بعد تعديل الموقع: production build، فحص كل معرف درس ورابط محلي، وتحقق UI من الرئيسية والقفز والعودة والحفظ والمختبرات. لا تسمّ محاكاة المتصفح تشغيلًا لـ.NET. سجل ما اختُبر وحدوده بوضوح.

لا تنشر أو ترفع مواد المستودع الأخرى ضمن هذا المنهج. احتفظ بتغييرات المستخدم السابقة. لا تغير Git لمجرد إكمال العمل.
