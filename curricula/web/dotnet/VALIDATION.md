# التحقق من رحلة TeamBoard

## مراجعة الألوان — 12 سبتمبر 2026

استبدلت الصبغة البنفسجية العامة بأسطح ونصوص محايدة، وأربع عائلات مرتبطة بمعنى: القلب، الأطراف، نجاح التحقق، والرفض. جميع ألوان المكونات تأتي من `site/src/styles/tokens.css`، وتُولد منه لوحة صفحات المحطات وأيقونة الموقع ولون المتصفح.

نجح بناء الموقع. فُحص تباين أزواج النص والخلفية في اللوحة حسابيًا: أدنى زوج مستخدم للنص الخافت 5.52:1، والعائلات الدلالية على أسطحها بين 7.26:1 و7.91:1. هذا فحص للأزواج المحددة، وليس شهادة وصول شاملة. راجعت الرئيسية ودرس السداسي في المتصفح، وثبات لون القلب عند تبديل الطرف، وحياد النصوص.

تاريخ التحقق: 11 سبتمبر 2026. التسليم موقع محلي؛ لم يُنشر إلى خدمة استضافة.

## المنهج والموقع

- مصدر محتوى موحد: 12 محطة، 31 درسًا، 94 لقطة، مع تكاليف ومراجع وتلميحات وحلول اختيارية.
- نجح بناء React/Vite للإنتاج.
- راجعت الواجهة في المتصفح بعرض 1440، وواجهة الهاتف بعرض 390. لا تجاوز أفقي للصفحة، والكود LTR داخل صفحة عربية RTL.
- تحققت من التنقل الحر، خريطة الدروس، الرجوع للدرس واللقطة، عرض روابط ملفات المحطة، نافذة المراجع، وضع التركيز وقائمة الجوال.
- اختبرت إجابة صحيحة وأخرى خاطئة وظهور شرح السبب.
- تحققت من بقاء ملاحظة بعد تحديث الصفحة، ثم أزلت ملاحظة الفحص وحافظت على تقدم المستخدم السابق.
- بدّلت مدخل محاكاة السداسي والتخزين والإشعار، وراجعت تبدّل العرض.
- لم تظهر أخطاء أو تحذيرات في سجل المتصفح خلال المراجعة النهائية.

## المشروع والمحطات

- .NET SDK 10.0.401، مكتبات Microsoft 10.0.12، وNpgsql 10.0.3.
- نجحت الاختبارات الـ27: قواعد العنوان، حالات الاستخدام وفصل الاعتمادات، HTTP والصلاحيات والتخزين، والإشعار عبر handler بديل.
- بُنيت النسخة المرجعية لكل محطة من المحطات الـ12، دون أخطاء أو تحذيرات.
- وُلدت migration وفُحص SQL وطُبّق على PostgreSQL 17 محلي مع بيانات مختبر.
- فحص HTTP فعلي مع JWT تطوير حقيقي: health 200، غياب الهوية 401، قراءة العضو 200، الفاعل خارج المشروع 403، مرشح خارج المشروع 400، تعيين صحيح 204 ثم قراءة القيمة المحفوظة، عنوان فارغ 400، إنشاء مهمة ومشروع 201.
- صُححت عدادات هوية PostgreSQL بعد إدراج بيانات seed ذات المعرّفات المحددة؛ تحقق الإنشاء من ذلك.
- فُحصت سلامة جميع ملفات ZIP، واستبعاد ملفات البناء والمفاتيح وملفات الأسرار منها.

## حدود التحقق

المحاكاة داخل موقع الدراسة تشرح الفكرة ولا تشغّل C# في المتصفح. التطبيق الفعلي على جهاز المتعلم. مقتطفات الدروس ليست كلها ملفات مستقلة قابلة للبناء؛ النسخ المرجعية للمحطات هي ما بُني. ملفات التكليف تحمل TODO مقصودة، وقد تفشل وظيفيًا قبل إكمالها.

اختبارات SQLite لا تثبت جميع خصائص PostgreSQL؛ لذلك أُضيف فحص PostgreSQL الفعلي أعلاه. اختبار إشعار HTTP يستخدم handler بديل، ولم يُختبر موفر إشعارات خارجي. الإشعار best effort بعد الحفظ، وليس نظام تسليم مضمونًا.

التقدم والملاحظات محليان في المتصفح، ويمكن تصديرهما. لا توجد مزامنة حسابات أو تنفيذ كود عن بعد. أدوات scripts/check-live*.py وverify-dotnet.sh خاصة ببيئة التحقق المحلية؛ أوامر تشغيل المتعلم العامة في project/README.md.
