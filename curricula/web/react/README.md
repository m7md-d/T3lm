# React — متطلّبات المنهج

**المادّة القديمة في [`archive/react`](../../../archive/react) — لا يُبنى
عليها.** ثلاثة عشر إقليماً، بلا أداة تحقّق: مخرَجاتها غير مفحوصة (الثابت ١).
وموقعها منشورٌ على `react.nodeksa.com` ولم يُسحَب. وفي الأرشيف كذلك
[`react-frontend-app`](../../../archive/react-frontend-app)، وهي محاولةٌ أقدم.

## المتطلّب المعرفيّ

- **JavaScript** بمستوىً عملـيّ، ولا يبني على منهجٍ آخر في المستودع.
- ويُسأل المتعلّم عن مستواه فيها قبل التصميم (القانون ٧)، ولا يُستنتَج.

## ما يجب أن يقوم عليه

الادّعاء الذي يستحقّ البقاء من المادّة القديمة: **يُبنى الألمُ الذي وُجد React
ليزيله قبل أن يُكتب أي JSX** — فيُشتقّ إعادةُ التصيير من السؤال لا يُحفَظ.
