# Python بعد C — الاسم والكائن والمصفوفة والحدّ

## لمن كُتب

**لمن C مرساتُه**، وكتب سكربتات Python صغيرة تعمل ولا يعرف لماذا تعمل.

والضغط الذي يعيشه: **يقرأ Python من خلف C فيغلط غلطاً منتظماً.** يظنّ `a = b`
نسخاً فيُفاجأ حين يتغيّر الاثنان، ويظنّ `list` مصفوفةً متجاورة، ويكتب حلقةً على
مليون عنصر فتأخذ عشرة أضعاف ما يتوقّع ولا يعرف أين ذهبت، ويسمع «استعمل NumPy»
فيستعملها ولا يعرف ما الذي تغيّر.

## ما يفترضه فيك

- **C بمستوى العمل**: المؤشّر، والمصفوفة، والمكدّس والكومة، و`sizeof`، والترجمة
  والربط. كلُّ مقارنةٍ في المنهج تُبنى عليها.
- **سكربت Python قرأتَه أو كتبتَه**: `if` و`for` والدالّة والصنف. **ولن يُعاد
  شرحُها** — يُعاد بناءُ ما تحتها.
- رياضياتٌ: لا شيء فوق الحساب.

**ولا يفترض:** خبرةً بالويب، ولا بعلوم البيانات، ولا بأيّ إطار، ولا NumPy.

## ما لن يُشرَح فيه

`async`/`await` وحلقةُ الأحداث — السؤال يملكه [`who-waits`](../../systems/who-waits/README.md)،
ويقف هذا المنهج عند حدّ الإقليم `15`: ما الذي يمنعه القفل، ولماذا الانتظار غير
الحساب. وكذلك الحزم والتوزيع، ونظامُ الأنواع بذاته، والتعلّمُ الآليّ.

## كيف يُدرَس

**الإقليم `00` نظريٌّ وحده، ثم يُبنى الـepitome.** جدولٌ عموديٌّ صغير في حدود مئة
سطر تكتبه بيدك، ويعدّله كلُّ إقليمٍ بعده أو يمدّه: يستجيب للبروتوكولات، ثم يُقاس
بطؤه، ثم يُستبدَل تخزينه، ثم تنتقل حلقتُه إلى C.

ولا حلول في المنهج. ولكل لغزٍ **مَخرجٌ تفتحه بيدك** حين تقف، وليس قبل.

**والأرقام تُقاس عندك.** كلُّ لوحةِ زمنٍ هنا من جهازٍ واحد، **والثابت هو النسبة**
لا القيمة.

## الطريق

**ثمانيةٌ وعشرون إقليماً في خمس حِزَم.**

| | | |
|---|---|---|
| | `00` | **لا شيء يُحسَم قبل التشغيل** — الضغوط الأربعة، والبديهيات الخمس، ونظام الأنواع |
| **الاسم والكائن** | `01`–`04` | الجدول (الـepitome) · الرِّباط · التغيّر · الهوية والعدّاد |
| **النموذج** | `05`–`10` | الكائن من الداخل · البروتوكولات · بحث الطريقة · الدالّة كائناً · المولّدات · الاستثناءات |
| **المفسّر** | `11`–`15` | البايت-كود · الإطار · الاستيراد · الذاكرة · القفل |
| **المصفوفة** | `16`–`21` | لماذا `list` ليست مصفوفة · `ndarray` · الـview · البثّ · الـufunc · الكلفة تُقاس |
| **الحدّ مع C** | `22`–`27` | البروتوكول العازل · `cffi` · مِلكية الذاكرة · إطلاق القفل · كتابة Python · الختام |

**والـepitome يمرّ بالحزم الخمس:** جدولٌ عموديٌّ تبنيه في `01`، فيصير بروتوكولات
في الثانية، ويُقاس بطؤه في الثالثة، ويقفز ×١٢٣ في الرابعة، وتنتقل حلقته إلى C في
الخامسة.

**ومعه ملحقان:** [`appendix/keywords.md`](appendix/keywords.md) سجلُّ تغطية كلّ
كلمةٍ محجوزةٍ في اللغة — ومواضعُه **يفحصها `verify.py`** —
و[`appendix/models.md`](appendix/models.md) النماذج والأرقام المقيسة كلُّها في
ورقةٍ واحدة.

## أدواته

```
python3.14                 # الإصدار مثبَّت، والسلوك يتغيّر بين إصدارات CPython
cc -std=c17 -shared -fPIC  # الطرف الآخر من الحدّ
numpy · cffi               # الحزمتان الرابعة والخامسة
dis · sys · gc · tracemalloc · timeit
```

**البيئة تُبنى مرّةً:**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install numpy cffi
```

**ونواةُ C تُبنى وحدها:** `verify.py` يترجم `programs/ffi/kernel.c` إن غابت
المكتبة أو تقادمت، فلا خطوةَ بناءٍ منفصلة.

**والفحص:** `python3 tools/verify.py` يشغّل كلَّ برنامجٍ في `programs/` ويقارن
مخرَجه بلوحته في الماركداون، ويعدّ ما لم يُفحَص فيظهر الثقب في التقرير.

**وأربع سلطاتٍ تُعلَن مع اللوحة:** `@lang` تضمنه اللغة · `@cpython` تفصيلُ تطبيقٍ
لا لغة · `@version` يتغيّر بين الإصدارات · `@machine` رقمٌ نسبتُه هي الثابتة.
