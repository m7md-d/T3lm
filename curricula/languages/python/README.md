# Python — الكائن والمفسّر والحدّ مع C

## لمن كُتب

**لمن كتب سكربتات Python صغيرة تعمل، ويعرف C.** الساينتاكس مفهوم، والبرنامج
يشتغل، وما تحت السطر مجهول: أين تعيش القيمة، ومن يملكها، ومتى تموت، ولماذا تبطئ
حلقةٌ بسيطة.

والأسئلة التي يجيب عنها:

- لماذا يظهر تعديلٌ على قائمةٍ في اسمٍ آخر لم تلمسه؟
- لماذا يشغل العدد `1` ثمانيةً وعشرين بايتاً؟
- لماذا لا يسرّع خيطان حساباً واحداً؟
- ما الذي تفعله NumPy ولا تفعله `list`؟
- وكيف تنادي دالّة C من Python بلا أن تخسر ذاكرةً أو تعطّل المفسّر؟

## ما يفترضه فيك

- **C بمستوى العمل**: المؤشّر، والمصفوفة، والذاكرة، والترجمة والربط. منهج
  [`languages/c`](../c/README.md) يكفي.
- **Python بمستوى السكربت**: تعرف `def` و`if` و`for` والقوائم والقواميس.

**ولا يفترض:** خبرةً بـNumPy، ولا بامتدادات C، ولا بداخليات المفسّر.

## ما لن يُشرَح فيه

**`async` وحلقة الأحداث** موضوعٌ آخر، ويقف المنهج عند حدّ القفل في الفصل `16`.
**وأطر الويب وعلوم البيانات** خارجه. **والأدوات** — `pip` و`venv` والتغليف —
تُذكَر عند الحاجة ولا تُشرَح فصلاً.

## كيف يُدرَس

**الفصل `00` يعطي المفردات في أقلّ من ألف كلمة، ثم يبدأ البناء.** الفصل `01`
يبني جدولاً بأعمدة في ستّةٍ وعشرين سطراً، وكل فصلٍ بعده يعدّله أو يمدّه: يُصلَح
اشتقاقُه في `03`، ويستجيب للبروتوكولات في `06`، ويُقاس بطؤه في `21`، ويُستبدَل
تخزينه في `18`، وتنتقل حلقتُه إلى C في `23`.

ولا حلول في المنهج، ولا تلميحاتٍ مفروضة.

**ومعه ملحقان:** [`appendix/keywords.md`](appendix/keywords.md) سجلُّ الكلمات
المحجوزة وأين تظهر كلٌّ منها — **ومواضعُه يفحصها `verify.py`** —
و[`appendix/models.md`](appendix/models.md) قرارات اللغة والأرقام المقيسة وأين
يُحسَم كلُّ شيء، في ورقةٍ واحدة.

**وكل مخرَجٍ معروضٍ منقولٌ من تشغيلٍ فعليّ** على Python 3.14.7، ويفحصه
`tools/verify.py` كتلةً كتلة. والأرقام الزمنية من جهازٍ واحد، والثابت هو النسبة.

## الطريق

ثمانيةٌ وعشرون فصلاً في خمس حزم.

| | | |
|---|---|---|
| **الافتتاح** | `00` | المفردات — خمس كلمات، وقرارات اللغة، والطريق |
| **الكائن** | `01`–`05` | الاسم والكائن · داخل الكائن · التغيّر والهوية · القاموس · النطاق |
| **النموذج** | `06`–`11` | البروتوكولات · الصنف · بحث الطريقة · الدالّة · المولّدات · الاستثناءات |
| **المفسّر** | `12`–`16` | البايت-كود · الإطار · الاستيراد · الذاكرة · القفل |
| **المصفوفة** | `17`–`21` | حدود `list` · `ndarray` · الـview · البثّ · الكلفة |
| **الحدّ مع C** | `22`–`27` | البروتوكول العازل · `cffi` · الملكية · إطلاق القفل · الاصطلاح · الختام |

## أدواته

```
python3 3.14.7          المفسّر المستهدَف، وكل مخرَجٍ منقولٌ منه
numpy 2.5.2             الحزمة الرابعة
cffi 2.1.1              الحزمة الخامسة
cc -std=c17             دالّة C التي تناديها في `23`
```

**البيئة تُبنى مرّةً:**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install numpy cffi
```

**والفحص:**

```bash
.venv/bin/python tools/verify.py
```

يشغّل كل برنامجٍ في `programs/` ويقارن مخرَجه بالمعروض في الماركداون، ويعدّ ما لم
يُفحَص فيظهر الثقب في التقرير.

**وأربعة وسومٍ تُعلَن مع المخرَج**، وهي تصنيف المنهج لمن يضمن ما تقرأ:

| الوسم | معناه |
|---|---|
| المخرَج | حتميّ — تعطيه اللغة نفسها في أي تشغيل |
| يختلف بين تشغيلين | عنوانٌ أو زمن. النسبة هي الثابت، والقيمة لا |
| رفضٌ من الأداة | رسالة المفسّر بنصّها |
| صدفة | مخرَجُ أمرٍ في الطرفية |
