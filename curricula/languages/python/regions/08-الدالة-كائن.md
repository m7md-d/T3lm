# الإقليم ٠٨ — الدالّة كائن

> رأيتَ في الإقليم السابق أن الطريقة دالّةٌ فيها `__get__`. وهذا يفترض شيئاً لم
> يُقَل صراحةً بعد: **الدالّة كائنٌ كامل**، له صفاتٌ تُقرأ وتُكتَب، ويُمرَّر
> ويُعاد ويُخزَّن.
>
> وفي C أقرب ما عندك مؤشّرُ دالّة: عنوانٌ لا يحمل شيئاً معه. الفرق بينهما هو هذا
> الإقليم.

## ما تحمله الدالّة

<!-- part: 08-function-object -->

```python
def f(a, b=2):
    return a + b


f.note = "دالّةٌ تحمل صفة"
print(f.note)
print(f.__name__, f.__defaults__, f.__code__.co_varnames)
print(f.__code__.co_argcount, f.__code__.co_consts)

g = f
del f
print(g(1), g.__name__)
```

<!-- out -->

```
دالّةٌ تحمل صفة
f (2,) ('a', 'b')
2 (None,)
3 f
```

**ثلاثة أشياء يستحيل نظيرها في C:**

أضفتَ صفةً إلى الدالّة — لأنها كائنٌ له `__dict__` كغيره (الإقليم `05`).

وقرأتَ داخلها: `__defaults__` فيها القيمة الافتراضية **ككائنٍ محفوظ** (وهذه هي
مصيدة الإقليم `00`)، و`__code__` فيها أسماء المتغيّرات والثوابت.

وحذفتَ الاسم `f` فبقيت الدالّة حيّةً على الاسم `g`. لأن `def` **ربطٌ** لا إعلان:
تبني كائن دالّةٍ ثم تربطه باسم، تماماً كما تفعل `=`.

ولاحظ أن `g.__name__` بقي `"f"` — الاسم في الكائن شيء، والاسم المربوط شيءٌ آخر.

## الـdecorator ليس ميزة

<!-- part: 08-decorator-desugar -->

```python
@loud
def add(x, y):
    return x + y


def sub(x, y):
    return x - y


sub = loud(sub)
```

<!-- out -->

```
  نداء add
5
  نداء sub
2
الاسم بعد التغليف: wrapper wrapper
```

النصفان متطابقان في الأثر. `@loud` **سكرٌ حرفيّ** لـ`add = loud(add)` يقع بعد
تعريف الدالّة مباشرةً.

وهذا يفسّر ما يحيّر: لماذا يعمل الـdecorator وقت الاستيراد لا وقت النداء (البديهية
الرابعة)، ولماذا يستطيع أن يعيد أي شيء — دالّةً أخرى، أو صنفاً، أو عدداً.

**والسطر الأخير هو الثمن:** الاسم صار `wrapper` في الحالتين. الدالّة الأصلية ما
زالت حيّةً داخل الـclosure، لكن كلَّ ما يقرأ `__name__` أو `__doc__` أو التوقيع
يرى الغلاف.

<!-- part: 08-wraps -->

```python
def kept(fn):
    @functools.wraps(fn)
    def wrapper(*a, **k):
        return fn(*a, **k)

    return wrapper
```

<!-- out -->

```
wrapper None
two 'ثانٍ'
الأصل محفوظ: two
```

`functools.wraps` ليست سحراً: تنسخ `__name__` و`__doc__` وأخواتها من المغلَّف إلى
الغلاف، وتترك `__wrapped__` مؤشّراً إلى الأصل. **صفاتٌ تُنسَخ في كائن**، ولا شيء
غير ذلك.

## التمرين

**اكتب decorator اسمه `counted` يعدّ كم مرّة نوديت الدالّة**، ويعرض العدّاد على
الدالّة المغلَّفة نفسها:

<!-- task -->

```python
@counted
def total(...): ...


total(...)
total(...)
print(total.calls)   # 2
```

**والقيد:** لا تستعمل متغيّراً عالمياً، ولا قاموساً خارج الدالّة. القيمة تسكن حيث
يجب أن تسكن — والإقليم `02` قال لك أين.

**ثم ضعه على `Table.total` وقِس:** كم يكلّفك العدّاد في المئة؟ إن لم تستطع قياسه
فقد اخترتَ المكان الصحيح.

## الخلاصة

الدالّة كائنٌ يحمل كوده وافتراضيّاته وخلاياه وصفاتِه، و`def` تبنيه وتربطه باسم.
و`@` سكرٌ لنداءٍ يقع مرّةً عند التعريف.

وبقي نوعٌ من الدوالّ لم نلمسه: التي لا تنتهي حين تعيد.
