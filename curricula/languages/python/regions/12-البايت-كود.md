# ١٢ — البايت-كود

الفصل `00` قال إن الملفّ يُنفَّذ بلا خطوة ترجمةٍ تراها. الخطوة موجودة، وأنت لا
تراها — وهذا الفصل يفتحها.

---

## ما يترجم إليه السطر

المفسّر يقرأ ملفَّك ويبني منه كائن كود فيه تعليماتٌ لآلةٍ افتراضية ذاتِ
مكدّس. ثم ينفّذ التعليمات واحدةً واحدة.

و`dis` تعرضها.

**مثال**

<!-- part: 12-dis -->

```python
import dis

from table import total

dis.dis(total)
```

**المخرَج**

<!-- out -->

```
 22           RESUME                   0

 23           LOAD_SMALL_INT           0
              STORE_FAST               1 (result)

 24           LOAD_FAST_BORROW         0 (values)
              GET_ITER
      L1:     FOR_ITER                11 (to L2)
              STORE_FAST               2 (value)

 25           LOAD_FAST_BORROW_LOAD_FAST_BORROW 18 (result, value)
              BINARY_OP               13 (+=)
              STORE_FAST               1 (result)
              JUMP_BACKWARD           13 (to L1)

 24   L2:     END_FOR
              POP_ITER

 26           LOAD_FAST_BORROW         1 (result)
              RETURN_VALUE
```

العمود الأول رقم السطر في `programs/table.py`. و`total` كلُّها ثلاثة عشر
تعليمة.

**واقرأ السطر `25`:** `result += value` صار تحميلَ الاثنين، ثم `BINARY_OP`، ثم
`STORE_FAST`. ثلاثُ تعليماتٍ لعمليةٍ تكتبها في حرفين.

**و`STORE_FAST`/`LOAD_FAST` هما ما رأيتَه في الفصل `05`:** الاسم المحلّيّ فهرسٌ
في مصفوفة — الرقم `1` هو موضع `result`. ولهذا حُسم محلّياً وقتَ الترجمة: الفهرس
يحتاج أن يُعرَف قبل التنفيذ.

**المكسب:** «Python بطيئة» ليست جملةً عن اللغة بل عن هذا العدد. كل تعليمةٍ هنا
دورةٌ في حلقة المفسّر، والحزمة الرابعة كلُّها عن إخراج الحلقة من هذه الآلة.

---

## أين تسكن الأسماء يظهر في التعليمة

الفصل `05` قال إن القراءة تصعد السلّم. والبايت-كود يقول إن السلّم **تعليماتٌ
مختلفة** لا بحثٌ واحد.

**مثال**

<!-- part: 12-names -->

```python
def uses_global(values):
    out = 0
    for v in values:
        if v < LIMIT:
            out += 1
    return out


def uses_local(values):
    limit = LIMIT
    out = 0
    for v in values:
        if v < limit:
            out += 1
    return out
```

**المخرَج**

<!-- runs: 12-names -->

```
uses_global    17.8 ms   داخل الحلقة: ['LOAD_FAST_BORROW', 'LOAD_GLOBAL']
uses_local     14.3 ms   داخل الحلقة: ['LOAD_FAST_BORROW_LOAD_FAST_BORROW']
```

الأرقام من جهازٍ واحد، والثابت هو النسبة.

**داخل الحلقة تعليمتان مختلفتان:** `LOAD_GLOBAL` بحثٌ في قاموس الوحدة ثم في
المدمجات، و`LOAD_FAST_BORROW` فهرسةُ مصفوفة. والثانية دمجت تحميلين في تعليمةٍ
واحدة.

**المكسب:** `limit = LIMIT` سطرٌ واحد قبل الحلقة نقل البحث من القاموس إلى
المصفوفة. وهذا هو أصل الاصطلاح الذي تراه في الكود الساخن، وسببُه في التعليمة لا
في الذوق.

## الحالات

### ما يُحسَم قبل التشغيل

بعض الحساب يقع وقت الترجمة.

<!-- part: 12-const -->

```python
def folded():
    return 60 * 60 * 24
```

<!-- out -->

```
(60, 86400)
  4           RESUME                   0

  5           LOAD_CONST               1 (86400)
              RETURN_VALUE
```

`86400` صار ثابتاً في `co_consts`، والضربتان اختفتا. وهذا هو **ما حُسم قبل
التشغيل** في لغةٍ قيل عنها إنها لا تحسم شيئاً: ثوابتُ العمليات على قيمٍ معروفة.

والحدُّ ضيّق: يقع على الأعداد والنصوص الحرفية، ولا يعبر إلى الأسماء لأن قيمتها
غير معروفةٍ وقت الترجمة.

### الملفّ المترجَم يُخزَّن

<!-- part: 12-cache -->

```python
src = pathlib.Path("programs/pkg/once.py")
cached = pathlib.Path(importlib.util.cache_from_source(str(src)))

py_compile.compile(str(src), doraise=True)

print("المصدر :", src.stat().st_size, "بايتاً")
print("المترجَم:", cached.stat().st_size, "بايتاً")
print("المسار  :", os.path.relpath(cached))
print("أحدثُ من المصدر:", cached.stat().st_mtime >= src.stat().st_mtime)
```

<!-- out -->

```
المصدر : 44 بايتاً
المترجَم: 192 بايتاً
المسار  : programs/pkg/__pycache__/once.cpython-314.pyc
أحدثُ من المصدر: True
```

المفسّر يكتب البايت-كود في `__pycache__` باسمٍ فيه رقم الإصدار، ويقرؤه في التشغيل
التالي إن لم يتغيّر المصدر. فخطوةُ الترجمة تحدث عند كل تعديل، وتُتخطّى في
التشغيلات التي بينها — وهذا ما يجعلها غير مرئية.

**والملفّ المترجَم أكبر من المصدر هنا** (١٩٢ مقابل ٤٤): البايت-كود يحمل الترويسة
والثوابت وجدول الأسطر معاً.
