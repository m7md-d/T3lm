# ٢٥ — إطلاق القفل

الفصل `16` قاس أن خيطين على حسابٍ واحدٍ لا يسرّعانه. والفصل `00` قال إن القفل
وُجد ليحمي عدّاد المراجع. هنا يجتمع الأمران.

---

## القفل يخصّ المفسّر، لا المعالج

الخيط يحمل القفل حين ينفّذ بايت-كود. ودالّةُ C التي لا تلمس كائناً واحداً من
Python **لا تحتاجه**، فيُطلَق أثناء عملها ويُستعاد بعده.

و`cffi` في وضع ABI يفعل ذلك افتراضياً.

**توقّع** قبل أن تقرأ: نفس الحساب، مرّةً بحلقة Python ومرّةً بحلقة C. ما نسبةُ
كلٍّ منهما على خيطين؟

<!-- part: 25-gil -->

```python
ffi.cdef("long long px_burn(long long n);")
lib = ffi.dlopen(str(pathlib.Path("programs/ffi/libkernel.dylib")))


def c_burn():
    lib.px_burn(N)


def py_burn():
    x = 0
    for _ in range(4_000_000):
        x += 1


for name, fn in (("حلقةُ Python", py_burn), ("حلقةُ C عبر cffi", c_burn)):
    one = measure(fn, 1)
    two = measure(fn, 2)
    print(f"{name:20} خيطٌ {one * 1000:7.1f} ms · خيطان {two * 1000:7.1f} ms   ×{2 * one / two:.2f}")
```

المخرَج:

<!-- runs: 25-gil -->

```
حلقةُ Python         خيطٌ    64.1 ms · خيطان   129.2 ms   ×0.99
حلقةُ C عبر cffi     خيطٌ   212.3 ms · خيطان   225.9 ms   ×1.88
```

الأرقام من جهازٍ واحد، والثابت هو النسبة.

**السطر الأول:** خيطان أخذا ضعفَ زمن الواحد. الكفاءة ×٠٫٩٩ — لا توازي.

**والسطر الثاني:** خيطان أخذا نفس زمن الواحد تقريباً. الكفاءة ×١٫٨٨ على نواتين.

**والفرق سطرٌ واحدٌ في `kernel.c`:** الحلقة لا تلمس كائن Python، فلا تحتاج القفل.

**المكسب:** هذا يغيّر معمار البرنامج. الحساب الثقيل في C يتوازى بخيوط Python
العادية — بلا `multiprocessing`، وبلا نسخِ بياناتٍ بين العمليات، وبلا تسلسل.

---

## الشرط الذي يجعله صحيحاً

**دالّة C التي تطلق القفل يجب ألّا تلمس شيئاً من Python:** لا `PyObject`، ولا
تخصيصاً بمخصّص Python، ولا نداءَ رجوعٍ إلى دالّة Python.

فإن لمست، فسادُ عدّاد المراجع من خيطين نتيجةٌ محتملة — وهو خطأٌ لا يظهر إلا تحت
حِمل، وينهار في موضعٍ لا علاقة له بالسبب.

**والمخزن نفسه آمن:** الفصل `22` قال إن `memoryview` تمنع نقل المخزن ما دامت
حيّة، والفصل `24` قال كيف يبقى الكائن ممسوكاً. فالبايتات ثابتةٌ أثناء النداء.

**وثلاثة حدودٍ عملية:**

`nd.sum()` على مصفوفةٍ كبيرة تطلق القفل، فخيطان على مصفوفتين يتوازيان. وعلى
الصغيرة لا تطلقه — كلفةُ الإطلاق والاستعادة أكبر من العمل، كما قاس الفصل `21`
على كلفة العبور.

**ووضع API يحتاج وسماً صريحاً** على الدالّة كي يطلق الغلافُ القفل. ونسيانُه يعني
نداءً يحمل القفل بلا حاجة، ويعمل صحيحاً ولا يتوازى.

**والحدُّ الأعلى عددُ النوى.** `×١٫٨٨` على نواتين، وثمانيةُ خيوطٍ على أربع نوًى
تعطي `×٤` بحدٍّ أقصى، ثم يصير التبديل بينها كلفةً صافية.
