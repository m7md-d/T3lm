# الإقليم ٢٣ — `cffi`

> عندك بايتاتٌ موصوفة، وعندك حلقةٌ تريد كتابتها بـC. بقي الجسر.
>
> و`cffi` تبنيه بسطرين: **تُعلن التوقيع نصّاً**، وتفتح المكتبة. ولأن التوقيع نصٌّ
> يُقرأ، يبقى العقد ظاهراً في كودك بدل أن يختفي في غلاف.

## الحلقة بـC

```c
long long col_sum(const long long *v, long n) {
    long long s = 0;
    for (long i = 0; i < n; i++) s += v[i];
    return s;
}

void group_sum(const long long *key, const long long *val, long n,
               long long *out, long k) {
    for (long i = 0; i < n; i++) {
        long g = (long)key[i];
        if (g >= 0 && g < k) out[g] += val[i];
    }
}
```

`group_sum` هي ما وعدتُك به في الإقليم `21`: **تجميعٌ بمفاتيح** لا تملك NumPy له
عمليةً متّجهةً مباشرة، فكان يعود بك إلى حلقة المفسّر.

## الجسر

<!-- part: 23-cffi -->

```python
ffi = FFI()
ffi.cdef("""
    long long col_sum(const long long *v, long n);
    void group_sum(const long long *key, const long long *val, long n,
                   long long *out, long k);
""")
lib = ffi.dlopen("programs/ffi/libkernel.dylib")

a = np.arange(1, 6, dtype=np.int64)
p = ffi.cast("const long long *", a.ctypes.data)
print("col_sum:", lib.col_sum(p, len(a)))
```

<!-- out -->

```
col_sum: 15
group_sum: [40 70 40]
```

**ثلاث خطوات لا أكثر:** `cdef` تُعلن ما في المكتبة بنحو C نفسه، و`dlopen` تفتحها،
و`cast` تحوّل عنوان بايتات المصفوفة إلى مؤشّرٍ من النوع المُعلَن.

و`out` مصفوفةُ NumPy مرّرناها **للكتابة**: دالّة C كتبت فيها مباشرةً، وقرأناها في
Python بلا نسخة. وهذا هو نمط العمل كلُّه — Python تملك الذاكرة، وC تعمل فيها.

## ما تفحصه cffi وما لا تفحصه

`cdef` تجعل الأنواع مُعلَنة، فتُمسَك أخطاءُ عددِ الوسائط وأنواعها **عند النداء**.

**ولا تفحص شيئاً عن الطول.** لو مرّرتَ `n` أكبر من طول المصفوفة الحقيقيّ لقرأت C
خارج الحدود — بلا رسالة، وبلا استثناء، وربما بلا انهيار. **هذا هو الحدّ الذي
تعبره:** خلفه لا يوجد فحصُ حدودٍ ولا استثناءات، وسلوك C غير المعرَّف يعود سلوكاً
غير معرَّف.

**والقاعدة التي تحميك:** الغلاف الذي تكتبه بـPython هو موضع الفحص. اجعله يأخذ
الطول من المصفوفة نفسها، ولا يقبله وسيطاً من المستعمل.

## التمرين

**اكتب `Table.group_total(key_col, val_col)` غلافاً حول `group_sum`.**

**والقيد:** الغلاف مسؤولٌ عن كلّ ما لا تفحصه C — تطابقُ الأطوال، والـ`dtype`،
والتجاور، ومدى المفاتيح. **اكتب لكلٍّ منها اختباراً يفشل قبل أن تصلح الغلاف.**

**ثم:** قارن نتيجتك بمرجعٍ بطيءٍ مكتوبٍ بـPython على مئة صفّ. المرجعُ البطيء ليس
إسرافاً؛ هو الشيء الوحيد الذي يكشف خطأً في حلقة C.

## الخلاصة

`cffi` تُعلن التوقيع نصّاً وتفتح المكتبة، والمصفوفة تُمرَّر عنواناً بلا نسخة —
للقراءة وللكتابة.

وما وراء الحدّ لا فحصَ فيه: الغلاف بـPython هو موضع كلّ شرطٍ يجب أن يُتحقَّق.
