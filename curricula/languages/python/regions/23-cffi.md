## ثلاث خطوات

**١) مكتبةٌ مشتركة.** تُترجَم بـ`cc` كأي مكتبةٍ أخرى:

<!-- shell -->

```
cc -O2 -std=c17 -shared -fPIC -o libkernel.dylib kernel.c
```

**٢) تصريحٌ بالتوقيعات.** `cffi` يقرأ تصريحاً بلغة C — نفس السطور من ملفّ
الترويسة:

<!-- head: ffi/kernel.c -->

```c
long long px_total(const long long *values, size_t n) {
void px_double(long long *values, size_t n) {
```

**٣) نداء.**

**مثال**

<!-- part: 23-cffi -->

```python
ffi = FFI()
ffi.cdef("""
long long px_total(const long long *values, size_t n);
void px_double(long long *values, size_t n);
""")
lib = ffi.dlopen(str(LIB))

a = np.arange(1_000_000, dtype=np.int64)

ptr = ffi.cast("long long *", ffi.from_buffer(a))
print("px_total :", lib.px_total(ptr, a.size))
print("nd.sum() :", int(a.sum()))

lib.px_double(ptr, a.size)
print("بعد px_double، أوّل خمسة:", a[:5])
```

**المخرَج**

<!-- out -->

```
px_total : 499999500000
nd.sum() : 499999500000
بعد px_double، أوّل خمسة: [0 2 4 6 8]
```

**السطران الأوّلان متساويان:** دالّةُ C قرأت بايتات NumPy نفسها.

**والسطر الأخير هو المهمّ:** `px_double` كتبت في مصفوفة Python. لم يُنسَخ شيء في
أي اتجاه، و`a` تغيّرت في مكانها.

**و`ffi.from_buffer(a)`** هي الوصلة: تأخذ الكائن العارض للمخزن وتعطي عنوانه.
و`ffi.cast` تعطي المؤشّر نوعَه.

**المكسب:** ثلاثةُ أسطرٍ بين مصفوفة Python ودالّة C، بلا كودٍ وسيطٍ يُكتَب وبلا
`Python.h`. وهذا وضعُ ABI: تعرّف التوقيعة، ويربط النظامُ الرمز عند التشغيل.

---

## وضعان، والفرق في من يترجم

| | ABI (`dlopen`) | API (`set_source`) |
|---|---|---|
| ما يُترجَم | مكتبتُك بـ`cc` | مكتبتُك + غلافٌ يولّده cffi |
| متى | قبل التشغيل، بيدك | عند البناء، ويحتاج `setuptools` |
| فحصُ التوقيعة | لا — تصريحك يُصدَّق | نعم، يقرأ ترويستك ويفشل عند الاختلاف |
| ماكرو أو `struct` معقّد | يُكتَب بيدك | يُقرأ من الترويسة |

**والفصل يستعمل ABI** لأن الترجمة تبقى مرئيةً بأمرٍ واحدٍ تقرؤه.

**والثمن معلوم:** تصريحٌ خاطئ لا يُكتشَف. لو قلتَ `int` حيث الدالّة `long long`،
قُرئت أربعةُ بايتاتٍ من ثمانية بلا رسالة — والنتيجة قيمةٌ خاطئةٌ صامتة.

**و`size_t` من هذا الباب:** ثمانيةُ بايتاتٍ على هدفٍ ٦٤-بت وأربعةٌ على ٣٢-بت،
و`cffi` يقرأ العرض من المنصّة. فالتصريح يجب أن يقول `size_t` لا `int`، والفرق
لا يظهر على جهازك ويظهر على غيره.

## الحالات

### المصفوفة يجب أن تبقى حيّةً أثناء النداء

`ptr` عنوانٌ خامّ لا يحمل إشارةً إلى `a`. فلو حُرِّرت `a` بقي `ptr` يشير إلى
ذاكرةٍ محرَّرة.

وهذا هو الفصل `15` في أخطر موضعٍ له: عدّاد المراجع لا يعرف بمؤشّرات C. والقاعدة
أن يبقى اسمٌ حياً على المصفوفة طولَ عمر المؤشّر، وهي القاعدة التي يفصّلها الفصل
التالي.
