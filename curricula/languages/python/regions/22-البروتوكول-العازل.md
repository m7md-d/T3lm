## `memoryview` عقدٌ على البايتات

البروتوكول العازل (buffer protocol) يجعل كائناً يعرض مخزنه الخامّ: عنوانَه،
وطولَه، ونوعَ عنصره، وهل يقبل الكتابة. و`memoryview` هي الواجهة التي تراها من
Python.

**مثال**

<!-- part: 22-memoryview -->

```python
buf = bytearray(b"0123456789")
mv = memoryview(buf)

print("format:", mv.format, "| itemsize:", mv.itemsize, "| nbytes:", mv.nbytes)
print("شريحة :", bytes(mv[2:6]))

mv[2:6] = b"ABCD"
print("بعد الكتابة في الشريحة:", buf)

arr = array.array("q", [1, 2, 3])
nd = np.arange(3, dtype=np.int64)

for name, obj in (("array('q')", arr), ("ndarray", nd), ("bytes", b"abc")):
    m = memoryview(obj)
    print(f"{name:12} format={m.format:>3} itemsize={m.itemsize} readonly={m.readonly}")
```

**المخرَج**

<!-- out -->

```
format: B | itemsize: 1 | nbytes: 10
شريحة : b'2345'
بعد الكتابة في الشريحة: bytearray(b'01ABCD6789')
array('q')   format=  q itemsize=8 readonly=False
ndarray      format=  l itemsize=8 readonly=False
bytes        format=  B itemsize=1 readonly=True
```

**والكتابة في الشريحة ظهرت في `buf`:** الشريحة view كما في الفصل `19`، والقاعدة
نفسها تسري على كل ما يعرض مخزنه.

**والجدول الأخير هو العقد:** ثلاثة أنواعٍ مختلفةٍ تعرض المخزن نفسه بأوصافٍ
موحّدة. و`bytes` وحدها `readonly=True` لأنها لا تقبل التعديل — والفصل `03`.

**المكسب:** دالّةٌ تكتب `memoryview(x)` تعمل مع `bytes` و`bytearray` و`array`
و`ndarray` وكل ما يتبع البروتوكول، بلا `isinstance` وبلا نسخ.

---

## بلا نسخ يعني بلا زمن

**مثال**

<!-- part: 22-nocopy -->

```python
N = 20_000_000
a = np.arange(N, dtype=np.int64)

timed("memoryview(a)", lambda: memoryview(a))
timed("a.tobytes()", lambda: a.tobytes())
timed("list(a)", lambda: list(a[: N // 20]))
```

**المخرَج**

<!-- runs: 22-nocopy -->

```
memoryview(a)                  0.0 ms   20000000
a.tobytes()                   16.4 ms   160000000
list(a)                       18.2 ms   1000000
```

`memoryview` بلا زمنٍ يُقاس: تبني وصفاً ولا تلمس بايتاً.

و`tobytes()` تنسخ ١٦٠ ميغابايتاً. و`list()` على **جزءٍ من عشرين** أخذت وقتاً
أطول، لأنها تبني مليون كائنِ `int` — وهو ثمن الكائنات الذي قاسه الفصل `21`.

**المكسب:** الطريق إلى C يجب أن يمرّ بـ`memoryview`. وكل `tobytes()` في مسارٍ
ساخنٍ نسخةٌ يمكن حذفها.

## الحالات

### التجاور يُفحَص، والحجم يُقفَل

<!-- part: 22-contig -->

```python
a = np.arange(10, dtype=np.int64)
step = a[::2]

print("a       : c_contiguous =", memoryview(a).c_contiguous)
print("a[::2]  : c_contiguous =", memoryview(step).c_contiguous, "| strides =", step.strides)

fixed = np.ascontiguousarray(step)
print("بعد ascontiguousarray:", memoryview(fixed).c_contiguous, "| نُسخت؟", fixed.base is None)

buf = bytearray(b"abc")
mv = memoryview(buf)
buf.append(100)
```

<!-- err: BufferError -->

```
a       : c_contiguous = True
a[::2]  : c_contiguous = False | strides = (16,)
بعد ascontiguousarray: True | نُسخت؟ True
BufferError: Existing exports of data: object cannot be re-sized
```

**السطر الثاني:** `a[::2]` معروضةٌ صحيحةً وليست متجاورة. ودالّةُ C التي تتوقّع
بايتاتٍ متجاورةً ستقرأ خطأً إن لم يُفحَص `c_contiguous`.

**والعلاج `np.ascontiguousarray`** — تنسخ إن احتاجت (`base is None` هنا) ولا
تنسخ إن كانت متجاورةً أصلاً.

**والسطر الأخير:** `bytearray` رفضت التمديد ما دام `memoryview` عليها حيّاً. لأن
التمديد قد يعيد التخصيص فينقل العنوان، وللـview عنوانٌ محفوظ.

وهذا العقد نفسه ما يحمي دالّة C من أن يُنقَل المخزن تحتها أثناء عملها.
