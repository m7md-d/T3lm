# الإقليم ١٣ — الاستيراد

> `import` ليست تعليمةً للمترجم كـ`#include`. **هي تنفيذُ ملفٍّ كاملٍ وربطُ اسم.**
>
> ومن هذه الجملة الواحدة يتساقط كلُّ ما يحيّر في الحزم والاستيراد الدائريّ وحالة
> الوحدة.

## يُنفَّذ مرّةً، ويُربَط كثيراً

<!-- part: 13-import-once -->

```python
print("قبل الاستيراد:", "pkg.once" in sys.modules)
import pkg.once
import pkg.once
from pkg import once

print("بعد ثلاث مرّات:", "pkg.once" in sys.modules)
print("الكائن نفسه:", sys.modules["pkg.once"] is once)
```

<!-- out -->

```
قبل الاستيراد: False
  once يُنفَّذ
بعد ثلاث مرّات: True
الكائن نفسه: True
```

ثلاثُ استيراداتٍ وتنفيذٌ واحد. لأن `import` تفعل شيئين: **إن لم تكن الوحدة في
`sys.modules` فنفّذ ملفّها وضع الناتج هناك**، ثم اربط الاسم.

**والوحدة كائن**، وقاموسُه هو الفضاء الاسميّ العالميّ لذلك الملفّ. فحين تكتب
`once.VALUE` أنت تقرأ صفةً من كائن (الإقليم `05`)، لا شيء آخر.

**وهذا يفسّر ثلاثة أشياء دفعةً واحدة:** لماذا الكود في مستوى الوحدة يعمل مرّةً
مهما استوردتَها، ولماذا تغييرُ متغيّرٍ في وحدةٍ يراه الجميع، ولماذا لا يُعاد
التحميل بمجرّد إعادة الاستيراد.

## الدائريّ

<!-- part: 13-circular -->

```python
# pkg/alpha.py
from pkg import beta

NAME = "alpha"

# pkg/beta.py
from pkg.alpha import NAME

USES = NAME
```

<!-- out -->

```
  alpha يُنفَّذ
  beta يُنفَّذ
  ImportError: cannot import name 'NAME' from partially initialized module 'pkg.alpha' (most likely due to a circular import) (programs/pkg/alpha.py)
بقي في sys.modules: ['pkg']
  alpha يُنفَّذ
  beta يُنفَّذ
والمحاولة الثانية أعادت التنفيذ من الصفر، وفشلت كذلك
```

**اقرأ الرسالة بدقّة: «وحدةٌ مهيّأةٌ جزئياً».**

بدأ تنفيذ `alpha`، فوصل إلى سطر الاستيراد قبل أن يصل إلى `NAME = "alpha"`. فذهب
ينفّذ `beta`، فطلبت `NAME` من `alpha` — **وهي موجودةٌ في `sys.modules` لكن سطرها
لم يُنفَّذ بعد.**

فالمشكلة ليست «حلقةً في الاعتماد» بمعناها الساكن. هي **ترتيبُ تنفيذٍ**: طُلب اسمٌ
قبل أن يُربَط. ولهذا يعمل الاستيراد الدائريّ أحياناً ويفشل أحياناً بحسب موضع
السطر — وهو أسوأ أنواع الأعطاب.

**والسطران الأخيران يكملان الصورة:** بعد الفشل بقي `pkg` وحده في `sys.modules`،
وأُزيلت الوحدتان الناقصتان. فالمحاولة الثانية **نفّذت الملفّين من جديد** — القاعدة
«يُنفَّذ مرّةً» تخصّ الاستيراد **الناجح** وحده.

**والعلاج مشتقٌّ من التشخيص:** إمّا أن تنقل الاستيراد إلى داخل الدالّة فيقع وقت
النداء لا وقت التحميل، وإمّا أن تستورد الوحدة نفسها (`from pkg import alpha`) ثم
تقرأ `alpha.NAME` عند الاستعمال — فتؤجّل قراءةَ الصفة.

## التمرين

اجعل جدولك حزمةً: `tbl/__init__.py` و`tbl/column.py` و`tbl/table.py`.

**والقيد:** `column.py` لا يستورد `table.py`، و`table.py` يستورد `column.py`.
**ثم اكسر القاعدة عمداً**: اجعل `Column` يحتاج شيئاً من `Table`، واكتب الحلّين
اللذين ذُكرا أعلاه، وقِس أيُّهما يؤخّر التحميل أكثر.

**ثم:** ما الذي يبقى في `__init__.py`؟ اكتب سطرين يبرّران ما وضعتَه فيه.

## الخلاصة

`import` تنفيذُ ملفٍّ مرّةً، وحفظُ الناتج في `sys.modules`، وربطُ اسم. والوحدةُ
كائنٌ قاموسُه فضاؤها العالميّ.

والاستيراد الدائريّ عطبُ **ترتيبٍ** لا عطبُ بنية: اسمٌ طُلب قبل أن يُربَط في وحدةٍ
لم يكتمل تنفيذها.

وبقي أن نسأل: هذه الكائنات كلُّها — أين تسكن، ومن يعيدها؟
