# ١٥ — الذاكرة

الفصل `02` قال إن كل كائنٍ يحمل عدّاد مراجعه، وإنه يُحرَّر حين يبلغ صفراً. هنا
تعرف متى لا يبلغه.

---

## العدّاد يحرّر فوراً

حين ينزل العدّاد إلى صفر، يُحرَّر الكائن في تلك اللحظة — لا في جولةِ جمعٍ لاحقة.
وهذا يختلف عن أغلب اللغات المُدارة.

**مثال**

<!-- part: 15-del -->

```python
class Loud:
    def __init__(self, name):
        self.name = name
        self.peer = None

    def __del__(self):
        print(f"  مات {self.name}")


x = Loud("مستقلّ")
del x
print("— انتهى الأوّل فوراً")

p, q = Loud("p"), Loud("q")
p.peer, q.peer = q, p
del p, q
print("— حُذف الاسمان، ولا شيء مات")

gc.collect()
print("— بعد gc.collect()")
```

**المخرَج**

<!-- out -->

```
  مات مستقلّ
— انتهى الأوّل فوراً
— حُذف الاسمان، ولا شيء مات
  مات p
  مات q
— بعد gc.collect()
```

**السطران الأوّلان:** `del x` حرّر الكائن قبل السطر الذي بعده. الترتيب في المخرَج
هو الدليل.

**والثالث هو المشكلة:** `p` و`q` يشير كلٌّ منهما إلى الآخر. حذفُ الاسمين أنزل
عدّاد كلٍّ منهما إلى واحد لا صفر، فبقيا.

والرابع والخامس: `gc.collect()` وجد الدورة وحرّرها.

**المكسب:** العدّاد وحده لا يحرّر دورةً. ولهذا في Python جامعان: عدّادٌ يعمل
دائماً، وجامعُ دوراتٍ يعمل على فترات.

**و`__del__` هنا أداةُ عرضٍ لا اصطلاحُ عمل.** الجامع ينادي `__del__` في الدورات
منذ Python 3.4، وبترتيبٍ غير مضمون بين كائناتها. فلا يُعتمَد عليه لتحرير مورد،
والاصطلاح `with` و`__exit__` — موضعُهما في الكود معروفٌ وقتَ القراءة.

---

## الدورة تُقاس

**مثال**

<!-- part: 15-cycle -->

```python
a = Node("a")
print("مراجع a:", sys.getrefcount(a) - 1)

b = Node("b")
a.peer = b
b.peer = a
print("بعد الحلقة:", sys.getrefcount(a) - 1)

gc.collect()
before = len(gc.get_objects())
del a, b
after = len(gc.get_objects())
print("بعد del، وقبل الجمع:", before - after, "كائناً تحرّر")

freed = gc.collect()
print("جمعُ الدورات حرّر:", freed, "كائناً")
```

**المخرَج**

<!-- out -->

```
مراجع a: 1
بعد الحلقة: 2
بعد del، وقبل الجمع: 0 كائناً تحرّر
جمعُ الدورات حرّر: 2 كائناً
```

`del a, b` حرّر صفر كائنات. والجمع حرّر الاثنين.

**والطرحُ `- 1` في كل سطر** سببه أن تمرير الكائن إلى `getrefcount` ينشئ إشارةً
مؤقّتة. والرقم بلا الطرح صحيحٌ ومضلّل.

**وبين السطرين يعيش تسريبٌ لا يُلاحَظ:** برنامجٌ ينشئ دوراتٍ في حلقةٍ طويلة
تكبر ذاكرتُه حتى يعمل الجامع. والجامع يعمل بعتباتٍ على عدد التخصيصات، فزمنُ
عمله يتبع معدّل إنشائك للكائنات.

---

## الحالات

### كل بنيةٍ شجرية بأبٍ هي دورة

`node.parent` و`parent.children` معاً دورةٌ في كل عقدة. وهذا يشمل الجدول لو أضفتَ
إليه إشارةً إلى الجدول الأصل، وهو ما تحتاجه لو أردتَ أن يعرف الجدول المشتقُّ من
أين جاء.

**والعلاج المعتمَد `weakref`:** إشارةٌ لا تزيد العدّاد. فالأب يمسك أبناءه، والابن
يشير إلى أبيه بلا أن يمسكه.
