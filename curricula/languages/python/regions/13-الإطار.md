# ١٣ — الإطار

الفصل السابق قال إن `LOAD_FAST` فهرسةُ مصفوفة. هذا الفصل يقول أين تلك المصفوفة:
في إطارٍ يُنشَأ لكل نداء.

---

## نداءٌ واحدٌ يعني إطاراً واحداً

كل نداءٍ ينشئ إطاراً (frame) فيه: كائنُ الكود، ومصفوفةُ المحلّيّات، وموضعُ
التنفيذ، **وإشارةٌ إلى الإطار الذي ناداه**. فالإطارات سلسلةٌ يمشي عليها المفسّر
صعوداً وهبوطاً.

**مثال**

<!-- part: 13-frame -->

```python
import sys


def outer():
    return middle()


def middle():
    return inner()


def inner():
    f = sys._getframe()
    names = []
    while f is not None:
        names.append(f.f_code.co_name)
        f = f.f_back
    return names


print(outer())
print(sys._getframe().f_code.co_name, sys._getframe().f_lineno)
```

**المخرَج**

<!-- out -->

```
['inner', 'middle', 'outer', '<module>']
<module> 22
```

`f_back` صعد من `inner` إلى الوحدة. والوحدة نفسها إطار، اسمُه `<module>`.

**المكسب:** الأثر الذي رأيتَه في الفصل `11` ليس نصّاً يبنيه المفسّر عند الفشل.
هو **قراءةٌ لهذه السلسلة**، وسلسلتُها موجودةٌ في كل لحظةٍ من التنفيذ.

## الاستثناء يحمل إطاراته

الاستثناء يحمل `__traceback__`، وهو سلسلةٌ موازية: كل حلقةٍ فيها إطارٌ وسطر.

**مثال**

<!-- part: 13-tb -->

```python
def a():
    b()


def b():
    raise ValueError("من b")


try:
    a()
except ValueError as e:
    tb = e.__traceback__
    while tb is not None:
        print(tb.tb_frame.f_code.co_name, "سطر", tb.tb_lineno)
        tb = tb.tb_next
    print("المحلّيّات عند الفشل:", e.__traceback__.tb_frame.f_locals.keys())
```

**المخرَج**

<!-- out -->

```
<module> سطر 10
a سطر 2
b سطر 6
المحلّيّات عند الفشل: dict_keys(['__name__', '__doc__', '__package__', '__loader__', '__spec__', '__builtins__', '__file__', '__cached__', 'a', 'b', 'e', 'tb'])
```

`tb_next` يهبط من موضع النداء إلى موضع الفشل — **عكس اتجاه `f_back`**.

**والسطر الأخير هو ما يجعل المشخِّصات ممكنة:** `f_locals` تعطي محلّيّات الإطار
لحظةَ الفشل. وأدوات مثل `pdb` وسجلّات الأخطاء المتقدّمة تقرأ هذا الحقل.

**المكسب:** استثناءٌ تحفظه في متغيّرٍ يحفظ معه سلسلةَ إطاراته، وكلُّ إطارٍ يحفظ
محلّيّاته. وهذا يعني أن حفظ الاستثناء **يمنع تحرير كائنات النداء كلِّها** — وذلك
موضوع الفصل التالي.

## الحالات

### الإطار يعيش أطول من النداء

<!-- part: 13-alive -->

```python
def leaky():
    secret = "محلّيٌّ انتهى نداؤه"
    big = list(range(5))
    return sys._getframe()


f = leaky()
print("الإطار حيّ:", f.f_code.co_name)
print("محلّيّاته:", {k: v for k, v in f.f_locals.items() if k != "big"})
print("big طولُه:", len(f.f_locals["big"]))
```

<!-- out -->

```
الإطار حيّ: leaky
محلّيّاته: {'secret': 'محلّيٌّ انتهى نداؤه'}
big طولُه: 5
```

الدالّة انتهت، والإطار حيٌّ ومحلّيّاته معه. فالإطار كائنٌ عاديّ يخضع لعدّاد
المراجع كغيره.

**وهذا يقع بلا قصد في `except`:** الاستثناء المحفوظ يحمل الأثر، والأثر يحمل
الإطارات، والإطارات تحمل محلّيّاتها. ولهذا يحذف Python الاسم بعد
`except X as e` عند نهاية الكتلة — والإبقاء عليه يُبقي السلسلة كلَّها.

### السطر يُحسَب من جدول

`f_lineno` ليس محفوظاً في كل تعليمة. كائن الكود يحمل جدولاً يربط مدى التعليمات
برقم السطر، ويُقرأ بـ`co_lines`.

<!-- part: 13-lines -->

```python
def spread(a,
           b,
           c):
    return (a +
            b +
            c)


for start, end, line in spread.__code__.co_lines():
    print(f"تعليماتٌ {start:>3}–{end:<3} ⇒ سطر {line}")
```

<!-- out -->

```
تعليماتٌ   0–2   ⇒ سطر 1
تعليماتٌ   2–4   ⇒ سطر 4
تعليماتٌ   4–6   ⇒ سطر 5
تعليماتٌ   6–18  ⇒ سطر 4
تعليماتٌ  18–20  ⇒ سطر 6
تعليماتٌ  20–34  ⇒ سطر 4
```

عبارةٌ واحدة موزَّعةٌ على ثلاثة أسطر، والجدول يعطي لكل مدًى سطرَه. والأرقام تتنقّل
بين ٤ و٥ و٦ ثم تعود إلى ٤ — لأن التعليمات لا تتبع ترتيب الأسطر.

**ومن هذا الجدول تأتي أرقام الأثر**، والسهام `~~~^^^` التي رأيتَها في الفصل `11`
تأتي منه بدقّة العمود.
