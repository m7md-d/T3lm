# ٠٩ — الدالّة كائن

الفصل `00` قال إن الدالّة كائن. هنا ترى ما يعنيه ذلك عملياً: سمات تُقرأ وتُكتَب،
وتمريرٌ كأي قيمة، ومنه تُبنى المزخرِفات.

---

## ما تحمله الدالّة

**مثال**

<!-- part: 09-funcobj -->

```python
def total(values):
    """يجمع عموداً."""
    result = 0
    for value in values:
        result += value
    return result


print(type(total))
print(total.__name__, total.__doc__)
print(total.__code__.co_varnames, total.__code__.co_argcount)

total.calls = 0
print(total.__dict__)

alias = total
print(alias([1, 2, 3]), alias.__name__)
```

**المخرَج**

<!-- out -->

```
<class 'function'>
total يجمع عموداً.
('values', 'result', 'value') 1
{'calls': 0}
6 total
```

`__name__` و`__doc__` سمتان عاديتان. و`__code__` كائنٌ يحمل الكود المترجَم،
وفيه `co_varnames` — أسماء المعامِلات والمتغيّرات المحلّية معاً، و`co_argcount`
عددُ المعامِلات وحدها.

والسطر الأخير: `alias = total` ربطٌ عاديّ كما في الفصل `01`. و`__name__` بقي
`total` لأنه سمةٌ في الكائن لا في الاسم الذي يشير إليه.

**المكسب:** `total.calls = 0` عمل. الدالّة تقبل سمات، وهذا ما تعتمد عليه
المزخرِفات لتحفظ حالةً بجانب الدالّة بلا متغيّرٍ عالميّ.

---

## المزخرِف سكرٌ فوق نداءٍ واحد

`@d` فوق `def f` تعني `f = d(f)` بعد التعريف. لا أكثر.

**مثال**

<!-- part: 09-decorator -->

```python
def counted(fn):
    def wrapper(*args, **kwargs):
        wrapper.calls += 1
        return fn(*args, **kwargs)

    wrapper.calls = 0
    return wrapper


@counted
def total(values):
    return sum(values)


print(total([1, 2]), total([3]), total.calls)
print(total.__name__)


def bare(values):
    return sum(values)


bare = counted(bare)
print(bare([1, 2]), bare.calls)
```

**المخرَج**

<!-- out -->

```
3 3 2
wrapper
3 1
```

النصفان متكافئان: `@counted` والنداء اليدويّ `bare = counted(bare)` أعطيا
السلوك نفسه.

**والسطر الثاني هو الثمن:** `total.__name__` صار `wrapper`. الاسم `total` يشير
الآن إلى `wrapper`، والدالّة الأصلية محفوظةٌ في إغلاقه ولا اسم لها.

---

## `functools.wraps` ينقل الهوية

**مثال**

<!-- part: 09-wraps -->

```python
def plain(fn):
    def wrapper(*a, **k):
        return fn(*a, **k)
    return wrapper


def kept(fn):
    @functools.wraps(fn)
    def wrapper(*a, **k):
        return fn(*a, **k)
    return wrapper
```

**المخرَج**

<!-- out -->

```
بلا wraps: wrapper | None | (*a, **k)
مع wraps : total | يجمع عموداً. | (values, start=0)
```

الثلاثة تُصلَح معاً: الاسم، والتوثيق، والتوقيعة.

**والتوقيعة أهمُّها عملياً:** `inspect.signature` تعطي `(*a, **k)` بلا `wraps`،
فيخسر كلُّ ما يقرأ التوقيعة — المحرّر، والمساعدة، وأدوات الفحص — معرفةَ معامِلات
الدالّة. و`wraps` تحفظ الأصل في `__wrapped__` فتتبعه هذه الأدوات.

**المكسب:** سطرٌ واحد يمنع فقدان معلومة لا تُلاحَظ عند الكتابة وتُلاحَظ عند
التشخيص.

## الحالات

### كلُّ دالّةٍ مزخرَفة تحصل على عدّادها

`def wrapper` داخل `counted` تُنفَّذ في كل نداءٍ لـ`counted`، فتبني كائنَ دالّةٍ
جديداً بإغلاقٍ جديد.

<!-- part: 09-percall -->

```python
@counted
def one(x):
    return x


@counted
def two(x):
    return x


one(1); one(2); two(3)
print(one.calls, two.calls)
print(one is two, one.__code__ is two.__code__)
```

<!-- out -->

```
2 1
False True
```

العدّادان مستقلّان. والسطر الأخير يفصل الأمرين: `one` و`two` كائنا دالّةٍ
مختلفان (`is` كاذب) ويتشاركان **كائن الكود نفسه** (`__code__` واحد).

فالكود يُترجَم مرّةً عند تنفيذ `def wrapper`، والذي يتكرّر كائنُ الدالّة وإغلاقُه.
وهذا هو `n` المستقلّ لكل `counter` في الفصل `05` بصيغةٍ أخرى.

### المزخرِف بوسائط ثلاث طبقات

`@retry(3)` تعني `f = retry(3)(f)`: نداءان لا واحد.

<!-- part: 09-args -->

```python
def retry(times):
    print(f"  retry({times}) نُوديت")

    def decorator(fn):
        print(f"  المزخرِف نُودي على {fn.__name__}")

        def wrapper(*a, **k):
            ...

        return wrapper

    return decorator


@retry(3)
def flaky(box):
    ...
```

<!-- out -->

```
  retry(3) نُوديت
  المزخرِف نُودي على flaky
3
```

السطران الأوّلان طُبعا عند التعريف لا عند النداء، وبهذا الترتيب: `retry(3)`
أوّلاً فأعادت `decorator`، ثم نُودي `decorator` على `flaky`.

والملفّ كاملاً في [`programs/09-args.py`](../programs/09-args.py).

## تمرين

اكتب `@memo` يحفظ نتائج الدالّة في قاموس. الشرط أن يعمل مع وسائط موضعية ومسمّاة
معاً، وأن يعرض عدد الإصابات في `fn.hits`.

<!-- task -->

```python
@memo
def total(values):
    return sum(values)
```

ثم شغّله على `total([1, 2])` مرّتين وقل ما حدث، **ولماذا لا يعمل الحلّ البديهيّ**.
