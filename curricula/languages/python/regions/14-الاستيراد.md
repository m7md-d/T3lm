# ١٤ — الاستيراد

`import` ليست تضميناً نصّياً. هي **تنفيذُ ملفٍّ مرّةً واحدة** ثم ربطُ اسمٍ
بالكائن الناتج.

---

## مرّةٌ واحدة، ثم قاموس

أوّل استيرادٍ ينفّذ ملفَّ الوحدة كاملاً، ويبني منه كائنَ وحدة، ويضعه في
`sys.modules`. وكل استيرادٍ بعده يجد الكائن هناك ولا ينفّذ شيئاً.

**مثال**

<!-- part: 14-once -->

```python
import sys

print("قبل الاستيراد:", "pkg.once" in sys.modules)

from pkg import once
from pkg import once as again
import pkg.once

print("بعد ثلاث مرّات:", once is again is pkg.once)
print("في sys.modules:", sys.modules["pkg.once"] is once)

once.VALUE.append(1)
print("الحالة مشتركة:", again.VALUE)
```

**المخرَج**

<!-- out -->

```
قبل الاستيراد: False
  pkg/__init__ نُفِّذ
  pkg/once نُفِّذ
بعد ثلاث مرّات: True
في sys.modules: True
الحالة مشتركة: [1]
```

ثلاث جمل استيراد، وسطرا الطباعة من الملفَّين ظهرا مرّةً واحدة.

**و`pkg/__init__` نُفِّذ أيضاً:** استيراد `pkg.once` يستورد `pkg` أولاً.

**والسطر الأخير هو الأثر العمليّ:** `once` و`again` اسمان لكائنٍ واحد، فقائمةُ
`VALUE` مشتركة. وهذا هو الفصل `01` مطبَّقاً على الوحدات: `import` ربطُ اسمٍ
بكائن.

**المكسب:** «حالةُ الوحدة» عالميّةٌ في العملية كلِّها. فكلُّ من يستورد الوحدة
يقرأ ويكتب في الكائن نفسه — وهو ما تريده في الإعداد، وما يفاجئك في كل ما عداه.

---

## الاستيراد الدوريّ يفشل في منتصف التنفيذ

الوحدة تُوضَع في `sys.modules` قبل أن يكتمل تنفيذها. فإن استوردها ملفٌّ آخر
في تلك اللحظة، وجدها موجودةً وناقصة.

**مثال**

<!-- part: 14-circular -->

```python
# pkg/alpha.py
from pkg import beta

NAME = "alpha"


# pkg/beta.py
from pkg.alpha import NAME

NAME_B = NAME + "-beta"
```

**المخرَج**

<!-- err: ImportError -->

```
ImportError: cannot import name 'NAME' from partially initialized module 'pkg.alpha' (most likely due to a circular import) (programs/pkg/alpha.py)
```

`alpha` بدأ التنفيذ، فسطرُه الأول استورد `beta`، و`beta` طلب `NAME` من `alpha`
الذي لم يبلغ سطر `NAME` بعد.

**والرسالة تسمّي السبب:** `partially initialized module`. وهي تقول الحالة
بلفظها: وحدةٌ في منتصف تنفيذها.

والحلّان: أن يُنقَل الاستيراد داخل الدالّة فيتأخّر إلى وقت النداء، أو أن
يُستورَد الاسمُ الوحدةَ لا العنصر — `from pkg import alpha` ثم `alpha.NAME` عند
الاستعمال. والثاني يعمل لأن الربط بالوحدة يقع الآن والقراءةُ لاحقاً.

## الحالات

### الترتيب في `sys.path` يحكم

<!-- part: 14-path -->

```python
# مجلّدٌ فيه `json.py` من سطرٍ واحد، يُوضَع أوّلَ المسار كما يُوضَع مجلّدُ السكربت
sys.path.insert(0, os.path.join("programs", "shadow"))

import json

here = os.path.relpath(json.__file__)
print("أوّل مسار:", sys.path[0])
print("json من  :", here)
print("محجوب؟   :", os.path.dirname(here) == sys.path[0])
```

<!-- out -->

```
أوّل مسار: programs/shadow
json من  : programs/shadow/json.py
محجوب؟   : True
```

`json.py` من سطرٍ واحد حجب وحدة المكتبة القياسية كلَّها.

الاستيراد يبحث في `sys.path` بالترتيب، وأوّلُه مجلّدُ السكربت. **والأثر يظهر في
مكانٍ بعيد:** وحدةٌ ثالثة تستورد `json` فتحصل على ملفِّك، فتفشل برسالةٍ لا تشير
إليك.

**والتخزين في `__pycache__` لا يمسّ هذا:** الفصل `12` قال إنه يوفّر الترجمة.
أمّا جسم الوحدة فيُنفَّذ في كل عملية، مرّةً واحدةً فيها.
