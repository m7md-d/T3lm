# ٠٠ — المفردات

هذا الفصل يعطيك الكلمات التي سيستعملها الفصل الأول، والقرارات التي تفسّر شكل
Python، ثم الطريق. تقرأه مرّة ثم تنتقل.

**الإصدار المستهدف: Python 3.14.7.** كل مخرَجٍ في هذا المنهج مأخوذٌ من تشغيلٍ
فعليّ عليه.

---

## خمس كلمات

**الكائن (object)** — وحدةُ التخزين في Python. له نوع، وقيمة، وعنوان في الذاكرة.
العدد `3` كائن، والقائمة كائن، والدالّة كائن، والصنف كائن.

**الاسم (name)** — مُدخَلٌ في جدول يشير إلى كائن. `x = 3` تضع في الجدول مدخلاً
اسمه `x` يشير إلى الكائن `3`.

**النوع (type)** — صفةٌ يحملها الكائن نفسه. تسأل عنه بـ`type(v)`، وتحصل على
جواب أثناء التشغيل.

**المفسّر (interpreter)** — البرنامج الذي يقرأ ملفّك وينفّذه. اسمه `python3` على
جهازك.

**البايت-كود (bytecode)** — تعليماتٌ وسيطة يترجم إليها المفسّر ملفَّك قبل أن
ينفّذه. تراها في الفصل `12`.

## القرارات التي تفسّر شكل اللغة

### القيمة كائن، والاسم يشير إليها

في C يعني `long x;` أن هناك خانةً بثمانية بايتات اسمُها `x`. هنا الاسم مدخلٌ في
جدول، وقيمتُه إشارةٌ إلى كائن.

**مثال**

<!-- part: 00-names -->
```python
a = [1, 2]
b = a

print(id(a) == id(b))
print(type(a), type(3), type(print))
```

<!-- out -->

**المخرَج**

```
True
<class 'list'> <class 'int'> <class 'builtin_function_or_method'>
```

`a` و`b` يشيران إلى الكائن نفسه، فـ`id` واحد. والدالّة المدمجة `print` لها نوعٌ
كما للقائمة والعدد.

**المكسب:** هذا يفسّر لاحقاً لماذا تعديلَ قائمةٍ عبر اسمٍ يظهر في الاسم الآخر.
الفصل `01` كلُّه عن هذه الجملة.

### النوع يُعرَف وقت التشغيل

النوع صفةُ الكائن، فلا يوجد إعلان نوعٍ للاسم. والاسم نفسه يشير إلى عددٍ ثم إلى
نصٍّ في السطر التالي، والدالّة تقبل ما يُمرَّر إليها حتى ينفّذ جسمُها عمليةً
يرفضها النوع.

**مثال**

<!-- part: 00-runtime-type -->

```python
def area(w, h):
    return w * h


x = 10
print(type(x).__name__, x)

x = "10"
print(type(x).__name__, x)

print(area("ab", 3))
print(area("ab", "3"))
```

**المخرَج**

<!-- err: TypeError -->

```
int 10
str 10
ababab
TypeError: can't multiply sequence by non-int of type 'str'
```

الاسم `x` حمل عدداً ثم نصّاً. و`area("ab", 3)` عملت وأعطت `ababab`، لأن `*` بين
نصٍّ وعددٍ تكرار. والنداء الرابع وحده فشل، وفشل **عند تنفيذ `w * h`** لا عند
النداء.

**الثمن:** ما من لحظةٍ قبل التشغيل يُفحَص فيها البرنامج كما يفحصه مترجم C.

### الملفّ يُنفَّذ بلا خطوة ترجمةٍ تراها

**مثال**

<!-- part: 00-late -->
```python
def report():
    return summarise([1, 2, 3])


print("الملفّ عمل، والاسم `summarise` غير معرَّف")
report()
```

<!-- err: NameError -->

**المخرَج**

```
الملفّ عمل، والاسم `summarise` غير معرَّف
NameError: name 'summarise' is not defined
```

السطر الأول طُبع. اسمٌ غير موجودٍ داخل دالّةٍ لا يمنع الملفّ من العمل، ويظهر حين
يصل التنفيذ إليه.

**المكسب:** هذا يحدّد أين تقع أخطاؤك — عند التنفيذ لا قبله — ويفسّر لماذا صار
`pytest` والفحص الساكن أدواتٍ أساسية في هذا الوسط.

### واجهة C مفتوحة

أي أحدٍ يستطيع كتابة مكتبةٍ بـC وعرضها كوحدة Python. من هنا جاءت NumPy وما بُني
فوقها.

**الثمن:** ليعمل ذلك، صار عدّاد المراجع جزءاً من الواجهة المعلنة — كل كائنٍ
يحمل عدد الإشارات إليه، وكل امتدادٍ بـC يزيده وينقصه بيده. وعدّادٌ مشتركٌ يُعدَّل
من خيطين يحتاج قفلاً، وذلك هو الـGIL. الفصلان `15` و`16`.

## ما رفضته اللغة عمداً

| المرفوض | القرار الذي حماه | ما تدفعه أنت |
|---|---|---|
| إعلان النوع للاسم | النوع صفة الكائن | لا فحص أنواعٍ قبل التشغيل |
| القيم البدائية خارج نظام الكائنات | القيمة كائن | العدد `1` يشغل ٢٨ بايتاً، وتقيسه في `02` |
| الأقواس لتحديد الكتلة | المسافة البادئة تحدّدها | خطأ مسافةٍ يوقف الملفّ |
| تعدّد الخيوط للحساب | عدّاد مراجعٍ مكشوف | خيطان على حسابٍ واحد لا يسرّعانه (`16`) |
