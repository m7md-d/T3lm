# ٠٢ — داخل الكائن

الفصل السابق قال إن الاسم يشير إلى كائن. هنا تفتح الكائن نفسه: ماذا يحمل، وكم
يزن، ومن يعدّ الإشارات إليه.

---

## ما يحمله كل كائن

كل كائن في Python يحمل ثلاثة أشياء قبل قيمته:

| الحقل | معناه | كيف تراه |
|---|---|---|
| النوع | إشارةٌ إلى كائن الصنف | `type(v)` |
| عدّاد المراجع | كم اسماً أو حاويةً تشير إليه | `sys.getrefcount(v)` |
| القيمة | البيانات نفسها | `v` |

هذا هو ثمن القرار الأول في الفصل `00`: القيمة كائن، والكائن يحمل ترويسة.

---

## كم يزن العدد

**مثال**

<!-- part: 02-size -->

```python
import array
import sys

print(sys.getsizeof(0), sys.getsizeof(1), sys.getsizeof(2**64), sys.getsizeof(2**1000))
print(sys.getsizeof([]), sys.getsizeof([1, 2, 3]), sys.getsizeof(list(range(1000))))
print(sys.getsizeof(array.array("q", range(1000))))
```

**المخرَج**

<!-- out -->

```
28 28 36 160
56 88 8056
8320
```

**السطر الأول:** العدد `1` يشغل ٢٨ بايتاً، بينما يشغل `long` في C ثمانية. والعدد
لا يحدّه عرض الكلمة: `2**1000` يشغل ١٦٠ بايتاً ويعمل.

**السطر الثاني:** قائمةٌ من ألف عدد تشغل ٨٠٥٦ بايتاً. هذا حجم مصفوفة إشاراتٍ
لا مصفوفة أعداد — ثمانية بايتات لكل إشارة، والأعداد نفسها في مكانٍ آخر.

**السطر الثالث:** `array.array("q", …)` يحمل الأعداد نفسها متجاورةً في ٨٣٢٠
بايتاً.

**المكسب:** الفرق بين السطرين الأخيرين هو سبب وجود NumPy، وهو موضوع الحزمة
الرابعة. `list` مصفوفةُ إشارات، فالمرور عليها يقفز في الذاكرة.

---

## عدّاد المراجع

كل كائن يعرف كم إشارةً تصل إليه. حين يبلغ العدّاد صفراً يُحرَّر الكائن في الحال.

**مثال**

<!-- part: 02-refcount -->

```python
import sys

values = [1, 2]
print("مرجعٌ واحد:", sys.getrefcount(values) - 1)

alias = values
print("بعد alias  :", sys.getrefcount(values) - 1)

holder = [values, values]
print("بعد holder :", sys.getrefcount(values) - 1)

del alias
print("بعد del    :", sys.getrefcount(values) - 1)
```

**المخرَج**

<!-- out -->

```
مرجعٌ واحد: 1
بعد alias  : 2
بعد holder : 4
بعد del    : 3
```

نطرح واحداً لأن تمرير الكائن إلى `getrefcount` ينشئ إشارةً مؤقّتة.

**والقائمة تعدّ مرّتين** لأنها تحمل الكائن نفسه في موضعين. الحاوية تشير كما يشير
الاسم.

**المكسب:** `del name` يحذف مدخلاً من جدول الأسماء وينقص العدّاد. لا يحذف الكائن،
والكائن يذهب حين يبلغ عدّاده صفراً. الفصل `15` يريك متى لا يبلغه.

## الحالات

### `is` على الأعداد جوابٌ عن سؤالٍ آخر

المفسّر يحتفظ بكائناتٍ جاهزةٍ للأعداد الصغيرة من `-5` إلى `256`، فيعيد الكائن
نفسه لكل طلب. وخارج هذا المدى يصنع كائناً جديداً.

**مثال**

<!-- part: 02-cache -->

```python
print("256:", int("256") is 256)
print("257:", int("257") is 257)

a = 1000
b = int("1000")
print("a is b:", a is b, "  a == b:", a == b)
```

**المخرَج**

<!-- out -->

```
256: True
257: False
a is b: False   a == b: True
programs/02-cache.py:1: SyntaxWarning: "is" with 'int' literal. Did you mean "=="?
  print("256:", int("256") is 256)
programs/02-cache.py:2: SyntaxWarning: "is" with 'int' literal. Did you mean "=="?
  print("257:", int("257") is 257)
```

الاختباران متطابقان في الشكل ومختلفان في الجواب. والسطران الأخيران تحذيرٌ من
المفسّر نفسه على مجرى الخطأ: `is` مع عددٍ مكتوبٍ في المصدر سؤالٌ عن الهوية حيث
تريد المساواة.

**والمدى تفصيلٌ في تنفيذ CPython** يجوز أن يتغيّر. المعتمَد أن `is` يسأل عن
الهوية، و`==` عن القيمة. الفصل `03`.

### `getsizeof` يقيس الكائن وحده

`sys.getsizeof([1, 2, 3])` أعطى ٨٨ بايتاً، وهي ٦٤ للترويسة وثمانيةٌ لكل إشارة.
والأعداد الثلاثة خارج هذا الرقم: ٢٨ بايتاً لكلٍّ منها، فمجموع ما تشغله البنية
كلُّها ١٧٢.

والفرق يكبر بالحجم: قائمةُ الألف أعطت ٨٠٥٦، ومحتواها ٢٨ ألف بايتٍ أخرى.

**المكسب:** `getsizeof` تقيس الترويسة ومصفوفة الإشارات. وما تخافه من الذاكرة
مجموعُ الكائنات كلِّها، وتمرين هذا الفصل يبني الرقم الذي يقيسه.
