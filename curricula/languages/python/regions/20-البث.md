# ٢٠ — البثّ

العملية بين مصفوفتين تحتاج شكلاً متوافقاً. والبثّ (broadcasting) قاعدةٌ تجعل
الأشكال المختلفة تعمل معاً بلا أن تُنسَخ البيانات.

---

## القاعدة

تُقارَن الأبعاد من اليمين. والبعدان متوافقان إن تساويا أو كان أحدهما `1`. والبعد
الذي طولُه `1` يُقرأ متكرّراً بلا أن يُنسَخ.

**مثال**

<!-- part: 20-broadcast -->

```python
rows = np.arange(6).reshape(3, 2)
col = np.array([[10], [20], [30]])
row = np.array([100, 200])

print(rows + col)
print(rows + row)
print("شكلُ الناتج:", (rows + col).shape, (rows + row).shape)

bad = np.array([1, 2, 3])
print(rows + bad)
```

**المخرَج**

<!-- err: ValueError -->

```
[[10 11]
 [22 23]
 [34 35]]
[[100 201]
 [102 203]
 [104 205]]
شكلُ الناتج: (3, 2) (3, 2)
ValueError: operands could not be broadcast together with shapes (3,2) (3,)
```

`rows` شكلُه `(3, 2)`.

**و`col` شكلُه `(3, 1)`:** البعد الأيمن `1` مقابل `2`، فيُقرأ العنصر مرّتين —
كل صفٍّ يُجمَع بقيمته.

**و`row` شكلُه `(2,)`:** يُحاذى إلى اليمين فيصير `(1, 2)`، والبعد الأيسر `1`
مقابل `3` فيُقرأ ثلاث مرّات — كل عمودٍ يُجمَع بقيمته.

**و`bad` شكلُه `(3,)`:** يُحاذى إلى اليمين فيصير `(1, 3)`، والبعد الأيمن `3`
مقابل `2` فلا يتوافق. والرسالة تعطي الشكلين.

**المكسب:** «جمعُ متّجهٍ على كل صفوف مصفوفة» عمليةٌ واحدةٌ بلا حلقة وبلا نسخ.
والحلقة في Python كانت ستكلّف ما قاسه الفصل `17`.

---

## قراءة الرسالة

`shapes (3,2) (3,)` تكفي للتشخيص إن قرأتَها بالقاعدة: حاذِ الشكلين إلى اليمين،
ثم انظر أول بعدين لا يتساويان ولا فيهما `1`.

| الشكلان | المحاذاة | النتيجة |
|---|---|---|
| `(3,2)` و`(3,1)` | `(3,2)` · `(3,1)` | ✓ الناتج `(3,2)` |
| `(3,2)` و`(2,)` | `(3,2)` · `(1,2)` | ✓ الناتج `(3,2)` |
| `(3,2)` و`(3,)` | `(3,2)` · `(1,3)` | ✗ `2` مقابل `3` |
| `(3,2)` و`(3,1,2)` | `(1,3,2)` · `(3,1,2)` | ✓ الناتج `(3,3,2)` |

**والصفّ الأخير هو الفخّ:** الشكلان توافقا وأعطيا ناتجاً **أكبر من الاثنين**.
والبثّ لا يخطئ هنا — الخطأ في شكلٍ لم تنتبه إليه.

**و`a[:, None]` تضبط المحاذاة بيدك:** تحوّل `(3,)` إلى `(3, 1)`، وتصرّح بأي بعدٍ
يُضاف وأين — بخلاف `reshape` الذي يعطي الشكل النهائيّ وحده. وهي view بلا كلفة
كما في الفصل `19`.

## الحالات

### الناتج يُخصَّص كاملاً

البثّ لا ينسخ مُدخَلاته، ويخصّص ناتجه كاملاً.

<!-- part: 20-size -->

```python
a = np.arange(10_000, dtype=np.int64).reshape(10_000, 1)
b = np.arange(10_000, dtype=np.int64).reshape(1, 10_000)

shape = np.broadcast_shapes(a.shape, b.shape)
count = int(np.prod(shape))

print("الشكلان :", a.shape, b.shape)
print("شكلُ الناتج:", shape)
print("عددُ القيم :", f"{count:,}")
print("ما سيُخصَّص:", count * 8 // 1024 // 1024, "ميغابايت")
```

<!-- out -->

```
الشكلان : (10000, 1) (1, 10000)
شكلُ الناتج: (10000, 10000)
عددُ القيم : 100,000,000
ما سيُخصَّص: 762 ميغابايت
```

مصفوفتان بـ٨٠ كيلوبايتاً لكلٍّ، وناتجٌ بـ٧٦٢ ميغابايت.

**والبثّ لا يعلن هذا قبل التخصيص:** السطر `a + b` إمّا يعمل وإمّا يقتل العملية.
و`np.broadcast_shapes` هي التي تعطيك الشكل بلا أن تخصّص شيئاً.
