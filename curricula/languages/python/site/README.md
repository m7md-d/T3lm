# موقع منهج Python — جدول الاشتقاق

الموقع ليس ثيماً فوق المنهج. كل قرار فيه مردودٌ إلى شيء موجود **فعلاً** في
ماركداون المنهج، وما لم أجد له سطراً هنا حذفتُه.

**حالته:** الفصول الثمانية والعشرون مكتوبةٌ كلُّها (`00`–`27`)، و١٣٨ مساراً
تُصيَّر. ويبقى في المدخل ميكانيزمُ البطاقة المقفلة لأي فصلٍ يُعلَن في جدول الطريق
ولا ملفّ له.

**اختبار القبول:** انقل هذا التصميم إلى منهج شبكات فيبدو *غير منطقيّ*: وسمُ
«يختلف بين تشغيلين» يصير بلا معنى لأن الحزمة تُلتقَط ولا تُقاس مرّتين، ومعجمُ
رموز المخرَج يلوّن `<class 'int'>` و`0x…` بلونين مختلفين لأن لكلٍّ ضامناً آخر —
وفي الشبكات الضامن واحد. **وشريطُ الأحجام** يقارن بايتات ثلاثِ بنياتٍ لعملية
واحدة، ولا نظير له حيث لا تُقاس البنية نفسها بطرقٍ ثلاث.

## ١) جدول الاشتقاق

الأعداد مقيسةٌ على الفصول المكتوبة بـ`grep -c`، لا مقدَّرة.

| القرار في الموقع | مصدره في المحتوى | لماذا هذا الشكل بالذات |
|---|---|---|
| الصفحة **قسمٌ واحد** لا نصٌّ متّصل | ١٢٤ عنوان `## ` في ٢٨ ملفّاً | التقطيع في النصّ قبل الموقع؛ وقالب الدرس في الأسلوب §٤ (ما هو ← الصيغة ← مثالٌ ومخرَجه ← الحالات) هو تخطيطُ الصفحة نفسه |
| **قسم «الحالات» ينقسم أجزاءً** | ٣٨ عنوان `### `، أكثرها تحت «الحالات» وأربعةٌ في `00` تحت «القرارات» | العمق يُقاس من الملفّ: قسمٌ فيه `### ` جزءٌ وأبناؤه أقسام، وما عداه قسمٌ مباشرةً — فإضافة جزءٍ عملٌ في الماركداون وحده |
| **كتلة الكود تحمل اسم ملفّها** | ٨٤ `<!-- part: NAME -->` و٦ `<!-- head: FILE -->` · و٨٦ ملفّاً في `programs/` | المقتطع لا يعمل وحده، وملفُّه في `programs/`؛ والقارئ يحتاج أن يعرف أين يجده |
| **المخرَج أربع هيئات** | ٥٢ `out` · ١٧ `err` · ١٥ `runs` · ٣ `shell` | العلامة نفسها التي يفرضها `tools/verify.py`: ما يُفحَص هو ما يُعرَض |
| وسمُ «يختلف بين تشغيلين» على ١٥ مخرَجاً | ١٥ `<!-- runs: … -->`، والريدمي: «الثابت هو النسبة» | العنوان يختلف عند القارئ، فالرقم المعروض لا يُقارَن — ويُقال ذلك قبل أن يُقرأ |
| **معجم رموز المخرَج**: النوع أزرق، والعنوان أزرقُ خافت، والرفض ورديّ، والقياس أصفر | ريدمي المنهج §أدواته — أربعة وسومٍ تُعلَن مع المخرَج | لونُ الرمز لونُ **مالكه**: يقرأ القارئ سطر مخرَجٍ فيرى من يضمن أيَّ جزءٍ منه. والتلوين درسٌ لا زينة |
| **سؤال التوقّع يقفل المخرَج وما بعده في القسم** | ١١ سطر `المخرَج:` وحدها | تنفيذٌ حرفيٌّ لعلامة المؤلّف. ويقفل الشرحَ معه لأنه يقول الجواب. ولا تُقفَل الستّةُ والسبعون مخرَجاً الباقية: السؤال بلا مرساةٍ معرفية حاجزٌ إداريّ (الأسلوب §٥) |
| **التمرين بطاقةٌ بحدٍّ أصفر** على الأرضيّة | ٢٨ قسم `## تمرين`، واحدٌ في كل فصل · و٢٥ كتلةَ `task` | التمرين **أرضيّة الفصل** لا قسماً — يُنتزَع من التسلسل ويُعرَض بعد آخر قسم |
| **سطر «الفصل التالي» يسمّي زرَّ الملاحة** | ٢٧ سطر `**الفصل التالي:** …`، آخر سطرٍ في كل ملفٍّ إلا الختام | بنيةُ النصّ هي الملاحة (الركيزة ٤): المؤلّف كتب ما يفتحه التالي، فلا pager عامٌّ بجانبه |
| **شريط الأحجام** موتيفَ المدخل | مخرَج `02-size`، والمنهج يعود إلى البايتات في `17` و`18` و`21` | المنهج **يقيس** البنية نفسها بثلاث طرق؛ فالموتيف قياسٌ لا رسم |
| المقياس في الشريط **لوغاريتميّ** | المدى في المخرَج نفسه: ٢٨ إلى ٨٣٢٠ بايتاً | خطّيّاً يختفي صفُّ العدد الواحد، والدرس فيه |
| **قرارات اللغة الأربعة** مادّةَ المدخل | عناوين أقسام «القرارات التي تفسّر شكل اللغة» في `regions/00` | الفصل يقول إنه يُشتقّ منها، ويحيل إليها بالاسم في `02` و`15` و`16` |
| **مختبر الرِّباط** بعد قسم «ما الذي تفعله `=`» | الفصل `01`: «`=` تربط اسماً بكائن، والطريقة تعدّل الكائن» | ادّعاءٌ يُقلَب بثلاث ضغطات؛ والتلاعب النشط d = 0.86 مقابل 0.17 للمشاهدة (أدلّة §٤) |
| **العنوان العدديّ على كل سهم** في المختبر | مخرَج `01-bind` — عناوين حقيقية من تشغيل | ٤٨٪ يقرؤون المؤشّر وعاءً يحوي البيانات حين يخلو السهم من عنوان (أدلّة §٥) |
| اللوحة والعلامة **من ملفّ python.org** | `public/python-logo.svg` | العلامة تُستورَد ولا تُرسَم؛ واللوحة منتزَعةٌ من الملفّ: `#306998` · `#5a9fd4` · `#ffd43b` · `#ffe873` |
| **الأحاديّ لا يمسّ العربية**، والعائلة العربية سابقةٌ في مكدّس المونو | مخرَجات المنهج فيها عربية (`مرجعٌ واحد: 1` في `02-refcount`، و«مات p» في `15-del`) | الخليّة الثابتة تفكّ وصل الحروف؛ ومقطعُ العربية في المخرَج يُعزَل اتجاهاً ويعود إلى خطّ النصّ |
| **حذفُ رقم الفصل من العنوان المعروض** | الرقم يفتح ٢٨ عنواناً، وهو معروضٌ بجانبها في الشريط والرصيف | الحقل الثابت ليس معلومة (الركيزة ٢ب) |
| **شريطٌ للقسم لا للمنهج**، وزرُّ التالي يسمّي ما بعده بثلاث كلمات | الأسلوب §١٣ «بلا توقيت» | الكلفة الظاهرة صغيرة، والأثر يتراكم خلفه — ولا عدَّ تنازلياً |
| **رصيفٌ جانبيّ بعرضه، والمتن يُزاح بمقداره** — ومعه سهما لوحة المفاتيح | الركيزة ٣ قاعدة ٣: «الانتقال بضغطةٍ واحدة، **في نفس الموضع دائماً**. زرٌّ ومفتاح»، والمحرَّم: «لا عمود جانبي يمرّ تحت الشريط» | زرٌّ يتحرّك بطول القسم يجعل كل انتقالٍ بحثاً عن موضعه؛ ولوحٌ يطفو فوق المتن يحجب ما يُقرأ. فالعمود بعرضه، وله تمريرُه الخاصّ المعتم |
| **الانتقال يبدأ من أعلى القسم** | الركيزة ٣ قاعدة ١: «نهاية القسم مرئيةٌ من بدايته» | من ضغط «التالي» وهو في القاع يجب أن يجد نفسه في بداية القسم الجديد، لا في قاع شيءٍ لم يقرأه |
| **الرصيف يحمل أقسام هذا الفصل وحده**، حتى `store.furthest` | الركيزة ١٠: «لا أعداد إجمالية»، والأسلوب §٩ كشفٌ تدريجيّ | القارئ داخل فصلٍ يحتاج أن يعرف أين هو منه وأن يعود إلى قسمٍ مرّ عليه. والفصول الأخرى مكانها المدخل: عرضُها هنا يضع أمامه كلفةَ ما لم يبلغه |
| **التمرين لا يظهر في الشجرة قبل بلوغ الأرضيّة** | الركيزة ٣: «لا يُعرَض جزءٌ في الأثر قبل بلوغه» | العقدة التي لم تُعبَر ليست أثراً |
| **ما توقّعتَه** يُعرَض عند الأرضيّة | سؤال التوقّع يحفظ نصَّ القارئ | كلُّ ما يُخزَّن يُعرَض؛ وحقلٌ يُحفَظ ولا يُعرَض وعدٌ لم يُنفَّذ. وبلا نسبةٍ ولا صواب/خطأ — الحكم للقارئ |
| **مفردات الواجهة طبيعية**: فصل · قسم · مثال · المخرَج · توقّع | الأسلوب §١٤: «المصطلح طبيعيّ» | الاسم المخترَع يُجبر القارئ على تعلّم مفردات الكاتب قبل الموضوع، ويمنعه من البحث عنه في أي مصدرٍ آخر |

### القيود السالبة

| ما مُنع | مصدره |
|---|---|
| **لا زرّ «اكشف الحلّ»** في الموقع كلّه | ريدمي المنهج: «ولا حلول في المنهج» — أيُّ reveal كان سيكذب |
| **لا زرّ تشغيل على أي كتلة** | لا منفّذ Python في المتصفّح يطابق `3.14.7` بـNumPy وcffi، والفرق في **الجواب** لا في الصيغة ⇒ بلا زرّ، ومخرَجٌ مسجَّلٌ يشغّله القارئ عنده (الركيزة ٨ب) |
| **لا نقاط ولا شارات ولا سلاسل** | الأسلوب §١٢ |
| **لا حركة تلقائية** | التماسك d ≈ 0.86 — الحركة التي لا تعلّم تُحذَف. والانتقال الوحيد عرضُ شريط الأحجام، بيد القارئ |
| **لا ثيم فاتح** | الحمض النووي للمستودع |
| **لا عدّاد إجماليّ ولا نسبة إنجاز** | التقدّم مقلوب (الركيزة ١٠) |
| **لا نبرةٍ في نصّ الواجهة** — لا تعريفَ بالنفي ولا تفضيل | الأسلوب §١٤، ويفحصه `node tools/prose.mjs` على المتن |
| **لا قسمَ بلا دليل** — كلُّ قسمٍ فيه كتلةٌ أو جدول | الأسلوب §١٤؛ ويعدّه الفاحص نفسه، فلا يبقى في الموقع قسمٌ يُقرأ إحالةً |

**ما حُذف لأنه بلا سطر:** شريطٌ جانبيّ دائم (القسم أقصر من أن يحتاجه) · فهرسُ
محتوياتٍ لكل صفحة · صفحة «أثر» مستقلّة · أيقونةٌ لكل فصل (تمييزٌ بلا معلومة).

## ٢) جدول مقابلة الأدلّة

| الرقم | ما يقرّره | الحال |
|---|---|---|
| **d = 0.86 / 0.17** — التلاعب مقابل المشاهدة | مخطّطٌ يُقلَب بيد القارئ | ⚠ **أضعفُ صفٍّ هنا**: مختبرٌ واحد (الرِّباط في `01`) وشريطُ أحجامٍ في المدخل. سبعةٌ وعشرون فصلاً بلا مختبر |
| **d ≈ 0.80** — التقارب المكانيّ | تشريحُ السطر مرسًى إلى سطره داخل الكتلة | ⚠ **غير مستوفى**: التشريح فقرةٌ تحت الكتلة. يحتاج إرساءً إلى الأسطر |
| **d ≈ 0.86** — التماسك | حذفُ كل عنصرٍ زخرفيّ | ✓ بلا حركةِ دخول، وضوءٌ واحدٌ من أعلى، ولا أيقونات تزيين |
| **d = 0.50–0.70** — التقطيع بتحكّم المتعلّم | قسمٌ في الصفحة، والانتقال بضغطة | ✓ ولا تقدّمَ تلقائيّ |
| **d = 0.45–0.60** — التنبّؤ قبل الشرح | ≤٣ أسئلة في الفصل، وبمرساة | ✓ ١١ في ٢٨ فصلاً، أقصاها اثنان في فصل |
| **d = 0.35 مقابل 0.12** — المساعدة المطلوبة | لا تلميح آليّ، والكشف بيد القارئ | ✓ وتأخيرُ عشر ثوانٍ لمن فتح بلا توقّع |
| **٤٨٪** — السهم بلا عنوان | عنوانٌ عدديّ على كل سهم | ✓ في مختبر الرِّباط |
| **d > 1.50** — أربع فئاتٍ لونية | ولكلٍّ قناةٌ ثانيةٌ واحدة | ✓ أربع عائلات، والقناة الثانية وسمٌ نصّيّ |
| **١٢٨ دراسة** — المكافأة الخارجية | لا تلعيب | ✓ |
| **d = 0.57** — المهمّة الكاملة أوّلاً | الـepitome مبكّراً | ✓ يُبنى في `01` ويعبر الحزم الخمس: `03` ينسخ · `06` يمرّ · `18` يستبدل تخزينه · `23` تنتقل حلقتُه إلى C · `26` يُعاد كتابته |
| **d ≈ 0.50** — النصّ النافي | على اعتقادٍ يحمله القارئ فعلاً | ✓ واحدٌ في `01` (`=` نسخُ بايتات — من مرساة C)، ومعه مخطّطُ المختبر |

**ما لم يُفحَص في متصفّح:** الحركة تحت المؤشّر، وحالات التركيز بلوحة المفاتيح،
وسلوك سؤال التوقّع بعد إعادة التحميل، وسهما لوحة المفاتيح، والرصيف على شاشةٍ
ضيّقة (تحت ٦٠rem يصير شريطاً في القاع). اللقطة الساكنة لا ترى شيئاً منها.

## ٣) الفحوص

```bash
npm run outputs     # tools/verify.py — كل مخرَجٍ معروضٍ يطابق تشغيله
npm run bidi        # ثنائية اللغة
npm run smoke       # كل مسارٍ يُصيَّر، والمحتوى مطابقٌ للماركداون ١:١
npm run typecheck
npm run build       # ثم node tools/sw.mjs — بلا أي أصل خارجيّ
npm run swcheck     # الزيارة الثانية تحت سيطرة عامل الخدمة
```

**والمظهر يُفحَص بلقطة:**

```bash
node ../../../../tools/screens.mjs . <out> "#/" "#/r/01/1" "#/r/03/6"
```
