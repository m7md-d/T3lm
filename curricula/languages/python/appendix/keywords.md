# سجلّ تغطية الكلمات

خمسٌ وثلاثون كلمةً محجوزة في Python 3.14، وأربع كلماتٍ ليّنة. **وكلُّ واحدةٍ هنا
لها موضع**: إمّا وقفةٌ في إقليم، وإمّا إعلانٌ صريح بأنها مفترَضةٌ معروفة أو متروكةٌ
لمنهجٍ آخر.

القائمة مولَّدة من `keyword.kwlist` و`keyword.softkwlist`، لا مكتوبةً باليد.

## وقفةٌ في إقليم

| الكلمة | الإقليم | ما يُقال فيها |
|---|---|---|
| `class` | `00` · `07` | جسدٌ يُنفَّذ ثم نداءُ `type`، والترتيب الخطّيّ للبحث |
| `def` | `08` | ربطٌ لكائن دالّة، لا إعلان |
| `lambda` | `02` | دالّةٌ بلا اسم، وخليّةُ الـclosure |
| `return` | `26` | وما تفعله بها `finally` |
| `yield` | `09` | إيقافُ إطارٍ واستئنافُه |
| `from` | `09` · `13` | `yield from` والتفويض · وإعادةُ المحاولة بعد فشل الاستيراد |
| `import` | `13` | تنفيذُ ملفٍّ مرّةً وربطُ اسم |
| `as` | `10` · `26` | ربطُ الاستثناء · وربطُ النمط في `case` |
| `global` · `nonlocal` | `02` | الكتابة لا تصعد إلا بإعلان، والفضاءات ثلاثة |
| `del` | `04` | إسقاطُ مرجعٍ لا حذفُ كائن |
| `is` | `04` | سؤالٌ عن الكائن، وحدُّ عقد اللغة |
| `and` | `04` | في `__eq__`، والقيمة المُعادة قيمةُ طرف |
| `not` | `03` | نفيُ نتيجة فحصٍ لا تحويلٌ إلى `bool` |
| `in` | `06` | فتحة `__contains__`، والسقوط إلى التكرار |
| `for` | `06` · `09` | بروتوكولا التكرار، والمولّد |
| `while` | `12` | الحلقة بديلاً عن التكرار الذيليّ |
| `if` · `else` | `10` | متى يكون الفحص المسبق أرخص من `try` |
| `try` · `except` | `10` · `12` | الكلفة بالنانو ثانية، والأثر بنيةً |
| `raise` | `10` | السلسلة، و`from` بين سببين |
| `finally` | `26` | الفخّ، وتحذير المترجم منه |
| `with` | `10` | فتحتان تضمنان الخروج |
| `assert` | `02` · `26` | معيارُ قبول، وتُحذَف تحت `-O` |
| `pass` | `00` · `07` | جسدٌ فارغٌ في صنفٍ يُنفَّذ |
| `None` · `True` · `False` | `04` | `is None` وحدها، و`__eq__` لما عداها |
| `match` · `case` · `_` | `26` | تفكيكُ بنيةٍ لا مقارنةُ قيمة |
| `type` (ليّنة) | `00` | كائنٌ نوعُه نفسُه، ونداءٌ يبني الأصناف |

## مفترَضةٌ معروفة

`break` · `continue` · `elif` · `or` — تحكّمٌ في التدفّق لا يفترق هنا عمّا في C،
ولا شيء فيه يُشتقّ من بديهيةٍ من الخمس. والريدمي يعلن أن أساسيات التدفّق مفترَضة.

## متروكةٌ لمنهجٍ آخر

| الكلمة | أين |
|---|---|
| `async` · `await` | [`who-waits`](../../../systems/who-waits/README.md) — والإقليم `15` يقف عند حدّ القفل |

## المعاملات التي لها وقفة

| المعامل | الإقليم |
|---|---|
| `=` | `02` — ربطٌ لا نسخ |
| `+=` وأخواتها | `03` — `__iadd__` أو `__add__` وربطٌ جديد |
| `:=` | `26` — ربطٌ داخل تعبير |
| `[]` | `06` — `__getitem__`، وبالاسم لا بالرقم في الجدول |
| `==` مقابل `is` | `04` |
| `@` (زخرفة) | `08` — سكرٌ لنداءٍ عند التعريف |
| `*` و`**` في النداء | `08` — في غلاف الـdecorator |
| `.` | `05` · `11` — بحثٌ يصعد، وكلفتُه مقيسة |
