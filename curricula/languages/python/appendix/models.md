# ورقةٌ مرجعية

قرارات اللغة، والأرقام المقيسة، وأين يُحسَم كلُّ شيء. تُقرأ بعد المنهج، ولا
تُقرأ بدله.

---

## قرارات اللغة الأربعة

| القرار | أثرُه الذي رأيتَه | الفصل |
|---|---|---|
| القيمة كائن، والاسم يشير إليها | تعديلٌ يظهر في اسمٍ آخر؛ والعدد `1` في ٢٨ بايتاً | `01` `02` |
| النوع يُعرَف وقت التشغيل | `area("ab", 3)` تعمل، والرابع يفشل عند `w * h` | `00` `06` |
| الملفّ يُنفَّذ بلا خطوة ترجمةٍ تراها | `NameError` بعد أن عمل نصفُ البرنامج | `00` `12` |
| واجهة C مفتوحة | عدّادُ مراجعٍ في عقدٍ عامّ، ومنه القفل، ومنه NumPy | `15` `16` `23` |

---

## أين يُحسَم ماذا

| ما يُحسَم | متى | كيف تراه |
|---|---|---|
| المحلّيّ من العالميّ | وقت الترجمة | `LOAD_FAST` مقابل `LOAD_GLOBAL` (`12`) |
| الثوابت على قيمٍ حرفية | وقت الترجمة | `co_consts` فيه `86400` (`12`) |
| قائمةُ ترتيب البحث | عند إنشاء الصنف | `__mro__`، والتعارض يُرفَض هناك (`08`) |
| القيمة الافتراضية للمعامِل | عند تنفيذ `def` | `add.__defaults__` (`05`) |
| النوع | وقت التشغيل | `type(v)` (`00`) |
| الطريقة التي تُنادى | وقت التشغيل | البحث في `__mro__` بالترتيب (`08`) |
| تحرير الكائن | حين يبلغ العدّاد صفراً | ترتيبُ `__del__` في المخرَج (`15`) |
| تحرير الدورة | عند جولة الجمع | `gc.collect()` يعيد عدداً (`15`) |

## الأرقام المقيسة

من جهازٍ واحد، والثابت هو النسبة. وما ليس زمناً ثابتٌ على Python 3.14.

| ما قيس | الرقم | الفصل |
|---|---|---|
| حجم `int` | ٢٨ بايتاً · و`2**1000` في ١٦٠ | `02` |
| `list` بألف عدد | ٨٠٥٦ للحاوية + ٢٨ ألفاً للقيم | `02` `17` |
| `array('q')` بألف | ٨٣٢٠ بايتاً تحمل القيم | `02` |
| قاموسٌ بـ`__dict__` مقابل `__slots__` | ٣٤٤ مقابل ٤٨ بايتاً | `07` |
| البحث في قاموسٍ بألف مقابل ١٠ ملايين | ٣٩٫٦ مقابل ٧٨٩٫٧ ns | `04` |
| مولّدٌ مقابل قائمةٍ بمئة ألف صفّ | ٢٠٨ مقابل ٨٠٠٩٨٤ بايتاً | `10` |
| اسمٌ عالميّ مقابل محلّيّ في حلقة | ١٧٫٨ مقابل ١٤٫٣ ms | `12` |
| خيطان على حسابٍ في Python | ×١٫٠٢ — لا توازي | `16` |
| ثمانيةُ خيوطٍ على انتظار | ×٧٫٧٨ | `16` |
| أربعُ عملياتٍ على حساب | ×٣٫٢٣ | `16` |
| جمعُ ٥ ملايين: حلقة · `sum` · `nd.sum` | ١٠١٫٧٥ · ٢٣٫٢٧ · ٠٫٦٦ ms | `21` |
| `nd.sum` على خمس قيم | ×٤٫٨ أبطأ من `sum` | `21` |
| `np.vectorize` مقابل `np.where` | ×٢٩ أبطأ | `21` |
| شريحةٌ · نسخةٌ · فهرسةٌ بقائمة | ٠٫٠ · ٥٫٩ · ٢٥٫٣ ms | `19` |
| `memoryview` مقابل `tobytes` | ٠٫٠ مقابل ١٦٫٤ ms | `22` |
| خيطان على حلقةِ C عبر cffi | ×١٫٨٨ — توازٍ | `25` |

## البروتوكولات المستعملة

| ما تكتبه | ما يُنادى على **النوع** | الفصل |
|---|---|---|
| `len(a)` | `__len__`، وتسقط إليها `bool` | `06` |
| `a[k]` · `k in a` · `for x in a` | `__getitem__` · `__contains__` · `__iter__` | `06` |
| `a + b` · `a * b` | `__add__` · `__mul__` | `06` |
| `a == b` | `__eq__`، ويُبطِل `__hash__` إن عُرِّف وحده | `04` `08` |
| `hash(a)` | `__hash__`، ويلزم أن يتّفق مع `__eq__` | `04` |
| `match a: case C(x)` | `__match_args__` | `06` |
| `memoryview(a)` | البروتوكول العازل | `22` |
| `with a:` | `__enter__` · `__exit__` | `15` |

## ثلاث حالاتٍ للمِلكية عبر الحدّ

| ما تفعله دالّة C | من يملك | ما عليك |
|---|---|---|
| تقرأ مخزنك | Python | اسمٌ حيٌّ على الكائن أثناء النداء |
| تكتب في مخزنك | Python | مخزنٌ قابلٌ للكتابة ومتجاور |
| تخصّص وتعيد مؤشّراً | C | `ffi.gc`، أو نداءُ التحرير في كل مسار |
