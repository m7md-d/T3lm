# Rust — ما يثبته المترجم

منهج عن بنية Rust: المِلكية والاستعارة والأعمار ونظام السمات، وما الذي يثبته
المترجم عن كودك قبل أن يعمل.

يبدأ بفصل نظري واحد يعرض قصّة اللغة وبديهياتها ونظام أنواعها كاملاً، ثم ينقلب:
تبني مفكِّك نصّ في مئة سطر، وتقضي عشرة فصول في تفكيكه، ثم فصلاً أخيراً في كتابته
كما تُكتب Rust. وكل فصل يبدأ من بذرة خلّفها الذي قبله.

والسؤال الذي يتكرّر في كل فصل: ما الذي يمنعه المترجم، وبأي ثمن يمنعه؟

---

## لمن كُتب

لمن يعرف **C** جيداً، ولم يكتب Rust.

يفترض عندك المؤشّرات، والمكدّس والكومة، و`malloc/free`، والبنى، والمحاذاة،
وأخطاء الذاكرة التي عشتَها: قراءة بعد تحرير، وتحرير مزدوج، وتجاوز حدود. لن
يُشرح شيء من ذلك هنا، وستُشرح Rust بوصفها جواباً على تلك الأخطاء بالذات.

ولا يفترض عندك شيئاً غير ذلك. لا لغةً ثانية، ولا كوداً كتبتَه، ولا مشروعاً
بنيتَه؛ المفكِّك يُبنى أمامك من سطره الأول.

---

## الإصدار المستهدف

```
rustc 1.98.0
```

كل مخرَج هنا منقول من تشغيل على هذا الإصدار، وكل رفض للمترجم منقول بنصّه.
و`python3 tools/verify.py` يعيد ترجمة كل لوحة في المنهج ويقارنها بتشغيلها، فإن
اختلفتا فشل الفحص.

والأحجام تفترض هدفاً 64-بت، فـ`&T` ثماني بايتات و`String` أربع وعشرون. إن بنيتَ
لهدف 32-بت فنصِّف كل مؤشّر، والنسب تبقى كما هي.

والإصدارة (edition) قرار لغويّ يُعلن في `Cargo.toml` أو في سطر الأمر:
`rustc --edition 2024`. نفس المترجم يقبل ويرفض أشياء مختلفة بحسبها، وترى ذلك
بعينك في الفصل ٠٠.

## كيف تُدرَس هذه المادة

قاعدة واحدة، وكسرها يُبطل المنهج:

> حين يُطلب منك **توقّع** مخرَج أو رفض، اكتبه قبل أن تشغّل. حرفياً، على ورقة أو
> في ملفّ. ثم شغّل.

ولا تقرأ فصلاً قبل ما قبله، فكل فصل يهدم شيئاً بناه سابقه.

ورفض المترجم مادّة تدريس هنا لا عقبة. ولكل رفض رمز مثل `E0502`، وأمر يشرحه:

```bash
rustc --explain E0502
```

## البديهيات الخمس

كل ما سيبدو غريباً في Rust يعود إلى خمسة قرارات، ولكلٍّ منها ادّعاء تتحقّق منه
بنفسك:

| # | البديهية | أوّل ما يتساقط منها |
|---|---|---|
| ١ | لكل قيمةٍ مالكٌ واحد، وتموت بموته | `Drop` في لحظةٍ معلومة · لا تحرير مزدوج |
| ٢ | كاتبٌ واحد أو قرّاءٌ كثيرون، ولا يجتمعان | `&mut` حصريّ · لا سباق بيانات في الآمن |
| ٣ | لا مرجعَ يعيش أطول من مرجوعه | `'a` في التواقيع · لا مؤشّر متدلٍّ |
| ٤ | لا سلوك غير معرَّفٍ في الآمن | الفيض معرَّف · `unsafe` كلمةٌ تُفتَّش |
| ٥ | التجريد بلا كلفةٍ في وقت التشغيل | التوحيد الشكليّ · `Option<&T>` بحجم `&T` |

وشرح كل بديهية ودليلها في الجزء الثاني من الفصل ٠٠، لا هنا.

## أدواتك

| الأداة | ماذا ترى بها |
|---|---|
| `rustc --explain E0502` | شرح المترجم لرمز الخطأ بأمثلته |
| `std::mem::size_of / align_of` | الحجم والمحاذاة والتخطيط الحقيقيّ |
| `-O` مقابل بلا `-O` | فرق الفيض، وفرق الدمج، وفرق السلوك غير المعرَّف |
| `#[global_allocator]` عادّ | عدد التخصيصات فعلياً — `appendix/counting-allocator.md` |
| `cargo test` | الوحدات والتكامل **وأمثلة التوثيق** |
| `cargo clippy` | أنماطٌ تُترجَم ويردّها مراجع |
| `cargo fmt` | تنسيقٌ واحد بلا نقاش |
| `cargo +nightly miri` | ما يخالف قواعد الاستعارة داخل `unsafe` |
| `rustup component add rust-src` | مصدر المكتبة القياسية، لتقرأه وتعدّ فيه |

## الطريق

ثلاثة عشر فصلاً في `regions/`:

| | | |
|---|---|---|
| `00` | **ما يثبته المترجم** | الفصل النظريّ الوحيد: تحت أي ضغط · البديهيات · نظام الأنواع · الطريق |
| `01` | **المفكِّك** | تبني مئة سطرٍ تعمل، وفيها ثلاثة أبوابٍ مفتوحة |
| `02` | **المِلكية** | النقل · `Copy` · `Drop` · `Cow` · تخصيصٌ واحد أم عشرة |
| `03` | **الاستعارة** | `NLL` · الحقول على حدة · `split_at_mut` · حارسٌ بلا وزن |
| `04` | **العمر** | الحذف وقواعده · `'static` · بنيةٌ تحمل مرجعاً · التباين |
| `05` | **الفشل** | `?` و`From` · خطأٌ خاصّ بك · `checked_*` · متى يُذعَر |
| `06` | **الشجرة** | `Box` والتعداد المتكرّر · الأسبقية · مُحلِّلٌ يعطي ٧٢ |
| `07` | **السمة** | التوحيد الشكليّ · `dyn` · السمة العامّة · النوع المرافق |
| `08` | **المكرِّر** | الكسل · المهايئات · صفريّة الكلفة مقاسة |
| `09` | **المشترَك** | `Rc` و`RefCell` · القاعدة في وقت التشغيل · الحلقة التي تسرّب |
| `10` | **الخيط** | `Send` و`Sync` · `Arc<Mutex>` · القناة · النطاق |
| `11` | **الحدّ** | `unsafe` · المؤشّر الخام · السلوك غير المعرَّف · ما لا يُثبَت |
| `12` | **كيف تُكتب Rust** | `cargo` · الوحدات · التوثيق · الاختبار · `clippy` · الإصدارة |

الفصل ٠٠ نظريّ، والفصول ٠١–١١ تفكيك، والفصل ١٢ كتابة. وكل فصل يبدأ من بذرة
خلّفها الذي قبله: البذور الثلاث التي تفتحها في الفصل ٠١ تُغلق في ٠٤ و٠٥ و٠٦.

## ما في المستودع

| | |
|---|---|
| `regions/` | الفصول الثلاثة عشر — وهي المصدر الوحيد للمحتوى |
| `appendix/` | مرجعان يُفتحان أثناء العمل: رموز الرفض، والمخصِّص العادّ |
| `programs/` | **البرامج الكاملة** التي خرجت منها لوحات المخرَجات، وفيها حزمة `12-calc` |
| `tools/verify.py` | يترجم كل لوحةٍ ويقارنها بتشغيلٍ حقيقيّ |
| `site/` | الموقع، وفيه جدول الاشتقاق |

```bash
python3 tools/verify.py     # كل لوحة في المنهج مقابل تشغيل حقيقي
```
