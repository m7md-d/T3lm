# البرامج الكاملة

الماركداون يعرض مقتطعات، بضعة أسطر تخصّ اللقطة. وهنا البرامج الكاملة التي خرجت
منها تلك المقتطعات، ومنها تُطبع اللوحات.

```bash
python3 tools/verify.py
```

يترجم كل لوحةٍ في `regions/` ويقارنها بتشغيلٍ حقيقيّ. والمقتطع يُربَط بملفّه هنا:

```
<!-- part: 06-arena -->     ← programs/06-arena.rs، ويُقارَن المخرَج حرفياً
<!-- runs: 07-dispatch-bench -->  ← يُفحَص أنه يعمل، والأرقام تختلف بين تشغيلين
```

**والملفّ الذي يحتاج علماً في سطر الأمر يعلنه في أوّل سطرٍ منه:**

```rust
//! rustc: -O
```

## الحزم

المجلّدات فيها حزم `cargo` كاملة، لا ملفّاتٍ مفردة:

| | |
|---|---|
| `12-calc/` | حاسبة الفصل ١٢ — ١٣ اختباراً تمرّ بـ`cargo test` |
| `12-semver-fails/` | حزمتان تُظهران أثر `#[non_exhaustive]`؛ **و`app` يُرفَض عمداً**، ولاحقةُ `-fails` تخبر الفاحص بذلك |

و`verify.py` يشغّل `cargo test` في كل حزمةٍ منها.

## للقارئ

هذه الملفّات تُنسخ وتُشغَّل كما هي:

```bash
rustc --edition 2024 06-arena.rs && ./06-arena
```

فإن اختلف عندك شيء، فتتبّعه: الإصدار، أو المعمارية، أو علَم في سطر الأمر.
