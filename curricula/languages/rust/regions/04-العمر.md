# الإقليم ٠٤ — العمر

> رأيتَ في الإقليم السابق أن حرفين — `'a` — يقلبان البرنامج من مرفوضٍ إلى مقبول.
>
> هنا تعرف ما هما. **والخلاصة التي ستخرج بها: `'a` ليست مدّةً تُقاس بالثواني ولا
> بالأسطر. هي اسمُ علاقةٍ بين مُدخلٍ ومُخرَج**، والمترجم يحلّها كما يحلّ معادلة.
>
> وبها تُغلق البذرة الأولى من الإقليم ٠١ إغلاقاً تامّاً.

## البذرة: من أين يُستعار المُرجَع؟

دالّةٌ تُرجع أطول النصّين:

```rust
fn longer(a: &str, b: &str) -> &str {
    if a.len() >= b.len() { a } else { b }
}
```

<!-- err: E0106 -->

```

```

**«does not say whether it is borrowed from `a` or `b`»** — هذا هو السؤال كلّه.

ولاحظ أن المترجم لم يشتكِ من الجسد. الجسد يُرجع أحدهما بحسب الطول، وهو أمرٌ
يُعرَف عند التشغيل. **والمستدعي يحتاج الجواب وقت الترجمة**، فلا بدّ من عقدٍ في
التوقيع.

## العمر علاقة، لا مدّة

اكتب التوقيع كما اقترحه المترجم، ثم استدعِها بمُدخلين عمرهما مختلف:

```rust
fn longer<'a>(a: &'a str, b: &'a str) -> &'a str {
    if a.len() >= b.len() { a } else { b }
}

fn main() {
    let x = String::from("12");
    let out;
    {
        let y = String::from("3000");
        out = longer(&x, &y);
        println!("داخل النطاق: {out}");
    }
    println!("خارجه: {out}");
}
```

<!-- err: E0597 -->

```
error[E0597]: `y` does not live long enough
  --> c02.rs:10:26
   |
 9 |         let y = String::from("3000");
   |             - binding `y` declared here
10 |         out = longer(&x, &y);
   |                          ^^ borrowed value does not live long enough
11 |         println!("داخل النطاق: {out}");
12 |     }
   |     - `y` dropped here while still borrowed
13 |     println!("خارجه: {out}");
   |                       --- borrow later used here
```

`'a` واحدة والمُدخلان اثنان، **فيحلّها المترجم إلى الأقصر**. والسطر الأخير يطلب
النتيجة بعد موت `y`، فيسقط.

**فاقرأ `'a` هكذا:** «المُرجَع صالحٌ ما دام كلا المُدخلين صالحاً». هي قيدٌ على
المستدعي، وليست وصفاً لما يحدث في الجسد.

## الحذف: ثلاث قواعد تكتبها عنك

أكثر التواقيع لا تحمل `'a` مكتوبة. توقّع مخرَج هذا:

<!-- part: 04-elision -->

```rust
fn first_word(s: &str) -> &str {
    s.split(' ').next().unwrap_or("")
}

impl<'a> Lexer<'a> {
    fn src(&self) -> &str { self.src }
    fn tail(&self) -> &'a str { &self.src[self.pos..] }
}
```

المخرَج:

```
سعر
سعر 12 + 30 | 2 + 30
```

القواعد ثلاث، وتُطبَّق بالترتيب:

| # | القاعدة |
|---|---|
| ١ | كل مُدخلٍ مستعار يأخذ عمراً خاصّاً به |
| ٢ | مُدخلٌ مستعارٌ **واحد** ⇒ المُرجَع يأخذ عمره |
| ٣ | فيها `&self` ⇒ المُرجَع يأخذ عمر `self` |

`first_word` تمرّ بالثانية. و`src` تمرّ بالثالثة. **و`longer` لا تمرّ بشيء** —
مُدخلان مستعاران ولا `self`، فوقع `E0106`.

**و`tail` تكتب `'a` لتخالف القاعدة الثالثة**، فتربط المُرجَع بالنصّ بدل المفكِّك.
وهو الفرق الذي دفعتَ ثمنه في الإقليم السابق.

## `'static` — ما يعيش مع البرنامج

النصّ الحرفيّ لا يُخصَّص ولا يُحرَّر: هو بايتاتٌ في الملفّ التنفيذيّ.

```rust
fn main() {
    let lit: &'static str = "أنا في الملفّ التنفيذيّ";
    println!("{lit}");

    let owned = String::from("أنا في الكومة");
    let borrowed: &str = &owned;
    println!("{borrowed}");

    println!("{}", std::mem::size_of::<&'static str>());
    println!("{}", std::mem::size_of::<&str>());
}
```

<!-- out -->

```
أنا في الملفّ التنفيذيّ
أنا في الكومة
16
16
```

**والرقمان متساويان — وهذا هو المكسب.**

`&'static str` و`&'a str` نوعان مختلفان عند المترجم، **وتمثيلٌ واحد عند المعالج**:
ستّ عشرة بايتاً، مؤشّرٌ وطول. العمر **يُمحى بعد الفحص**، فلا يبقى منه بايتٌ في
البرنامج.

## و`'static` في التوقيع قيدٌ على المستدعي

```rust
fn keep(s: &'static str) -> &'static str { s }

fn main() {
    println!("{}", keep("حرفيّ"));

    let owned = String::from("مملوك");
    println!("{}", keep(&owned));
}
```

ولهذا يُقال في مجتمع Rust إن `'static` في توقيعٍ **رائحةُ تصميم** غالباً: من كتبها
هرباً من `E0106` نقل مشكلته إلى كل من يستدعيه.

## `T: 'static` معناه آخر

نفس الكلمة على **معامل نوع** تقول شيئاً مختلفاً تماماً:

```rust
use std::fmt::Debug;

fn owns_it<T: Debug + 'static>(x: T) {
    println!("{x:?}");
}

fn main() {
    let s = String::from("مملوك");
    owns_it(s);

    owns_it("حرفي");
    owns_it(42);
}
```

توقّع: أيّها يمرّ؟

المخرَج:

```
"مملوك"
"حرفي"
42
```

**الثلاثة تمرّ.** و`String` مملوكةٌ في الكومة وتموت في نهاية `main` — ومع ذلك
تحقّق `'static`.

لأن `T: 'static` تعني: **«النوع `T` لا يحمل داخله استعارةً أقصر من عمر البرنامج»**.
والنوع المملوك لا يحمل استعارةً أصلاً، فيحقّقها مهما قصر عمر **القيمة**.

## ويرفض ما يحمل استعارة

غيّر سطراً واحداً — مرّر مرجعاً بدل القيمة:

```rust

fn owns_it<T: Debug + 'static>(x: T) {
    println!("{x:?}");
}

fn main() {
    let t = String::from("مملوك");
    owns_it(&t);
}
```

ألّا يحمل استعارةً قد تموت قبله. وستراه في إقليم الخيوط بحرفه.

## البنية لا تُعمَّر فوق مرجعها

`Lexer<'a>` بنيةٌ تحمل نافذة. فماذا يمنعها أن تعيش بعد نصّها؟

```rust
struct Lexer<'a> {
    src: &'a str,
    pos: usize,
}

fn main() {
    let lx;
    {
        let src = String::from("سعر 12");
        lx = Lexer { src: &src, pos: 0 };
    }
    println!("{}", lx.pos);
}
```

<!-- err: E0597 -->

```
error[E0597]: `src` does not live long enough
  --> c08.rs:10:27
   |
 9 |         let src = String::from("سعر 12");
   |             --- binding `src` declared here
10 |         lx = Lexer { src: &src, pos: 0 };
   |                           ^^^^ borrowed value does not live long enough
11 |     }
   |     - `src` dropped here while still borrowed
12 |     println!("{}", lx.pos);
   |                    ------ borrow later used here
```

**والسطر المستعمَل `lx.pos`** — عددٌ صحيح لا علاقة له بالنصّ. ومع ذلك رُفض.

لأن `'a` معامل **للنوع كلّه**: `Lexer<'a>` نوعٌ لا يصلح خارج `'a` بأي حقلٍ من
حقوله. فالبنية التي تحمل مرجعاً **تكتسب قيده**، وهذا ما تعنيه `<'a>` في تعريفها.

## عمران، لأن المصدرين اثنان

مُحلِّلٌ يمسك النصّ ويمسك شريحةَ رموزٍ منه:

```rust
struct Parser<'src, 'tok> {
    src: &'src str,
    tokens: &'tok [&'src str],
}

impl<'src, 'tok> Parser<'src, 'tok> {
    fn source(&self) -> &'src str { self.src }
    fn count(&self) -> usize { self.tokens.len() }
}

fn main() {
    let src = String::from("سعر 12 + 30");
    let toks: Vec<&str> = src.split_whitespace().collect();

    let p = Parser { src: &src, tokens: &toks };
    println!("{} · {}", p.source(), p.count());
}
```

<!-- out -->

```
سعر 12 + 30 · 4
```

`'tok` عمر المتّجه، و`'src` عمر النصّ. **والرموز نفسها `&'src str`** — نوافذ على
النصّ وإن سكنت في متّجهٍ أقصر عمراً.

فلو دمجتهما في عمرٍ واحد لأجبرتَ المتّجه على أن يعيش بحياة النصّ. **وعمرٌ إضافيّ
في التوقيع حرّيةٌ إضافية للمستدعي**، لا تعقيدٌ زائد.

## التباين: الطويل يمرّ حيث يُطلب القصير

```rust
fn shortest<'a>(a: &'a str, b: &'a str) -> &'a str {
    if a.len() <= b.len() { a } else { b }
}

fn main() {
    let long: &'static str = "نصٌّ حرفيّ يعيش مع البرنامج";
    let owned = String::from("قصير");

    let r = shortest(long, &owned);
    println!("{r}");
}
```

<!-- out -->

```
قصير
```

`long` عمرها `'static`، و`&owned` عمرها سطران. ومع ذلك مرّتا في معاملٍ واحد.

**لأن `&'long T` يصلح حيث يُطلب `&'short T`** — النافذة الأطول تُقصَّر بلا خطر.
اسمُ هذا **التغاير** (covariance)، وهو ما يجعل معظم الكود يمشي بلا أن تفكّر فيه.

## و`&mut` يغلق الباب

نفس الفكرة خلف مرجعٍ قابلٍ للتعديل:

```rust
fn assign<'a>(dst: &mut &'a str, src: &'a str) {
    *dst = src;
}

fn main() {
    let mut r: &'static str = "طويل";
    {
        let s = String::from("قصير");
        assign(&mut r, &s);
    }
    println!("{r}");
}
```

<!-- err: E0597 -->

```
error[E0597]: `s` does not live long enough
  --> c07.rs:9:24
   |
 6 |     let mut r: &'static str = "طويل";
   |                ------------ type annotation requires that `s` is borrowed for `'static`
 7 |     {
 8 |         let s = String::from("قصير");
   |             - binding `s` declared here
 9 |         assign(&mut r, &s);
   |                        ^^ borrowed value does not live long enough
10 |     }
   |     - `s` dropped here while still borrowed
```

**تخيّل لو مرّ**: لكتب `assign` نافذةً قصيرة في مكانٍ نوعه `&'static str`، ثم قرأ
`println!` نافذةً على ذاكرةٍ ميّتة. هذا هو المؤشّر المتدلّي بعينه.

فما وراء `&mut` **لا يتغاير**: العمر هناك ثابتٌ لا يقصر ولا يطول. والسبب أن ما
تكتب فيه لا يُقصَّر بأمان.

## المفكِّك: الحذف يكتبها عنك

بعد كل هذا، انظر كم `'a` تحتاج في المفكِّك فعلاً:

```rust
#[derive(Debug)]
struct Token<'a>(&'a str);

fn lex(src: &str) -> Vec<Token<'_>> {
    src.split_whitespace().map(Token).collect()
}

fn main() {
    let src = String::from("سعر 12 + 30");
    let tokens = lex(&src);

    println!("{tokens:?}");
    println!("أوّلها بطول {}", tokens[0].0.chars().count());
}
```

<!-- out -->

```
[Token("سعر"), Token("12"), Token("+"), Token("30")]
أوّلها بطول 3
```

**ولا `'a` واحدة في `lex`.** مُدخلٌ مستعارٌ واحد، فالقاعدة الثانية كافية.

و`'_` تقول: «هنا عمرٌ، والمترجم يعرف أيّه». وهي مطلوبةٌ لأن `Vec<Token>` بلا شيء
كان سيخفي أن المُخرَج مربوطٌ بالمُدخل. **فالكتابة هنا للقارئ، والاستنتاج
للمترجم.**

## البذرة الأولى، مُغلَقة

عد إلى بذرة الإقليم ٠١: مفكِّكٌ يتقدّم ونوافذُ خرجت منه:

```rust
struct Lexer<'a> {
    src: &'a str,
    pos: usize,
}

impl<'a> Lexer<'a> {
    fn new(src: &'a str) -> Self {
        Lexer { src, pos: 0 }
    }
    fn rest(&self) -> &'a str {
        &self.src[self.pos..]
    }
    fn bump(&mut self, n: usize) {
        self.pos += n;
    }
}

fn main() {
    let src = String::from("سعر 12 + 30");
    let mut lx = Lexer::new(&src);

    let a = lx.rest();
    lx.bump(7);
    let b = lx.rest();

    println!("{a}");
    println!("{b}");
    println!("النصّ حيٌّ، والاثنان نافذتان عليه: {}", src.len());
}
```

<!-- out -->

```
سعر 12 + 30
12 + 30
النصّ حيٌّ، والاثنان نافذتان عليه: 14
```

نافذتان حيّتان معاً، والمفكِّك تحرّك بينهما بـ`&mut self`. **والذي أجاز ذلك سطرٌ
واحد**: `fn rest(&self) -> &'a str`.

| | ما يقيّده |
|---|---|
| `-> &str` | حياة المفكِّك — فيقفله أوّل نافذة |
| `-> &'a str` | حياة النصّ — فالمفكِّك حرّ |

**وهذه هي الرافعة التي اشتراها هذا الإقليم**: أن تعرف بأي شيءٍ تربط مُخرَجك.

## بذرة

المِلكية والاستعارة والعمر أجابت عن **الذاكرة**. والبرنامج الآن لا يقرأ ما مات
ولا يحرّر مرّتين ولا يكتب من كاتبين.

وبقيت البذرة الثانية من الإقليم ٠١ كما تركناها: `parse().unwrap()` و`acc + rhs`
بلا حارس. **توقيعٌ يقول `Result<i64, EvalError>` وفيه مسارٌ يخرج بالذعر.**

فالنوع الذي أعلنتَه **يكذب**. والإقليم القادم عن جعله صادقاً.
