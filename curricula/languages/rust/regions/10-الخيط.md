# الإقليم ١٠ — الخيط

> ظهرت في آخر الإقليم السابق كلمةٌ لم تُشرَح: **`Send`** — سمةٌ فارغة منعت `Rc` من
> العبور إلى خيط.
>
> والدعوى التي يقوم عليها هذا الإقليم: **اللغة لم تُضِف شيئاً لأجل التزامن**. كل ما
> بناه المترجم في تسعة أقاليم — المِلكية والاستعارة والأعمار — كان هو نفسه ما يمنع
> سباق البيانات. والزيادة **سمتان فارغتان**.

## البذرة: أربعة خيوط ومتّجهٌ واحد

أبسط ما يُكتب: كل خيطٍ يزيد خانته.

```rust
use std::thread;

fn main() {
    let mut counts = vec![0u64; 4];

    for i in 0..4 {
        thread::spawn(move || {
            counts[i] += 1;
        });
    }

    println!("{counts:?}");
}
```

<!-- err: E0382 -->

```
error[E0382]: borrow of moved value: `counts`
  --> i01.rs:12:16
   |
 4 |     let mut counts = vec![0u64; 4];
   |         ---------- move occurs because `counts` has type `Vec<u64>`, which does not implement the `Copy` trait
 6 |     for i in 0..4 {
   |     ------------- inside of this loop
 7 |         thread::spawn(move || {
   |                       ------- value moved into closure here, in previous iteration of loop
...
12 |     println!("{counts:?}");
   |                ^^^^^^ value borrowed here after move
```

**ولا كلمة عن الخيوط في الرسالة.** `move` نقلت المتّجه إلى المغلَّف الأوّل، فلم يبق
شيءٌ للثاني.

هذا `E0382` نفسه الذي قابلتَه في إقليم المِلكية. **والقاعدة التي منعت السباق هنا
هي قاعدة النقل**، وقد كُتبت قبل أن تُذكر الخيوط.

## ولا استعارةٌ تعبر بلا ضمان

احذف `move` وجرّب الاستعارة:

```rust
use std::thread;

fn main() {
    let src = String::from("سعر 12 + 30");

    let h = thread::spawn(|| {
        println!("{}", src.len());
    });

    h.join().unwrap();
}
```

<!-- err: E0373 -->

```
error[E0373]: closure may outlive the current function, but it borrows `src`, which is owned by the current function
 --> i02.rs:6:27
  |
6 |     let h = thread::spawn(|| {
  |                           ^^ may outlive borrowed value `src`
7 |         println!("{}", src.len());
  |                        --- `src` is borrowed here
  |
note: function requires argument type to outlive `'static`
help: to force the closure to take ownership of `src` (and any other referenced variables), use the `move` keyword
```

**«requires argument type to outlive `'static`»** — وهذا هو `T: 'static` الذي
شرحتَه في إقليم العمر، بنفس معناه: **ما يعبر يجب ألّا يحمل استعارةً قد تموت**.

و`join` في السطر الأخير لا تُغيّر شيئاً عند المترجم: **توقيع `spawn` لا يعرف أنك
ستنضمّ**، فيطلب الضمان الأقوى.

## `Arc<Mutex<T>>` — المشاركة عبر الحدّ

نفس شكل الإقليم السابق، بعدّادٍ ذرّيّ وقفل:

```rust
use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let counter = Arc::new(Mutex::new(0u64));
    let mut hs = Vec::new();

    for _ in 0..8 {
        let c = Arc::clone(&counter);
        hs.push(thread::spawn(move || {
            for _ in 0..100_000 {
                *c.lock().unwrap() += 1;
            }
        }));
    }

    for h in hs {
        h.join().unwrap();
    }

    println!("المجموع: {}", counter.lock().unwrap());
    println!("المنتظَر: {}", 8 * 100_000);
}
```

<!-- out -->

```
المجموع: 800000
المنتظَر: 800000
```

**والمهمّ ما لا تراه:** لا يوجد في هذا البرنامج طريقةٌ لقراءة العدّاد بلا قفل.
`Mutex<u64>` **تملك** الرقم، ولا سبيل إليه إلا عبر `lock`.

قارِن بـC: القفل والبيان شيئان منفصلان، والربط بينهما في رأسك وفي التعليقات. **وهنا
الربط في النوع** — وهذا هو الفرق البنيويّ.

و`lock()` تُرجع `Result` لسببٍ سنراه بعد شوطين.

## `Send` و`Sync` — سمتان فارغتان

كل ما أضافته اللغة للتزامن:

```rust
use std::cell::{Cell, RefCell};
use std::sync::{Arc, Mutex};

fn send<T: Send>() -> &'static str { "نعم" }
fn sync<T: Sync>() -> &'static str { "نعم" }

fn main() {
    println!("i64             Send={} Sync={}", send::<i64>(), sync::<i64>());
    println!("String          Send={} Sync={}", send::<String>(), sync::<String>());
    println!("&String         Send={} Sync={}", send::<&String>(), sync::<&String>());
    println!("Cell<i64>       Send={}", send::<Cell<i64>>());
    println!("RefCell<i64>    Send={}", send::<RefCell<i64>>());
    println!("Mutex<i64>      Send={} Sync={}", send::<Mutex<i64>>(), sync::<Mutex<i64>>());
    println!("Arc<Mutex<i64>> Send={} Sync={}", send::<Arc<Mutex<i64>>>(), sync::<Arc<Mutex<i64>>>());
}
```

<!-- out -->

```
i64             Send=نعم Sync=نعم
String          Send=نعم Sync=نعم
&String         Send=نعم Sync=نعم
Cell<i64>       Send=نعم
RefCell<i64>    Send=نعم
Mutex<i64>      Send=نعم Sync=نعم
Arc<Mutex<i64>> Send=نعم Sync=نعم
```

| السمة | معناها |
|---|---|
| `Send` | يجوز **نقل** القيمة إلى خيطٍ آخر |
| `Sync` | يجوز مشاركة `&T` بين خيوط — أي `&T: Send` |

**والسطران الرابع والخامس ناقصان عمداً:** `Cell` و`RefCell` تحملان `Send` ولا
تحملان `Sync`. تستطيع أن **تنقلهما**، ولا تستطيع أن تشاركهما — لأن عدّاد الاستعارة
فيهما عددٌ عاديّ.

والسمتان تُشتقّان تلقائياً: **النوع يحملهما إن حملهما كل حقلٍ فيه**. فلا تكتبهما، ولا
تُسأل عنهما، حتى تُخالف.

## والمخالفة رفضٌ بحرفه

```rust
use std::cell::Cell;

fn is_sync<T: Sync>() -> bool { true }

fn main() {
    println!("{}", is_sync::<Cell<i64>>());
}
```

<!-- err: E0277 -->

```
error[E0277]: `Cell<i64>` cannot be shared between threads safely
 --> i08.rs:6:30
  |
6 |     println!("{}", is_sync::<Cell<i64>>());
  |                              ^^^^^^^^^ `Cell<i64>` cannot be shared between threads safely
  |
  = help: the trait `Sync` is not implemented for `Cell<i64>`
  = note: if you want to do aliasing and mutation between multiple threads, use `std::sync::RwLock` or `std::sync::atomic::AtomicI64` instead
```

**واقرأ سطر `note`:** المترجم يسمّي لك البديلين الصالحين للعبور. وهذا نمطٌ يتكرّر في
رسائل Rust — الرفض يحمل معه الطريق.

## السباق غير قابلٍ للتعبير

وهنا دعوى الإقليم كلّها. جرّب أن تكتب سباق بياناتٍ **صريحاً** في الكود الآمن:

```rust
use std::thread;

fn main() {
    let mut total = 0u64;

    thread::scope(|s| {
        s.spawn(|| { total += 1; });
        s.spawn(|| { total += 1; });
    });

    println!("{total}");
}
```

<!-- err: E0499 -->

```
error[E0499]: cannot borrow `total` as mutable more than once at a time
 --> i11.rs:8:17
  |
6 |     thread::scope(|s| {
  |                    - has type `&'1 Scope<'1, '_>`
7 |         s.spawn(|| { total += 1; });
  |         ---------------------------
  |         |       |    |
  |         |       |    first borrow occurs due to use of `total` in closure
  |         |       first mutable borrow occurs here
8 |         s.spawn(|| { total += 1; });
  |                 ^^   ----- second borrow occurs due to use of `total` in closure
  |                 |
  |                 second mutable borrow occurs here
```

**`E0499`.** هو نفسه الذي قابلتَه في الإقليم ٠٣ حين كتبتَ `&mut src` مرّتين في
سطرين متتاليين، **في برنامجٍ بخيطٍ واحد**.

سباق البيانات تعريفه: كاتبٌ مع أيٍّ آخر على موضعٍ واحد بلا ترتيب. **وقاعدة الاستعارة
تعريفها: كاتبٌ واحد أو قرّاءٌ كثيرون.** الجملتان واحدة.

فلم تحتج اللغة كاشف سباقاتٍ في وقت التشغيل. **ولا تحتاج أن تشغّل البرنامج لتعرف.**

## `scope` — استعارةٌ تعبر لأن العمر معروف

`spawn` تطلب `'static` لأنها لا تعرف متى ينتهي الخيط. و`scope` تعرف:

<!-- part: 10-scope -->

```rust
use std::thread;

fn main() {
    let src = String::from("سعر 12 + 30 * 2");
    let mut lens = vec![0usize; 3];

    thread::scope(|s| {
        for (i, chunk) in lens.chunks_mut(1).enumerate() {
            let text = &src;
            s.spawn(move || {
                chunk[0] = text.split_whitespace().nth(i).map(str::len).unwrap_or(0);
            });
        }
    });

    println!("{lens:?}");
    println!("النصّ ما زال هنا: {}", src);
}
```

<!-- out -->

```
[6, 2, 1]
النصّ ما زال هنا: سعر 12 + 30 * 2
```

**ولا `Arc` ولا `Mutex` ولا `clone`.** `scope` تضمن أن كل خيطٍ ينتهي قبل خروجها،
فصار للاستعارة عمرٌ يعرفه المترجم.

و`chunks_mut` هي الحيلة الثانية: **شرائح قابلة للتعديل لا تتقاطع** — نفس
`split_at_mut` التي رأيتها في الإقليم ٠٣. فلا حاجة إلى قفلٍ حين تكون المواضع
منفصلة، **والمترجم يعرف أنها منفصلة**.

## القفل يُسمَّم

فلماذا تُرجع `lock()` نوع `Result`؟

<!-- part: 10-poison -->

```rust
let c = Arc::clone(&m);
let h = thread::spawn(move || {
    let _g = c.lock().unwrap();
    panic!("سقط الخيط وهو ممسكٌ بالقفل");
});

println!("انضمام: {:?}", h.join().is_err());

match m.lock() {
    Ok(v) => println!("سليم: {v:?}"),
    Err(e) => {
        println!("مسموم: {}", e);
        println!("والبيانات ما زالت: {:?}", e.into_inner());
    }
}
```

<!-- out: قبله رسالة ذعر الخيط -->

```
انضمام: true
مسموم: poisoned lock: another task failed inside
والبيانات ما زالت: [1, 2, 3]
```

**الذعر داخل القفل يعني أن البيانات قد تكون نصف معدَّلة.** فتُعلَّم الخانة، ويُخبَر
كل من يقفل بعدها.

و`into_inner` تعطيك البيانات على أي حال — **القرار لك**: أن تُصلحها، أو تُسقط
العملية. والذي رفضته اللغة أن تأخذها **بلا أن تعرف**.

ولاحظ `h.join()` تُرجع `Err` كذلك: **ذعر الخيط يصل إلى من ينضمّ إليه**، ولا يُسقط
البرنامج كلّه.

## القناة: مِلكيةٌ تعبر

بدل المشاركة، انقل:

```rust
use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::channel::<String>();

    for i in 0..3 {
        let tx = tx.clone();
        thread::spawn(move || {
            tx.send(format!("من الخيط {i}")).unwrap();
        });
    }
    drop(tx);

    let mut got: Vec<String> = rx.iter().collect();
    got.sort();
    for g in &got {
        println!("{g}");
    }
    println!("العدد: {}", got.len());
}
```

<!-- out -->

```
من الخيط 0
من الخيط 1
من الخيط 2
العدد: 3
```

**`send` تأخذ القيمة بالمِلكية**، فمن أرسلها لم يعد يملكها. فلا سباق أصلاً — لا
لأن قفلاً منع، بل لأن **مالكاً واحداً في كل لحظة**.

و`drop(tx)` سطرٌ ضروريّ: `rx.iter()` تنتهي حين يموت **كل** المُرسِلين. ولولاه لبقي
المُرسِل الأصليّ حيّاً في `main` فانتظر المستقبِل إلى الأبد.

**والترتيب غير مضمون** — لهذا `sort` قبل الطباعة.

## الذرّيّ مقابل القفل، مقيساً

ثمانية خيوطٍ تزيد عدّاداً نصف مليون مرّة، بالطريقتين:

<!-- runs: 10-atomic-vs-mutex -->

```rust
for _ in 0..N { *c.lock().unwrap() += 1; }      // قفل
for _ in 0..N { c.fetch_add(1, Relaxed); }      // ذرّيّ
```

<!-- out: بـ`-O`؛ الأزمنة تختلف عندك -->

```
Mutex  : 104.555792ms   (4000000)
Atomic : 84.056083ms   (4000000)
النسبة : 1.2×
```

**١٫٢× إلى ١٫٧× في أربع تشغيلات** — لا عشرة أضعافٍ كما يُقال.

والسبب أن `Mutex` في Rust ليست قفل نظامٍ ثقيلاً: تبدأ بمحاولةٍ ذرّية، ولا تنزل إلى
النواة إلا عند التزاحم الفعليّ. **فالفارق هنا فارق تعليماتٍ قليلة، لا فارق نداءِ
نظام.**

**والقاعدة:** اختر الذرّيّ للعدّادات والأعلام البسيطة. واختر القفل حين تحرس
**أكثر من كلمة** — لأن ذرّيَّين متتاليين ليسا عمليةً واحدة.

## المفكِّك: أربعة أسطرٍ في أربعة خيوط

كل سطرٍ يُفكَّك وحده، والرموز **نوافذ على النصّ الأصليّ**:

<!-- part: 10-parallel-lex -->

```rust
fn main() {
    let text = String::from("سعر 12 + 30\nكمية 4 * 2\nخصم 7 + 1\nمجموع 9 * 9");
    let lines: Vec<&str> = text.lines().collect();
    let mut out: Vec<Vec<Token>> = Vec::new();

    thread::scope(|s| {
        let handles: Vec<_> = lines.iter().map(|line| s.spawn(move || lex(line))).collect();
        for h in handles {
            out.push(h.join().unwrap());
        }
    });
    // … الطباعة
}
```

<!-- out -->

```
سطر 0: [Word("سعر"), Num(12), Sym('+'), Num(30)]
سطر 1: [Word("كمية"), Num(4), Sym('*'), Num(2)]
سطر 2: [Word("خصم"), Num(7), Sym('+'), Num(1)]
سطر 3: [Word("مجموع"), Num(9), Sym('*'), Num(9)]
النصّ حيّ: 59 بايت
```

**ولا نسخة واحدة للنصّ.** أربعة خيوطٍ تقرأ `&str` واحداً، و`Token<'a>` يخرج منها
حاملاً عمر النصّ.

والذي أجاز ذلك: `&str` تحمل `Sync` (قرّاءٌ كثيرون بلا كاتب)، و`scope` أعطت العمر.
**والترتيب مضمون هنا** لأن `join` بترتيب المقابض، لا بترتيب الانتهاء.

**وهذا هو ما يسمّونه «التزامن بلا خوف»**: لم تفكّر في السباق لأن الكود الذي فيه
سباقٌ لا يُترجَم.

## بذرة

عشرة أقاليم، ولم تكتب `unsafe` مرّةً واحدة.

لكن `split_at_mut` فيها `unsafe` داخلياً — قلتُها في الإقليم ٠٣ ولم أُثبتها.
و`Arc` فيها. و`Vec` كلّها مبنيّةٌ عليها. **فالمكتبة التي تحرسك مبنيّةٌ بما لا
يحرسها.**

فأين ينتهي ما يثبته المترجم؟ **وماذا يبقى عليك أنت أن تُثبته حين تكتب الكلمة؟**

**الإقليم القادم عن الحدّ** — وفيه تكتب سلوكاً غير معرَّف بيدك، وترى بعينك كيف
يتغيّر الجواب بين `-O` وبلا `-O`.
