# الإقليم ٠٢ — المِلكية

> خرجتَ من الإقليم السابق ببذرة: **مفكِّكك لا يستطيع أن يعيش بعد نصّه**. رموزه
> نوافذُ على `String` تموت قبله.
>
> هنا تفكّك المِلكية نفسها: ما الذي يحدث في الإسناد، وما الذي ينتقل، ومتى يموت
> ما انتقل. ثم تُصلح المفكِّك بطريقتين، **وتعرف ثمن كلٍّ منهما مقيساً**.

## البذرة: نصٌّ يموت قبل رموزه

الدالّة التالية تقرأ نصّاً وتُرجع رموزه. اكتبها كما يكتبها من جاء من C:

```rust
fn tokens_of_file() -> Vec<&str> {
    let src = String::from("سعر 12 + 30");
    src.split(' ').collect()
}
```

<!-- err: E0106 -->

```
error[E0106]: missing lifetime specifier
 --> a01.rs:1:28
  |
1 | fn tokens_of_file() -> Vec<&str> {
  |                            ^ expected named lifetime parameter
  |
  = help: this function's return type contains a borrowed value, but there is no value for it to be borrowed from
help: instead, you are more likely to want to return an owned value
  |
1 - fn tokens_of_file() -> Vec<&str> {
1 + fn tokens_of_file() -> Vec<String> {
```

**«no value for it to be borrowed from»** — الجملة كلّها. المُرجَع نافذةٌ، والمترجم
يسأل: نافذةٌ على ماذا؟ `src` تموت في السطر الأخير، والمدخلات صفر.

وفي C يُترجَم نظير هذا ويعمل، ثم ينهار عند مستدعٍ بعيد. **والمكسب هنا أن السؤال
جاء وقت الترجمة**، ومعه اقتراحان اثنان لا أكثر — لأن الأجوبة الممكنة اثنان.

## الإسناد ينقل

أبسط سطرين في اللغة:

```rust
fn main() {
    let a = String::from("سعر 12");
    let b = a;
    println!("{a}");
    println!("{b}");
}
```

<!-- err: E0382 -->

```
error[E0382]: borrow of moved value: `a`
 --> a02.rs:4:16
  |
2 |     let a = String::from("سعر 12");
  |         - move occurs because `a` has type `String`, which does not implement the `Copy` trait
3 |     let b = a;
  |             - value moved here
4 |     println!("{a}");
  |                ^ value borrowed here after move
```

في C يكون `b = a` نسخاً للبنية، فيصير مؤشّران إلى كومةٍ واحدة، فيحرّرها الاثنان.
وهنا **الإسناد نقلٌ**: `a` لم تعد صالحة للقراءة، وحُذفت من حساب المترجم.

**والمكسب:** التحرير المزدوج لم يُمنَع بفحصٍ في وقت التشغيل. هو **غير قابلٍ
للتعبير عنه**، لأن المالك واحد دائماً.

## ما الذي انتقل بالضبط

«نقل» كلمةٌ توحي بحركة. فقِسها:

```rust
use std::mem::size_of;

fn main() {
    let a = String::from("سعر 12 + 30 * 2");
    let pa = a.as_ptr();
    let b = a;
    let pb = b.as_ptr();

    println!("size_of::<String>() = {}", size_of::<String>());
    println!("نفس عنوان الكومة؟ {}", pa == pb);
    println!("len={} cap={}", b.len(), b.capacity());
}
```

<!-- out -->

```
size_of::<String>() = 24
نفس عنوان الكومة؟ true
len=18 cap=18
```

**الذي انتقل أربعٌ وعشرون بايتاً**: مؤشّرٌ وطولٌ وسَعة. والبايتات الثمانية عشر في
الكومة لم تتحرّك — نفس العنوان.

فالنقل **نسخُ ترويسةٍ بحجمٍ معلوم، ثم إبطالُ الأصل في دفتر المترجم**. لا استدعاء،
ولا `memcpy` للمحتوى، ولا أثرَ في الملفّ التنفيذيّ. الحركة كلّها في وقت الترجمة.

## `Copy` استثناءٌ لا يُمنَح لمن يملك

`i64` يُنسخ ولا يُنقَل. والفرق ليس في الحجم:

```rust
#[derive(Clone, Copy, Debug)]
struct Span { start: usize, end: usize }

#[derive(Clone, Copy, Debug)]
struct Named { span: Span, text: String }
```

<!-- err: E0204 -->

```
error[E0204]: the trait `Copy` cannot be implemented for this type
  --> a04.rs:8:8
   |
 7 | #[derive(Clone, Copy, Debug)]
   |                 ---- in this derive macro expansion
 8 | struct Named {
   |        ^^^^^
 9 |     span: Span,
10 |     text: String,
   |     ------------ this field does not implement `Copy`
```

`Span` ستّ عشرة بايتاً ويُنسخ. `Named` أربعون بايتاً ويُرفَض. **والقاعدة: `Copy`
لمن نسخُ بايتاته نسخةٌ كاملة صحيحة.** و`String` تملك كومةً، فنسخُ ترويستها يصنع
مالكَين.

فحين ترى نوعاً `Copy` فاعلم أنه **لا يملك شيئاً خلف نفسه**. وهذا أكثر ما تخبرك به
الكلمة.

## الموت في لحظةٍ معلومة

المالك يموت في نهاية نطاقه، وموته يستدعي `Drop`. توقّع ترتيب الأسطر الستّة:

```rust
struct Loud(&'static str);

impl Drop for Loud {
    fn drop(&mut self) { println!("مات {}", self.0); }
}

fn main() {
    let _a = Loud("أ");
    let _b = Loud("ب");
    {
        let _c = Loud("ج");
        println!("— نهاية النطاق الداخليّ —");
    }
    let d = Loud("د");
    drop(d);
    println!("— نهاية main —");
}
```

المخرَج:

```
— نهاية النطاق الداخليّ —
مات ج
مات د
— نهاية main —
مات ب
مات أ
```

ثلاثة أشياء في هذه الستّة: النطاق الداخليّ يقتل `ج` عند قوسه. و`drop(d)` تقتل `د`
**قبل** نهاية `main`. والباقي يموت **معكوسَ ترتيب ولادته**.

**و`drop` دالّةٌ عادية جسدها فارغ**: تأخذ القيمة بالمِلكية، فتموت عندها. لا كلمة
محجوزة ولا سحر — النقل وحده كافٍ.

## التمرير يأكل

النقل يقع في تمرير الوسائط كما يقع في الإسناد:

```rust
fn count_words(src: String) -> usize {
    src.split_whitespace().count()
}

fn main() {
    let src = String::from("سعر 12 + 30 * 2");
    println!("{}", count_words(src));
    println!("{}", src.len());
}
```

<!-- err: E0382 -->

```
error[E0382]: borrow of moved value: `src`
 --> a06.rs:8:20
  |
7 |     println!("{}", count_words(src));
  |                                --- value moved here
8 |     println!("{}", src.len());
  |                    ^^^ value borrowed here after move
  |
note: consider changing this parameter type in function `count_words` to borrow instead if owning the value isn't necessary
 --> a06.rs:1:21
  |
1 | fn count_words(src: String) -> usize {
  |    -----------      ^^^^^^ this parameter takes ownership of the value
```

**اقرأ الملاحظة الثانية**: المترجم يشير إلى **التوقيع**، لا إلى موضع الخطأ.
`count_words` تعدّ ولا تحتاج المِلكية، فأخذها كان قراراً خاطئاً في السطر الأوّل.

فالتوقيع في Rust **إعلانُ نيّة**: `String` يعني «سآخذها منك»، و`&str` يعني
«سأنظر». وأكثر ما يُصلَح من `E0382` يُصلَح في التوقيع.

## `clone` ثمنٌ مكتوب

لو أردتَ نسخةً حقيقية فاطلبها بالاسم:

```rust
fn main() {
    let a = String::from("سعر 12 + 30 * 2");
    let b = a.clone();

    println!("نفس عنوان الكومة؟ {}", a.as_ptr() == b.as_ptr());
    println!("نفس المحتوى؟     {}", a == b);
    println!("طولان: {} و{}", a.len(), b.len());
}
```

<!-- out -->

```
نفس عنوان الكومة؟ false
نفس المحتوى؟     true
طولان: 18 و18
```

**قارِن بشوط «ما الذي انتقل»**: هناك كان الجواب `true`، وهنا `false`. فالنقل يترك
البايتات مكانها، و**`clone` تخصيصٌ ثانٍ ونسخُ بايتات** — مكتوبةٌ في الكود بستّة
أحرف.

وهذا هو الفرق عن لغةٍ تنسخ ضمنياً: الكلفة **مرئيّة في موضعها**. حين تقرأ مراجعةً
فيها ثلاث `clone` في حلقة، ترى الثلاث.

## كم يكلّف أن يملك؟

«المِلكية أغلى» ادّعاء. قِسه بعدّادٍ يحسب كل تخصيص:

<!-- part: 02-alloc-count -->

```rust
#[global_allocator]
static A: Counting = Counting;   // يزيد COUNT وBYTES عند كل alloc

fn main() {
    let src = String::from("سعر البيت 12 زائد 30 ضرب 2 ناقص 7");
    let n = src.split_whitespace().count();

    let (c0, b0) = snap();
    let mut borrowed: Vec<&str> = Vec::with_capacity(n);
    borrowed.extend(src.split_whitespace());
    let (c1, b1) = snap();

    let mut owned: Vec<String> = Vec::with_capacity(n);
    owned.extend(src.split_whitespace().map(String::from));
    let (c2, b2) = snap();
    // … طباعة الفروق
}
```

توقّع الرقمين قبل أن تقرأ. تسعةُ رموز.

المخرَج:

```
رموز: 9
مستعير: 1 تخصيصاً · 144 بايت
مالك  : 10 تخصيصاً · 260 بايت
```

**تخصيصٌ واحد مقابل عشرة.** المستعير خصّص للمتّجه وحده؛ المالك خصّص للمتّجه
**وتسعةً للكلمات** — واحدةً لكل رمز.

وعلى ملفٍّ بمليون رمز يصير الفرق مليون استدعاءٍ للمخصِّص. **وهذا هو الثمن الذي
اشتراه العمر `'a` في الإقليم السابق.**

> `#[global_allocator]` يستبدل مخصِّص البرنامج كلّه بواحدٍ من عندك. الملفّ كاملاً
> في `appendix/counting-allocator.md`، وهو أداةُ قياسٍ ستعود إليها.

## `Cow` يستعير حتى يضطرّ

بين «يستعير دائماً» و«يملك دائماً» نوعٌ ثالث يقرّر عند التشغيل:

```rust
use std::borrow::Cow;
use std::mem::size_of;

fn normalize(w: &str) -> Cow<'_, str> {
    if w.bytes().any(|b| b.is_ascii_uppercase()) {
        Cow::Owned(w.to_ascii_lowercase())
    } else {
        Cow::Borrowed(w)
    }
}

fn main() {
    for w in ["price", "SIZE"] {
        let kind = match normalize(w) {
            Cow::Borrowed(_) => "مستعار — بلا تخصيص",
            Cow::Owned(_) => "مملوك — تخصيصٌ واحد",
        };
        println!("{w} -> {}  ({kind})", normalize(w));
    }
    println!("Cow<str>: {} بايت", size_of::<Cow<str>>());
    println!("String  : {} بايت", size_of::<String>());
}
```

<!-- out -->

```
price -> price  (مستعار — بلا تخصيص)
SIZE -> size  (مملوك — تخصيصٌ واحد)
Cow<str>: 24 بايت
String  : 24 بايت
```

`Cow` تعدادٌ من متغايرين: `Borrowed(&'a str)` و`Owned(String)`. والكلمة التي لا
تحتاج تعديلاً تمرّ **بلا تخصيص**.

**والحجم أربعٌ وعشرون** — نفس `String` بالضبط. فالمتغاير الثاني يسكن في مساحة
الأوّل، والتمييز يُخبَّأ في المؤشّر. (البديهية الخامسة: تجريدٌ لا يظهر في وقت
التشغيل.)

## النقل الجزئيّ

الحقل ينتقل وحده، والبنية تبقى بما فيها:

```rust
struct Source { name: String, text: String, line: u32 }

fn main() {
    let s = Source { name: String::from("lex.rs"),
                     text: String::from("12 + 30"), line: 1 };
    let text = s.text;
    println!("النصّ  : {text}");
    println!("الاسم : {}", s.name);
    println!("السطر : {}", s.line);
}
```

<!-- out -->

```
النصّ  : 12 + 30
الاسم : lex.rs
السطر : 1
```

`s.text` انتقلت، و`s.name` و`s.line` سليمتان. **فالمِلكية تُتتبَّع بالحقل**، لا
بالبنية.

وأوّل استعمالٍ للبنية **كلّها** يسقط:

<!-- err: E0382 -->

```
error[E0382]: borrow of partially moved value: `s`
   |
15 |     let text = s.text;
   |                ------ value partially moved here
17 |     println!("{s:?}");
   |                ^ value borrowed here after partial move
```

## أن تأخذ وتترك صالحاً

النقل الجزئيّ ممنوعٌ من **خلف مرجع**: لو أخذتَ حقلاً من `&mut self` لتركتَ البنية
ناقصة. و`mem` تحلّها بالتبادل:

```rust
use std::mem;

struct Lexer { src: String, pos: usize }

fn main() {
    let mut lx = Lexer { src: String::from("12 + 30"), pos: 7 };

    let old = mem::replace(&mut lx.src, String::from("9 * 9"));
    println!("القديم: {old:?}  ·  الحاليّ: {:?}  ·  pos={}", lx.src, lx.pos);

    let taken = mem::take(&mut lx.src);
    println!("المأخوذ: {taken:?}  ·  الحاليّ: {:?}", lx.src);
}
```

<!-- out -->

```
القديم: "12 + 30"  ·  الحاليّ: "9 * 9"  ·  pos=7
المأخوذ: "9 * 9"  ·  الحاليّ: ""
```

`replace` تضع بديلاً وتُعيد القديم. و`take` تضع **القيمة الصفرية** وتُعيد القديم —
وهي `mem::replace(x, Default::default())` باسمٍ أقصر.

**وهنا تظهر فائدة `String::new()` الفارغة**: نوعٌ له قيمةٌ صفرية صالحة يمكن أن
يُؤخذ منه بلا `Option` وبلا علامة.

## الموت داخل الحاويات

المتّجه يملك عناصره. توقّع الأسطر السبعة:

```rust
struct Loud(u32);

impl Drop for Loud {
    fn drop(&mut self) { println!("مات {}", self.0); }
}

fn main() {
    let v = vec![Loud(1), Loud(2), Loud(3)];
    println!("— قبل —");
    drop(v);
    println!("— بعد —");

    let w = vec![Loud(7), Loud(8)];
    for x in w {
        println!("أخذتُ {}", x.0);
    }
    println!("— انتهت الحلقة —");
}
```

المخرَج:

```
— قبل —
مات 1
مات 2
مات 3
— بعد —
أخذتُ 7
مات 7
أخذتُ 8
مات 8
— انتهت الحلقة —
```

`drop(v)` تقتل العناصر **بترتيب ولادتها** — عكس المتغيّرات المحلّية، لأن المتّجه
يمشي على مصفوفته من أوّلها.

و`for x in w` تأكل `w`: كل عنصرٍ **ينتقل** إلى `x`، فيموت في نهاية الدورة. ولهذا
لا تستطيع استعمال `w` بعد الحلقة. (وهذا هو الفرق بين `into_iter` و`iter` — والثاني
بابُ الإقليم القادم.)

## إصلاح المفكِّك: طريقان

عد إلى البذرة. الجوابان اللذان اقترحهما المترجم في أوّل شوطٍ من هذا الإقليم هما
كلّ ما هنالك.

**الأوّل — الرمز يملك نصّه.** فيعيش بعد مصدره:

```rust
#[derive(Debug)]
enum Owned {
    Word(String),
    Num(i64),
    Sym(char),
}

fn lex_owned(src: &str) -> Vec<Owned> {
    src.split_whitespace()
        .map(|w| match w.parse::<i64>() {
            Ok(n) => Owned::Num(n),
            Err(_) if w.chars().all(char::is_alphabetic) => Owned::Word(w.to_owned()),
            Err(_) => Owned::Sym(w.chars().next().unwrap()),
        })
        .collect()
}

fn main() {
    let escaped;
    {
        let src = String::from("سعر 12 + 30");
        escaped = lex_owned(&src);
    }

    println!("{escaped:?}");

    for t in &escaped {
        match t {
            Owned::Word(w) => println!("كلمة بطول {}", w.chars().count()),
            Owned::Num(n) => println!("عدد {n}"),
            Owned::Sym(c) => println!("رمز {c}"),
        }
    }
}
```

<!-- out -->

```
[Word("سعر"), Num(12), Sym('+'), Num(30)]
كلمة بطول 3
عدد 12
رمز +
عدد 30
```

**`src` ماتت عند القوس، والرموز خرجت من النطاق حيّة.** هذا هو ما رفضه المترجم في
أوّل الإقليم، وقد صار يُترجَم — بثمنٍ عرفتَه: تخصيصٌ لكل كلمة.

## والثاني: أن تصعد المِلكية فوق

الطريق الآخر يُبقي `Token<'a>` نافذةً، ويرفع المِلكية إلى **المستدعي**:

```rust
fn lex(src: &str) -> Vec<Token<'_>> { /* … */ }
```

فمن يريد الرموز يُبقي النصّ حيّاً ما دام يستعملها. والمترجم يفرض ذلك عليه بنفس
`E0597` التي رأيتها في نهاية الإقليم السابق.

| | تخصيصات لتسعة رموز | القيد |
|---|---|---|
| `Owned` | **١٠** | لا شيء — الرموز تعيش وحدها |
| `Token<'a>` | **١** | النصّ يبقى حيّاً ما دامت الرموز |

**ومكتبات Rust تختار الثاني وتوفّر الأوّل.** `serde` و`regex` تُرجعان نوافذ على
مدخلك حيث أمكن، ولكلٍّ نظيرٌ يملك حين يحتاج المستعمل ذلك.

**وبعد هذا الإقليم صار الاختيار عندك، وصار له رقم.**

## بذرة

المِلكية أجابت عن «من يحرّر». وبقي سؤالان فتحهما هذا الإقليم:

`&mut self` في المفكِّك — **من يجوز أن يقرأ الموضع بينما هو يتحرّك؟** و`for x in w`
تأكل، بينما `&v[0]` تنظر — **وما الذي يحدث لو نظر أحدٌ ثم عدّل آخر؟**

وقد رأيتَ الجواب مرّةً في الفصل صفر برمز `E0502`. **الإقليم القادم يبنيه من
أوّله.**
