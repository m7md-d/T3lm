# الإقليم ١٢ — كيف تُكتب Rust

> أحد عشر إقليماً، وكل ما بنيتَه **ملفٌّ واحد يُترجَم بـ`rustc`**. ولا مشروعَ
> حقيقيّ كذلك.
>
> هنا تُعيد بناء المفكِّك والمُحلِّل والحاسب **حزمةً**: وحداتٌ وواجهةٌ عامّة
> وتوثيقٌ يُختبَر واختباراتٌ تمرّ. والفصل عن **كيف تُكتب**، لا كيف تعمل.
>
> **والحزمة كاملةً في `programs/12-calc/`** — تُنسخ ويُشغَّل فيها `cargo test`.

## البذرة: `cargo new` وما يصنعه

```bash

**ثلاثة مواضع لا رابع:** `src/lib.rs` جذر المكتبة، و`src/*.rs` وحداتها،
و`tests/` اختباراتُ تكاملٍ تراها **من الخارج** كما يراها مستعمِلك.

و`Cargo.lock` يُلتزَم في المستودع للتطبيقات ويُهمَل للمكتبات — لأن التطبيق يريد
بناءً واحداً معاداً، والمكتبة تريد أن تُبنى مع ما يختاره مستعمِلها.

## الوحدة ملفّ، والجذر يعلنها

```rust
//! حاسبةُ تعبيراتٍ صغيرة: نصٌّ ← رموز ← شجرة ← عدد.

pub mod ast;
pub mod lexer;
pub mod parser;

pub use ast::Expr;
pub use lexer::{Lexer, Token};
pub use parser::{parse, ParseError};
```

**`mod` تُدخِل الملفّ في الشجرة، و`use` تختصر المسار.** بلا `pub mod lexer;` لا
يُترجَم `src/lexer.rs` أصلاً — لا يوجد اكتشافٌ تلقائيّ.

**و`pub use` تصنع الواجهة.** المستعمِل يكتب `calc::Token` لا
`calc::lexer::Token`، فتبقى لك حرّية نقل النوع بين الوحدات بلا كسر أحد.

**والخصوصية هي الأصل:** ما لا يحمل `pub` لا يُرى خارج وحدته. و`pub(crate)` وسطٌ
بينهما — عامٌّ داخل الحزمة، مخفيٌّ خارجها.

## التسمية تحمل الثمن

Rust ليس فيها `get_`. وفيها ثلاث بادئاتٍ **تقول لك كم تكلّف الطريقة**:

```rust
struct Wrapper(String);

impl Wrapper {
    /// `as_` — استعارةٌ رخيصة، ولا تخصيص.
    fn as_str(&self) -> &str { &self.0 }

    /// `to_` — تحويلٌ يكلّف، ويُرجع مملوكاً.
    fn to_upper(&self) -> String { self.0.to_uppercase() }

    /// `into_` — يبتلع `self` ويُعطي ما بداخله.
    fn into_inner(self) -> String { self.0 }
}

fn main() {
    let w = Wrapper(String::from("price"));
    println!("as_str    : {}", w.as_str());
    println!("to_upper  : {}", w.to_upper());
    println!("into_inner: {}", w.into_inner());
}
```

<!-- out -->

```
as_str    : price
to_upper  : PRICE
into_inner: price
```

| البادئة | المِلكية | الكلفة |
|---|---|---|
| `as_` | مستعار ← مستعار | مجّاناً |
| `to_` | مستعار ← مملوك | تخصيصٌ ونسخ |
| `into_` | مملوك ← مملوك | نقلٌ، والأصل يذهب |

**وترى الفرق في السطر الأخير من `main`:** بعد `into_inner` ماتت `w`، ولو
استعملتَها لسقط البرنامج بـ`E0382`. **البادئة تنبّهك قبل أن يفعل المترجم.**

وبقيّة الأعراف: `snake_case` للدوالّ والوحدات، و`CamelCase` للأنواع والسمات،
و`SCREAMING_CASE` للثوابت. **و`cargo fmt` لا يناقشك فيها.**

## التوثيق يُختبَر

`///` توثّق ما بعدها، و`//!` توثّق ما هي فيه. **والأمثلة داخلها تُترجَم وتُشغَّل**:

```rust
/// مكرِّرٌ يعطي رموز النصّ واحداً واحداً.
///
/// ```
/// use calc::{Lexer, Token};
/// let mut lx = Lexer::new("12 + سعر");
/// assert_eq!(lx.next(), Some(Token::Num(12)));
/// assert_eq!(lx.next(), Some(Token::Sym('+')));
/// assert_eq!(lx.next(), Some(Token::Word("سعر")));
/// assert_eq!(lx.next(), None);
/// ```
pub struct Lexer<'a> {
    rest: &'a str,
}
```

## الاختبار يسكن مع الكود

وحدةٌ خاصّة داخل الملفّ نفسه، مبنيّةٌ في بناء الاختبار وحده:

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn arabic_word_is_one_token() {
        let toks: Vec<_> = Lexer::new("سعر 12").collect();
        assert_eq!(toks, vec![Token::Word("سعر"), Token::Num(12)]);
    }

    #[test]
    fn empty_gives_nothing() {
        assert_eq!(Lexer::new("   ").count(), 0);
    }

    #[test]
    fn rest_shrinks() {
        let mut lx = Lexer::new("12 + 30");
        lx.next();
        assert_eq!(lx.as_str().trim(), "+ 30");
    }
}
```

**`#[cfg(test)]` تعني: لا تُترجَم هذه إلا عند الاختبار.** فلا تدخل الملفّ التنفيذيّ
ولا تُبطئ البناء العاديّ.

**و`use super::*` تعطي الاختبار كل ما في الوحدة — بما فيه الخاصّ.** وهذا فرقٌ
جوهريّ عن `tests/`: اختبار الوحدة يرى الداخل، واختبار التكامل يرى الواجهة وحدها.

## `clippy` يردّ ما يُترجَم

المترجم يقبل، والمراجع يردّ. و`clippy` هو المراجع الذي لا يتعب:

```rust
pub fn count_syms(src: &str) -> usize {
    let mut n = 0;
    for i in 0..src.len() {
        if src.as_bytes()[i] == b'+' {
            n = n + 1;
        }
    }
    return n;
}

pub fn describe(x: &String) -> String {
    if x.len() > 0 { format!("{}", x) } else { "فارغ".to_string() }
}
```

## ما يكسر مستعمليك

رقم الإصدار عقد. و`0.1.0 → 0.2.0` كسرٌ مُعلَن، و`0.1.1` وعدٌ بأن لا شيء انكسر.

**وأخطر كسرٍ لا يظهر:** إضافةُ شكلٍ إلى تعدادٍ عامّ. من طابق عليه في حزمةٍ أخرى
سقط بـ`E0004` — وقد رأيتَ هذا الرمز في الفصل ٠٠.

```rust
/// خطأٌ مفتوحٌ للنموّ — إضافة شكلٍ إليه ليست كسراً.
#[non_exhaustive]
#[derive(Debug)]
pub enum Fault { Empty, Overflow }

/// خطأٌ مغلق — إضافة شكلٍ إليه تكسر كل من طابق عليه.
#[derive(Debug)]
pub enum Sealed { Empty, Overflow }
```

<!-- err: E0004 -->

```
error[E0004]: non-exhaustive patterns: `&_` not covered
  --> src/main.rs:11:11
   |
11 |     match f {
   |           ^ pattern `&_` not covered
   |
note: `Fault` defined here
 4 | pub enum Fault {
   | ^^^^^^^^^^^^^^
   = note: `Fault` is marked as non-exhaustive, so a wildcard `_` is necessary to match exhaustively
```

**`#[non_exhaustive]` تقلب الكلفة:** تدفعها **مرّةً واحدة الآن** — ذراع `_` عند كل
مستعمِل — بدل أن تدفعها كسراً في كل إصدارٍ لاحق.

وتُوضَع على ما تتوقّع أن ينمو: تعدادات الأخطاء، وبنى الإعدادات. **ولا تُوضَع على
ما هو مغلقٌ بطبعه** مثل `Option`.

## حلقة العمل قبل الدفع

خمسة أوامر، بهذا الترتيب:

```bash
cargo fmt                       # لا نقاش في الشكل
cargo clippy -- -D warnings     # التحذير خطأ
cargo test                      # الوحدات والتكامل والتوثيق
cargo doc --no-deps             # الروابط المكسورة تظهر هنا
cargo build --release           # الفيض يلتفّ هنا لا يذعر
```

**والترتيب مقصود.** التنسيق أولاً ليكون الفرق في المراجعة معنىً لا مسافات. وبناء
الإصدار آخراً لأنه **بناءٌ آخر بسلوكٍ آخر** — رأيتَ ذلك في إقليم الفشل: الفيض
يذعر في التطوير ويلتفّ في الإصدار.

**وزِد سادساً إن كتبتَ `unsafe`:**

```bash
cargo +nightly miri test
```

فما لا يراه المترجم ولا الاختبار يراه `Miri` — وقد رأيتَ ذلك في الإقليم السابق.

## بذرة

انتهى المنهج.

بدأتَ بسؤالٍ واحد يتكرّر: **ما الذي يمنعه المترجم، وبأي ثمنٍ يمنعه؟** وعندك الآن
جوابه في كل موضع: المِلكية بثمن التخصيص أو قيد المستدعي، والاستعارة بثمن إعادة
التفكيك، والأعمار بثمن التوقيع، والتجريد بثمن حجم الملفّ أو جدولٍ في الكلمة
الثانية، والمشاركة بثمن عدّادٍ وذعرٍ محتمل، والأمان بحدٍّ مرسوم ينتهي عند `unsafe`.

**والذي تخرج به ليس أنك «تعرف Rust».** هو أنك حين تقابل رفضاً جديداً — رمزاً لم
يمرّ بك — **تعرف من أي بديهيةٍ جاء**، وأي ثمنٍ يطلبه منك.

وما بقي ليس فصلاً يُقرأ. **اكتب شيئاً يُستعمل.** خذ `calc` من `programs/12-calc`،
وأضِف إليها الطرح والقسمة والأقواس والمتغيّرات — وستقابل في أوّل ساعةٍ ثلاثة
رفوضٍ لم تمرّ بك، **وستعرف من أين جاء كلٌّ منها.**
