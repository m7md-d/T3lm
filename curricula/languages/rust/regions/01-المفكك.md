# الإقليم ٠١ — المفكِّك

> ستبني في هذا الإقليم **مفكِّك نصّ** يعمل: مئة سطرٍ تأخذ نصّاً وتعطيك رموزه، ثم
> تحسب تعبيراً منها.
>
> وحين ينتهي، سيكون فيه **ثلاثة أشياء تعمل ولا ينبغي أن تعمل هكذا**، وكلٌّ منها
> بابُ إقليم.
>
> وهذا المفكِّك **مرجع المنهج كلّه**. كل ما يأتي بعده يفكّكه أو يمدّه.

## نافذةٌ على نصّ غيرك

الرمز الذي يخرج من المفكِّك يحمل نصّاً. وأمامك طريقان: أن **ينسخه** إلى `String`
يملكها، أو أن يكون **نافذةً** على النصّ الأصليّ.

```rust
#[derive(Debug, PartialEq)]
enum Token<'a> {
    Word(&'a str),
    Num(i64),
    Sym(char),
}
```

`Word(&'a str)` تعني: **هذا الرمز يعيش ما دام النصّ الذي جاء منه حيّاً**. والعمر
`'a` اسمُ هذه العلاقة، وليس رمزاً زائداً.

**والمكسب مقيسٌ من الفصل صفر:** `&str` ستّ عشرة بايتاً، و`String` أربعٌ وعشرون
**زائداً تخصيصاً في الكومة ونسخَ بايتات**. فمفكِّكٌ يعالج ملفّاً بمليون رمز يخصّص
مليون مرّة — أو صفر مرّة.

**والثمن الذي ستدفعه في آخر هذا الإقليم:** لا يمكنك أن تتخلّص من النصّ وتحتفظ
بالرموز. والمترجم سيقولها لك بنفسه.

## حالةٌ تتحرّك

المفكِّك موضعٌ في نصّ:

```rust
struct Lexer<'a> {
    src: &'a str,
    pos: usize,
}

impl<'a> Lexer<'a> {
    fn new(src: &'a str) -> Self {
        Lexer { src, pos: 0 }
    }

    fn rest(&self) -> &'a str {
        &self.src[self.pos..]
    }
}
```

**لاحظ توقيع `rest`:** يأخذ `&self` ويُرجع `&'a str` — لا `&str` مربوطاً بحياة
`self`. والفرق جوهريّ: النافذة المُرجَعة تعيش بحياة **النصّ**، لا بحياة المفكِّك.
ولولا ذلك لماتت الرموز بموت المفكِّك.

**وهذا أوّل موضعٍ تكتب فيه `'a` بيدك**، ولا يستنتجه الحذف: للدالّة مدخلٌ واحد
(`&self`)، فالحذف كان سيربط المُرجَع به.

## السمة تعطيك اللغة كلّها

تحويل المفكِّك إلى **مكرِّر** ليس تجميلاً: هو ما يجعل `for` و`collect` و`map`
تعمل عليه بلا سطرٍ إضافي.

```rust
impl<'a> Iterator for Lexer<'a> {
    type Item = Token<'a>;

    fn next(&mut self) -> Option<Token<'a>> {
        let rest = self.rest();
        let skip = rest.len() - rest.trim_start().len();
        self.pos += skip;

        let rest = self.rest();
        let c = rest.chars().next()?;
        // … تصنيف الرمز
        self.pos += c.len_utf8();
        Some(Token::Sym(c))
    }
}
```

**`&mut self` قاعدة الاستعارة في العمل:** المكرِّر يعدّل موضعه، فلا يجوز أن يقرأه
أحدٌ في اللحظة نفسها. والمترجم يفرض ذلك بلا قفلٍ وبلا كلفة.

**و`?` على `Option`:** `chars().next()` تُرجع `None` عند نهاية النصّ، و`?` تعني
«اخرج بـ`None`». وهذه هي نفس `?` التي رأيتها على `Result` — عاملٌ واحد لنوعين.

## التقدّم بالبايتات، والحدّ حرف

`pos` فهرسُ **بايتات**. وزيادته بواحدٍ بعد رمزٍ عربيّ تضعه **داخل حرف**، فيذعر
أوّل تقطيعٍ بعده — وقد رأيت الرسالة في الفصل صفر.

```rust
self.pos += c.len_utf8();
```

**`len_utf8` تقول: كم بايتاً شغل هذا الحرف؟** واحدةٌ للاتينيّ، واثنتان للعربيّ،
وأربعٌ لبعض الرموز.

وتصنيف الرمز يستعمل نفس المبدأ — نبحث عن **أوّل موضعٍ يخالف الشرط** ونقطع عنده:

```rust
if c.is_ascii_digit() {
    let end = rest.find(|x: char| !x.is_ascii_digit()).unwrap_or(rest.len());
    self.pos += end;
    return Some(Token::Num(rest[..end].parse().unwrap()));
}
```

**و`find` تُرجع فهرس بايت** يقع على حدّ حرفٍ دائماً، لأنها تفتّش بالحروف.

## أوّل تشغيل

**فوق ما بنيتَه حتى الآن** — `Token` و`Lexer` وتنفيذ `Iterator`:

<!-- part: 01-lexer -->

```rust
fn main() {
    let src = String::from("سعر 12 + 30 * 2");
    let tokens: Vec<Token> = Lexer::new(&src).collect();
    println!("{:?}", tokens);
}
```

توقّع الرموز الستّة: كم `Word`، وكم `Num`، وكم `Sym`؟

المخرَج:

```
[Word("سعر"), Num(12), Sym('+'), Num(30), Sym('*'), Num(2)]
```

**و`collect` لم تكن مكتوبةً عندك.** جاءت من `Iterator`، ومعها `map` و`filter`
و`take_while` وعشرات غيرها. **هذا ما تشتريه بتنفيذ سمةٍ واحدة.**

**ولاحظ `Vec<Token>` بلا عمر:** استنتجه المترجم من `src`.

## الحساب: مطابقةٌ على شكلين

الحساب يمرّ على الرموز: عددٌ، ثم (رمزٌ وعدد) مكرَّرة.

```rust
fn eval(tokens: &[Token]) -> Result<i64, EvalError> {
    let mut it = tokens.iter();

    let mut acc = match it.next() {
        None => return Err(EvalError::Empty),
        Some(Token::Num(n)) => *n,
        Some(_) => return Err(EvalError::NotANumber),
    };

    while let Some(op) = it.next() {
        let sym = match op {
            Token::Sym(c) => *c,
            _ => return Err(EvalError::NotANumber),
        };
        let rhs = match it.next() {
            Some(Token::Num(n)) => *n,
            _ => return Err(EvalError::NotANumber),
        };
        acc = match sym {
            '+' => acc + rhs,
            '*' => acc * rhs,
            other => return Err(EvalError::BadOperator(other)),
        };
    }

    Ok(acc)
}
```

**`&[Token]` شريحة**: تقبل `Vec` كاملاً أو جزءاً منه (`&tokens[1..]`) بلا نسخ.

**و`*n` تفكّ المرجع**: `it.next()` تعطي `&Token`، والمطابقة تُدخِلك على `&i64`.
والنجمة تنسخ الأربع بايتات — **مسموحٌ لأن `i64` يحمل `Copy`** (البديهية الأولى).

## الخطأ شكلٌ في النوع

```rust
#[derive(Debug)]
enum EvalError {
    Empty,
    NotANumber,
    BadOperator(char),
}
```

ثلاثة أشكال، وأحدها **يحمل الرمز المخالف معه** — فالخطأ لا يقول «فشل» فقط، بل
يقول **بماذا** فشل.

**و`#[derive(Debug)]` سطرٌ يولّد تنفيذاً كاملاً** لسمة الطباعة التشخيصية. ولولاه
لما طُبع `Err(NotANumber)` أصلاً: **الطباعة سمةٌ تُنفَّذ، لا قدرةٌ في كل نوع.**

## أربعة مسارات، وتوقّعٌ واحد

المستدعي يفرغ الخطأ بالمطابقة، و`if let` تختصرها حين يعنيك شكلٌ واحد:

<!-- part: 01-lexer -->

```rust
let minus: Vec<Token> = Lexer::new("7 - 1").collect();
if let Err(EvalError::BadOperator(c)) = eval(&minus) {
    println!("عاملٌ غير مدعوم: {c}");
}
```

توقّع مخرَجات الأربعة: `eval(&tokens[1..])` و`eval(&tokens)` و`eval(&[])` والسطر
أعلاه.

المخرَج:

```
Ok(84)
Err(NotANumber)
Err(Empty)
عاملٌ غير مدعوم: -
```

**ولا `try` ولا `catch` ولا مسارٌ خفيّ.** الفشل قيمةٌ عادت من دالّة، والتوقيع
أعلنها قبل أن تقرأ سطراً من الجسد.

## الملفّ كاملاً

مئة سطرٍ وأربعة. وفيها فرعان لم يمرّا بك: تصنيف **الكلمة** (نظير تصنيف العدد)،
والمطابقة على العامل داخل `eval`.

```rust
#[derive(Debug, PartialEq)]
enum Token<'a> {
    Word(&'a str),
    Num(i64),
    Sym(char),
}

struct Lexer<'a> {
    src: &'a str,
    pos: usize,
}

impl<'a> Lexer<'a> {
    fn new(src: &'a str) -> Self {
        Lexer { src, pos: 0 }
    }

    fn rest(&self) -> &'a str {
        &self.src[self.pos..]
    }
}

impl<'a> Iterator for Lexer<'a> {
    type Item = Token<'a>;

    fn next(&mut self) -> Option<Token<'a>> {
        let rest = self.rest();
        let skip = rest.len() - rest.trim_start().len();
        self.pos += skip;

        let rest = self.rest();
        let c = rest.chars().next()?;

        if c.is_ascii_digit() {
            let end = rest
                .find(|x: char| !x.is_ascii_digit())
                .unwrap_or(rest.len());
            self.pos += end;
            return Some(Token::Num(rest[..end].parse().unwrap()));
        }

        if c.is_alphabetic() {
            let end = rest
                .find(|x: char| !x.is_alphabetic())
                .unwrap_or(rest.len());
            self.pos += end;
            return Some(Token::Word(&rest[..end]));
        }

        self.pos += c.len_utf8();
        Some(Token::Sym(c))
    }
}

#[derive(Debug)]
enum EvalError {
    Empty,
    NotANumber,
    BadOperator(char),
}

fn eval(tokens: &[Token]) -> Result<i64, EvalError> {
    let mut it = tokens.iter();

    let mut acc = match it.next() {
        None => return Err(EvalError::Empty),
        Some(Token::Num(n)) => *n,
        Some(_) => return Err(EvalError::NotANumber),
    };

    while let Some(op) = it.next() {
        let sym = match op {
            Token::Sym(c) => *c,
            _ => return Err(EvalError::NotANumber),
        };
        let rhs = match it.next() {
            Some(Token::Num(n)) => *n,
            _ => return Err(EvalError::NotANumber),
        };
        acc = match sym {
            '+' => acc + rhs,
            '*' => acc * rhs,
            other => return Err(EvalError::BadOperator(other)),
        };
    }

    Ok(acc)
}

fn main() {
    let src = String::from("سعر 12 + 30 * 2");

    let tokens: Vec<Token> = Lexer::new(&src).collect();
    println!("{:?}", tokens);

    println!("{:?}", eval(&tokens[1..]));
    println!("{:?}", eval(&tokens));
    println!("{:?}", eval(&[]));

    let minus: Vec<Token> = Lexer::new("7 - 1").collect();
    if let Err(EvalError::BadOperator(c)) = eval(&minus) {
        println!("عاملٌ غير مدعوم: {c}");
    }
}
```

**اقرأه سطراً سطراً قبل أن تشغّله.** وكل ما فيه مرّ عليك في الفصل صفر: تعدادٌ يحمل
قيماً، ومطابقةٌ شاملة، وعمرٌ يربط الرموز بمصدرها، وسمةٌ نُفِّذت، و`Result` و`?`.

واستعارة، وعمرٌ يربط الرموز بمصدرها، وسمةٌ نُفِّذت فأعطت مكتبةً كاملة، و`Result`

**وهو الآن مرجعك.** ولن أعطيك برنامجاً آخر: كل إقليمٍ بعده يفكّك سطراً من هذا.

## البذرة الأولى: النصّ يجب أن يبقى

`Token::Word` نافذةٌ على `src`. فماذا لو مات `src` والرموز حيّة؟

```rust
fn main() {
    let tokens;
    {
        let src = String::from("1 + 2");
        tokens = src.split(' ').collect::<Vec<&str>>();
    }
    println!("{:?}", tokens);
}
```

<!-- err: E0597 -->

```
error[E0597]: `src` does not live long enough
 --> life2.rs:5:18
  |
4 |         let src = String::from("1 + 2");
  |             --- binding `src` declared here
5 |         tokens = src.split(' ').collect::<Vec<&str>>();
  |                  ^^^ borrowed value does not live long enough
6 |     }
  |     - `src` dropped here while still borrowed
```

**رُفض، وهذا صحيح.** لكنّه يعني أن مفكِّكك **لا يستطيع أن يُرجع رموزاً من نصٍّ
قرأه من ملفٍّ ثم أغلقه**. والحلّ يغيّر شكل النوع نفسه.

**وهذا بابُ إقليم المِلكية.**

## البذرة الثانية: `unwrap` مرّتان

في المفكِّك `parse().unwrap()`، وفي `eval` جمعٌ وضربٌ بلا حارس. وكلاهما يعمل على
مدخلاتك أنت:

<!-- out: مخرَجا برنامجين، وبعد كلٍّ سطر backtrace -->

```
$ ./lex   # على النصّ "9000000000000000000 + 9000000000000000000"
thread 'main' panicked at lex2.rs:79:20:
attempt to add with overflow

$ ./big   # على "99999999999999999999".parse::<i64>()
thread 'main' panicked at big.rs:2:49:
called `Result::unwrap()` on an `Err` value: ParseIntError { kind: PosOverflow }
```

**برنامجٌ يذعر على مدخَلٍ من المستخدم برنامجٌ ناقص.** والتوقيع الذي كتبتَه يقول
`Result<i64, EvalError>`، **وهو يكذب**: فيه مسارٌ يخرج بالذعر لا بالخطأ.

**وهذا بابُ إقليم الفشل**، وفيه `checked_add` و`?` على أنواعٍ مختلفة.

## البذرة الثالثة: ٨٤ وليس ٧٢

`12 + 30 * 2` أعطت **٨٤**. فالحساب يمشي من اليسار: `(12 + 30) * 2`.

وهذا **ليس خطأ برمجة** — الكود ينفّذ ما كُتب بالضبط. هو **خطأ تصميم**: بنية
البيانات المسطّحة (`&[Token]`) لا تحمل أسبقيةً أصلاً، فالمطلوب شكلٌ يحملها.

| الشكل | ماذا يعبّر عنه |
|---|---|
| `Vec<Token>` | تسلسلٌ مسطّح — لا أسبقية ولا تعشيش |
| شجرةٌ من `enum` | `Add(Box<Expr>, Box<Expr>)` — التعشيش في النوع |

**ولاحظ `Box`:** التعداد الذي يحوي نفسه يحتاج حجماً معلوماً، والمِلكية في الكومة
تعطيه ثمانيَ بايتات. **وهذا بابُ إقليم الأنواع المتكرّرة.**

## بذرة

ثلاثة أبوابٍ فُتحت، ولم يُغلق منها شيء:

**النصّ الذي يجب أن يبقى** · **الذعر الذي يكذب على التوقيع** · **الأسبقية التي لا
تحملها البنية**.

وقبل أن تفتح الإقليم التالي، **شغّل المفكِّك على نصّك أنت**: أدخِل عربيةً ولاتينية
وأرقاماً ورموزاً، وانظر أين يصمد وأين ينهار. **الأسئلة التي تخرج بها من ذلك أثمن
من أي تمرينٍ أكتبه لك.**
