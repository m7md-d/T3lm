# موقع «Rust — ما يثبته المترجم» — جدول الاشتقاق

هذا الموقع ليس ثيماً فوق المنهج. كل قرار فيه — بنيةً ولوناً وحركةً ومكوّناً
وتفاعلاً — مردودٌ إلى شيء موجود **فعلاً** في ماركداون المنهج، ومعدودٍ لا مُقدَّر.
ما لم أجد له سطراً هنا، حذفتُه.

**اختبار القبول:** انقل هذا التصميم إلى منهج شبكاتٍ أو وسائط وسيبدو *غير منطقيّ*:
لا رفضَ مترجمٍ يُعرَض بلوكاً، ولا حكمَ ثنائيّ يصبغ الصفحة، ولا معنى لأربع حالاتٍ
للقيمة، ولا مقياسَ استعارةٍ يُعاد ترتيبه.

## ١) جدول الاشتقاق

|---|---|---|
| **لا زرّ تشغيل في الموقع كلّه** | ٤٢ بلوك رفضٍ من المترجم، و١١٠ لوحةَ مخرَجٍ تحتاج `rustc` | Rust تُترجَم، ولا مفسّر لها في المتصفّح يعطي جواب `rustc` — **وأكثر ما يُدرَّس هنا رفضٌ لا يقع إلا في مترجمٍ حقيقيّ**. وزرٌّ يعطي جواباً غير جوابه أسوأ من لا زرّ (`CLAUDE.md` قانون ١) |
| **«رفض المترجم» بلوكٌ قائم بذاته** | `<!-- err: … -->` ٤٢ مرّةً في ثلاثة عشر فصلاً | الرفض هنا **دليل** لا فشل: نصف حقائق المِلكية لا تُرى إلا في رسالة خطأ. فله رأسٌ ووسمٌ ولونٌ خاصّ، ولا يُعرَض كمخرَجٍ ملوَّن |

| **`rustc --explain` مكتوبٌ في ذيل كل رفض** | `README.md` §«كيف تُدرَس»: «ولكل رفضٍ رمز… وأمرٌ يشرحه» | الاكتفاء الذاتي: القارئ لا يبحث عن معنى الرمز، الأمر أمامه |
| **مقياس الاستعارة: ثلاثة أسطر تُرتَّب** | لقطة «ثلاثة أسطر، ترتيبان» — نفس الأسطر بترتيبين وحكمان متعاكسان | اللقطة تعرض ترتيبين، **والستّة كلّها بيد القارئ**. والتلاعب يرفع الأثر من d = 0.17 إلى d = 0.86 (أدلّة §٤)، ولا يدفع من ميزانية البوّابات |
| **أحكام المقياس الستّة مسجَّلة، لا محسوبة** | ستّة تباديل × تشغيلة `rustc` لكلٍّ | نموذجٌ يخمّن نيابةً عن المترجم يخالف ثابت ١. فشُغِّلت الستّة ونُقلت أحكامها — ومنها ثلاثةٌ ترفض بـ`E0425` لا `E0502`، وهو ما لم يكن ليخطر ببال نموذج |
| **الشريط الرأسيّ = عمر الاستعارة** | «المترجم يعرف أين ينتهي **الاستعمال**، لا أين ينتهي النطاق» (NLL) | القاعدة مرسومة: التعديل داخل الشريط ⇒ رفض، وخارجه ⇒ قبول. **الصورة هي القاعدة**، لا زينةٌ بجانبها |
| **أربع عائلات لون** | للقيمة أربع حالات في المتن: مملوكة · مستعارة للقراءة · مستعارة للتعديل · منقولة | الحدّ قبل-الانتباهيّ ٤–٥ فئات ثم يصير اللون ضوضاء (أدلّة §٨). وأربعٌ هنا **عدد الحالات نفسه**، لا اختياراً |
| **حكمٌ بلونين لا ثالث** | كل مقطعٍ في المنهج إمّا يُترجَم وإمّا يُرفَض | ثنائية المترجم ثنائيةٌ في الصفحة. والوسم النصّيّ («قبِل» / «رفض») قناةٌ ثانية، ولا ثالثة |
| **البديهيات الخمس بطاقاتٌ تُفتح، ووجهها رمزُ رفضها** | جدول البديهيات في ٠٠، وجدول الرموز في `appendix/` وفيه عمودٌ اسمه «البديهية» | **المؤلّف هو من ربطهما**. ووجه البطاقة يحمل `E0382` — الحقل الذي **يفرّق** بين الخمس، لا وسماً مكرّراً تحتها |
| **الكود ملوَّنٌ بمحلّل Rust نفسه** | ٣٨ مقطعاً في فصلين، وأطولها ١٠٤ أسطر | مقطعٌ بلا توكنة يُقرأ كتلةً واحدة. والتلوين **ساكن**: يخرج من `@codemirror/lang-rust` عبر `@t3lm/kit/highlight` بلا محرّرٍ ولا زرّ — العدّة تعطي الأصناف، والمنهج يعطي الألوان |
| **`'a` بلون الاستعارة** | العمر رمزٌ يتكرّر في `Token<'a>` و`Lexer<'a>` و`rest()` | صنفه `tok-variableName2` من المحلّل، ولونه `--v-shared` — **فالعين تربط الرمز بالحالة** قبل أن يقرأ القارئ شرحه |
| **خمس عائلات توكنة لا أكثر** | كلمةٌ محجوزة · نوع · نصّ · عدد · تعليق | تلوين كل شيءٍ تلوينُ لا شيء؛ وما عداها يبقى بلون النصّ |
| **لا رقم إصدارةٍ في الترويسة** | `rustc --edition 2024` في أوامر التشغيل، ولقطةٌ كاملة تشرح الإصدارات | الرقم في الترويسة **يُقرأ قديماً** بعد سنة ولا يضيف شيئاً. موضعه سطر الأمر الذي يُنسَخ، والفصل الذي يشرحه |
| **الأحجام تُنسَب إلى «هدف ٦٤-بت»** | `&i32` ٨ · `String` ٢٤ · `&dyn` ١٦ | ما يعتمد عليه الرقم **عرضُ المؤشّر**، لا اسم جهاز المؤلّف ولا نظامه |
| **الأثر يفتح كل ما عُبر** | ٣٩ لقطةً في الفصل ٠٠ | القارئ الذي أنهى فصلاً ثم عاد لنقطةٍ فيه **يعرف أين هي**؛ وإجباره على المرور تسلسلياً مشوارٌ بلا عائد. والتقدّم محفوظٌ أصلاً |
| **بطاقة الفصل تحمل ادّعاءه الافتتاحيّ** | نبذة كل فصلٍ تفتح بجملةٍ تسمّي ما سيُبنى | فصلان فقط، ولو حمل كلاهما وسم «الإقليم» لكان الوسم صفر معلومة |
| **الأثر بدل شريط التقدّم** | ٥٢ لقطة، لا يُعرَض منها إلا ما مضى | العدّ التنازليّ يعرض الكلفة كاملةً قبل البدء؛ والأثر يعدّ من حيث بدأ القارئ (`profiles/default.md` §٧) |
| **الأجزاء الأربعة تظهر بعد بلوغها** | الفصل ٠٠ فيه `## ` أربعة و`### ` تسعة وثلاثون | ٣٩ لقطةً بلا معالم تُقرأ قائمة. وعنوان جزءٍ لم يُبلَغ **إعلانٌ عن كلفةٍ قادمة** |
| **الأبواب الثلاثة المختومة بنصّ بذورها** | «النصّ الذي يجب أن يبقى» · «الذعر الذي يكذب على التوقيع» · «الأسبقية التي لا تحملها البنية» | كشفٌ تدريجيّ ببذرةٍ لا بعنوان: الباب يقول **ما فُتح**، ولا يعد بما لم يُكتب |
| **الحوافّ حادّة (`--ck-r: 2px`)** | لغةٌ تعلن حدودها: مالكٌ واحد، واستعارةٌ حصرية، ورفضٌ صريح | نصفُ قطرٍ ناعم يلطّف ما لا يلطّفه المترجم |
| **أرضية صدئة دافئة** | «Rust تسكن مكان C» — نواةً ومحرّك متصفّح | التمييز عن المناهج الأخرى **داخل الظلام**، لا بالسطوع |
| **المقياس مضاعفات ٤** | `char` أربع بايتات · `&str` كلمتان · `Vec` ثلاث | وحدة هذا المنهج **بايت**، لا كلمة آلة |
| **أيقونة التطبيق `&`** | عامل الاستعارة — ومحور المنهج كلّه | الأيقونة تُرى بلا نصّ، فتحمل **السؤال** لا اسم اللغة: الرمز الذي يفصل Rust عن C |
| **بطاقة المشاركة رفضٌ من المترجم** | ٤٢ بلوك رفض · «رفض المترجم مادّةُ تدريسٍ هنا لا عقبة» | ما يُرى قبل الدخول هو **ما يُدرَّس**: رسالةٌ حقيقية برمزها وموضعها، لا شعارٌ عن اللغة |
| **العربية لا تُكتب بالخطّ الأحاديّ** | كل رفضٍ ومخرَجٍ لاتينيّ | خليّة المونو تفكّ وصل الحروف. الأحاديّ للكود والرفض والأرقام، ويُوسَم `.en` |
| **`&` أيقونةَ الموقع** | عامل الاستعارة، ومحور المنهج | حرفٌ من اللغة نفسها، لا رسمٌ مخترَع |

| **جدول الفصول مقروءٌ من `README.md`** | جدول «الطريق» فيه ثلاثة عشر صفّاً | العدد والأسماء والمحتويات في موضعٍ واحد. وما في `regions/` وليس في الجدول (أو العكس) **يُفشِل فحص الدخان** |
| **البطاقة المقفلة تحمل اسم فصلها ومحتوياته** | نفس صفّ الجدول | الفصل الذي لم يُكتب بعد **يُعلَن بما فيه**، فتُعرف بقيّة الطريق قبل بلوغها. وتختفي بطاقته وحدها حين يُكتب |

**وما حُذف:** زرّ التشغيل (لا مفسّر) · الطرفية (لا شيء يُنفَّذ هنا) · محرّر الكود
(نسخٌ ولصقٌ إلى `rustc` أصدق) · شريط التقدّم · أي حركةٍ تلقائية.

## ٢) البناء

```
npm run dev     خادم التطوير
npm run build   tsc -b ثم vite build
npm run smoke   يصيّر كل مسارٍ خارج المتصفّح، ويفحص أن الاستخراج ما زال يعمل
```

```
npm run outputs  يترجم كل لوحةٍ في المنهج ويقارنها بتشغيلٍ حقيقيّ (tools/verify.py)
```

**والمخرَج:** `639 kB` جافاسكربت (`204 kB` مضغوطة) و`18 kB` CSS، بلا أي أصلٍ
خارجيّ سوى الخطوط (انظر «ما لم يُنجَز»). وثلثه محتوى المنهج نفسه — ٢٥ ألف كلمة
مُصرَّفةً في الحزمة.

**والمحلّل يُستورَد من `@lezer/rust` لا من `@codemirror/lang-rust`:** الثاني يجرّ
بيئة المحرّر كاملةً لعرضٍ ساكن — **٢١٠ كيلوبايت زائدة، قِيست بحذف الاستيراد
وإعادة البناء.**

**و`smoke` يفحص المحتوى لا التصيير فقط:** أن كل فصلٍ في `regions/` له صفٌّ في
جدول الطريق والعكس، وأن البديهيات خمس ولكلٍّ شرحُها ولقطتها، وأن **أربعاً منها على
الأقلّ يحرسها رمز**، وأن كل بلوك رفضٍ يحمل رمزه، وأن **التلوين يُخرِج أصنافاً
فعلاً** من محلّل Rust. فالبنية كلّها مستخرَجةٌ من الماركداون، وتحريرُ عنوانٍ فيه قد
يكسر الاستخراج **بلا أن يفشل البناء**.

**و`outputs` يفحص ما لا يفحصه أيّ منهما:** أن اللوحة تطابق التشغيل. وتقريره يعدّ
ما لم يُفحَص آلياً — لوحات الصدفة والمقتطعات بلا ملفّ — **فلا يختفي الثقب بصمت**.

### الرفع — من `dist/` إلى Cloudflare Pages

الأمر كاملاً، من الفحص إلى المضغوط:

```bash
npm run outputs && npm run smoke && npm run build
rm -f rust.zip && (cd dist && zip -qr ../rust.zip . -x '.DS_Store' '**/.DS_Store' '__MACOSX/*')
unzip -l rust.zip | head -5      # index.html في جذر المضغوط لا داخل مجلّد
```

**الضغط من داخل `dist/`، لا من فوقه.** Cloudflare Pages يجعل جذر المضغوط جذر
الموقع؛ فإن حوى مجلّداً واحداً سكن الموقع تحت `/dist/` وأعطى الجذر ٤٠٤.

يُرفَع `rust.zip` في مشروع **`t3lm-rust`**:
Workers & Pages ← المشروع ← *Create deployment* ← *Upload assets*.
والعنوان `rust.nodeksa.com`.

## ٣) أصول التطبيق

| الأصل | مصدره | يُولَّد بـ |
|---|---|---|
| `public/fonts/*.woff2` + `fonts.css` | Google Fonts، كتلَ `unicode-range` كما تُقدَّم | `npm run fonts` |
| `public/icons/*.png` (١٩٢ · ٥١٢ · قناعان · apple-touch) | `assets/icon.html` — `&`، عامل الاستعارة | `npm run assets` |
| `public/og.png` (١٢٠٠×٦٣٠) | `assets/og.html` — رفضُ `E0502` بنصّه | `npm run assets` |
| `dist/sw.js` | قائمة `dist/` مبصومةً | ضمن `npm run build` |

المصدر HTML لا SVG ليكون الرمز حرفاً في `IBM Plex Mono` نفسه، خطّ الموقع، لا
رسماً يشبهه. والناتج ملتزَم في `public/`، فالبناء لا يحتاج شبكة ولا متصفّحاً.

`manifest.webmanifest` بأربع أيقونات، وعامل خدمةٍ يخزّن ٢٨ ملفّاً مسبقاً واسمُ
مخزنه بصمةُ المخرَج.

ويفشل البناء عند أي أصل خارجي، لأن `tools/sw.mjs` يفحص مراجع HTML وCSS.
