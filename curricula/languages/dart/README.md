# Dart — لغةٌ مُدارة بعد لغةٍ عارية

منهجٌ يفكّك Dart من نظام أنواعها إلى حلقة أحداثها وisolatها، بمنظور من يعرف
**أين تسكن كل قيمة ومن يملكها ومتى تموت** — ثم يدخل لغةً لا تجيب عن أيٍّ من
هذه الأسئلة، ويسأل ماذا وضعت مكانها.

---

## لمن كُتب

**لمن أنهى [منهج C](../c/README.md) ولم يفتح Dart.** المرساة C، وكل مقارنةٍ
تصميمية هنا مبنيّةٌ عليها: `malloc` و`free` والمكدّس والمؤشّر مفرداتٌ تُستعمل بلا
تمهيد.

**ولمن يقصد Flutter، هذا ما يسبقه.** [`web/flutter`](../../web/flutter/README.md)
يبني على هذا المنهج ولا يعيده — ولا widget واحدة هنا.

## ما يفترضه فيك

| يفترض | لا يفترض |
|---|---|
| تقرأ C وتكتبها، وتعرف الفرق بين المكدّس والكومة | أي سطر Dart سابق |
| تعرف ما «المؤشّر» و«التحرير المزدوج» | أي معرفةٍ بـJava أو JavaScript أو TypeScript |
| تشغّل أوامر في طرفية وتقرأ رسائل مترجم | إطار عملٍ أو محرّراً بعينه |

**وما لن يُشرَح:** أساسيات البرمجة، والتحكّم في السير، وما معنى «دالّة». هذا
منهج لغةٍ ثانية.

## الأدوات

```
dart --version        # 3.13.2 — مثبَّت، والسلوك الذي يتغيّر بالإصدار مُعلَّم
dart analyze · dart test · dart run --observe
dart compile exe · dart compile js · dart compile kernel
```

**الويب ليس هدف المنهج.** كل لوحةٍ من `dart run` على آلةٍ أصلية، إلّا حيث يكون
اختلاف الويب **هو الدرس** — فتُعرَض اللوحتان معاً بوسم `@web`، ويُفحَص كلاهما
آلياً (`dart compile js` ثم node).

**ولا زرّ تشغيل في موقع هذا المنهج.** مشغّل المتصفّح يمرّ بـJavaScript، وقد
ثبت في الإقليم ٠٠ أنه يعطي **جواباً مختلفاً** لأسئلة الفصل الثاني. المخرَجات
مسجّلة، والقارئ يشغّلها عنده.

## السلطات

كل ادّعاءٍ في المنهج يحمل من يضمنه:

| | |
|---|---|
| `@spec` | تضمنه مواصفة اللغة على أي منصّة |
| `@vm` | تقرّره الآلة الافتراضية — كترتيب الطابورين وسلوك الجامع |
| `@web` | يختلف بعد الترجمة إلى JavaScript |
| `@aot` | يظهر في الترجمة المسبقة وحدها، أو يغيب فيها |

## البديهيات الخمس

| # | البديهية | أوّل ما يتساقط منها |
|---|---|---|
| ١ | كلُّ شيء كائن — وللعدم نوع | لا أنواعَ بدائية منفصلة · ولا `sizeof` |
| ٢ | النوع لا يكذب (sound) | ما يقوله المدقّق يصحّ حيّاً · وحيث عجز البرهان، زُرع فحص |
| ٣ | لا ذاكرة مشتركة | الـisolate يملك كومته وحده · والرسائل **تُنسَخ** · فلا سباق أصلاً |
| ٤ | `async` ليست خيطاً | حلقةُ أحداثٍ وطابوران · وترتيبُ التنفيذ **يُحسَب على ورقة** |
| ٥ | الضمانات لها وزن | JIT للتطوير وAOT للنشر · وما يعمل في الأوّل قد يُرفَض في الثاني |

## الطريق — خمس حِزَم

| | | |
|---|---|---|
| `00–01` | **البداية** | الفصل النظريّ الوحيد، ثم برنامجٌ يعمل قبل أن تفهم نصفه |
| `02–05` | **القيمة والاسم** | ما تحمله، ومن يملكها، ومتى تموت — بلا `free` |
| `06–12` | **النوع** | الصنف والوراثة والـmixin والعموم والأنماط، ثم الكومة والجامع |
| `13–17` | **الزمن** | حلقة الأحداث والـFuture والـStream والـisolate والأخطاء |
| `18–22` | **من النصّ إلى برنامجٍ يُسلَّم** | الحزمة والترجمة وFFI والاختبار، ثم ختام |

### وتفصيلُها

| | | |
|---|---|---|
| `00` | **ما يضمنه النوع** | ✅ الفصل النظريّ الوحيد: القصّة تحت ضغطها · البديهيات الخمس بأدلّةٍ تعمل · نظام الأنواع كاملاً · وجسرٌ من C |
| `01` | **أوّل برنامج يعمل** | ✅ أداةُ سطر أوامرٍ في نحو مئة سطر تقرأ ملفّاً وتحلّله وتطبع تقريراً. **فيها ثلاثة أشياء لن تفهمها اليوم** |
| `02` | **العدد والقيمة** | ✅ `int` و`double` و`num` · وأن `int` على الويب ليست هي · والمقارنة بـC صريحة |
| `03` | **`null` نوعاً** | ✅ `?` و`!` و`late` · ولماذا هي مسألةُ **نوعٍ** لا فحصٍ بـ`if` |
| `04` | **الاسم والثبات** | ✅ `var` و`final` و`const` · والتقييس: `const` واحدةٌ في الذاكرة مهما تكرّرت |
| `05` | **الدالّة قيمة** | ✅ الوسائط المسمّاة والاختيارية · الـclosure وما تلتقطه · والـtear-off |
| `06` | **الصنف** | ✅ البانيات: مولِّدة ومسمّاة وموجِّهة و`factory` · قائمةُ التهيئة ولماذا تسبق الجسم |
| `07` | **الوراثة والواجهة** | ✅ `extends` و`implements` · وقيود الإصدار الثالث (`final` و`base` و`interface`) |
| `08` | **الـmixin** | ✅ `with` · وخطّية الحلّ: **الترتيب يغيّر النتيجة**، ويُرى ببرنامج |
| `09` | **العموم** | ✅ التباين · `covariant` · وأين تُزرَع فحوص السلامة وكم تكلّف |
| `10` | **التوسعة** | ✅ `extension` على نوعٍ لا تملكه · و`extension type` وأين يختفي حيّاً |
| `11` | **الأنماط** | ✅ `sealed` والمطابقة الشاملة · `records` · والتفكيك |
| `12` | **الكومة والجامع** | ✅ جامعُ الأجيال · ولماذا الكائنُ الصغير قصيرُ العمر رخيص · و**لماذا لا يوجد `sizeof`** |
| `13` | **حلقة الأحداث** | ✅ طابورُ المهامّ الدقيقة وطابورُ الأحداث · وتتنبّأ بالترتيب قبل أن تشغّل |
| `14` | **`Future` و`async`/`await`** | ✅ ما الذي يُترجَم إليه `await` · وأين تعود السيطرة |
| `15` | **`Stream`** | ✅ المفردة والمذاعة · الاشتراك والإلغاء · الضغطُ الخلفيّ · و`async*` |
| `16` | **الـisolate** | ✅ كومةٌ لكلٍّ · `SendPort` · **نسخُ الرسائل وثمنه مقيساً** · وما الذي لا يُنسَخ |
| `17` | **الأخطاء** | ✅ `Exception` مقابل `Error` · والالتقاطُ عبر `await` كيف يختلف · والـzone |
| `18` | **الحزمة** | ✅ `pub` و`pubspec` · قيودُ الإصدار وحلُّها |
| `19` | **الترجمة** | ✅ JIT مقابل AOT · حجمُ الناتج وtree shaking · و**قياسُ الفرق** |
| `20` | **FFI** | ✅ `dart:ffi` · استدعاءُ دالّة C · و**ملكيةُ الذاكرة عبر الحدّ**: من يحرّر؟ |
| `21` | **الاختبار والأدوات** | ✅ `test` · المدقّق واللِّنت · و`--observe` والملاحظة الحيّة |
| `22` | **الختام** | ✅ مشروعٌ بمعايير قبول بلا كودٍ جاهز: أداةٌ تُترجَم AOT، تستعمل isolates لعملٍ ثقيل وFFI لقدرةٍ من C |

## كيف يُدرَس

اقرأ بالترتيب. الأقاليم تبني بعضها، والإقليم ٠١ يُعدَّل ويُمدّ في كل ما بعده.

**ولا تصدّق لوحةً — شغّلها.** كل بلوكٍ في هذا المنهج **برنامجٌ كامل بذاته**:
احفظه باسم `main.dart` و`dart run main.dart`. ورسائلُ المترجم في اللوحات مكتوبةٌ بهذا الاسم، فما تراه هو ما تقرأ. والبلوك الذي لا يصلح وحده مُعلَّمٌ بذلك،
وبرنامجه الكامل في [`programs/`](programs/).

## التحقّق

```bash
python3 tools/verify.py          # كل الأقاليم
python3 tools/verify.py 02 03    # أقاليم بعينها
python3 tools/bidi.py            # انضباط اللغتين خارج بلوكات الكود
```

يشغّل كل بلوكٍ ويقارن مخرَجه بلوحته، ويفشل باسم الملفّ والسطر عند أي فرق.
ويشمل: الرفضَ من المترجم، ومخرَجَ الويب بعد `dart compile js` على node، والرفضَ
من الترجمة المسبقة، وبرامجَ C المقارِنة. **واللوحة التي لا تُفحَص تُعدّ وتُذكَر
في التقرير** — الثقب الصامت أخطر من المعلوم.

ولوحةُ الصدفة تُفحَص هي الأخرى حين تحمل أوامرها: سطرٌ بادئٌ بـ`$ ` يُشغَّل
ويُقارَن ما تحته — فتُترجَم مكتبةُ C وتُشغَّل حزمةٌ باختباراتها داخل الفحص نفسه.
واللوحة بلا أمرٍ **تُعدّ يدويةً وتُذكَر**.

و`bidi.py` يفرض قاعدتي الحقل ١٣: لا مقطع كودٍ يتجاوز ثلاث كلمات داخل سطرٍ عربيّ،
ولا عربية داخل مقطع كود.

## الموقع

`regions/` و`programs/` هما مصدر الحقيقة، و[`site/`](site/README.md) يصرّفهما
(Vite + React، بلا خادم). **ولوحتُه من شعار Flutter** — استمراراً إلى المنهج
الذي يبني على هذا — **وعلامتُه ملفُّ Dart الرسميّ مستورَداً** بلا تعديل.

```bash
cd site && npm install && npm run dev
npm run smoke      # ١٥٧ مساراً · ١٤٣ لوحة · مطابقة المحتوى للريدمي
```

**جدول الاشتقاق كاملاً في [`site/README.md`](site/README.md)** — وفيه لماذا لا
زرّ تشغيل، ولماذا ثلاث فئات لونٍ لا أربع، ولماذا تعود العربية إلى خطّ المتن
داخل تسعٍ وخمسين لوحة.

## ما يتركه لغيره

  لا فصل.
