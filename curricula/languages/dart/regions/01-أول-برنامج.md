# الإقليم ٠١ — أوّل برنامج يعمل

> في الإقليم السابق لم تكتب سطراً. هنا تكتب **أداةً تعمل**: تقرأ سجلّ وصولٍ
> سطراً سطراً، وتفصل السليم من المكسور، وتطبع تقريراً.
>
> وفيها **ثلاثة أشياء لن تفهمها اليوم**. هذا مقصود: هي بذور الأقاليم القادمة،
> وسأسمّيها لك في آخر الإقليم بالاسم وبرقم إقليمها.
>
> واحفظ كل بلوكٍ باسم `main.dart` وشغّله بـ`dart run main.dart`. **كلُّها برامج
> كاملة بذاتها** — لا بلوك هنا يعتمد على بلوكٍ قبله.

## السجلّ الذي أمامك

سبعة أسطر. خمسةٌ منها ثلاثةُ حقولٍ مفصولةٍ بمسافة — عنوانٌ ثم حالةٌ ثم حجم —
واثنان ليسا كذلك:

```
10.0.0.1 200 1200
10.0.0.2 404 90
10.0.0.1 200 3400
10.0.0.3 500 0
10.0.0.1 404 90
سطرٌ مكسور
10.0.0.2 200 لاعدد
```

والمطلوب تقريرٌ يقول: كم سطراً قُرئ، وكم رُفض ولماذا، وأيّ العناوين أكثر
طلباً، وكم بايتاً خرج.

في C كنتَ ستكتب `struct` وتقرأ بـ`fgets` وتفكّك بـ`strtok`، وتحمل همّ من يحرّر
كل شيء. **وهنا سنبني القطعة الأولى في تسعة أسطر.**

## السطر شكلٌ لا نصّ

أوّل قرار: ما الذي يخرج من التحليل؟ ثلاث قيمٍ مرتبطة، ولا تستحقّ صنفاً.

```dart
typedef Hit = (String ip, int status, int bytes);

Hit? parse(String raw) {
  final f = raw.split(' ');
  if (f.length != 3) return null;
  final status = int.tryParse(f[1]);
  final bytes = int.tryParse(f[2]);
  if (status == null || bytes == null) return null;
  return (f[0], status, bytes);
}

void main() {
  print(parse('10.0.0.1 200 1200'));
  print(parse('سطرٌ مكسور'));
  print(parse('10.0.0.2 200 لاعدد'));
}
```

<!-- out -->

```
(10.0.0.1, 200, 1200)
null
null
```

**ثلاثة أشياء في هذه التسعة:**

سطر `typedef` يعرّف **سجلّاً** — قيمةً فيها ثلاثة حقول مسمّاة، بلا صنفٍ تكتبه. ورأيتَ في الإقليم ٠٠ أن نوعه **شكلُه** لا اسمُه.

`int.tryParse` تُرجِع `int?` لا `int`. والعلامة ليست زينة: هي **نوعٌ آخر**، ولن
يدعك المترجم تجمعه أو تقارنه قبل أن تستبعد `null` — وهذا ما فعله السطر السابع.

`Hit?` في التوقيع يقول: قد لا يوجد جواب. **وهذا هو الادّعاء الذي سنهدمه بعد
قليل.**

## `null` يقول «فشل» ولا يقول «لماذا»

المخرَج أعلاه فيه عيبٌ صامت: السطران المرفوضان طبعا `null` نفسه. أحدهما مكسور
البنية والآخر مكسور المحتوى، والتقرير لا يفرّق.

وفي C كنت ستُرجِع `-1` أو تضع `errno`. **والجواب في Dart أن الفشل نوعٌ لا قيمة
مفقودة.**

```dart
typedef Hit = (String ip, int status, int bytes);

sealed class Line {
  const Line();
}

final class Ok extends Line {
  final Hit hit;
  const Ok(this.hit);
}

final class Bad extends Line {
  final String raw;
  final String why;
  const Bad(this.raw, this.why);
}

Line parse(String raw) {
  final f = raw.split(' ');
  if (f.length != 3) return Bad(raw, 'حقولٌ ${f.length} لا ٣');
  final status = int.tryParse(f[1]);
  if (status == null) return Bad(raw, 'الحالة «${f[1]}» ليست عدداً');
  final bytes = int.tryParse(f[2]);
  if (bytes == null) return Bad(raw, 'الحجم «${f[2]}» ليس عدداً');
  return Ok((f[0], status, bytes));
}

String describe(Line line) => switch (line) {
      Ok(hit: (final ip, final status, final n)) => '$ip حالتُه $status وحجمُه $n',
      Bad(:final why) => 'مرفوض: $why',
    };

void main() {
  for (final raw in ['10.0.0.1 200 1200', 'سطرٌ مكسور', '10.0.0.2 200 لاعدد']) {
    print(describe(parse(raw)));
  }
}
```

<!-- out -->

```
10.0.0.1 حالتُه 200 وحجمُه 1200
مرفوض: حقولٌ 2 لا ٣
مرفوض: الحجم «لاعدد» ليس عدداً
```

**نوع الإرجاع صار `Line` بلا علامة استفهام.** لا غياب هنا: كل سطرٍ يُنتج قيمة،
والفرق أنها من أحد فرعين.

و`switch` هذه **تعبيرٌ لا جملة** — تُرجِع قيمةً بـ`=>`. وتفكّك السجلّ داخل النمط: نمطُ `Ok`
يقول «إن كان من هذا الفرع، فسمِّ حقول سجلّه هكذا» — فيصير الفحص والتسمية
والتفكيك سطراً واحداً.

## المترجم يعدّ الحالات

الكلمة الحاسمة هي `sealed`: لا يستطيع أحدٌ خارج هذا الملفّ أن يشتقّ من `Line`.
والمترجم يعرف أن الفرعين هما كل شيء.

احذف حالة `Bad` من الـ`switch` وشغّل:

```dart
sealed class Line {
  const Line();
}

final class Ok extends Line {
  const Ok();
}

final class Bad extends Line {
  const Bad();
}

String describe(Line line) => switch (line) {
      Ok() => 'سليم',
    };

void main() => print(describe(const Ok()));
```

<!-- err -->

```
main.dart:13:39: Error: The type 'Line' is not exhaustively matched by the switch cases since it doesn't match 'Bad()'.
```

**هذا هو المكسب.** أضِف غداً فرعاً ثالثاً — `Skipped` مثلاً — وسيريك المترجم
**كل موضعٍ** نسيتَ فيه معالجته. لا `default` يبتلع الحالة الجديدة بصمت، ولا
مراجعةً بشرية تعتمد على انتباهك.

وهذا ما لا تملكه في C: `switch` على `enum` بلا `default` يعطيك تحذيراً إن طلبته،
و`struct` بحقل نوعٍ لا يعطيك شيئاً.

## عدّادٌ واحد لكل ما يُعدّ

التقرير يعدّ ثلاثة أشياء: طلباتٍ لكل عنوان، وأسطراً لكل حالة، وبايتاتٍ لكل
عنوان. والمفاتيح مختلفة الأنواع — `String` مرّةً و`int` مرّة.

```dart
class Tally<K> {
  final Map<K, int> _n = {};

  void add(K key, [int by = 1]) => _n[key] = (_n[key] ?? 0) + by;

  int get total => _n.values.fold(0, (a, b) => a + b);

  int of(K key) => _n[key] ?? 0;

  List<(K, int)> top(int k) {
    final all = [for (final e in _n.entries) (e.key, e.value)]
      ..sort((a, b) {
        final byCount = b.$2.compareTo(a.$2);
        return byCount != 0 ? byCount : '${a.$1}'.compareTo('${b.$1}');
      });
    return all.take(k).toList();
  }
}

void main() {
  final byIp = Tally<String>();
  final byStatus = Tally<int>();

  byIp.add('10.0.0.1');
  byIp.add('10.0.0.2');
  byIp.add('10.0.0.1');
  byStatus.add(200);

  print(byIp.top(3));
  print(byIp.total);
  print(byIp.runtimeType);
}
```

**المخرَج**:

```
[(10.0.0.1, 2), (10.0.0.2, 1)]
3
Tally<String>
```

**السطر الأخير هو الاختبار.** في Java يُمحى الوسيط بعد الترجمة فتقول
`Tally`. وهنا `Tally<String>` — لأن الأنواع تبقى حيّة، كما رأيت في الإقليم ٠٠.

والوسيط الثاني في `add` **موضعيّ اختياريّ** بقيمةٍ افتراضية، فـ`add(ip)` تزيد
واحداً و`add(ip, n)` تزيد `n`. والمقارِن المُمرَّر إلى `sort` دالّةٌ **قيمةً** — والإقليم ٠٥ يفكّك ما تلتقطه مثل هذه.

## الملفّ مجرًى لا مصفوفة

بقيت القراءة. وفي `dart:io` طريقان، والفرق في نوعيهما لا في راحتهما:

<!-- part -->

```dart
Future<List<String>> whole = f.readAsLines();  // الملفّ كلّه في الكومة
Stream<List<int>> chunks   = f.openRead();     // قطعةً قطعة
```

الأوّل يحجز الملفّ كلَّه. والثاني **مجرًى**: قيمٌ تصل واحدةً بعد أخرى، وتعالجها
وتنساها. وسجلٌّ بغيغابايت يفرض الثاني.

```dart
import 'dart:convert';
import 'dart:io';

const sample = '''
10.0.0.1 200 1200
10.0.0.2 404 90
10.0.0.1 200 3400
''';

Stream<String> lines(File f) => f
    .openRead()
    .transform(utf8.decoder)
    .transform(const LineSplitter())
    .where((s) => s.trim().isNotEmpty);

Future<void> main() async {
  final f = File('sample.log');
  await f.writeAsString(sample);

  print('بدأتُ القراءة');
  var n = 0;
  await for (final line in lines(f)) {
    n++;
    print('$n: $line');
  }
  print('انتهيتُ بعد $n سطراً');
}
```

<!-- out -->

```
بدأتُ القراءة
1: 10.0.0.1 200 1200
2: 10.0.0.2 404 90
3: 10.0.0.1 200 3400
انتهيتُ بعد 3 سطراً
```

**السلسلة تقرأ من اليمين معناها:** بايتاتٌ ← نصّ ← أسطر ← ما ليس فارغاً. وكل
حلقةٍ فيها تحوّل مجرًى إلى مجرًى، ولا شيء يُقرأ حتى يبدأ `await for`.

**هذه `switch` جملةٌ لا تعبير** — بـ`case` و`:` بدل `=>`. والصيغتان لنفس

## ثلاثة أشياء لن تفهمها اليوم

| ما هو | أين في الكود | متى يُفكَّك |
|---|---|---|
| **`await for` وما ينتظره** | حلقة القراءة | الإقليم ١٣ (الطابوران) ثم ١٥ (المجرى) |
| **من يحرّر `Tally` و`Map` والأسطر كلَّها** | لا موضع — وهذا هو السؤال | الإقليم ١٢ (الكومة والجامع) |
| **لماذا `const sample` ولا نسخةَ لها** | تصريح العيّنة | الإقليم ٠٤ (التقييس) |

**والرابع الذي لم أعدّه:** `String` عندك وحداتُ UTF-16. جرّب سطراً فيه إيموجي
وعُدّ حروفه — الجواب سيفاجئك، وموضعه الإقليم ٠٢.

## التمرين

**١ — وسّع الشكل.** أضف حقلاً رابعاً للسطر: المسار المطلوب. غيّر `Hit` وحده،
ثم شغّل `dart analyze`.

اقرأ ما يقوله المدقّق **قبل أن تصلح شيئاً**. كم موضعاً عدَّه؟ ولماذا وجدها كلَّها
وأنت لم تلمس إلا سطراً واحداً؟ الجواب في نوع السجلّ، وقد قيل في الإقليم ٠٠.

**٢ — اكسر الترتيب.** في `top` احذف سطر فضّ التعادل، فيصير الترتيب بالعدد وحده.
ثم شغّل الأداة على سجلٍّ فيه **أربعون** عنواناً بأعدادٍ متساوية، وشغّلها مراراً.

هل الترتيب هو نفسه؟ ثم أنقص العناصر إلى **ثلاثين** وأعِد. هل تغيّر شيء؟

فإن وجدتَ حدّاً، فاذهب إليه في مصدر SDK: `lib/internal/sort.dart` سطر ١٨.
وماذا يعني ذلك لكل ترتيبٍ كتبتَه بلا فضّ تعادل؟

**٣ — ابنِ الأداة من الصفر بلا `sealed`.** استعمل `Hit?` ورسالةَ خطأٍ في متغيّرٍ
جانبيّ. ثم أضف نوع فشلٍ ثالثاً إلى النسختين، وقارن: كم موضعاً دلّك عليه المترجم
في كلٍّ منهما؟

## الخلاصة

| ما بنيتَه | العقدة في الشجرة | أين يُفصَّل |
|---|---|---|
| سجلٌّ بثلاثة حقول | النوع البنيويّ الوحيد | ١١ |
| `int?` من `tryParse` | `null` نوعاً | ٠٣ |
| `sealed` ومطابقةٌ شاملة | الاتّحاد المُحكَم | ٠٧ · ١١ |
| `Tally<K>` | العموم، والأنواع الحيّة | ٠٩ |
| دالّةٌ مُرَّرت إلى `sort` | الدالّة قيمة | ٠٥ |
| `Stream` و`await for` | حلقة الأحداث | ١٣ · ١٥ |

**وهذا الملفّ لا يُرمى.** كل إقليمٍ بعده يعدّله أو يمدّه: الإقليم ٠٩ يجعل
`Tally` أدقّ، و١٦ ينقل التحليل إلى isolate، و١٩ يترجمه ملفّاً تنفيذياً، و٢١
يكتب له اختبارات.

## البذرة

في التقرير سطرٌ يقول إن مجموع البايتات ٤٧٨٠ — اجمع العمود بيدك، النتيجة نفسها.

الآن ضع في السجلّ حجماً واحداً هو `9007199254740992`، ثم اجعل التقرير يقارن مجموع
البايتات بنفسه زائداً واحداً، ويطبع نتيجة المقارنة.

على آلتك سيطبع `false`. ثم ترجم البرنامج نفسه بـ`dart compile js` وشغّله على
node.

**سيطبع `true`.** عددٌ يساوي نفسَه زائداً واحداً — على المنصّة نفسها التي وُلدت
Dart لتسكنها. ولماذا، وأين ينكسر بالضبط: الإقليم ٠٢.
