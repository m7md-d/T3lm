# الإقليم ١٩ — الترجمة

> البديهية الخامسة قالت إن الضمانات لها وزن، وأريتُك في الإقليم ٠٠ برنامجاً من
> سطرٍ واحد يصير خمسة ميغابايت. وأريتُك `dart:mirrors` تعمل في وجهٍ وتُرفَض في
> آخر.
>
> وهذا الإقليم في تحصيل ذلك: **ما الذي يجري بين المصدر والتشغيل، في كلا
> الوجهين** — وما الذي يُحذَف، وما الذي لا يُحذَف أبداً، ولماذا.

## أربعة مخرَجات لبرنامجٍ واحد

```dart
void main() {
  print('مرحباً');
}
```

<!-- shell -->

```
dart compile js            -o out.js     →     12 120 بايت
dart compile aot-snapshot  -o out.aot    →    927 232 بايت
dart compile exe           -o out.exe    →  5 749 600 بايت
dart compile kernel        -o out.dill   →  8 621 208 بايت
```

*(الأرقام من SDK مثبَّت وجهازٍ واحد. **والثابت هو الرتبة** لا الرقم.)*

| المخرَج | ما فيه | من يشغّله |
|---|---|---|
| `kernel` (`.dill`) | شجرةٌ وسيطة لبرنامجك **ومكتبات SDK كلِّها** | الـVM بـJIT |
| `aot-snapshot` | شيفرة آلةٍ لبرنامجك وما يستعمله | مشغّلٌ خارجيّ |
| `exe` | اللقطة **ومعها الـruntime كاملاً** | نفسه — مستقلّ |
| `js` | JavaScript، والـruntime هو المتصفّح | المتصفّح أو node |

**والصفّان الأول والأخير يفسّران البديهية الخامسة كلَّها.** الـkernel أكبر من
التنفيذيّ لأنه يحمل SDK **بلا حذف** — الـJIT يحتاجه كاملاً، فقد تُطلَب أي طريقةٍ
في أي لحظة.

## الحذف: ما لا يُنادى لا يُشحَن

```dart
class Used {
  void go() => print('مستعمَل');
}

class NeverUsedZZZ {
  void go() => print('لن يُستعمَل');
}

void main() {
  Used().go();
}
```

<!-- out -->

```
مستعمَل
```

<!-- shell -->

```
$ dart compile kernel -o out.dill main.dart >/dev/null && strings out.dill | grep -c NeverUsedZZZ
2
$ dart compile exe -o out.exe main.dart >/dev/null && strings out.exe | grep -c NeverUsedZZZ
0
```

**الاسم موجودٌ في مخرَج الـJIT، ومحذوفٌ من مخرَج AOT.** والصنف كلُّه ذهب: لا كود،
ولا اسم، ولا معلومة نوع.

وفي مخرَج الويب الأمر نفسه — ترجم بلا تصغير، ثم عُدّ:

<!-- shell -->

```
$ dart compile js --no-minify -O0 -o out.js main.dart >/dev/null && grep -c 'NeverUsedZZZ' out.js
0
$ grep -c 'Used' out.js
7
```

### الآلية، ولماذا `dart:mirrors` مستحيلة

<!-- part -->

```
   AOT starts from main() and walks every call it can PROVE happens.
   Anything not reached is deleted — code, names, type information.

        main ──▶ Used.go ──▶ print          kept
        NeverUsedZZZ                        deleted, entirely

   Now suppose a library could do this at run time:

        reflectClass(byName('NeverUsedZZZ')).newInstance(...)

   The name comes from a STRING. The compiler cannot prove which class
   is reachable — so it must keep ALL of them, with all their names.

   Tree shaking and reflection cannot both exist.
```

**ولهذا رُفضت `dart:mirrors` في الإقليم ٠٠** — لا لسياسةٍ، بل لأن وجودها يُبطِل
الحذف كلَّه، ويعيد حجم التنفيذيّ إلى حجم الـkernel.

**والبديل الذي اختارته اللغة:** التوليد وقت البناء. الحزم التي تحتاج انعكاساً —
تسلسلَ JSON، وحقن الاعتماديات — **تكتب كوداً** يقرؤه المترجم كأنك كتبتَه بيدك،
فيراه ويحذف ما لا يُستعمَل منه.

## زمن البدء

<!-- shell -->

```
time dart run main.dart      →  real 0.13 s   ·   0.13   ·   0.13
time ./main.exe              →  real 0.02 s   ·   0.01   ·   0.01
```

*(جهازٌ واحد. **والثابت هو النسبة**: عشرة أضعافٍ تقريباً.)*

**ولماذا؟** الـJIT يقرأ الـkernel، ويهيّئ الـVM، ويفسّر الشيفرة أوّلاً ثم يترجم
ما يسخن. والـAOT يبدأ من شيفرة آلةٍ جاهزة.

**والمقايضة معكوسة في الطرف الآخر:** برنامجٌ يعمل ساعةً في حلقةٍ ضيّقة قد يتفوّق
فيه الـJIT — لأنه يشاهد الأنواع الحقيقية أثناء التشغيل ويتخصّص لها، بينما الـAOT
حسم كل شيء وهو أعمى.

| | JIT (`dart run`) | AOT (`compile exe`) |
|---|---|---|
| زمن البدء | مئات الميلي ثانية | **عشراتها** |
| الذروة | يتحسّن مع التسخين | ثابتٌ من أوّل لحظة |
| الحجم | SDK كاملاً | المستعمَل + الـruntime |
| `dart:mirrors` | تعمل | **مرفوضة** |
| `assert` | بعَلَم | محذوفة |
| إعادة التحميل الساخنة | **نعم** | لا |

**والسطر الأخير هو سبب الوجهين أصلاً**، كما قيل في الإقليم ٠٠: التطوير يحتاج
برنامجاً حيّاً تتغيّر شيفرته تحته، والنشر يحتاج بدءاً فورياً.

## وعلى الويب: مترجمٌ ثالث

`dart compile js` ليس AOT ولا JIT — هو **مترجمٌ مصدرٍ إلى مصدر**، ويحذف أشدّ من
الاثنين لأن كل بايتٍ يُنقَل عبر الشبكة.

**ومعه قيود الإقليم ٠٢:** `int` تصير عدداً عائماً، ولا isolates بمعناها الحقيقيّ
(بل عمّالُ الويب برسائل)، ولا `dart:io` أصلاً.

**وهذه أشدّ نقطةٍ تختلف فيها اللغة عن نفسها.** ولذلك ثُبِّت هذا المنهج على الآلة
الأصلية، وأُعلِن الفرق حيث كان درساً.

## التمرين

**١ — اقتل الحذف بيدك.** اكتب برنامجاً فيه عشرة أصناف، تسعةٌ منها لا تُنادى.
ترجمه AOT وقِس الحجم.

الآن أضف **سطراً واحداً** يجعل المترجم عاجزاً عن إثبات أن التسعة غير مستعمَلة،
فيبقيها كلَّها. قِس من جديد. **ما هو ذلك السطر؟**

**٢ — اعثر على نقطة التقاطع.** اكتب حسبةً ثقيلة في حلقة، وشغّلها بـJIT وبـAOT
لأزمانٍ من عشر ميلي ثانية إلى عشر ثوانٍ.

**عند أي مدّةٍ يتفوّق الـJIT؟** وإن لم يتفوّق أبداً، فغيّر الحسبة إلى واحدةٍ
تعتمد على نوعٍ لا يظهر إلا وقت التشغيل، وأعِد.

**٣ — وازِن الثلاثة.** خذ `programs/tally.dart` من الإقليم ٠١ وترجمه بالثلاثة.
اقرأ السجلّ نفسه بكلٍّ منها وقِس: زمن البدء · زمن المعالجة · الحجم.

أيّها تشحن لأداةٍ تُنادى ألف مرّةٍ في نصٍّ برمجيّ؟ وأيّها لخادمٍ يعمل شهراً؟
اكتب حكمك ولماذا.

## الخلاصة

| ما رأيتَه | البديهية | أين يعود |
|---|---|---|
| أربعة مخرَجات، ولكلٍّ قارئه | الخامسة | ٢٢ |
| ما لا يُنادى يُحذَف | الحذف يفسّر رفض الانعكاس | ٢١ |
| البدء أسرع عشرةً في AOT | الخامسة — ثمن الضمانات | ٢٢ |
| الويب مترجمٌ ثالث بقيوده | أثر ٢٠١٥ (٠٠ · ٠٢) | — |

## البذرة

`dart compile exe` أنتج خمسة ميغابايت فيها **الـruntime كاملاً**: الجامع،
ومجدول الـisolates، وحلقة الأحداث، وجداول الأنواع.

فهذا الملفّ برنامجٌ أصليّ يعمل على نظامك مباشرةً، كأي ناتج `cc`.

**فهل يستطيع أن ينادي دالّةً في مكتبةٍ كتبتَها بـC؟**

جرّب: اكتب دالّة C تجمع عددين، وترجمها مكتبةً مشتركة، ونادِها من Dart. سيعمل.

ثم اكتب دالّة C تُرجِع `char *` من `malloc`. **من يحرّرها الآن؟** الجامع لا يعرف
أنها موجودة، وأنت لا تملك `free` في هذه اللغة.

والإقليم ٢٠ يجيب — وهناك يلتقي هذا المنهج بمنهج C التقاءً كاملاً.
