# الإقليم ١١ — الأنماط

> بنيتَ في الإقليم ٠١ اتّحاداً بـ`sealed` وطابقتَه، ورأيتَ المترجم يعدّ الحالات.
> وهذا الإقليم يفكّك تلك الآلية كاملةً: ما «النمط»، وأين يصحّ، وكيف يُحسَب
> الشمول، ومتى يسقط.
>
> والمرجع هنا C: البنية ذات الوسم (`tagged union`) موجودةٌ فيها منذ نصف قرن،
> والفرق ليس في التعبير — الفرق في **من يمسك يدك**.

## ما يفعله C

```c
#include <stdio.h>

enum Tag { TEXT, MOVE, QUIT };

struct Msg {
    enum Tag tag;
    union {
        const char *body;
        struct { int x, y; } to;
    };
};

void render(struct Msg m) {
    switch (m.tag) {
        case TEXT: printf("نصّ %s\n", m.body); break;
        case MOVE: printf("حركة %d,%d\n", m.to.x, m.to.y); break;
    }
}

int main(void) {
    render((struct Msg){ .tag = MOVE, .to = { 3, 4 } });
    render((struct Msg){ .tag = QUIT });
    printf("انتهى\n");
    return 0;
}
```

<!-- c -->

```
حركة 3,4
انتهى
```

**رسالة `QUIT` لم تُطبَع، والبرنامج خرج بالرمز صفر.** والمترجم قال ما عنده:

<!-- shell -->

```
$ cc -Wall -o msg native.c 2>&1 | head -1
native.c:14:13: warning: enumeration value 'QUIT' not handled in switch [-Wswitch]
```

**تحذير.** يُقرأ إن قرأتَه، ويُبتلَع في مخرَجِ بناءٍ فيه ألف سطر. وثلاثة أشياء
لا يمسكها C أصلاً: أن تقرأ `m.body` والوسم `MOVE`، وأن تنسى ضبط الوسم، وأن
تُضيف وسماً رابعاً فتنسى موضعاً في ملفٍّ آخر.

## وما تفعله Dart

```dart
sealed class Msg {
  const Msg();
}

final class Text extends Msg {
  final String body;
  final int len;
  const Text(this.body, this.len);
}

final class Move extends Msg {
  final (int, int) to;
  const Move(this.to);
}

final class Quit extends Msg {
  const Quit();
}

String render(Msg m) => switch (m) {
      Text(body: final b, len: final n) when n > 5 => 'نصٌّ طويل: $b',
      Text(body: final b) => 'نصّ: $b',
      Move(to: (final x, final y)) => 'حركة إلى $x,$y',
      Quit() => 'خروج',
    };

void main() {
  print(render(const Text('أهلاً', 5)));
  print(render(const Text('أهلاً يا صاح', 12)));
  print(render(const Move((3, 4))));
  print(render(const Quit()));
}
```

<!-- out -->

```
نصّ: أهلاً
نصٌّ طويل: أهلاً يا صاح
حركة إلى 3,4
خروج
```

**أربعة أشياء في تعبيرٍ واحد**، وكلٌّ منها كان سطراً في C:

الوسم صار **النوع** — لا حقلَ يُضبَط ولا يُنسى، والبانِي يضمنه (الإقليم ٠٦).

نمطُ `Text` **يفحص ويستخرج ويسمّي** معاً. ولا سبيل إلى قراءة
`body` من رسالةِ حركة: النمط الذي أعطاك الاسم هو الذي أثبت النوع.

ونمطُ `Move` **نمطٌ داخل نمط** — سجلٌّ مفكَّكٌ داخل صنفٍ مطابَق.

و`when` حارسٌ يميّز حالتين من النوع نفسه.

## الشمول يُحسَب، ويسقط

`sealed` تعطي المترجم قائمةً مغلقة (الإقليم ٠٧). فيعدّ الفروع ويقارن.

**ومَن ظنّ أن الحارس يشارك في العدّ أخطأ:**

```dart
sealed class Shape {
  const Shape();
}

final class Circle extends Shape {
  final double r;
  const Circle(this.r);
}

final class Square extends Shape {
  final double s;
  const Square(this.s);
}

String name(Shape x) => switch (x) {
      Circle(r: final r) when r > 10 => 'دائرة كبيرة',
      Square() => 'مربّع',
    };

void main() => print(name(const Square(1)));
```

<!-- err -->

```
main.dart:15:33: Error: The type 'Shape' is not exhaustively matched by the switch cases since it doesn't match 'Circle()'.
```

**الحارس لا يُحسَب.** والسبب أن `r > 10` تعبيرٌ يُقيَّم وقت التشغيل، ولا يستطيع
المترجم أن يبرهن أنه يصدق. فالفرع المحروس يغطّي «بعض» `Circle` — و«بعض» لا تكفي
لإغلاق النوع.

**وهذه ليست نقيصة.** هي الخطّ نفسه الذي يفصل البديهية الثانية عن التمنّي: ما
يُبرهَن يُقبَل، وما لا يُبرهَن يُطلَب صراحةً. أضف `Circle()` بلا حارس، فيُقبَل.

## النمط ليس في `switch` وحده

```dart
void main() {
  final (a, b) = (1, 'اب');
  print('$a $b');

  final [x, y, ...rest] = [1, 2, 3, 4];
  print('$x $y $rest');

  final json = <String, Object>{'name': 'أ', 'age': 5};
  if (json case {'name': final String n, 'age': final int g}) {
    print('$n $g');
  }

  var (p, q) = (1, 2);
  (p, q) = (q, p);
  print('$p $q');
}
```

<!-- out -->

```
1 اب
1 2 [3, 4]
أ 5
2 1
```

السطر الأول تفكيكٌ في **التصريح**. و`...rest` يلتقط الباقي في نمط قائمة.

و`if` بـ`case` **فحصٌ وتفكيكٌ معاً**: لو لم يكن المفتاح موجوداً، أو لم
يكن نوعه `String`، لفشل النمط ولم تدخل الكتلة. وهذا هو المدخل الآمن الوحيد إلى
`jsonDecode` — بدل سلسلةٍ من `as` و`!`.

**والسطر الأخير تبديلٌ بلا متغيّرٍ مؤقّت:** الطرف الأيمن يُقيَّم كاملاً قبل أن
يُسنَد أيُّ جزءٍ من الأيسر.

## السجلّ: النوع البنيويّ الوحيد

مرّ بك في الإقليم ٠٠ أن السجلّ **شكلُه**. وهذا ما يجعله شريك الأنماط:

```dart
(String, {int line, int col}) locate(String s) => (s, line: 3, col: 7);

void main() {
  final (name, :line, :col) = locate('main.dart');
  print('$name عند $line:$col');

  final a = (1, name: 'أ');
  final b = (1, name: 'أ');
  print(a == b);
  print(a.$1);
  print(a.name);
}
```

<!-- out -->

```
main.dart عند 3:7
true
1
أ
```

**حقولٌ موضعية ومسمّاةٌ معاً**: `$1` للموضعيّ، والاسم للمسمّى. و`:line` اختصارٌ
لـ`line: final line`.

**ومساواته من حقوله** بلا أن تكتب `==` ولا `hashCode` — وقارن بالإقليم ٠٦، حيث
كتبتَ الاثنين بيدك لصنفٍ بحقلين.

**والحدّ:** لا طرقَ للسجلّ، ولا يطبّق واجهةً، ولا يُسمّى نوعُه إلّا بشكله. فما
كبر ولزمه سلوكٌ يصير صنفاً.

## متى صنفٌ ومتى سجلّ

| | سجلّ | صنف |
|---|---|---|
| النوع | **بنيويّ** — شكله | اسميّ — اسمه |
| المساواة | من الحقول، مجّاناً | هويّة، إلّا أن تكتبها |
| طرقٌ وسلوك | لا | نعم |
| يطبّق واجهة | لا | نعم |
| يمنع الخلط | **لا** — شكلان متطابقان نوعٌ واحد | نعم |
| كلفة التصريح | صفر | صنفٌ كامل |

**والصفّ قبل الأخير هو الفاصل:** `(double, double)` للإحداثيات و`(double, double)`
للأمتار والثواني — **النوع نفسه**، ولا شيء يمنع خلطهما. فإن كان المنع مطلوباً،
فالصنف أو نوعُ التوسعة (الإقليم ١٠).

## التمرين

**١ — أغلق الحارس.** خذ `Shape` أعلاه واجعل الشمول يُقبَل **مع بقاء الحارس**،
بثلاث طرقٍ مختلفة. أيّها يبقي المترجم يعدّ لك عند إضافة فرعٍ ثالث؟

**٢ — اقرأ JSON بلا `as`.** خذ استجابةً متداخلة — كائنٌ فيه مصفوفةٌ فيها كائنات —
واستخرج منها ثلاثة حقولٍ بنمطٍ واحد.

ثم **أفسِد الاستجابة**: احذف حقلاً، غيّر نوع آخر، اجعل المصفوفة كائناً. في كل
مرّة: هل انفجر البرنامج أم فشل النمط؟ وما الفرق في يدك؟

**٣ — ابنِ `Result` كامل.** اكتب اتّحاداً `Result<T, E>` بفرعين، وطريقتين عليه:
`map` تحوّل النجاح وتترك الفشل، و`unwrapOr` تُرجِع بديلاً.

ثم استعمله في `programs/tally.dart` بدل `sealed class Line`. **كم موضعاً تغيّر؟**
وهل صار الكود أوضح أم أطول؟ اكتب حكمك ولماذا.

## الخلاصة

| ما رأيتَه | البديهية | أين يعود |
|---|---|---|
| الوسم صار نوعاً | الأولى — كل شيء كائن | ١٧ |
| النمط يفحص ويستخرج ويسمّي | الثانية | ١٥ · ١٧ |
| الحارس لا يُحسَب في الشمول | حدّ البرهان الساكن | — |
| النمط في `if` والتصريح والإسناد | — | ١٨ |
| السجلّ بنيويّ ولا يمنع الخلط | استثناء الاسمية (٠٠) | ١٠ |

## البذرة

بنيتَ في هذا الإقليم `Msg` بأربعة فروع، وكلُّ فرعٍ كائنٌ يُحجَز في الكومة. وفي
`render` بنيتَ سلاسل نصّية جديدة في كل نداء.

فمن يحرّرها؟ ومتى؟

سؤالٌ مؤجَّلٌ منذ الإقليم ٠٠، وحان وقته. جرّب هذا: احجز مليون كائنٍ قصير العمر
في حلقة، ثم احجز مليوناً تحتفظ بها كلِّها في قائمة. شغّل الاثنين بـ`--observe`
وقارن.

**أحدهما سيكون أرخص بكثير، والفرق ليس في العدد.** والإقليم ١٢ يقول لماذا، ولماذا
لا يوجد `sizeof` أصلاً.
