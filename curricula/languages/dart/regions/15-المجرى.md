# الإقليم ١٥ — `Stream`

> `Future` قيمةٌ واحدة تصل مرّة. والمجرى **سلسلةٌ** تصل مرّاتٍ لا تعرف عددها،
> وقد لا تنتهي أبداً.
>
> وفي C تقرأ من واصفٍ في حلقةٍ بـ`read`، وتملك أنت وتيرة القراءة. والمجرى يقلب
> الاتّجاه: المصدر هو الذي يدفع. وهذا الإقليم في كيف تستعيد السيطرة — ومتى
> تفقدها بلا أن تنتبه.

## المجرى كسول، ولا يبدأ حتى يُستمَع إليه

```dart
Stream<int> counter() async* {
  print('  [المصدر بدأ]');
  for (var i = 1; i <= 3; i++) {
    print('  [ينتج $i]');
    yield i;
  }
  print('  [المصدر انتهى]');
}

Future<void> main() async {
  print('أ · بنيتُ المجرى');
  final s = counter();
  print('ب · لم يعمل شيء بعد');
  await for (final v in s) {
    print('ج · استلمتُ $v');
  }
  print('د · انتهى');
}
```

<!-- out -->

```
أ · بنيتُ المجرى
ب · لم يعمل شيء بعد
  [المصدر بدأ]
  [ينتج 1]
ج · استلمتُ 1
  [ينتج 2]
ج · استلمتُ 2
  [ينتج 3]
ج · استلمتُ 3
  [المصدر انتهى]
د · انتهى
```

**ثلاثة أشياء في هذا المخرَج:**

نداء `counter()` لم ينفّذ سطراً. المجرى **وصفةٌ** لا عمل، ولا يبدأ حتى يستمع
أحد.

و`async*` تجعل الدالّة تُرجِع `Stream` بدل `Future`، و`yield` تُرسِل قيمةً
**وتتوقّف**.

**والتناوب هو الأهمّ:** «ينتج ٢» طُبعت **بعد** «استلمتُ ١»، لا قبلها. المصدر
يخطو خطوةً واحدة لكل خطوةٍ يخطوها المستهلك. وهذا هو **الضغط الخلفيّ**
(backpressure) في أبسط صوره: المصدر لا يسبق من يقرأ منه.

**وأثره في يدك:** الإقليم ٠١ قرأ ملفّاً بمجرًى. ولو كان الملفّ بغيغابايت، لبقيت
الذاكرة ثابتة — لأن `openRead` لا تسبق `await for`.

## مفردٌ ومُذاع

```dart
Stream<int> counter() async* {
  yield 1;
  yield 2;
}

Future<void> main() async {
  final s = counter();
  s.listen((v) => print('أ $v'));
  s.listen((v) => print('ب $v'));
  await Future.delayed(Duration.zero);
}
```

<!-- err -->

```
أ 1
Unhandled exception:
Bad state: Stream has already been listened to.
```

**المجرى المفرد لمستمعٍ واحد.** والسبب في السطر السابق: ما دام المصدر يتناوب مع
المستهلك، فأيّهما يحدّد الوتيرة إن كانا اثنين؟

والنوع الآخر لا يتناوب مع أحد:

```dart
import 'dart:async';

Future<void> main() async {
  final c = StreamController<int>.broadcast();

  c.stream.listen((v) => print('أ $v'));
  c.add(1);
  await Future.delayed(Duration.zero);

  c.stream.listen((v) => print('ب $v'));
  c.add(2);
  await Future.delayed(Duration.zero);

  await c.close();
  print('أُغلق');
}
```

<!-- out -->

```
أ 1
أ 2
ب 2
أُغلق
```

**المستمع الثاني لم يرَ `1`.** المذاع يبثّ ما يقع **بعد** الاشتراك، ولا يحتفظ
بشيء — لأنه لا يعرف كم مستمعاً سيأتي ولا متى.

| | مفرد | مُذاع |
|---|---|---|
| كم مستمعاً | واحد | بلا حدّ |
| متى يبدأ | عند الاستماع | يبثّ على أي حال |
| ما فات المشترك | يصل — لأنه لم يبدأ | **يضيع** |
| ضغطٌ خلفيّ | نعم | **لا** |
| مثاله | ملفّ · مقبس · مجرى `async*` | نقراتٌ · أحداثُ نظام |

**والاختيار ليس ذوقاً:** إن كان المصدر يستطيع أن ينتظر، فمفرد. وإن كان يقع سواءٌ
نظرتَ أم لم تنظر، فمذاع.

## الاشتراك شيءٌ تملكه — وتُغلقه

```dart
import 'dart:async';

Stream<int> forever() async* {
  var i = 0;
  while (true) {
    yield i++;
    await Future.delayed(const Duration(milliseconds: 1));
  }
}

Future<void> main() async {
  final sub = forever().listen((v) {
    if (v < 3) print('استلمت $v');
  });
  await Future.delayed(const Duration(milliseconds: 20));
  await sub.cancel();
  print('ألغيت');
  await Future.delayed(const Duration(milliseconds: 20));
  print('انتهى');
}
```

<!-- out -->

```
استلمت 0
استلمت 1
استلمت 2
ألغيت
انتهى
```

**`forever` حلقةٌ لا نهائية، والبرنامج خرج.** لأن `cancel` أوقفت المصدر عند
`yield`، فلم تعد الحلقة تدور.

**ولو لم تُلغَ، لبقيت تدور إلى الأبد** — ومعها كلُّ ما يلتقطه ردّ النداء. وهذا هو
الصفّ الثالث في جدول التسريب بالإقليم ١٢:

<!-- part -->

```
   sub = stream.listen(cb)      the SOURCE now holds a reference to cb
     │                          cb holds everything it captured  (ch. 05)
     ▼
   nothing you own points at the source any more
     │
     ▼
   the GC still cannot free any of it — the source is alive,
   because a timer / socket / file in the runtime is holding it.
```

**والقاعدة:** كل `listen` يقابله `cancel`. والمجرى الذي ينتهي بنفسه يلغي اشتراكه،
**والذي لا ينتهي مسؤوليتك**.

## البناء والتحويل

```dart
Stream<int> naturals() async* {
  for (var i = 1;; i++) {
    yield i;
  }
}

Stream<int> evens() async* {
  yield 0;
  yield* naturals().where((n) => n.isEven);
}

Future<void> main() async {
  print(await evens().take(5).toList());
  print(await naturals().take(4).map((n) => n * n).reduce((a, b) => a + b));
  print(await naturals().take(3).join('-'));
}
```

<!-- out -->

```
[0, 2, 4, 6, 8]
30
1-2-3
```

**`naturals` لا تنتهي، والبرنامج انتهى.** لأن `take(5)` تلغي الاشتراك بعد
الخامسة، فتموت الحلقة عند `yield`.

و`yield*` تُفرِغ مجرًى كاملاً في مجرى، بلا حلقةٍ تكتبها.

**وكلُّ محوِّلٍ هنا كسول:** `where` و`map` و`take` لا تنفّذ شيئاً حتى يسحب أحدٌ من
الطرف الآخر. والسلسلة تُقرأ من اليمين، والسحب يجري من اليسار.

## التمرين

**١ — اصنع الضغط الخلفيّ ثم اكسره.** اكتب مصدراً يطبع عند كل إنتاج، ومستهلكاً
ينتظر عشر ميلي ثانية عند كل استلام.

شغّله بـ`await for` وعُدّ ما أنتجه المصدر خلال ثانية. ثم استبدل بـ`listen` بلا
انتظار، وعُدّ من جديد. **ما الذي تغيّر، ولماذا؟**

**٢ — ابنِ مذاعاً يحتفظ.** اكتب غلافاً حول مجرًى مذاع يعطي كل مشتركٍ جديدٍ **آخر
قيمة** قبل أن يبدأ ببثّ الجديد.

كم حالةً احتجتَ أن تحفظ؟ وماذا يحدث إن اشترك أحدٌ قبل أن تصل أي قيمة؟

**٣ — امسك التسريب.** اكتب صنفاً يشترك في مجرًى في بانِيه ولا يلغي، وابنِ منه
عشرة آلاف كائنٍ ثم ارمِها كلَّها.

شغّل بـ`--observe` وخذ لقطتين للكومة. **كم نجا؟** ثم أضف طريقة `dispose` وأعِد.

## الخلاصة

| ما رأيتَه | البديهية | أين يعود |
|---|---|---|
| المجرى وصفةٌ لا عمل | الرابعة | ١٦ |
| التناوب هو الضغط الخلفيّ | الرابعة — حلقةٌ واحدة | ١٦ |
| المفرد ينتظر، والمذاع يبثّ | اختيارٌ من طبيعة المصدر | ١٧ |
| الاشتراك يُلغى وإلّا سرّب | ١٢ — طريقٌ لم تقصده | ٢١ |
| المحوّلات كسولةٌ كلُّها | — | — |

## البذرة

كلُّ ما سبق في **isolate واحد**: حلقةٌ واحدة، وطابوران، ومصدرٌ يتناوب مع مستهلك.
ولا شيء منه يستعمل أكثر من نواةٍ واحدة في معالجك.

فإن كان `tally.dart` من الإقليم ٠١ يحلّل سجلّاً بغيغابايت، فالقراءة لا تشغل
المعالج — والتحليل يشغله كلَّه. وحلقةُ الأحداث **متوقّفة** طوال ذلك.

جرّب: مرّر مليون عنصرٍ من isolate إلى آخر بـ`Isolate.run`، وقِس. ثم مرّر
مليونين.

**العلاقة خطّية.** وهذا وحده يقول لك ما الذي يجري بينهما — والإقليم ١٦ يسمّيه،
ويقول ما الذي يُستثنى منه.
