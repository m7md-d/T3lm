# الإقليم ٠٥ — الدالّة قيمة

> في C تملك **مؤشّر دالّة**: عنوانُ كودٍ، ولا شيء معه. ولذلك كل واجهةٍ في C
> تأخذ رَدَّ نداءٍ تأخذ معه `void *user_data` — لأن المؤشّر وحده لا يحمل سياقاً.
>
> وفي Dart الدالّة **كائن** كأي كائن (البديهية الأولى). وهذا الإقليم في ما
> يترتّب على ذلك: ما الذي تحمله معها، ومن يبقيه حيّاً، ومتى تكون دالّتان
> «نفسها».

## التوقيع نوع

```dart
void main() {
  int Function(int) f = (n) => n * 2;
  print(f(3));
  print(f is int Function(int));
  print(f is num Function(int));
  print(f is int Function(num));
}
```

<!-- out -->

```
6
true
true
false
```

**السطران الأخيران قاعدةُ تباينٍ كاملة في مخرَجين.**

`int Function(int)` **هي** `num Function(int)`: من وعد بإرجاع `int` يفي بعقدٍ
يطلب `num`. النوع المُرجَع **متغاير** (covariant).

وليست `int Function(num)`: من يقبل `int` فقط لا يصلح مكان من يقبل أي `num` —
سيُعطى `3.5` يوماً. المعامل **متغاير عكسياً** (contravariant).

**وقارن بالإقليم ٠٠:** في `List<T>` قبلت اللغة التغاير رغم أنه غير سليم، وزرعت
فحصاً حيّاً. وهنا رفضت ساكناً. **والفرق أن الرفض هنا لا يكلّف شيئاً** — توقيع
الدالّة معروفٌ كاملاً وقت الترجمة، بخلاف ما يُكتب في قائمةٍ بعد سنة.

## ما الذي تحمله معها

**الاعتقاد الشائع:** «الدالّة الداخلية تلتقط **قيمة** المتغيّر عند إنشائها.»

**ولماذا يبدو مقنعاً:** لأن أوّل مثالٍ يجرّبه الناس حلقة `for`، وهي تعطي الجواب
الذي يتوقّعه القائل بالضبط — للسبب الخاطئ.

```dart
void main() {
  final fs = <void Function()>[];
  for (var i = 0; i < 3; i++) {
    fs.add(() => print(i));
  }
  for (final f in fs) f();

  var j = 0;
  final gs = <void Function()>[];
  while (j < 3) {
    gs.add(() => print(j));
    j++;
  }
  for (final g in gs) g();
}
```

**المخرَج**:

```
0
1
2
3
3
3
```

**الحلقتان تفعلان الشيء نفسه، والمخرَجان مختلفان.**

### الآلية

<!-- part -->

```
   for (var i = 0; i < 3; i++)        ← a NEW binding of `i` per iteration

     closure #0 ──→ [ i = 0 ]
     closure #1 ──→ [ i = 1 ]         three cells, three closures
     closure #2 ──→ [ i = 2 ]

   var j = 0;  while (j < 3)          ← ONE binding of `j`, ever

     closure #0 ──┐
     closure #1 ──┼──→ [ j = 3 ]      one cell, three closures
     closure #2 ──┘                     (and the loop left it at 3)
```

**القاعدة الصحيحة:** الإغلاق يلتقط **المتغيّر** لا قيمته — فيرى كل تغيّرٍ يقع
عليه بعد الالتقاط. و`for` تصنع ربطاً جديداً في كل دورة، فتبدو كأنها التقطت
قيمة.

**وحدُّها:** هذا سلوك `for` **بمتغيّرها الخاصّ**. حرّك التصريح خارج الحلقة
وأبقِ الإسناد في رأسها، فيعود الجواب ثلاثةً في المرّات الثلاث.

**وأين يؤذي:** كل ردّ نداءٍ يُسجَّل داخل حلقة على متغيّرٍ خارجها. والعيب لا يظهر
حتى يُستدعى ردُّ النداء لاحقاً — بعد أن تكون الحلقة انتهت.

## والسياق يبقى حيّاً

```dart
int Function(int) adder(int by) {
  var calls = 0;
  return (int n) {
    calls++;
    print('نداءٌ رقم $calls');
    return n + by;
  };
}

void main() {
  final add5 = adder(5);
  print(add5(1));
  print(add5(2));
  final add7 = adder(7);
  print(add7(1));
}
```

<!-- out -->

```
نداءٌ رقم 1
6
نداءٌ رقم 2
7
نداءٌ رقم 1
8
```

**`adder` انتهت، و`calls` و`by` لم يموتا.** والنداء الثالث بدأ من واحدٍ لأن
`adder` الثانية صنعت خليّةً أخرى.

في C هذا مؤشّرٌ متدلٍّ حتماً: `by` على المكدّس، وإطار `adder` أُزيل عند
`return`. **وفي Dart المتغيّر الملتَقَط ينتقل إلى الكومة**، ويعيش ما دام الإغلاق
يشير إليه.

**وهذا هو ثمنه:** إغلاقٌ صغير يبقي على قيد الحياة **كل** ما التقطه. واحتفظ به في
حقلٍ طويل العمر، فتكون احتفظت بما لم تقصده — وهذا شكل التسريب في لغةٍ بجامع،
والإقليم ١٢ يقيسه.

## الوسائط: مسمّاةٌ واختياريةٌ ومطلوبة

```dart
String tag({required String name, int level = 1, String? note}) =>
    '$name/$level${note == null ? '' : " ($note)"}';

void main() {
  print(tag(name: 'أ'));
  print(tag(level: 3, name: 'ب'));
  print(tag(name: 'ج', note: 'ملاحظة'));
}
```

<!-- out -->

```
أ/1
ب/3
ج/1 (ملاحظة)
```

**الأقواس المعقوفة تجعل الوسائط مسمّاةً**، والترتيب عندها لا يعني شيئاً. و
`required` تعيد الإلزام إلى وسيطٍ مسمًّى، و`= 1` قيمةٌ افتراضية **يجب أن تكون
ثابتاً** بمعنى الإقليم ٠٤.

ورأيتَ في الإقليم ٠١ الشكل الآخر — الأقواس المعقوفة الحاصرة — وسيطٌ **موضعيّ**
اختياريّ، يُمرَّر بموضعه لا باسمه.

**ولماذا هذا كلُّه بدل التحميل الزائد؟** لأن Dart رفضت التحميل الزائد عمداً
(جدول الإقليم ٠٠). واسمٌ واحدٌ بوسائط مسمّاة يقول في موضع النداء ما يقوله توقيعٌ
ثانٍ — وأنت تقرأ النداء أكثر مما تقرأ التعريف.

## الاقتطاف، ومتى تكون دالّتان «نفسها»

```dart
class Counter {
  int n = 0;
  void bump() => n++;
}

void main() {
  final c = Counter();
  final f = c.bump;
  f();
  f();
  print(c.n);
  print(identical(c.bump, c.bump));
  print(c.bump == c.bump);
  print(identical(print, print));
}
```

<!-- out -->

```
2
false
true
true
```

`c.bump` بلا أقواس **اقتطافٌ** (tear-off): قيمةٌ دالّية تحمل الطريقة **ومستقبِلَها
معاً**. وهي جواب Dart عن `void *user_data` في C: لا يوجد سياقٌ منفصل، لأن السياق
داخل القيمة.

**والسطران الأوسطان يفرّقان بين سؤالين:**

`identical` تسأل عن الكائن — وكل اقتطافٍ لطريقةِ نسخةٍ يبني **كائناً جديداً**،
فالجواب `false`.

`==` على الاقتطاف معرَّفةٌ في اللغة: تتساوى إن كانت الطريقة نفسها والمستقبِل
نفسه. فالجواب `true`.

والدالّة العليا (`print`) ليس لها مستقبِل، فاقتطافها **مقيَّس** — كما تُقيَّس
`const` في الإقليم ٠٤ — و`identical` تصدّق.

**وأين يؤذي:** واجهةٌ تسجّل ردود نداء وتلغيها بالمطابقة. سجّل `c.bump` وألغِ
`c.bump`، فإن كان الإلغاء بـ`identical` لم يُلغَ شيء. احفظ القيمة في متغيّرٍ
وألغِ به.

## التمرين

**١ — اصنع الفرق بيدك.** اكتب حلقةً واحدة تنتج `0 1 2` وأخرى تنتج `3 3 3`،
**بلا `while`** — بـ`for` في الحالتين، وبتغييرٍ في سطرٍ واحد.

ثم اشرح لنفسك أين ذهب الربط الجديد.

**٢ — امسك التسريب.** اكتب دالّةً تبني قائمةً بعشرة ملايين عنصر، ثم تُرجِع إغلاقاً
**لا يستعمل القائمة** لكنه يستعمل متغيّراً آخر صُرّح في نفس النطاق.

احتفظ بالإغلاق وشغّل `dart run --observe`. **هل تحرّرت القائمة؟** ثم انقل
المتغيّر المستعمَل إلى نطاقٍ أضيق وأعِد القياس.

**٣ — ابنِ التحميل الزائد.** أعطِ صنفاً طريقةً واحدة تتصرّف كثلاث: `Point.from`
تقبل إمّا `(int, int)` أو نصّاً `"3,4"` أو سجلّاً. **بلا `dynamic`.**

كم صيغةً وجدتَ؟ وأيّها يبقي المدقّق يفحص؟ (وواحدةٌ منها من الإقليم ٠٠.)

## الخلاصة

| ما رأيتَه | البديهية | أين يعود |
|---|---|---|
| توقيع الدالّة نوع، وتباينُه سليمٌ ساكناً | الثانية | ٠٩ |
| الإغلاق يلتقط المتغيّر لا القيمة | المرجع دائماً (٠٠) | ١٣ · ١٤ |
| الملتقَط ينتقل إلى الكومة | الأولى — الجامع يملك | ١٢ |
| وسائط مسمّاة بدل التحميل الزائد | الوضوح على الإيجاز | ٠٦ |
| الاقتطاف يحمل المستقبِل | الأولى — كل شيء كائن | ١٥ · ١٧ |

## البذرة

بنيتَ في هذا الإقليم `Counter` بحقلٍ وطريقة، وكتبتَ `Counter()` بلا كلمة `new`.
وفي الإقليم ٠٤ رفض المترجم بانياً `const` لأن حقلاً واحداً لم يكن `final`.

**فما الذي يجري بين `Counter()` وأوّل سطرٍ في الجسم؟**

اكتب صنفاً بحقلٍ `final` يُهيَّأ من وسيط، وحقلٍ آخر `final` يُحسَب منه، وضع
`print` في الجسم. ثم حاول إسناد الحقل الثاني **داخل الجسم**.

المترجم سيرفض، ورسالتُه تذكر موضعاً لم تكتبه: **قائمة التهيئة**. والإقليم ٠٦
يقول لماذا توجد أصلاً، ولماذا تسبق الجسم حتماً.
