# الإقليم ١٦ — الـisolate

> كلُّ ما بنيتَه في الأقاليم الثلاثة السابقة يعمل في **نواةٍ واحدة**. حلقةٌ واحدة،
> وطابوران، ومصدرٌ يتناوب مع مستهلك — ولا سطر منه يستعمل معالجك كلَّه.
>
> وأريتُك في الإقليم ٠٠ عدّاداً بقي `7` هنا بينما رآه الآخر `1000`. وهذا الإقليم
> في الآلة التي تحت تلك الجملة: **كومةٌ لكلٍّ**، ورسائل تُنسَخ، وثمنٌ يُقاس.

## عاملٌ في سطر

```dart
import 'dart:isolate';

int heavy(int n) {
  var s = 0;
  for (var i = 0; i < n; i++) {
    s += i % 7;
  }
  return s;
}

Future<void> main() async {
  print('أ · بدأتُ');
  final r = await Isolate.run(() => heavy(50000000));
  print('ب · $r');
}
```

<!-- out -->

```
أ · بدأتُ
ب · 149999997
```

`Isolate.run` تبني isolate جديداً، وتشغّل الإغلاق فيه، وتُرجِع النتيجة، وتقتله.
**وحلقةُ الأحداث هنا بقيت حرّةً** طوال ذلك — تخدم مؤقّتاتٍ ومقابس بينما ذاك يحسب.

**وهذا هو الفرق عن كل ما سبق:** `await` في الإقليم ١٤ لم تكن توازياً، وهذه توازٍ
حقيقيّ على نواةٍ أخرى.

## والثمن: كل شيءٍ يُنسَخ

```dart
import 'dart:isolate';

int sum(List<int> xs) => xs.fold(0, (a, b) => a + b);

Future<void> main() async {
  for (final n in [1000000, 2000000, 4000000]) {
    final data = List<int>.generate(n, (i) => i);
    final t0 = DateTime.now();
    final r = await Isolate.run(() => sum(data));
    final ms = DateTime.now().difference(t0).inMilliseconds;
    print('$n عنصراً → $ms م.ث  (المجموع $r)');
  }
}
```

<!-- runs -->

```
1000000 عنصراً → 14 م.ث
2000000 عنصراً → 22 م.ث
4000000 عنصراً → 35 م.ث
```

*(الأرقام من جهازٍ واحد. **والثابت هو الشكل**: ضاعِف المُدخَل يتضاعف الزمن.)*

**العلاقة خطّية، وهذا وحده يثبت النسخ.** فلو كانت الذاكرة مشتركة لكان الزمن
ثابتاً مهما كبرت القائمة.

**والحساب الذي يجب أن تجريه قبل كل `Isolate.run`:**

<!-- part -->

```
   worth it   ⟺   compute_time  >  copy_in + copy_out

   summing 4M ints :  copy ≈ 35 ms  ·  compute ≈ 8 ms    → LOSS
   parsing 4M ints :  copy ≈ 35 ms  ·  compute ≈ 900 ms  → WIN
```

**فالـisolate ليس أسرع بطبيعته.** هو أسرع حين يكون العمل أثقل من نقل مادّته —
وإلّا فقد دفعتَ نقلاً واشتريتَ تأخيراً.

## ما لا يُنسَخ

```dart
import 'dart:isolate';

class Frozen {
  final int n;
  const Frozen(this.n);
}

Future<void> main() async {
  const f = Frozen(1);
  const s = 'نصٌّ ثابت';
  final list = [1, 2, 3];

  final r = await Isolate.run(() => [
        identical(f, const Frozen(1)),
        identical(s, 'نصٌّ ثابت'),
        list.length,
      ]);
  print(r);
}
```

<!-- out -->

```
[true, true, 3]
```

**الكائن الثابت هو نفسه على الجانبين.** `identical` صدّقت داخل isolate آخر — أي
أنه **لم يُنسَخ**.

والسبب أن ما لا يتغيّر لا يحتاج عزلاً: البديهية الثالثة تمنع الذاكرة المشتركة لأن
المشترك **المتغيّر** يُنتج سباقاً. والثابت لا يُنتج شيئاً.

**وهنا يُدفَع ثمن `const` من الإقليم ٠٤ ويُسترجَع:** ما بنيتَه وقت الترجمة يعبر
الحدّ مجّاناً، وما بنيتَه وقت التشغيل يُنسَخ.

**وقائمة ما يعبر بلا نسخ:** الأعداد والقيم المنطقية و`null` · السلاسل الحرفية ·
الكائنات `const` · `SendPort` نفسه · والكود (الـisolates في مجموعةٍ واحدة تتشارك
الشيفرة المترجَمة).

## أو يُنقَل ولا يُنسَخ

للبيانات الثقيلة مهربٌ يُغيّر الدلالة:

```dart
import 'dart:isolate';
import 'dart:typed_data';

Future<void> main() async {
  final t = TransferableTypedData.fromList([Uint8List(8)]);
  final n = await Isolate.run(() => t.materialize().lengthInBytes);
  print('هناك: $n بايتاً');
  print('هنا : ${t.materialize().lengthInBytes}');
}
```

<!-- err -->

```
هناك: 8 بايتاً
Unhandled exception:
Invalid argument(s): Attempt to materialize object that was transferred already.
```

**هذه دلالةُ نقل** (move) لا نسخ: المخزن انتقل، **والمصدر مات**. وهي أقرب ما في
Dart إلى `std::move`، ولا تصلح إلا لبيانات `dart:typed_data`.

**والقاعدة:** إن كان ما تنقله بايتاتٍ خامّاً — صورةً أو ملفّاً أو رزمةً — فانقله
ولا تنسخه. وما كان رسماً من كائنات، فلا مهرب: يُنسَخ أو يُعاد تصميمه.

## الحوار الطويل

`Isolate.run` ترسل مرّةً وتستقبل مرّةً ثم تموت. وللحوار المستمرّ:

```dart
import 'dart:isolate';

Future<void> main() async {
  final fromWorker = ReceivePort();

  await Isolate.spawn((SendPort out) {
    final inbox = ReceivePort();
    out.send(inbox.sendPort);
    inbox.listen((msg) {
      if (msg == 'قف') {
        inbox.close();
        return;
      }
      out.send('صدى: $msg');
    });
  }, fromWorker.sendPort);

  final events = fromWorker.asBroadcastStream();
  final toWorker = await events.first as SendPort;

  toWorker.send('أ');
  toWorker.send('ب');
  await for (final m in events.take(2)) {
    print(m);
  }
  toWorker.send('قف');
  fromWorker.close();
}
```

<!-- out -->

```
صدى: أ
صدى: ب
```

**المصافحة هي النمط:** الوالد يفتح منفذَ استقبال ويمرّر `sendPort` إلى الوليد،
والوليد يفتح منفذَه ويرسل `sendPort` الخاصّ به في أوّل رسالة. وعندها يملك كلٌّ
طريقاً إلى الآخر.

**ولاحظ ما لا يوجد هنا:** لا قفل، ولا `mutex`، ولا `volatile`، ولا فحص سباق. لأن
الشرط المادّي للسباق غير موجود — وهو ما وعدت به البديهية الثالثة.

## والخطأ يعبر

```dart
import 'dart:isolate';

Future<void> main() async {
  try {
    await Isolate.run(() => throw StateError('انفجر هناك'));
  } on StateError catch (e) {
    print('التُقط هنا: ${e.message}');
  }
}
```

<!-- out -->

```
التُقط هنا: انفجر هناك
```

**الاستثناء نُسخ وأُعيد رميُه** في هذا الجانب. وهذا من `Isolate.run` وحدها —
و`Isolate.spawn` الخام لا تفعله، فتحتاج `onError` تمرّره عند التوليد وإلّا مات
الوليد صامتاً.

## Dart مقابل C في التزامن

| | خيوط C | isolates |
|---|---|---|
| الذاكرة | مشتركة | **معزولة** |
| نقل البيانات | مجّانيّ (مؤشّر) | نسخٌ خطّيّ الكلفة |
| السباق | ممكن، واحتماليّ الظهور | **مستحيل** |
| الأداة الواقية | قفلٌ تكتبه وتصيبه أو تخطئه | لا شيء — بلا حاجة |
| الخلل النموذجيّ | سباقٌ يظهر مرّةً في الألف | **تصميمٌ ينسخ أكثر مما يحسب** |
| القياس قبل البناء | تحليلُ سباقات | **حسابُ نسخٍ مقابل حساب** |

**والصفّ الأخير هو ما ينتقل إليك:** المهارة في C أن تعرف أين تقفل. والمهارة هنا
أن تعرف **ما الذي يستحقّ العبور**.

## التمرين

**١ — اعثر على نقطة التعادل.** خذ عمليةً على `List<int>` واحسب زمنها في الـisolate
الرئيس وفي isolate آخر، لأحجامٍ من ألفٍ إلى عشرة ملايين.

**عند أي حجمٍ يصير الـisolate رابحاً؟** ثم غيّر العملية إلى واحدةٍ أثقل عشر
مرّات، وأعِد. كيف تحرّكت النقطة؟

**٢ — أعِد تصميم النقل.** عندك مليون سجلٍّ من صنفٍ بأربعة حقول، وتريد معالجتها في
isolate. انقلها بثلاث صيغ: قائمةَ كائنات · قائمةَ سجلّات · و`Uint8List` مُرمَّزة
بيدك.

قِس الثلاث. **وأيّها كلّفك أكثر في الكود؟** اكتب حكمك على المقايضة.

**٣ — ابنِ مسبحاً.** اكتب مجموعةً من أربعة isolates تبقى حيّة، وتوزّع عليها
مهامّاً من طابور. قِس مقابل `Isolate.run` لكل مهمّة.

كم وفّرتَ؟ ومن أين جاء التوفير — من النسخ أم من البناء؟

## الخلاصة

| ما رأيتَه | البديهية | أين يعود |
|---|---|---|
| توازٍ حقيقيّ على نواةٍ أخرى | الثالثة | ١٩ |
| النسخ خطّيّ، والحساب قبل البناء | الثالثة — ثمنها | ٢٢ |
| الثابت يعبر مجّاناً | ٠٤ — التقييس | ٢٢ |
| النقل يقتل المصدر | مهربٌ منضبط | ٢٠ |
| لا قفل ولا سباق | الثالثة | — |

## البذرة

`Isolate.run` نسخت قائمةً بأربعة ملايين عنصرٍ في خمسٍ وثلاثين ميلي ثانية.
و`TransferableTypedData` نقلت أربعين ميغابايت ولم تنسخ.

فما الذي يقرّر أيّهما؟ ولماذا لا تستطيع أن تنقل قائمةً من كائنات؟

الجواب سؤالٌ آخر: **أين تسكن بايتات `Uint8List`، وأين تسكن بايتات كائن؟**

وسؤالٌ ثالث يفتح ما بعده: إن كان لـ`Uint8List` مخزنٌ متّصلٌ بعنوان، **فهل تستطيع
أن تعطي عنوانه لدالّة C؟**

جرّب `dart:ffi`. والإقليم ٢٠ يقول من يملك تلك البايتات حين تعبر الحدّ، ومن
يحرّرها.
