# الإقليم ١٢ — الكومة والجامع

> منذ الإقليم ٠٠ وأنت تحمل سؤالاً معلّقاً: **من يحرّر؟ ومتى؟** وسؤالاً ثانياً
> أشدّ إزعاجاً لمن جاء من C: **لماذا لا يوجد `sizeof`؟**
>
> والجوابان واحد. وهذا الإقليم يعطيه — بأرقامٍ تقيسها، وبحدٍّ تصطدم به.

## عابرٌ ومحفوظ: الفرق ليس في العدد

**الاعتقاد الشائع:** «الحجز ثمنٌ يُدفَع مرّةً لكل كائن. فمليون كائنٍ يكلّف مليون
حجزة، سواءٌ احتفظتَ بها أم رميتها.»

**ولماذا يبدو مقنعاً:** لأنه صحيحٌ حرفياً في C. `malloc` مليون مرّة كلفتُه
واحدة، و`free` بعدها كلفةٌ أخرى، والاحتفاظ مجّانيّ.

هذان برنامجان. كلاهما يبني **عشرين مليون** كائنٍ من الصنف نفسه، وكلاهما يعمل في
كومةٍ حدُّها أربعةٌ وستّون ميغابايت:

<!-- part: heap-transient -->

```dart
var sink = 0;
for (var i = 0; i < 20000000; i++) {
  sink += Small(i).a;        // يُبنى ثم لا يُشار إليه
}
```

<!-- out -->

```
نجا، والمجموع: 199999990000000
```

<!-- part: heap-retained -->

```dart
final kept = <Small>[];
for (var i = 0; i < 20000000; i++) {
  kept.add(Small(i));        // يُبنى ويبقى مُشاراً إليه
}
```

<!-- err -->

```
Exhausted heap space, trying to allocate 16 bytes.
Unhandled exception:
Out of Memory
```

**العدد واحد، والصنف واحد، والحدّ واحد. والنتيجة نجاةٌ وموت.**

### الآلية: جيلان لا كومةٌ واحدة

<!-- part -->

```
   ┌── new space (small, scanned often) ──┐   ┌── old space (large, rare) ──┐
   │                                      │   │                             │
   │   allocation = bump a pointer        │   │   survivors are copied here │
   │   ↓                                  │   │   collection here is costly │
   │  [obj][obj][obj][obj]────────▶       │   │                             │
   │                                      │   │                             │
   └──────────────────────────────────────┘   └─────────────────────────────┘

   Collection of new space COPIES OUT the live objects, then declares
   the whole region empty in one step.

     cost  ∝  number of SURVIVORS        not  number of allocations
```

**تكلفة الجمع تتناسب مع ما نجا، لا مع ما حُجز.** وفي الحلقة الأولى لا ينجو
شيء — فيُمسَح الفضاء كلُّه في خطوةٍ واحدة، مهما بلغ العدد. وفي الثانية ينجو كلُّ
شيء، فيُنسَخ إلى الفضاء القديم حتى يمتلئ.

**القاعدة الصحيحة:** الحجز في Dart تحريكُ مؤشّر، وثمنُه يقع على **البقاء** لا على
الإنشاء.

**وحدُّها:** «قصير العمر» يعني أن يموت قبل جمعةٍ للفضاء الجديد. وكائنٌ يعيش عبر
عدّة جمعاتٍ يُرقّى إلى الفضاء القديم ويصير ثمنُه ثمن الأبد.

**وأين يفيد:** إطارٌ يعيد بناء شجرة واجهةٍ ستّين مرّةً في الثانية يبني ملايين
الكائنات ويرميها. لولا هذا التقسيم لكان تصميماً مستحيلاً.

## وهذا شكله في الزمن

```dart
import 'dart:io';

class Small {
  final int a;
  Small(this.a);
}

void main() {
  const n = 5000000;

  var sink = 0;
  final t0 = DateTime.now();
  for (var i = 0; i < n; i++) {
    sink += Small(i).a;
  }
  final transient = DateTime.now().difference(t0).inMilliseconds;

  final before = ProcessInfo.currentRss;
  final kept = <Small>[];
  final t1 = DateTime.now();
  for (var i = 0; i < n; i++) {
    kept.add(Small(i));
  }
  final retained = DateTime.now().difference(t1).inMilliseconds;
  final grew = ProcessInfo.currentRss - before;

  print('عابر  : $transient م.ث');
  print('محفوظ : $retained م.ث');
  print('نموّ   : ${grew ~/ 1048576} م.ب  ← ${grew ~/ n} بايتاً للكائن');
  print(sink != 0 && kept.length == n);
}
```

<!-- runs -->

```
عابر  : 3 م.ث
محفوظ : 218 م.ث
نموّ   : 172 م.ب  ← 36 بايتاً للكائن
true
```

*(الأرقام من جهازٍ واحد. **والثابت هو النسبة**: خمسون إلى سبعين ضعفاً.)*

## ولماذا لا يوجد `sizeof`

شغّل البرنامج أعلاه ثلاث مرّات، وانظر السطر الثالث:

<!-- shell -->

```
نموّ : 172 م.ب  ← 36 بايتاً للكائن
نموّ : 126 م.ب  ← 26 بايتاً للكائن
نموّ : 197 م.ب  ← 41 بايتاً للكائن
```

**الصنف نفسه، والعدد نفسه، وثلاثة أجوبة.** وليس هذا عيباً في القياس — هو الجواب
نفسه:

- الجامع **يؤجّل** ما لا يحتاج إلى تحريره، فما تراه مقيمٌ لا مطلوب.
- الكائن قد يكون في الفضاء الجديد أو منسوخاً إلى القديم، **ومعه نسخته المؤقّتة**.
- والـruntime يحجز من النظام على دفعاتٍ لا بالبايت.

**فلو وُجد `sizeof` لكان كاذباً.** السؤال «كم يشغل هذا الكائن؟» لا جواب **واحد**
له في لغةٍ يملك فيها الـruntime التمثيلَ وتوقيتَ التحرير معاً.

**وما بقي لك بدلاً منه:** القياس الإحصائيّ أعلاه، و`dart run --observe` لملفّ
التخصيص الحيّ، و`dart:typed_data` حين تحتاج عرضاً تعرفه بالبايت (الإقليم ٠٢).

## التسريب في لغةٍ بجامع

الجامع يحرّر ما لا طريق إليه. **فالتسريب ليس نسياناً — هو طريقٌ لم تقصده.**

```dart
class Cache {
  static final _entries = <String, List<int>>{};

  static void put(String key) {
    _entries[key] = List<int>.filled(1000, 0);
  }

  static int get count => _entries.length;
}

void main() {
  for (var i = 0; i < 100000; i++) {
    Cache.put('مفتاح $i');
  }
  print('محتفَظٌ به: ${Cache.count}');
}
```

<!-- out -->

```
محتفَظٌ به: 100000
```

**لا خطأ هنا في نظر أي أداة.** والكود صحيحٌ نوعياً، ولا شيء «مفقود» — كل قائمةٍ
لها مالكٌ حيّ، وهو حقلٌ ساكن يعيش عمر البرنامج.

**وثلاثة أشكالٍ لهذا الطريق غير المقصود**، كلُّها مرّت بك:

| الشكل | من أين | الإقليم |
|---|---|---|
| حقلٌ ساكن يجمع ولا يُفرِّغ | كما أعلاه | — |
| إغلاقٌ يبقي كلَّ ما التقطه | مُخزَّنٌ في حقلٍ طويل العمر | ٠٥ |
| مستمعٌ لم يُلغَ اشتراكه | يبقيه المصدر حيّاً | ١٥ |

**والأداة الوحيدة:** `--observe` ثم لقطتان للكومة بينهما عمل، ومقارنةُ ما نما.

## الجدول الذي يُختَم به سؤال الإقليم ٠٠

| السؤال | C | Dart |
|---|---|---|
| من يحجز؟ | أنت | الـruntime، بتحريك مؤشّر |
| كم يكلّف الحجز؟ | بحثٌ في قوائم حرّة | **تحريك مؤشّر** |
| من يحرّر؟ | أنت | الجامع |
| متى يُحرَّر؟ | حين تقول | حين لا يبقى طريق — ولا تعرف متى |
| ما ثمن الكثرة؟ | عدد الحجزات | **عدد الناجين** |
| كم يشغل الكائن؟ | `sizeof` | لا جواب واحد |
| ما شكل الخلل؟ | تحريرٌ مزدوج · مؤشّرٌ متدلٍّ | **طريقٌ لم تقصده** |

## التمرين

**١ — ارفع الحدّ حتى ينجو.** خذ البرنامج المحفوظ أعلاه واضبط
`--old_gen_heap_size` بمضاعفةٍ ثم تنصيف حتى تجد أصغر قيمةٍ ينجو عندها.

اقسمها على عشرين مليوناً. **كم بايتاً للكائن؟** وقارن الرقم بالسطر الثالث في
القياس الإحصائيّ — أيّهما أصدق، ولماذا؟

**٢ — رقِّ كائناً بيدك.** اكتب حلقةً تحتفظ بكل كائنٍ **مؤقّتاً** في مصفوفةٍ
دائرية سعتها `k`، فيعيش الكائن `k` دورةً ثم يُنسى.

جرّب `k` من واحدٍ إلى مليون وقِس الزمن. **أين تقفز الكلفة؟** وماذا يقول ذلك عن
حجم الفضاء الجديد؟

**٣ — امسك التسريب الثاني.** ابنِ التسريب الذي مصدره **إغلاق** لا حقلٌ ساكن
(الصفّ الثاني في الجدول)، بحيث يبدو الكود سليماً في المراجعة.

ثم أصلحه بتغييرٍ في سطرٍ واحد، وأثبت الإصلاح بـ`--observe` لا بالنظر.

## الخلاصة

| ما رأيتَه | البديهية | أين يعود |
|---|---|---|
| الحجز تحريكُ مؤشّر | الأولى — الـruntime يملك الكومة | ١٩ |
| الثمن على الناجين لا الحجزات | جيلان | ١٦ |
| لا `sizeof`، ولا جواب واحد | الأولى | ٢٠ |
| التسريب طريقٌ لم تقصده | الجامع يحرّر ما انقطع | ١٥ |

## البذرة

كل ما في هذا الإقليم كان في **isolate واحد**: كومةٌ واحدة، وجامعٌ واحد يوقف
كودَها ليجمع.

فماذا لو كان لديك اثنان؟

في C جوابك خيطان يتشاركان الكومة، ومعهما قفلٌ وسباق. وقلتُ لك في الإقليم ٠٠ إن
Dart لا تفعل ذلك، وأريتُك عدّاداً بقي `7` بينما رآه الآخر `1000`.

فإن لم تُشارَك الكومة، **فكيف تعبر قائمةٌ بمليون عنصرٍ من هنا إلى هناك؟**

جرّبها. ثم قِس الزمن ومرّة أخرى بمليونين. **العلاقة خطّية** — وهذا وحده يقول لك
ما الذي يجري. والإقليم ١٦ يسمّيه، ويقول ما الذي لا يُنسَخ.
