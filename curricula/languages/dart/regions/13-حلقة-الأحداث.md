# الإقليم ١٣ — حلقة الأحداث

> قلتُ في الإقليم ٠٠ إن `async` ليست خيطاً، وأريتُك ترتيباً يتكرّر في كل تشغيل.
> وقلتُ في ١٢ إن الجامع يوقف كود الـisolate ليجمع — **كودَه هو، لأنه واحد**.
>
> وهذا الإقليم في الآلة التي تجعل الاثنين ممكنين: **حلقةٌ واحدة وطابوران**.
> وحين تفهمها، تصير كل `await` في المنهج حساباً على ورقة لا مفاجأة.

## الطابوران

```dart
import 'dart:async';

void main() {
  print('١ · متزامن');

  Timer.run(() => print('٦ · Timer.run'));
  Future(() => print('٧ · Future()'));
  Future.delayed(Duration.zero, () => print('٨ · delayed(0)'));

  scheduleMicrotask(() => print('٣ · scheduleMicrotask'));
  Future.microtask(() => print('٤ · Future.microtask'));
  Future.value(0).then((_) => print('٥ · value().then'));

  print('٢ · متزامن');
}
```

<!-- out -->

```
١ · متزامن
٢ · متزامن
٣ · scheduleMicrotask
٤ · Future.microtask
٥ · value().then
٦ · Timer.run
٧ · Future()
٨ · delayed(0)
```

**شغّله عشر مرّات: الترتيب نفسه.** ولاحظ أن السطور الثلاثة الأخيرة سُجِّلت
**قبل** الثلاثة التي سبقتها في المخرَج — ومع ذلك تأخّرت.

### الآلية

<!-- part -->

```
   ┌───────────────────────────────────────────────────────────┐
   │  1.  run the synchronous code to completion               │
   │                                                           │
   │  2.  drain the MICROTASK queue — all of it,               │
   │      including anything appended while draining           │
   │                                                           │
   │  3.  take exactly ONE item from the EVENT queue           │
   │                                                           │
   │  4.  go back to step 2                                    │
   └───────────────────────────────────────────────────────────┘

   microtask queue :  scheduleMicrotask · Future.microtask · .then on a
                      Future that is ALREADY complete · resuming after await
   event queue     :  Timer · Future() · Future.delayed · I/O · streams
```

**قاعدتان تفسّران كل ما سبق:**

الأولى: **المهامّ الدقيقة تُستنزَف كلُّها قبل أي حدث.** فالطابور الأول له أولويةٌ
مطلقة، لا مجرّد أسبقية.

الثانية: **كلُّ طابورٍ يخدم بترتيب التسجيل.** ولذلك جاء `Timer.run` قبل `Future()`
— سُجّل قبله.

## ولهذا تُجَوَّع الحلقة

الأولوية المطلقة ليست مجّانية.

```dart
import 'dart:async';

void main() {
  final t0 = DateTime.now();
  Timer.run(() {
    final ms = DateTime.now().difference(t0).inMilliseconds;
    print('الحدث وصل بعد $ms م.ث');
  });

  var n = 0;
  void loop() {
    n++;
    var junk = 0;
    for (var i = 0; i < 200; i++) junk += i;
    if (junk >= 0 && n < 200000) scheduleMicrotask(loop);
  }

  scheduleMicrotask(loop);
  print('سجّلتُ حدثاً ثم مئتي ألف مهمّةٍ دقيقة');
}
```

<!-- runs -->

```
سجّلتُ حدثاً ثم مئتي ألف مهمّةٍ دقيقة
الحدث وصل بعد 26 م.ث
```

**الحدث سُجّل أوّلاً وانتظر ستّاً وعشرين ميلي ثانية.** ولو كان هذا إطاراً في
واجهةٍ لضاع، ولو كان قراءةَ مقبسٍ لتأخّرت.

**والمهمّة الدقيقة تستطيع أن تُطيل الطابور وهو يُستنزَف** — وهي ما فعلته الحلقة
أعلاه. فلو لم يكن للعدّاد حدّ، لما وصل الحدث **أبداً**، والبرنامج حيٌّ لا معلّق.

**والقاعدة:** لا تضع في الطابور الدقيق إلا ما يجب أن يقع **قبل** أن يلمس أحدٌ
حالةً غير متّسقة. وكل ما عداه إلى طابور الأحداث.

## `await` تنقلك إلى الطابور الدقيق

```dart
import 'dart:async';

Future<void> main() async {
  print('أ');
  await null;
  print('ج');
  scheduleMicrotask(() => print('د'));
  await Future.delayed(Duration.zero);
  print('هـ');
}
```

<!-- out -->

```
أ
ج
د
هـ
```

**`await null` ليست عدماً.** هي: سجّل بقيّة الدالّة **مهمّةً دقيقة** وعُد الآن.
ولذلك طُبع السطر الذي يليها بعد أن انتهى الكود المتزامن، لا في مكانه.

و`await Future.delayed` تنتظر **حدثاً**، فتمرّ عليه كلُّ المهامّ الدقيقة أوّلاً —
ومنها المهمّة المسجّلة قبلها.

**والقاعدة التي تختصر الإقليم كلَّه:** `await` لا تُوقف شيئاً. تقطع الدالّة
عندها، وتضع الباقي في طابور، وتعود.

## لا تزامنٌ حقيقيّ

```dart
Future<void> main() async {
  var counter = 0;

  Future<void> bump() async {
    final read = counter;
    await null;
    counter = read + 1;
  }

  await Future.wait([bump(), bump(), bump()]);
  print(counter);
}
```

<!-- out -->

```
1
```

**ثلاث «مهامّ متوازية» وعدّادٌ صار واحداً.** وفي C هذا سباقٌ كلاسيكيّ يحتاج قفلاً.

**وهنا ليس سباقاً.** لا توجد لحظةٌ تنفَّذ فيها تعليمتان معاً — الثلاث قرأت `0`
قبل أن يكتب أحدها، لأن `await null` قطعت كلاً منها في الموضع نفسه بالضبط.

**والفرق في يدك:** الخطأ **حتميّ**. يقع في كل تشغيل، ويظهر في أوّل اختبار.
وسباق C يقع مرّةً في الألف، وعلى جهاز الإنتاج وحده.

**والقاعدة:** لا تحتاج قفلاً في Dart، **وتحتاج أن تعرف أين تُقطَع دالّتك**. وكل
`await` نقطةُ قطع.

## ما تختاره حين تسجّل

| تريد | استعمل | الطابور |
|---|---|---|
| أن يقع بعد الكود المتزامن مباشرةً | `scheduleMicrotask` | دقيق |
| أن يقع بعد كل ما هو معلّقٌ الآن | `Future(() => …)` | أحداث |
| أن يقع بعد مدّة | `Future.delayed` · `Timer` | أحداث |
| أن تُكمل بعد نتيجةٍ جاهزة | `.then` على مكتملة · `await` | دقيق |
| أن تُكمل بعد عملٍ حقيقيّ | `await` على غير مكتملة | أحداث |

**والصفّان الأخيران هما مصدر أغلب المفاجآت:** `await` نفسها تقع في طابورٍ أو آخر
**حسب حال ما تنتظره**، لا حسب ما كتبتَه.

## التمرين

**١ — رتّب قبل أن تشغّل.** اكتب دالّةً فيها ستّ `await` متداخلةً في حلقتين، بعضها
على `Future.value` وبعضها على `Future.delayed(Duration.zero)`، مع `print` بين كلٍّ
واثنتين.

**اكتب الترتيب المتوقّع على ورقة**، ثم شغّل. كم سطراً أصبت؟ والذي أخطأتَ فيه —
هل كان الخطأ في القاعدة الأولى أم الثانية؟

**٢ — جوّع الحلقة بلا حلقة.** الحلقة أعلاه كانت صريحة. **ابنِ التجويع نفسه بكودٍ
يبدو بريئاً**: سلسلة `.then` على futures مكتملةٍ سلفاً، أو `await` في حلقةٍ على
قيمٍ جاهزة.

كم عنصراً احتجتَ حتى يتأخّر الحدث عشر ميلي ثانية؟

**٣ — أصلح العدّاد.** خذ برنامج `Future.wait` أعلاه واجعله يطبع `3`، بثلاث طرق
مختلفة. أيّها يبقى صحيحاً لو صارت `bump` تنتظر **حدثاً** لا مهمّةً دقيقة؟

## الخلاصة

| ما رأيتَه | البديهية | أين يعود |
|---|---|---|
| طابوران بأولويةٍ مطلقة | الرابعة — `async` ليست خيطاً | ١٤ · ١٥ |
| الترتيب يُحسَب لا يُخمَّن | الرابعة | ١٤ |
| المهامّ الدقيقة تجوّع الأحداث | ثمن الأولوية | ١٥ |
| `await` قطعٌ وتسجيلٌ وعودة | — | ١٤ |
| لا سباق، وأخطاءٌ حتميّة | الثالثة — لا ذاكرة مشتركة | ١٦ |

## البذرة

كتبتُ `await null` وقلتُ إنها «تسجّل بقيّة الدالّة». **فأين تُسجَّل؟ وما شكلها؟**

الدالّة `async` ليست دالّةً عادية. اكتب واحدةً فيها ثلاث `await` وترجمها إلى
JavaScript بلا تصغير، وابحث عن اسمها في المخرَج.

**لن تجد جسمها كما كتبتَه.** ستجد آلةَ حالاتٍ برقمٍ يقفز. والإقليم ١٤ يفكّ سكّر
`async` إلى ما يكافئه بيدك، ويقول أين تعود السيطرة بالضبط.
