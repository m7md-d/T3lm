# موقع منهج Dart — جدول الاشتقاق

الحال: **مبنيٌّ وموصولٌ بالمحتوى.** ١٥٧ مساراً تُصيَّر، و٢٣ إقليماً و١٥٥ لقطة
و١٤٣ لوحة تُقرأ من `../regions/` برمجياً، ولا نصَّ محتوًى واحد داخل الكود.

والجدول أوّلاً كما تفرضه المهارة، وكل صفٍّ فيه يشير إلى سطرٍ موجودٍ فعلاً في
`../regions/` أو `../README.md` أو `../curriculum.json`. وما لم أجد له صفّاً
حذفته وسجّلته في §٦.

**اختبار القبول:** انقل هذا التصميم إلى منهج شبكات — يصير وسم الآلة (`@vm` · `@web` · `@aot`) فارغاً لأن لا آلتين هناك
تجيبان عن سؤالٍ واحد، ويصير العمودان المتقابلان بلا سببٍ يقابلهما،
ويصير «بلا زرّ تشغيل» تقشّفاً لا حجّة. **غير منطقيّ، لا أقبح.**

## ٢) الهوية — التوكنز واشتقاقها

**اللوحة من شعار Flutter، بطلب المؤلّف.** ويسندها سطرٌ في المحتوى:
`../README.md` يقول «ولمن يقصد Flutter، هذا ما يسبقه». فالاستمرار البصريّ بين
المنهجين قرارٌ في محلّه، **وأُعلنه قراراً لا اشتقاقاً** — بقيّة الجدول مشتقّة،
وهذا الصفُّ منقولٌ عن أمر المؤلّف ومسنودٌ بسطرٍ واحد.

**والقيم منقولةٌ حرفياً من الملفّ الرسميّ** في مستودع `flutter/website`
(`sites/docs/web/assets/images/branding/flutter/logo/default.svg`)، لا مقدَّرةً
بالعين:

| | | أين تسكن في الموقع |
|---|---|---|
| `#39CEFD` | الوجه المضيء | `--fl-ok` — الفئة المهيمنة، ١٠٢ لوحة |
| `#16B9FD` | الوجه الأوسط | `--fl-facet-fold` — الفواصل، ومعيّن اللوحة، وشريط اللقطة |
| `#03569B` | الوجه الغائر | `--fl-facet-deep` — ذراع الانعطاف في الموتيف |
| `#1A237E` | ظلُّ الطيّ (٤٠٪ شفافية في الشعار) | **الأرض** بعد إهباطه إلى الظلام |

**واللوحة شيء والعلامة شيء.** اللوحة تُشتقّ منها ألوانُ الأسطح والدلالة،
**أمّا علامةُ الموقع فملفُّ Dart الرسميّ مستورَداً** (`public/dart.svg` من
`sites/docs/web/assets/images/branding/dart/logo.svg`)، يُعرَض `img` بلا تعديلٍ
ولا إعادة تلوين. وهو المنهجُ في كل علامةٍ موجودة: **تُستورَد ولا تُرسَم.**

**وما لا يعطيه الشعار لا يُخترَع منه.** الشعار كلُّه أزرق، والرفضُ يحتاج لوناً
يفصله عن القبول فصلاً قبل-انتباهيّاً — فـ`--fl-no` ورديٌّ محمرّ. والمرساة C
تأخذ **لون ظلّ الطيّ مرفوعاً ليُقرأ** (`--fl-c` نيليّ)، فتنفصل عن الأزرق بلا أن
تخرج عن اللوحة.

**والخطّان:** `Cairo` للمتن — هندسيٌّ يجاور نبرة Material — و`Roboto Mono`
للكود، وهو الأحاديّ الذي تستعمله المنظومة نفسها. **والعربية بديلٌ داخل الأحاديّ**
لأن `Roboto Mono` بلا عربية، وبلا هذا البديل يقع الاحتياط على خطٍّ لا نتحكّم به
فتنفكّ الحروف في بلوكات الكود التي تطبع سلاسل عربية (١٣ · ١٦).

**دارك مود دائماً**، ولا ثيم فاتح.

## ٣) التصريف — من الماركداون إلى بنية

`src/content/compile.ts` يقرأ **مفردات `../tools/verify.py` نفسها**. الملفّ واحد
عمداً: ما يفحصه الفاحص يعرضه الموقع، فلا يفترق المعروض عن المتحقَّق منه. والدليل
عدديّ: الفاحص يقول ١٤٣ لوحة، والموقع يقول ١٤٣ لوحة.

```
```dart بلا علامة              برنامجٌ كامل — يُحفَظ main.dart
<!-- part -->                  مقتطعٌ لا يعمل وحده…
<!-- part --> + سياجٌ بلا لغة   …أو رسمٌ نصّيّ (١٨)
<!-- part: NAME -->            والملفّ الكامل programs/NAME.dart
<!-- out|err|web|aot|c|runs -->  لوحةُ البرنامج الذي قبلها
<!-- shell --> · <!-- shell: DIR -->   أوامرٌ، وسطرُ الأمر `$ `
**المخرَج**:                   بوّابةٌ تقفل اللوحة التي بعدها
```

وبرنامجٌ تلته **لوحتان** يصير «وجهَي طيّة». وتشغيلان متجاوران بآلتين مختلفتين
(دارت ثم C) يصيران كذلك — والترتيب في الماركداون هو ما يقرّر، لا وسمٌ يُضاف.

## ٤) الواجهة الرئيسية

ستّة أقسام، ولا نصَّ محتوًى فيها: العنوان والخطّاف من `../curriculum.json`،
والبديهيات والسلطات والحِزَم من `../README.md`، والبرنامج من
`../programs/tally.dart`.

١) **المشهد**: علامة Dart، ثم العنوان والوصف وزرّ البدء.
٢) **ادّعاءٌ يُقلَب بيد القارئ**: الخطّاف جملتان — واحدةٌ عن C وواحدةٌ عن Dart —
   فيُقسَم على حدّه ويُعرَض وجهين يقلبهما القارئ. لحظة التفاعل الواجبة (الركيزة ٣ب).
٣) **البديهيات الخمس**، ومعها أوّل ما يتساقط منها.
٤) **من يضمن ما تقرأ**: وسوم اللوحات كلِّها، تُعرَض مرّةً هنا فلا تُشرَح تحت كل لوحة.
٥) **الطريق**: خمسُ بطاقات، كلٌّ تُفتَح على أقاليمها بسطر كلٍّ منها.
٦) **ما ستكتبه بيدك**: `tally.dart` — **مطويّاً حتى يُطلَب**. مئةٌ وثلاثة وثلاثون
   سطراً قبل أن يعرف القارئ الموضوع تُقرأ تهديداً لا دعوة.

## ٥) المختبران

اثنان فقط، ولكلٍّ **حالةٌ مفاجئة** ومكانٌ واحدٌ يفرضه فحصٌ آليّ.

| | يُحقَن بعد | الادّعاء الذي يقلبه | الحالة المفاجئة |
|---|---|---|---|
| **آلتان، جوابان** | ٠٢ «وعلى الويب ليست كذلك» | «أعدادك الصحيحة آمنةٌ حتى 2^53 لا 2^63» | `9007199254740992` — حيث تصير `n + 1 == n` صادقة |
| **الطابوران، خطوةً خطوة** | ١٣ «ولهذا تُجَوَّع الحلقة» | «لو لم يكن للعدّاد حدّ، لما وصل الحدث أبداً — والبرنامج حيٌّ لا معلّق» | «مهمّة دقيقة تُسجّل مثلها»: تخطو ولا يُخدَم حدثٌ واحد |

**ولا يدّعي أيٌّ منهما أنه يشغّل Dart**، ويقولها في متنه:

- الأوّل **حاسبةُ نموذجَي عدد**: `BigInt` ملفوفةٌ إلى ٦٤ بتاً في وجه، وحسابُ
  المتصفّح في الوجه الآخر — وهو حسابُ الويب نفسه، لأن `int` بعد `dart2js` **ليس**
  نوعاً آخر بل عددُ JavaScript بعينه. فالوجه الأيمن ليس محاكاة.
- الثاني **محاكاةٌ للقاعدة التي يرسمها الإقليم**، وبرنامجه الافتراضيّ هو برنامج
  اللقطة الأولى نفسه — فترتيبه قابلٌ للمقارنة سطراً بسطر باللوحة المسجَّلة فوقه.

**وما حُذف بعد أن جُرّب:**

- **علامةٌ مرسومةٌ باليد**: بُنيت أوّلاً «طيّةٌ» من ثلاثة أوجهٍ بلغة الشعار
  الهندسية. ولا تشبه Dart ولا Flutter، وتُقرأ شرطةً في الشريط العلويّ. **حُذفت،
  ومكانها الملفّ الرسميّ.** والقاعدة صارت مكتوبةً في مهارة المواقع.
- **ركنان مطويّان** على بطاقة القلب وبطاقة المختبر: زخرفةٌ بلا معلومة، وكانا
  امتداداً لتلك العلامة. حُذفا (أثر التماسك، d ≈ 0.86).
- **سهمٌ بين وجهَي المختبر**: يوحي بأن أحدهما أصلُ الآخر، وليس كذلك — صار
  معيّناً بلا اتّجاه.
- **بطاقةٌ لكل إقليمٍ في الرئيسية**: ثلاثةٌ وعشرون صفّاً لوحةٌ لا تُقرأ. صارت
  خمسَ حزمٍ تُفتَح.
- **صفحةُ حزمةٍ مستقلّة** (كما في منهج دوكر): لا يوجد هنا برنامجٌ واحدٌ تفكّكه
  الحِزَم سطراً سطراً، فالصفحة كانت ستكون قائمةً بغلاف.
- **رمّادُ الأرقام الكبيرة في اللوحات**: قاعدةٌ بالشكل تُرمِّد `9007199254740992`
  وهو **مقصد** الإقليم ٠٢. صار التقلّب يُقرأ من وسم المؤلّف `<!-- runs -->` وحده.

## ٧) الفحوص الآلية

```bash
npm run typecheck   # الأنواع
npm run smoke       # التصيير + المحتوى (أدناه)
npm run outputs     # ../tools/verify.py — اللوحات مقابل التشغيل الحقيقيّ
npm run bidi        # ../tools/bidi.py — انضباط اللغتين في الماركداون
```

و`npm run smoke` يفحص خمسة أشياء لا يراها المتصفّح:

1. **كل مسارٍ يُصيَّر** — ١٥٧ مساراً، منها لقطةٌ لقطة.
2. **الماركداون الخام لا يصل القارئ** — لا `**` ولا `` ` `` خارج `code`/`pre`.
3. **كل مختبرٍ يطابق لقطةً واحدة بالضبط** — لا صفر ولا اثنتين.
4. **جدول «وتفصيلُها» يطابق `../regions/` ١:١**.
5. **كل رقم إقليمٍ في عمود «أين يعود» موجودٌ فعلاً**، وعددُ البديهيات والسلطات
   والحِزَم كما يعلنه المنهج.

**واللقطة في متصفّحٍ حقيقيّ** هي وحدها التي ترى الخطّ واللون والتخطيط:

```bash
node ../../../../tools/screens.mjs . /tmp/shots "#/" "#/r/00/0" "#/r/02/3" "#/r/13/1"
FULL=0 node ../../../../tools/screens.mjs . /tmp/shots "#/trace"
```

**والصفحةُ التي لا تفيض عن الشاشة تُلتقَط بـ`FULL=0`.** التقاطُ ما وراء الإطار
في صفحةٍ RTL ارتفاعُها ارتفاعُ الشاشة بالضبط يزيح اللقطة أفقياً — وليس في
الصفحة فيض: `scrollWidth === clientWidth` على كل المسارات، مقيسةً في المتصفّح.

## ٨) الإصدار

```bash
npm run typecheck && npm run smoke && npm run build
rm -f dart.zip && (cd dist && zip -qr ../dart.zip . -x '.DS_Store' '**/.DS_Store' '__MACOSX/*')
unzip -l dart.zip | head -5
```

**الضغط من داخل `dist/` لا من فوقه**: Cloudflare Pages يجعل جذر المضغوط جذر
الموقع. المشروع `t3lm-dart`، والعنوان المشتقّ `https://dart.nodeksa.com`.

وقبل ذلك، حين تتغيّر الهوية أو الخطوط:

```bash
npm run fonts    # يستضيف Cairo وRoboto Mono محلياً — بلا أصولٍ خارجية
npm run assets   # الأيقونات والأقنعة وبطاقة ١٢٠٠×٦٣٠ من assets/*.html
```

## ٩) ما لم تره اللقطة

لقطةُ المتصفّح ساكنة، فلا ترى:

- **قلبَ الوجهين** في الرئيسية، ولا حركة الدخول التي تصحبه.
- **خطوَ حلقة الأحداث**: بناء البرنامج، ثم الخطوة خطوةً، ثم رسالة التجويع بعد
  ستّ خطوات.
- **تغيّر جوابَي المختبر الأوّل** عند تحرير العدد، ولا تلوّن المعيّن عند الاختلاف.
- **البوّابة**: قفلَها، وحفظَ التوقّع، وظهورَه في «ما توقّعتَه» عند أرضيّة الإقليم.
- **زرّ النسخ** وتبدُّلَ نصّه.
- **التثبيت تطبيقاً** وعملَ عامل الخدمة بلا شبكة.

وهذه كلُّها تُجرَّب باليد قبل الإصدار.
