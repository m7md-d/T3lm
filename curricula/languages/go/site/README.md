# موقع «Go — من الجذور» — جدول الاشتقاق

هذا الموقع ليس ثيماً فوق المنهج. كل قرار فيه — بنيةً ولوناً وحركةً ومكوّناً
وتفاعلاً — مردودٌ إلى شيء موجود **فعلاً** في ماركداون المنهج، ومعدودٍ لا مُقدَّر.
ما لم أجد له سطراً هنا، حذفتُه.

**اختبار القبول:** انقل هذا التصميم إلى منهج تشفير أو أنظمة موزّعة وسيبدو *غير
منطقيّ* لا أقبح فقط: لا خمس بديهيات تصبغ الأقاليم، ولا شريط كلمات آلة تحت كل
مقطع، ولا وسم «يُشغَّل محلياً» له معنى، ولا سبب لأن يكون مقياس البايت وحدةَ
التخطيط.

## ٠) الأدلّة المعدودة

```
فصول مفتوحة                                →  ١٣          (٠٠ … ١٢)
أجزاء داخل الفصل ٠٠                        →   ٤
لقطات                                      → ٢٠٣
أقصى نثرٍ في لقطة                          →  ١٦٧ كلمة    (الحدّ ٢٥٠)
أقصى كتلٍ في لقطة                          →   ٢          (الحدّ ٢)
لقطات تجاوزت الحدّ                          →   ٠

أسيجة Go في المتن                          → ١٢٢
منها برامج كاملة                           →  ٩١
منها بزرّ تشغيل                            →  ٥٨
منها معروضة بلا زرّ                        →  ٦٤

مخرَجات مسجَّلة                             →  ٧٤
منها طوبقت آلياً بـgo1.26.6                →  ٨٦ / ٨٧
اختلافٌ مُعلَنٌ في موضعه                    →   ١          (ترتيب goroutines غير مضمون)
لوحاتٌ من أدواتٍ أخرى (doc · test · vet · إحصاء) →  ١١
منها طوبقت أيضاً بمفسّر المتصفّح            →  ٥٣ / ٥٤

بوّابات تنبّؤ                              →  ٣٥          (الحدّ ٣ لكل فصل)
مخطّطات ونصوص تصوّرية                       →  ٣٢
أوامر تُشغَّل محلياً لا في المتصفّح          →  ١٥
سطر الـepitome                             →  ٧٥
```

**كل رقمٍ هنا مقيسٌ آلياً**، ولا واحد منها مقدَّر. والمطابقة تجري بانتزاع كل برنامجٍ
من الماركداون وتشغيله — مرّةً على `go1.26.6` ومرّةً على مفسّر المتصفّح — ومقارنة
مخرَجه بالمسجَّل حرفاً بحرف.

## ١) جدول الاشتقاق

| القرار في الموقع | مصدره في المحتوى | لماذا هذا الشكل بالذات |
|---|---|---|
| **الفصل ٠٠ وحده مقسَّمٌ إلى أجزاء** | ٥٤ لقطةً فيه، و`### ` تحت `## ` في ماركداونه — بينما الفصل ٠١ لقطاته `## ` مباشرةً | أثرٌ من ٥٤ سطراً بلا معالم يُقرأ كقائمة. والقارئ لا يقرأ نفس النوع من النصّ في أربعتها: قصّةٌ ثم بديهياتٌ ثم نظام أنواعٍ ثم طريق. **والبنية تُقرأ من الماركداون** ولا تُعلَن في الكود |
| **الأجزاء تظهر في الأثر بعد عبورها** | نفس مصدر «الأثر بدل الشريط» | عنوان جزءٍ لم يُبلَغ بعدُ إعلانٌ عن كلفةٍ قادمة — وهو ما بُني الأثر لمنعه |
| **الجزء التالي يُسمّى فوق اللقطة التالية** | حدود الأجزاء الأربعة | عبور جزءٍ حدثٌ يُعلَن قبل وقوعه، لا مفاجأةٌ بعد الضغط |
| **مقدّمة الجزء عند لقطته الأولى فقط** | لكل جزءٍ مقدّمةٌ في الماركداون | تمهيدٌ يُقرأ مرّة؛ وترويسةٌ متكرّرة ضوضاء |
| **البديهيات الخمس تُستخرَج من جدولها في المتن** | جدولٌ من خمسة صفوف في لقطة «لماذا خمسٌ بالذات» | كانت منسوخةً في `content.ts`، فصار للنصّ الواحد ثلاثة مواضع. **الموقع يُصرِّف ولا يُفرِّع** |
| **٦٤ بلوكاً بلا زرّ تشغيل** | برامج لا تُترجَم عمداً · برامج يخطئ فيها المفسّر · مقتطفات ليست برامج · حزمٌ متعدّدة الملفّات | **محقَّق بالتشغيل:** المفسّر يطبع النوع الأساسيّ بدل النوع المسمّى، ويخطئ في مجموعات الطُّرق — وهما درسا نصف الجزء الثالث. زرٌّ يعطي جواباً معكوساً أسوأ من لا زرّ |
| **لوحةٌ مقتطعة تقول ذلك بنفسها** | أثر المكدّس بعد الذُّعر يحمل مسارات جهاز المؤلّف | نقلُه كذبٌ على القارئ، وحذفُه بصمت كذبٌ آخر. `<!-- out: السبب -->` يجعل **اللوحة** تُفصح، فلا يُترَك الإفصاح للنثر ولا يُنسى عند تحرير النصّ |
| **١٥ أمراً يُشغَّل محلياً** | مقاييس · `-gcflags='-m'` · `-race` · `go vet` · بناءٌ متعدّد الحزم | ما لا يقع في متصفّح لا يُعرَض كأنه يقع فيه. والوسم يقوله **قبل** أن يحاول القارئ |
| **وسم «يُشغَّل محلياً»** | أمرٌ واحد: `find $(go env GOROOT)/src/runtime -name '*.c'` | ادّعاءُ «خرجت C من سلسلة الأدوات» يُتحقَّق منه على جهاز القارئ لا في المتصفّح — والوسم يقول ذلك قبل أن يحاول |
| **الـepitome مرجعاً ثابتاً** | الفصل ٠١ يبني مخزناً في ٧٥ سطراً، وكل بذرةٍ فيه تعود إليه | المنهج لا يفترض عند قارئه شيئاً — يبني معه نظاماً عاملاً ثم يفكّكه. المهمّة الكاملة تتفوّق في النقل البعيد (`evidence/findings.md` §١) |
| **اللقطة وحدةَ العرض** | ١٨٧ لقطة، أقصاها ١٦٧ كلمة وكتلتان | القارئ يقدّر الكلفة قبل أن يبدأ. صفحةٌ لا يُرى قعرها تُستثقَل، ونهايةٌ مرئيةٌ تُعبَر |
| **البديهيات بطاقاتٌ تُفتح** | لكل بديهيةٍ ثلاثةُ مواضع في الفصل ٠٠: صفٌّ في جدولها، ولقطةٌ تشرحها، وصفوفٌ في جدول «ما رفضته اللغة عمداً» | **المؤلّف نفسه ربطها**: العمود الأوسط في جدول المرفوضات رقمُ بديهية. فالبطاقة **وصلٌ لما هو موصولٌ أصلاً**، لا تجميعٌ من عندنا. وكانت قائمةً تستجيب للمؤشّر ولا تُنقَر — وعدُ تفاعلٍ بلا تفاعل |
| **واحدةٌ مفتوحةٌ في كل مرّة** | خمس بديهيات لا أكثر | خمسٌ مفتوحةً معاً تُعيد الحائط الذي فُتحت البطاقات لتجنّبه |
| **رابط `?s=` يفتح لقطةً بعينها** | «وسأشير إليها بأرقامها في كل فصل. فإن قرأتَ ‹البديهية الثانية› فارجع هنا» | النصّ يأمر القارئ بالرجوع، فالموقع يجعل الرجوع نقرةً واحدة بدل بحثٍ في ٥٤ لقطة |
| **بطاقة الفصل تحمل ادّعاءه الافتتاحيّ** | ١٠ من ١٢ نبذةً تفتح بجملةٍ تعود إلى المخزن: «في مخزنك سطرٌ واحد بريء…» · «مخزنك يقفل قبل كل كتابة» | كان تحت كل بطاقةٍ وسمُ «الإقليم» — قيمةٌ واحدة في اثنتي عشرة بطاقة، أي **صفر معلومة**. والنبذة تفرّق بينها بكلمات المؤلّف، ومعها يعرف القارئ **من أين يبدأ الفصل** لا اسمه فقط |
| **«عبرتَ ن لقطة» على البطاقة، ولا شيء عن الباقي** | نفس مصدر الأثر | ما مضى يُعَدّ وما بقي لا يُعرَض — والخريطة تتبع قاعدة الفصل نفسها |
| **سطرُ شرطٍ في الترويسة بدل قائمة وعود** | README §«لمن كُتب»: «لمن يعرف C جيداً، ولمسَ Go لمساً سطحياً» · «ولا يفترض المنهج عندك شيئاً غير ذلك» | سؤال القارئ عند الباب «هل هذا لي؟» لا «ماذا ستقدّم لي؟». وأربعةُ أسطرٍ تعدّ ما سيأتي **تعرض الكلفة قبل البدء** — وهو ما بُني الأثر على منعه |
| **الأثر بدل شريط التقدّم** | ١٨٧ لقطة، لا يُعرَض منها إلا ما مضى | العدّ التنازليّ يعرض الكلفة كاملةً قبل البدء. والأثر يعدّ من حيث بدأ القارئ — نفس البيانات، ونفسيّةٌ معاكسة (§٧) |
| **الخطوة القادمة تسمّي نفسها** | عناوين اللقطات قصيرة ومحدّدة | خطوةٌ معلومةٌ رخيصة المظهر، لا قفزةٌ في المجهول |
| **٣ بوّابات لا أكثر** | ٣٢ بوّابة في ١٢ فصلاً — **ولا فصل تجاوز الثلاث** | التشبّع حادّ بعد الثالث (d=1.20 ثم 0.15)، والخبير المدفوع إلى بوّاباتٍ كثيفة يخمّن ليتجاوزها (§٣) |
| **كل بلوكٍ يَعِد بالتشغيل برنامجٌ كامل** | ٥٨ بلوكاً قابلاً للتشغيل، لا واحد منها مقتطع | القارئ يشغّل **بلوكاً واحداً** لا الصفحة. واللقطة المكتفية ذاتياً تُنتج ذلك بلا جهد إضافي |
| **مخطّط الآلة التصوّرية عند كل اعتقادٍ يُهدَم** | ٣ مخطّطات: تخطيط البنية · رأسا النسخة · كلمتا الواجهة | الهدم بلا بديلٍ مرئيّ يُنتج ترقيعاً للنموذج الفاسد. والقارئ المتقدّم يفترض علّةً في الأداة حتى يرى العناوين (§٥) |
| **العنوان الستّ عشريّ على كل سهم** | مخطّط النسخة يحمل `0x14000a` و`0x14000c` | صندوق-وسهم بلا عنوان جعل ٤٨٪ يعاملون المؤشّر وعاءً يحوي البيانات (§٥) |
| **الوحدة البصرية = كلمة الآلة (٨ بايت)** | «٤٨ = ست كلمات»، و«الرأس ثلاث كلمات»، و«الواجهة كلمتان» | المنهج يقيس بالكلمة نصّاً، فالمقاس والشبكة مضاعفاتها |
| **أربعة ألوان دلالية، لكلٍّ وسمٌ نصّيّ** | أربعة أنواع كتل: كود · مخرَج مسجَّل · بوّابة · مخطّط | الحدّ قبل-الانتباهيّ ٤–٥ فئات، و٨٪ من الذكور لا يميّزون الأحمر من الأخضر. ولا قناة ثالثة: فرط الترميز ضوضاء (§٨) |
| **لا حركة تلقائية** | لا شيء في المحتوى زمنيّ إلا التزامن | الحركة التلقائية توهم بالفهم ولا تتفوّق على الساكن؛ وحذف الزخرفة أعلى أثرٍ بصريّ (§٨) |
| **تحذير صدق قبل زرّ التشغيل** | مفسّر المتصفّح يطبع الذُّعر بصيغةٍ أخرى · وترتيب الـgoroutines غير مضمون | محقَّقان بتشغيل البلوكين على المفسّر نفسه. والإنذار يسبق المخرَج |
| **المكشوف «مخرَج مسجَّل» لا طرفية** | README يعلن `go1.26.6 darwin/arm64`، وتُستخرَج منه لا تُكتب في الكود | هيئة الطرفية تقول «جرى الآن»، والموقع لا يشغّل نيابةً عن قارئه |
| **العربية لا تُكتب بالخطّ الأحاديّ** | كل وسمٍ عربيّ، وكل كودٍ ومخرَجٍ لاتينيّ | خليّة المونو تفكّ وصل الحروف. الأحاديّ للكود والأرقام، ويُوسَم `.en` |
| **مخطّطات الذاكرة تبقى LTR** | مخطّطات البايتات والرؤوس | قلبها للعربية يصادم كل أداةٍ حقيقية يستعملها القارئ (§٩) |
| **أيقونة التطبيق كلمتا الواجهة** | مخطّط «كلمتا الواجهة» — أحد المخطّطات الثلاثة · والوحدة البصرية كلمةُ الآلة | الأيقونة تُرى بلا نصّ، فتحمل **وحدة القياس** التي يقوم عليها الموقع كلّه: كلمتان، ورأسٌ يشير |
| **بطاقة المشاركة رأس الشريحة بعناوينه** | `0x14000a` على أسهم مخطّط النسخة · «الرأس ثلاث كلمات» | ما يُرى قبل الدخول هو **ما يُدرَّس**: ثلاث كلماتٍ بقيمها وأحجامها، لا شعارٌ عن اللغة |
| **الأيقونات مستورَدة** | أزرار التشغيل والنسخ والاسترجاع والتنقّل | الرمز المرتجَل يخرج مكسوراً. والاستثناء ما اشتُقّ من المحتوى: مخطّط البايتات |

## ٢) اختبار القبول

انقل هذا التصميم إلى منهج تشفيرٍ أو أنظمةٍ موزّعة فسيبدو **غير منطقيّ** لا أقبح
فقط: لا `epitome` يُفكَّك، ولا مخطّطَ بايتاتٍ له معنى، ولا سبب لأن تكون الوحدة
البصرية ثماني بايتات، ولا لأن يحمل كل سهمٍ عنواناً ستّ عشرياً.

## ٣) البناء والمفسّر

```
npm run dev        خادم التطوير
npm run build      tsc -b ثم vite build
npm run smoke      يصيّر كل مسارٍ خارج المتصفّح، ويفحص أن الاستخراج ما زال يعمل
wasm-src/build.sh  يفحص الاستيرادات ثم يبني مفسّر Go إلى WASM
```

**و`smoke` يفحص المحتوى لا التصيير فقط:** أن الفصول اثنا عشر، وأن البديهيات خمس
ولكلٍّ شرحُها ولقطتها، وأن **لا فصلين يحملان نفس الادّعاء الافتتاحيّ**. فالبنية
كلّها مستخرَجةٌ من الماركداون، وتحريرُ عنوانٍ فيه قد يكسر الاستخراج **بلا أن
يفشل البناء**.

**والمفسّر مقيَّدٌ بحدّ رفع.** `stdlib.Symbols` يربط مكتبة Go القياسية كلّها
فيُخرج **٣٩ ميغابايت**، وحدّ الملف الواحد على Cloudflare Pages **٢٥**. فالمربوط
حزم المنهج وحدها (٢٧ حزمة)، والناتج **١٣٫٤ ميغابايت**.

| الفحص | متى | ماذا يمنع |
|---|---|---|
| `check-imports.py` | قبل كل بناء | بلوكٌ **بزرّ** يستورد حزمةً غير مربوطة — فيعطي الزرّ خطأً لا جواباً |
| حدّ الحجم في `build.sh` | بعد البناء | ملفٌّ لا يُرفَع، يُكتشَف عند النشر لا عند البناء |

**والاقتطاع فُحِص لا فُرِض:** شُغِّلت البلوكات الثمانية والخمسون ذات الزرّ على
المفسّرَين — الكامل والمقتطع — وقُورنت حرفاً بحرف. وكشفت المقارنة عيباً كان
سيمرّ: بلا `symbols/maptypes.go` يطبع `fmt.Println` القيمة الخام بدل استدعاء
`String()`، فطبع بلوكٌ `36.6` بدل `36.6°C`. أُضيف الملف، فصار **٥٨ / ٥٨**.

### الرفع — من `dist/` إلى Cloudflare Pages

الأمر كاملاً، من الفحص إلى المضغوط:

```bash
npm run smoke && npm run build
rm -f go.zip && (cd dist && zip -qr ../go.zip . -x '.DS_Store' '**/.DS_Store' '__MACOSX/*')
unzip -l go.zip | head -5      # index.html في جذر المضغوط لا داخل مجلّد
```

**الضغط من داخل `dist/`، لا من فوقه.** Cloudflare Pages يجعل جذر المضغوط جذر
الموقع؛ فإن حوى مجلّداً واحداً سكن الموقع تحت `/dist/` وأعطى الجذر ٤٠٤.

يُرفَع `go.zip` في مشروع **`t3lm-go`**:
Workers & Pages ← المشروع ← *Create deployment* ← *Upload assets*.
والعنوان `go.nodeksa.com`.

**وإن مسستَ المفسّر أو استيرادات بلوكٍ ذي زرّ، فـ`bash wasm-src/build.sh` قبل
هذا كلّه** — وإلا حُزِم `main.wasm` القديم. وحدّ الملفّ الواحد ٢٥ ميغابايت، فإن
رُفض الرفع فالمتّهم الأوّل هو.

## ٤) أصول التطبيق

| الأصل | مصدره | يُولَّد بـ |
|---|---|---|
| `public/fonts/*.woff2` + `fonts.css` | Google Fonts، كتلَ `unicode-range` كما تُقدَّم | `npm run fonts` |
| `public/icons/*.png` (١٩٢ · ٥١٢ · قناعان · apple-touch) | `assets/icon.html` — كلمتا الواجهة: رأسٌ وبيانات | `npm run assets` |
| `public/og.png` (١٢٠٠×٦٣٠) | `assets/og.html` — رأس الشريحة بعناوينه | `npm run assets` |
| `public/favicon.svg` | نفس الرمز في ٣٢ بكسل | بيد |
| `dist/sw.js` | قائمة `dist/` مبصومةً | ضمن `npm run build` |

المصادر HTML لا SVG لتستعمل خطّ الموقع نفسه. والناتج ملتزَم في `public/`،
فالبناء لا يحتاج شبكة ولا متصفّحاً.

`manifest.webmanifest` بأربع أيقونات، وعامل خدمة يخزّن ٣٩ ملفّاً مسبقاً. أمّا
المفسّر (١٣٫٤ ميغابايت) فخارج التخزين المسبق: يُخزَّن عند أوّل تشغيل لبلوك، فلا
يُثقَل التثبيت بما قد لا يُستعمل.

ويفشل البناء عند أي أصل خارجي، لأن `tools/sw.mjs` يفحص مراجع HTML وCSS.
