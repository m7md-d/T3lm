# الإقليم ٠١ — المخزن

> ستبني في هذا الإقليم **مخزناً صغيراً** يعمل: ٧٥ سطراً تحفظ قيماً وتقرأها
> وتسجّلها. وحين ينتهي، سيكون فيه **ثلاثة أخطاء لم ترها**، وكلٌّ منها بابٌ لإقليم.
>
> هذا المخزن هو **مرجع المنهج كلّه**. كل ما يأتي بعده يفكّكه أو يمدّه.

---

## الحقل الأول

كل شيء في المخزن سجلّ: مفتاحٌ نصّيّ، وقيمةٌ بايتات، وعَلَمٌ يقول إن السجلّ حُذف.

```go
package main

import (
	"fmt"
	"unsafe"
)

type Record struct {
	Key     string
	Value   []byte
	Deleted bool
}

func main() {
	var r Record
	fmt.Printf("حجم Record = %d بايت\n", unsafe.Sizeof(r))
	fmt.Printf("مجموع أحجام حقوله = %d\n",
		unsafe.Sizeof(r.Key)+unsafe.Sizeof(r.Value)+unsafe.Sizeof(r.Deleted))
}
```

<!-- out -->

```
حجم Record = 48 بايت
مجموع أحجام حقوله = 41
```

**سبعة بايتات ذهبت.** لم تطلبها، ولا تستطيع الوصول إليها، وتدفع ثمنها في كل سجلّ.

---

## أين ذهبت السبعة

الحقول لا تُرصّ. كل حقل يبدأ عند إزاحةٍ تقبل القسمة على **محاذاته**، وحجم البنية
يُقرَّب لأكبر محاذاةٍ فيها.

```
إزاحة   00        08        10        18        20        28
        ├─────────┴─────────┼─────────┴─────────┴─────────┤
        │   Key (16)        │       Value (24)            │
        ├───────────────────┴─────────────────────────────┤
        │ Deleted (1) │ ///////// حشو 7 ///////// │
        └─────────────┴───────────────────────────┘
                        العنوان 0x28 … 0x2F
```

`Deleted` يقع عند الإزاحة ٤٠، فيصير الحجم ٤١ — ثم يُقرَّب إلى **٤٨** لأن أكبر
محاذاةٍ في البنية ثمانية.

**والقاعدة التي ستسمعها:** «رتّب الحقول من الأكبر إلى الأصغر فتوفّر». جرّبها في
اللقطة التالية.

---

## القاعدة التي لا تعمل

```go
package main

import (
	"fmt"
	"unsafe"
)

type Record struct {
	Key     string
	Value   []byte
	Deleted bool
}

type ByBiggest struct {
	Value   []byte
	Key     string
	Deleted bool
}

func main() {
	fmt.Printf("Record    = %d بايت\n", unsafe.Sizeof(Record{}))
	fmt.Printf("ByBiggest = %d بايت\n", unsafe.Sizeof(ByBiggest{}))
}
```

<!-- out -->

```
Record    = 48 بايت
ByBiggest = 48 بايت
```

**لم يتغيّر شيء.**

الترتيب من الأكبر للأصغر ليس قاعدةً، بل **عَرَضٌ** لقاعدةٍ أخرى: أن تقلّ فجوات
المحاذاة الداخلية. وهنا لا فجوة داخلية أصلاً — الحقلان الأوّلان مضاعفان لثمانية،
والضياع كلّه في **الذيل**. وذيلُ بنيةٍ محاذاتها ثمانية وفيها بايتٌ واحد زائد يضيع
سبعةً مهما رتّبت.

**تُوفَّر السبعة بشيءٍ واحد فقط:** أن تجد لها ساكناً — حقلاً صغيراً آخر يسكن معها.

## ثلاثة حقول، أربعة سلوكيات

الآن المخزن نفسه. ثلاثة حقول: قفلٌ يحمي، وخريطةٌ تخزّن، وشريحةٌ تسجّل.

```go
package main

import (
	"fmt"
	"sync"
)

type Store struct {
	mu   sync.Mutex
	data map[string]string
	log  []string
}

func main() {
	var s Store

	s.mu.Lock()
	fmt.Println("القفل: نجح")
	s.mu.Unlock()

	s.log = append(s.log, "أول")
	fmt.Println("الشريحة:", s.log, len(s.log))

	fmt.Println("قراءة من الخريطة:", s.data["غائب"], len(s.data))

	s.data["k"] = "v"
	fmt.Println("لن يصل هنا")
}
```

`var s Store` بلا تهيئة. البديهية الأولى تقول إن القيمة الصفرية **صالحة
للاستعمال**. أربعة أسطر تختبرها.

<!-- notice: المفسّر داخل متصفّحك يطبع الذُّعر بصيغةٍ أخرى — سطرَ موضعٍ ورسالةً منفصلة. السلوك واحد، والنصّ يختلف. -->

<!-- out: بعده أثر المكدّس ورمز الخروج، وفيهما مسار جهاز المؤلّف -->

```
القفل: نجح
الشريحة: [أول] 1
قراءة من الخريطة:  0
panic: assignment to entry in nil map
```

ثلاثةٌ نجحت وواحدٌ ذعر. **وليس عشوائياً أيّها.**

---

## لماذا الخريطة وحدها

ثلاث قيمٍ صفرية، وثلاثة تصميمات مختلفة:

| الحقل | صفرُه | لماذا يعمل — أو لا |
|---|---|---|
| `sync.Mutex` | بنيةٌ أصفارها كلها | القفل المفتوح **هو** حالة الصفر. لا شيء يُهيَّأ |
| `[]byte` | مؤشّرٌ صفريّ، طول ٠، سعة ٠ | `append` يرى السعة صفراً فيخصّص. الصفر حالةٌ صالحة |
| `map` | مؤشّرٌ صفريّ | القراءة تُرجع الصفر بلا لمس الذاكرة. **الكتابة تحتاج جدولاً لا وجود له** |

والفرق ليس مزاجاً: الخريطة بنيةٌ تحتاج تخصيصاً وحساب بصمات وسلالاً. ولو جعلها
المترجم تُخصَّص عند أول كتابة، لدفع **كل** استعمالٍ للخريطة ثمن فحصٍ في كل كتابة.

**فالبديهية الأولى صحيحة، وحدُّها معلوم:** الصفر صالحٌ لما يستطيع أن يكون صالحاً
بلا تخصيص. وما يحتاج تخصيصاً يحتاج `make`.

## القفل والتأجيل

```go
package main

import (
	"fmt"
	"sync"
)

type Store struct {
	mu   sync.Mutex
	data map[string]string
}

func (s *Store) Put(key, value string) {
	s.mu.Lock()
	defer s.mu.Unlock()

	if value == "" {
		fmt.Println("خرجتُ مبكّراً")
		return
	}
	s.data[key] = value
}

func main() {
	s := &Store{data: make(map[string]string)}
	s.Put("a", "")
	s.Put("b", "قيمة")
	fmt.Println("لم يتجمّد شيء:", s.data)
}
```

<!-- out -->

```
خرجتُ مبكّراً
لم يتجمّد شيء: map[b:قيمة]
```

للدالة مخرجان: `return` المبكّر، والنهاية. و`defer` تضمن أن القفل يُفتَح في
الحالتين.

**لكن انتبه لصياغة الضمان:** `defer` لا تُنفَّذ عند نهاية الكتلة `{}`، بل عند
**رجوع الدالة**. الفرق سيؤذيك في حلقةٍ تفتح ملفاً في كل دورة — وذاك إقليمٌ قادم.

## نسخةٌ واحدة، حقلان، سلوكان

`Get` تُرجع `Record` — **قيمةً لا مؤشّراً**. فالمستدعي يأخذ نسخته الخاصّة.

```go
package main

import "fmt"

type Record struct {
	Key   string
	Value []byte
}

func main() {
	store := map[string]Record{}
	store["greeting"] = Record{Key: "greeting", Value: []byte("hello")}

	r := store["greeting"]
	r.Key = "CHANGED"
	r.Value[0] = 'X'

	fmt.Printf("Key   = %q\n", store["greeting"].Key)
	fmt.Printf("Value = %q\n", store["greeting"].Value)
}
```

سطران متتاليان، كلاهما يعدّل **النسخة**. توقّع ما يراه المخزن بعدهما.

المخرَج:

```
Key   = "greeting"
Value = "Xello"
```

---

## أين انكسر الضمان

النسخة نسخت **الحقول** كما هي. و`Value` ليس بايتاته، بل رأسٌ من ثلاث كلمات:

```
النسخة r                        المخزن store["greeting"]
┌──────────────────────┐        ┌──────────────────────┐
│ Key   ptr → 0x14000a │        │ Key   ptr → 0x14000a │   نصّ، للقراءة فقط
│       len 8          │        │       len 8          │
├──────────────────────┤        ├──────────────────────┤
│ Value ptr → 0x14000c │───┐    │ Value ptr → 0x14000c │───┐
│       len 5  cap 8   │   │    │       len 5  cap 8   │   │
└──────────────────────┘   │    └──────────────────────┘   │
                           ▼                               ▼
                     0x14000c: [ X e l l o ]  ← مصفوفةٌ واحدة، يشير إليها الاثنان
```

**كلا الحقلين نُسخ نسخاً كاملاً.** الفرق أن أحدهما يشير إلى بايتاتٍ **لا يمكن
تعديلها** لأن النصّ في Go للقراءة فقط، والآخر يشير إلى مصفوفةٍ قابلة للكتابة.

**فالبديهية الثانية ليست «بعض الأشياء تُنسخ سطحياً».** هي: *كل شيء يُنسخ نسخاً
كاملاً، والنسخة الكاملة لرأسٍ فيه مؤشّر تعطيك المؤشّر نفسه.* لا استثناء ولا سحر —
٤٨ بايتاً تُنقَل كما هي.

## عقدٌ لا يُعلَن

المخزن يكتب كل سجلّ إلى وجهة. وأيّ وجهة؟ لا يعرف ولا يريد.

```go
package main

import "fmt"

type Record struct{ Key string }

type Sink interface {
	Write(Record) error
}

type Printer struct{ n int }

func (p *Printer) Write(r Record) error {
	p.n++
	fmt.Printf("[%d] %s\n", p.n, r.Key)
	return nil
}

func main() {
	var s Sink = &Printer{}
	s.Write(Record{Key: "a"})
	s.Write(Record{Key: "b"})

	var empty Sink
	fmt.Println("واجهة فارغة == nil؟", empty == nil)

	var p *Printer
	var s2 Sink = p
	fmt.Println("مؤشّر صفريّ داخل واجهة == nil؟", s2 == nil)
}
```

`Printer` لا يذكر `Sink` في أي موضع. يحمل الدالة بالتوقيع المطلوب، **فهو ينطبق**.
والفحص عند الترجمة لا عند التشغيل.

المخرَج:

```
[1] a
[2] b
واجهة فارغة == nil؟ true
مؤشّر صفريّ داخل واجهة == nil؟ false
```

## قيمةٌ تساوي الصفر ولا تساويه

السطر الأخير هو أشهر فخٍّ في اللغة، وسببه في التمثيل:

```
واجهةٌ فارغة              واجهةٌ تحمل مؤشّراً صفرياً
┌──────────────┐          ┌──────────────┐
│ type → nil   │          │ type → *Printer │   ← ليس صفراً
│ data → nil   │          │ data → nil      │
└──────────────┘          └──────────────┘
   == nil ✓                    == nil ✗
```

الواجهة **كلمتان**: نوعٌ وبيانات. وتساوي `nil` حين تكون **الكلمتان** صفراً. ومؤشّر
`*Printer` صفريّ يملأ خانة النوع، فلم تعد الواجهة فارغة — صارت واجهةً تحمل «مؤشّراً
صفرياً من نوعٍ معلوم».

هنا لا يفيدك حدسٌ ولا قاعدة. **يفيدك أن ترى الكلمتين.**

## المخزن يعمل

اجمع القطع: قفلٌ وخريطةٌ وسجلّ ووجهة، وثلاث goroutines تكتب معاً.

```go
package main

import (
	"fmt"
	"sync"
)

type Record struct {
	Key     string
	Value   []byte
	Deleted bool
}

type Sink interface{ Write(Record) error }

type Store struct {
	mu   sync.Mutex
	data map[string]Record
	log  []Record
	sink Sink
}

func NewStore(sink Sink) *Store {
	return &Store{data: make(map[string]Record), sink: sink}
}

func (s *Store) Put(key string, value []byte) error {
	s.mu.Lock()
	defer s.mu.Unlock()
	r := Record{Key: key, Value: value}
	s.data[key] = r
	s.log = append(s.log, r)
	if s.sink == nil {
		return nil
	}
	return s.sink.Write(r)
}

func (s *Store) Get(key string) (Record, bool) {
	s.mu.Lock()
	defer s.mu.Unlock()
	r, ok := s.data[key]
	return r, ok
}

type Printer struct{ n int }

func (p *Printer) Write(r Record) error {
	p.n++
	fmt.Printf("[%d] %s = %q\n", p.n, r.Key, r.Value)
	return nil
}

func main() {
	s := NewStore(&Printer{})

	var wg sync.WaitGroup
	for i := 0; i < 3; i++ {
		wg.Add(1)
		go func(n int) {
			defer wg.Done()
			s.Put(fmt.Sprintf("k%d", n), []byte("v"))
		}(i)
	}
	wg.Wait()

	s.Put("greeting", []byte("hello"))
	r, _ := s.Get("greeting")
	r.Value[0] = 'X'
	back, _ := s.Get("greeting")
	fmt.Printf("بعد تعديل النسخة: %q\n", back.Value)
	fmt.Printf("عدد السجلّات في اللوج: %d\n", len(s.log))
}
```

شغّله مرّتين. توقّع ما الذي سيختلف بين التشغيلتين — وما الذي لن يختلف أبداً.

<!-- notice: هذا مخرَج تشغيلةٍ واحدة. ترتيب الأسطر الثلاثة الأولى يتغيّر بين تشغيلةٍ وأخرى — وهذا هو الدرس، لا خلل. -->

المخرَج:

```
[1] k0 = "v"
[2] k2 = "v"
[3] k1 = "v"
[4] greeting = "hello"
بعد تعديل النسخة: "Xello"
عدد السجلّات في اللوج: 4
```

**الثلاثة الأولى ترتيبها غير مضمون.** لا اللغة تعد به ولا الجدولة تكرّره. وما
**هو** مضمون: أن الأربعة تصل، وأن اللوج فيه أربعة، وأن التعديل على النسخة وصل
المخزن. **التزامن يضمن السلامة لا الترتيب** — وهذه أوّل مرّة يظهر فيها الفرق.

## بذرة

المخزن يعمل. وفيه ثلاثة أشياء لم نقلها:

**واحد.** `s.log` تنمو بـ`append`. وقد رأيتَ أن الشريحة رأسٌ يشير إلى مصفوفة. فماذا
يحدث للمصفوفة القديمة حين تمتلئ الجديدة؟ ومن يملكها؟

**اثنان.** `Put` تقفل ثم تستدعي `s.sink.Write` — **وهي تحمل القفل**. ماذا لو كانت
الوجهة بطيئة؟ وماذا لو كتبت في المخزن نفسه؟

**ثلاثة.** `Get` تُرجع نسخةً تشارك المخزن مصفوفتها. الحلّ الواضح أن تنسخ البايتات.
وثمن ذلك يظهر في مكانٍ لن تتوقّعه.

الإقليم القادم يبدأ من الأول.
