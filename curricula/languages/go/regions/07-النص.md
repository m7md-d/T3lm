# الإقليم ٠٧ — النصّ

> في مخزنك `Key string` و`Value []byte`. والفرق بينهما **ليس** أن أحدهما نصٌّ
> والآخر بايتات — كلاهما بايتات.
>
> الفرق أن `string` **للقراءة فقط**، وأن اللغة تعامله على أنه UTF-8 حين تمرّ
> عليه. وقد رأيتَ في الفصل صفر أن `len("مرحبا")` = ١٠.
>
> هذا الإقليم يجيب عن سؤالٍ يبدو تافهاً: **كم حرفاً في هذا النصّ؟**

---

## أربعة أجوبة صحيحة

```go
package main

import (
	"fmt"
	"unicode"
	"unicode/utf16"
	"unicode/utf8"
)

func graphemes(s string) int {
	n := 0
	for _, r := range s {
		if !unicode.Is(unicode.Mn, r) {
			n++
		}
	}
	return n
}

func report(label, s string) {
	fmt.Printf("%-14s bytes=%2d  runes=%2d  utf16=%2d  visible=%2d\n",
		label, len(s), utf8.RuneCountInString(s),
		len(utf16.Encode([]rune(s))), graphemes(s))
}

func main() {
	report("hello", "hello")
	report("marhaba", "مرحبا")
	report("marhaba+marks", "مَرْحَبًا")
	report("thumbs-up", "👍")
}
```

أربعة نصوص، وأربعة مقاييس. **توقّع الأربعة أرقام في السطرين الأخيرين.**

المخرَج:

```
hello          bytes= 5  runes= 5  utf16= 5  visible= 5
marhaba        bytes=10  runes= 5  utf16= 5  visible= 5
marhaba+marks  bytes=18  runes= 9  utf16= 9  visible= 5
thumbs-up      bytes= 4  runes= 1  utf16= 2  visible= 1
```

## أيّ عمودٍ تقصد

السطر الأول تتّفق فيه الأعمدة الأربعة — **ولهذا يمرّ خطأ من يختبر بالإنجليزية
فقط**. ثم تفترق:

| العمود | ما يقيسه | من يسأل عنه |
|---|---|---|
| `bytes` | حجم التخزين | قاعدة بيانات · شبكة · `len` |
| `runes` | نقاط ترميز Unicode | حلقة `range` · `[]rune` |
| `utf16` | وحدات UTF-16 | **JavaScript وJava** — و`length` عندهما |
| `visible` | ما يراه الإنسان حرفاً | **المستخدم**، وحدَه |

**والصفّ الثالث سببُ أخطاءٍ حقيقية بين الخدمات:** حدُّ «٢٨٠ حرفاً» في واجهةٍ
بجافاسكربت **ليس** حدَّ ٢٨٠ في Go. والرمز التعبيريّ الواحد يُحسَب اثنين هناك،
وواحداً هنا.

**والرابع لا تعطيه Go في مكتبتها القياسية.** حسبتُه أعلاه بتقريبٍ ساذج — تخطّي
العلامات المركَّبة — وهو يكفي للعربية ولا يكفي لكل اللغات. والحلّ الكامل في
`golang.org/x/text`، **وهي خارج المكتبة القياسية عمداً**: لأن قواعد Unicode
تتغيّر بإصداراتها، ووعدُ التوافق يمنع تغييرها داخل اللغة.

## نصٌّ لا يُكتَب فيه

<!-- run: no -->

```go
package main

import "fmt"

func main() {
	s := "مرحبا"
	s[0] = 'X'
	fmt.Println(s)
}
```

<!-- out -->

```
# command-line-arguments
./main.go:7:2: cannot assign to s[0] (neither addressable nor a map index expression)
```

**«غير قابلٍ للعنونة».** لا يوجد في اللغة `const` للنصوص لأنها لا تحتاجه: النصّ
غير قابلٍ للتعديل **في نظام الأنواع نفسه**.

وهذا يشتري ثلاثة أشياء: النصّ يُمرَّر بلا نسخ بايتاته (رأسٌ من كلمتين فقط)،
ويُستعمل مفتاحاً في الخريطة بأمان، ويُشارَك بين `goroutines` بلا قفل.

**ولهذا كان `Key` في مخزنك محميّاً و`Value` مكشوفاً** — وقد رأيتَ ذلك في الفصل ٠١
قبل أن تعرف السبب.

## والتحويل نسخة

```go
package main

import "fmt"

func main() {
	s := "مرحبا"

	fmt.Println(len(s))
	fmt.Printf("%d %q\n", s[0], s[0:2])

	b := []byte(s)
	b[0] = 'X'
	fmt.Println(s)
	fmt.Printf("%q\n", string(b))
}
```

<!-- out -->

```
10
217 "م"
مرحبا
"X\x85رحبا"
```

ثلاثة دروس في أربعة أسطر:

**`s[0]` بايت** — ٢١٧ — ونصف حرف. **و`s[0:2]` نصٌّ** طوله بايتان، وهو الحرف كاملاً.
فالفهرسة تعطي بايتاً والتقطيع يعطي نصّاً.

**`[]byte(s)` تنسخ.** ولذلك `s` لم تتغيّر، وهذا ما يحفظ الضمان أعلاه. **والنسخ
يعني تخصيصاً** — وقد صار عندك مقياسٌ لهذا.

**والنتيجة `"X\x85رحبا"`** نصٌّ غير صالح: كسرنا الحرف الأول فبقي نصفه.

## بايتاتٌ ليست نصّاً

Go لا تمنعك من بناء نصٍّ فاسد، ولا تنهار عنده:

<!-- notice: مفسّر المتصفّح يتقدّم ثلاثة بايتات بدل واحد في البايت الفاسد. المخرَج المسجَّل من الأداة الحقيقية. -->

<!-- run: no -->

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	bad := string([]byte{0xd9, 0xff, 0x85})

	fmt.Println(utf8.ValidString(bad))
	for i, r := range bad {
		fmt.Printf("%d:%U ", i, r)
	}
	fmt.Println()
	fmt.Println(utf8.RuneError == 0xFFFD)
}
```

<!-- out -->

```
false
0:U+FFFD 1:U+FFFD 2:U+FFFD 
true
```

**ثلاث نقاط استبدال** — `U+FFFD` — واحدةٌ لكل بايتٍ فاسد. و`range` **تتقدّم بايتاً
واحداً** عند الفساد، لا ثلاثة.

فالسلوك معرَّفٌ لا عشوائيّ: لا ذُعر، ولا حلقة لا تنتهي، ولا تخطٍّ صامت.
**و`utf8.ValidString` هي الحارس** إن كانت البايتات من الخارج.

## اعكس النصّ

سؤالٌ يُطرَح في المقابلات، وجوابه المعتاد خاطئ:

```go
package main

import "fmt"

func reverseBytes(s string) string {
	b := []byte(s)
	for i, j := 0, len(b)-1; i < j; i, j = i+1, j-1 {
		b[i], b[j] = b[j], b[i]
	}
	return string(b)
}

func reverseRunes(s string) string {
	r := []rune(s)
	for i, j := 0, len(r)-1; i < j; i, j = i+1, j-1 {
		r[i], r[j] = r[j], r[i]
	}
	return string(r)
}

func main() {
	fmt.Printf("%q\n", reverseBytes("مرحبا"))
	fmt.Printf("%q\n", reverseRunes("مرحبا"))
	fmt.Printf("%q\n", reverseRunes("مَرْحَبًا"))
}
```

عكسٌ بالبايتات، ثم عكسٌ بالرموز — **مرّتين**. توقّع الثلاثة.

المخرَج:

```
"\xa7بحر\u0605\xd9"
"ابحرم"
"اًبَحْرَم"
```

## لماذا كسر الثالث

الأول متوقَّع: قلبُ البايتات يفصل الحرف عن نصفه الآخر، فيخرج فسادٌ محض.

والثاني **صحيح**: `"مرحبا"` معكوسةً `"ابحرم"`. فبدا أن `[]rune` هو الجواب.

والثالث يفضحه. انظر إلى `"مَرْحَبًا"` قبل وبعد:

```
قبل:  م  َ   ر  ْ   ح  َ   ب  ً   ا        ← كل علامةٍ تتبع حرفها
بعد:  ا  ً   ب  َ   ح  ْ   ر  َ   م        ← كل علامةٍ صارت تتبع حرفاً آخر
```

**العلامة ليست حرفاً؛ هي لاحقةٌ تلتصق بما قبلها.** فالعكس نقل كلّاً منها إلى حرفٍ
غريب. و«الحرف المُدرَك» — الحرف مع علاماته — وحدةٌ ثالثة لا `byte` ولا `rune`.

**والدرس أوسع من العكس:** كل عمليةٍ تقصّ أو ترتّب أو تعدّ **بالرموز** تكسر
النصوص التي فيها علاماتٌ مركَّبة. والعربية والهندية والكورية كلّها كذلك.

## حرفان متطابقان لا يتساويان

وهذه أخبث من سابقتها، لأنها تمرّ من عينك:

```go
package main

import "fmt"

func main() {
	a := "أ"
	b := "أ"

	fmt.Printf("%q %q\n", a, b)
	fmt.Println(len(a), len(b))
	fmt.Println(a == b)
}
```

نصّان يبدوان متطابقين في المصدر وفي الطباعة. **توقّع الأرقام والمقارنة.**

المخرَج:

```
"أ" "أ"
2 4
false
```

## صورتان لحرفٍ واحد

Unicode يسمح بكتابة الحرف نفسه بطريقتين:

```
NFC  →  U+0623            ألف بهمزة، نقطةٌ واحدة      2 بايت
NFD  →  U+0627 U+0654     ألف  +  همزة مركَّبة فوقها   4 بايت
```

والاثنان **متكافئان دلالياً** ويُرسمان سواء. و`==` في Go **مقارنة بايتات**، فتقول
لا.

**وهذا ليس عيباً في اللغة.** المقارنة البايتية سريعة ومعرَّفة وقابلة للاستعمال في
خريطة. والمقارنة الدلالية تحتاج جداول Unicode، وتتغيّر بإصداراته — فلا مكان لها
في المواصفة.

**والقاعدة العملية:** كل نصٍّ يدخل نظامك من الخارج — من لوحة مفاتيح، من نظام
ملفّات، من واجهة — **يُوحَّد عند الحدّ** قبل أن يُخزَّن أو يُقارَن. والتوحيد في
`golang.org/x/text/unicode/norm`.

وفي مخزنك تحديداً: مفتاحان يبدوان واحداً وهما مدخلان مختلفان في الخريطة.

## البناء بالتراكم

آخر لقطة، وهي عن الثمن لا عن المعنى:

<!-- notice: عدّاد التخصيص لا يُقاس في المتصفّح. شغّله محلياً. -->

<!-- run: no -->

```go
package main

import (
	"fmt"
	"runtime"
	"strings"
)

func mallocs(f func()) uint64 {
	var a, b runtime.MemStats
	runtime.GC()
	runtime.ReadMemStats(&a)
	f()
	runtime.ReadMemStats(&b)
	return b.Mallocs - a.Mallocs
}

var out string

func main() {
	parts := []string{"a", "b", "c", "d", "e", "f", "g", "h"}

	plus := mallocs(func() {
		s := ""
		for _, p := range parts {
			s += p
		}
		out = s
	})

	builder := mallocs(func() {
		var b strings.Builder
		b.Grow(len(parts))
		for _, p := range parts {
			b.WriteString(p)
		}
		out = b.String()
	})

	fmt.Println("بـ +=      :", plus)
	fmt.Println("بـ Builder :", builder)
	fmt.Println(out)
}
```

<!-- out -->

```
بـ +=      : 7
بـ Builder : 1
abcdefgh
```

**سبعة تخصيصات مقابل واحد.** لأن النصّ لا يُعدَّل: كل `s += p` تبني نصّاً جديداً
كاملاً وتنسخ ما قبله إليه. فثمنه يتربّع مع الطول.

و`strings.Builder` شريحةُ بايتات تنمو كما رأيتَ في إقليم الشريحة، ثم تُسلَّم نصّاً
**بلا نسخٍ أخير**. و`Grow` تُلغي حتى نموّها.

**ولاحظ أن هذا نفس درس الإقليم ٠٤ بلباسٍ آخر:** العمل ليس هو الكلفة، التخصيص هو
الكلفة.

## بذرة

النصّ الآن مفهوم: بايتاتٌ في تخزينه، رموزٌ في مروره، علاماتٌ في إدراكه، وبايتاتٌ
في مقارنته.

وبقيت من مخزنك القطعةُ التي لم نفكّكها بعد. `Put` تُنادى من ثلاث `goroutines`
معاً، وقلنا إن القفل يحميها.

**لكن القفل ليس أداة Go الأولى للتزامن.** الأداة الأولى `chan` — كلمةٌ مفتاحية
رأيتَ نوعها واتجاهه ولم تشغّلها بعد.

الإقليم القادم عن القناة، وعن ما يحدث حين تُغلَق وقارئان ينتظران.
