# الإقليم ٠٢ — من يملك المصفوفة

> في مخزنك سطرٌ واحد بريء: `s.log = append(s.log, r)`.
>
> وقد رأيتَ في الفصل صفر أن الشريحة **رأسٌ من ثلاث كلمات** يشير إلى مصفوفة. فحين
> تنمو، أين تذهب المصفوفة القديمة؟ ومن يقرأ منها بعد أن نمت؟
>
> هذا الإقليم كلّه عن **الملكيّة**: من يملك البايتات، ومن يظنّ أنه يملكها.

---

## اللوج ينمو

`append` لا تضيف خانةً واحدة. تنظر في السعة، فإن ضاقت **خصّصت مصفوفةً أكبر**.

<!-- run: no -->

```go
package main

import "fmt"

func main() {
	var log []string
	prev := -1

	for i := 0; i < 10; i++ {
		log = append(log, "سجلّ")
		if cap(log) != prev {
			fmt.Printf("len=%2d  cap=%2d\n", len(log), cap(log))
			prev = cap(log)
		}
	}
}
```

<!-- out -->

```
len= 1  cap= 2
len= 3  cap= 4
len= 5  cap= 8
len= 9  cap=16
```

**عشر إضافات، وأربع عمليات تخصيص.** والباقي كتابةٌ في مكانٍ محجوزٍ سلفاً.

فلوجُك إذن ليس مصفوفةً واحدة عبر عمر البرنامج، بل **سلسلةً من مصفوفات** كلٌّ منها
ضِعف ما قبلها، وكل واحدةٍ تُهجَر حين تُخلَق التي بعدها.

## من يملك المصفوفة القديمة

الجواب: **لا أحد، ولذلك يجمعها الكانس.** لكن السؤال الأخطر عكسه — ماذا يحدث
**قبل** أن تضيق السعة؟

```
قبل النموّ (cap يتّسع)          بعد النموّ (cap ضاق)

 s ─┐                            s ─┐            القديمة ─┐
    ▼                               ▼                     ▼
 [ a │ b │ _ │ _ ]              [ a │ b │ c │ _ │ _ … ]  [ a │ b │ c ]
    ▲                                                     مهجورة
    └── t (شريحةٌ أخرى تشير إليها)                        └── وt ما زالت هنا
```

فـ`append` لها **حالتان لا واحدة**:

**إن اتّسعت السعة** كتبت في المصفوفة الموجودة — وكل شريحةٍ أخرى تشير إليها **ترى
الكتابة**.

**وإن ضاقت** خصّصت ونسخت — فانفكّ الارتباط، ولم تعد الشريحتان تريان بعضهما.

**والحالة تتقرّر وقت التشغيل**، بحسب سعةٍ لم تكتبها أنت. وهذا مصدر أخبث أخطاء Go.

## قبل النموّ: المصفوفة واحدة

```go
package main

import "fmt"

func main() {
	a := []int{1, 2, 3, 4}
	b := a[:2]

	fmt.Println("b:", b, "len", len(b), "cap", cap(b))

	b = append(b, 99)

	fmt.Println("a:", a)
	fmt.Println("b:", b)
}
```

`b` شريحةٌ فرعية من `a`، فيها عنصران. ثم نضيف إليها عنصراً واحداً.

**توقّع الأسطر الثلاثة.** وانتبه للسطر الأول: ما سعة `b`؟

المخرَج:

```
b: [1 2] len 2 cap 4
a: [1 2 99 4]
b: [1 2 99]
```

## الحدّ الثالث

`b := a[:2]` أخذت طولاً اثنين و**سعةً أربعة** — لأن التقطيع يرث السعة من موضع
البداية إلى نهاية المصفوفة. فكانت هناك خانةٌ فارغة، فكتبت فيها `append`.

ولصيغة التقطيع **حدٌّ ثالث** يقصّ السعة نفسها: `a[low:high:max]`.

```go
package main

import "fmt"

func main() {
	a := []int{1, 2, 3, 4}
	b := a[:2:2]

	fmt.Println("cap(b) =", cap(b))
	b = append(b, 99)

	fmt.Println("a:", a)
	fmt.Println("b:", b)
	fmt.Println("نفس المصفوفة؟", &a[0] == &b[0])
}
```

<!-- out -->

```
cap(b) = 2
a: [1 2 3 4]
b: [1 2 99]
نفس المصفوفة؟ false
```

**السعة صفر زائدةً، فاضطرّت `append` أن تخصّص.** وانفكّ الارتباط قسراً.

فحين تعطي شريحةً فرعية إلى كودٍ لا تثق به، **اقصص سعتها**. هذا هو الاستعمال
الحقيقيّ الوحيد للحدّ الثالث، وسبب وجوده.

## سياسة النموّ ليست «الضِّعف»

الجملة المشهورة: «`append` تضاعف السعة». **قِسها.**

<!-- run: no -->

```go
package main

import "fmt"

func main() {
	var s []byte
	prev := 0

	for len(s) < 3000 {
		s = append(s, 0)
		if cap(s) != prev {
			if prev != 0 {
				fmt.Printf("%5d → %5d   ×%.2f\n", prev, cap(s), float64(cap(s))/float64(prev))
			}
			prev = cap(s)
		}
	}
}
```

<!-- out -->

```
   32 →    64   ×2.00
   64 →   128   ×2.00
  128 →   256   ×2.00
  256 →   512   ×2.00
  512 →   896   ×1.75
  896 →  1408   ×1.57
 1408 →  2048   ×1.45
 2048 →  3072   ×1.50
```

**الضِّعف صحيحٌ حتى ٢٥٦، ثم يهبط تدريجياً.** لأن مضاعفة مصفوفةٍ بميغابايت تطلب
ميغابايتين، والذاكرة المهدورة تكبر مع الحجم لا مع العدد.

ولاحظ أن الأرقام ليست ضرباً نظيفاً: `896` و`1408` **أحجام فئاتٍ في المخصِّص**.
السعة تُقرَّب لأقرب فئة، فالرقم الذي تراه ليس ما حسبته الخوارزمية بل ما أعطاه
المخصِّص.

**والدرس العمليّ:** إن عرفتَ العدد فاطلبه — `make([]T, 0, n)` تُلغي هذه السلسلة
كلّها.

## `copy` هو النسخ الصريح

`append` تنسخ **حين تضطرّ**. و`copy` تنسخ **حين تطلب**:

```go
package main

import "fmt"

func main() {
	src := []int{1, 2, 3}

	dst := make([]int, 2)
	n := copy(dst, src)
	fmt.Println("نُسخ:", n, dst)

	own := make([]int, len(src))
	copy(own, src)
	own[0] = 99
	fmt.Println(src, own)
}
```

<!-- out -->

```
نُسخ: 2 [1 2]
[1 2 3] [99 2 3]
```

**`copy` تنسخ أقلّ الطولين ولا تنمو أبداً** — ولذلك أعادت ٢ لا ٣. من نسي هذا فقد
بايتاته بصمت.

والسطر الأخير هو **الحلّ** لمشكلة `Get` في مخزنك: خصّص بطول المصدر ثم انسخ، فتصير
النسخة مالكةً لبايتاتها. وثمن ذلك إقليمٌ قادم.

## عشرة بايتات تحتجز ميغابايت

```go
package main

import "fmt"

func main() {
	big := make([]byte, 1<<20)
	small := big[:10]

	fmt.Println("len =", len(small))
	fmt.Println("cap =", cap(small))
}
```

<!-- out -->

```
len = 10
cap = 1048576
```

`small` طولها عشرة، **ومصفوفتها ميغابايت**. والرأس يشير إلى أوّل المصفوفة، فما دام
`small` حيّاً فالميغابايت كلّه **غير قابل للجمع**.

وهذا تسريبٌ حقيقيّ، وأكثر مواضعه شيوعاً: تقرأ ملفاً كبيراً، وتحتفظ بسطرٍ منه.

**والعلاج نسخة:** `own := make([]byte, len(small)); copy(own, small)`. عشرة بايتات
مقابل ميغابايت — أرخص صفقةٍ في هذه اللغة.

## صفريّة أم فارغة

`var a []int` و`b := []int{}` **ليستا واحدة**، وإن تصرّفتا كذلك في أغلب اليوم:

```go
package main

import (
	"encoding/json"
	"fmt"
)

func main() {
	var a []int
	b := []int{}

	fmt.Println(a == nil, b == nil)
	fmt.Println(len(a), len(b), a, b)

	ja, _ := json.Marshal(a)
	jb, _ := json.Marshal(b)
	fmt.Printf("%s %s\n", ja, jb)
}
```

<!-- out -->

```
true false
0 0 [] []
null []
```

الطول واحد، والطباعة واحدة، و`append` تعمل على الاثنتين (البديهية الأولى). **ثم
يفترقان عند الحدود**: الصفريّة تُسلسَل `null`، والفارغة `[]`.

فلو أرجعت دالّتك شريحةً صفرية، رأى عميلُك `null` حيث توقّع قائمةً فارغة. **والقاعدة
العملية:** استقبل الاثنتين، وأرجع الصفريّة دائماً — إلا إن كان المخرَج JSON، فسمِّ
الفرق صراحةً.

## الحذف يترك شبحاً

المصطلح الشائع لحذف عنصر:

```go
package main

import "fmt"

func main() {
	s := []string{"a", "b", "c"}
	s = append(s[:1], s[2:]...)

	fmt.Println(s, len(s), cap(s))
	fmt.Printf("%q\n", s[:cap(s)])
}
```

السطر الأول واضح. **والثاني يقرأ المصفوفة كاملةً حتى سعتها.** توقّع ما فيه.

المخرَج:

```
[a c] 2 3
["a" "c" "c"]
```

## لماذا بقي الشبح

لأن الحذف **لم يحذف**. أزاح: نسخ `"c"` فوق `"b"`، وأنقص الطول واحداً. والخانة
الأخيرة بقيت كما كانت.

```
قبل:  [ "a" │ "b" │ "c" ]   len=3
بعد:  [ "a" │ "c" │ "c" ]   len=2  ←  الطول يخفيها، والسعة تفضحها
                    ↑
                 شبحٌ حيّ
```

ومع النصوص الشبح **مرجعٌ حيّ**: النصّ رأسٌ فيه مؤشّر، فبايتات `"c"` غير قابلة
للجمع. وإن كانت عناصرك مؤشّرات أو بنًى كبيرة، فأنت تحتجز ما حذفتَه ظاهرياً.

**والعلاج سطرٌ واحد** بعد الإزاحة: صفّر الخانة الأخيرة قبل قصّ الطول.

`s[len(s)-1] = ""` — أو `clear(...)` إن كان المحذوف أكثر من واحد.

## الشريحة في التوقيع

آخر لغزٍ في هذا الإقليم، وأكثره وقوعاً في الكود الحقيقيّ:

```go
package main

import "fmt"

func grow(s []int) {
	s = append(s, 99)
	fmt.Println("داخل الدالة:", s)
}

func fill(s []int) {
	s[0] = 99
	fmt.Println("داخل الدالة:", s)
}

func main() {
	a := make([]int, 3, 8)
	grow(a)
	fmt.Println("بعدها:", a, len(a))

	fill(a)
	fmt.Println("بعدها:", a)
}
```

دالّتان تعدّلان نفس الشريحة، **وسعتها تتّسع للاثنتين**. توقّع الأربعة أسطر.

المخرَج:

```
داخل الدالة: [0 0 0 99]
بعدها: [0 0 0] 3
داخل الدالة: [99 0 0]
بعدها: [99 0 0]
```

## لماذا نجحت واحدةٌ وفشلت الأخرى

**لأن الاثنتين نجحتا فيما فعلتا، والفرق فيما عُدِّل.**

`fill` عدّلت **المصفوفة** عبر المؤشّر المنسوخ. فالكتابة وصلت.

`grow` عدّلت **الرأس** — أسندت إلى `s` رأساً جديداً طولُه أربعة. و`s` نسخةٌ محلّية
من ثلاث كلمات، تموت عند `return`. فالبايت التاسع والتسعون **كُتب فعلاً في مصفوفة
`a`**، لكن طول `a` بقي ثلاثة فلا يراه أحد.

```
main.a  [ ptr │ 3 │ 8 ]           ┌─► [ 0 │ 0 │ 0 │ 99 │ … ]
grow.s  [ ptr │ 4 │ 8 ]  (نسخة) ──┘        كُتب هنا، وطول a يخفيه
```

**ولهذا توقيع `append` يُرجع شريحة.** لو كانت تعدّل المستقبِل لما احتاجت ذلك. وكل
من كتب `append(s, x)` بلا إسناد كتب سطراً لا يفعل شيئاً — و`go vet` يمسكه.

## بذرة

المصفوفة ملكيّتها الآن واضحة. وفي مخزنك بقيت مسألتان لم تُحلّا:

**واحد.** `Put` تقفل، **ثم تنادي `s.sink.Write` وهي ما زالت تحمل القفل**. والوجهة
كودٌ لا تعرفه. ماذا لو نادت المخزن من داخلها؟

**اثنان.** عرفتَ علاج `Get`: انسخ البايتات. وقِسها — ستجد الثمن في مكانٍ لن
تتوقّعه.

الإقليم القادم يبدأ من الأول.
