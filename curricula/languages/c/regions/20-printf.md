# الإقليم ٢٠ — `printf`

> استعملتَها منذ السطر الأول، وقلتُ في الفصل صفر إنها **دالّةٌ عادية** كتبها
> إنسان. هذا هو الإقليم الذي يثبت ذلك.
>
> وستخرج منه بشيئين: كيف تأخذ دالّةٌ عدداً غير معلومٍ من الوسائط، ولماذا كان
> **لا بدّ** من نصّ صيغة — ثم تكتب `my_printf` بنفسك.

---

## لماذا يوجد نصّ الصيغة أصلاً

السؤال الذي يسبق كل شيء: لماذا `printf("%d", x)` ولا `printf(x)`؟

**لأن البديهية الأولى:** لا يبقى وقت التشغيل إلا البايتات. حين تصل `printf`،
عندها عنوانٌ وبايتاتٌ على الـstack، **ولا شيء يقول ما هي**. لا نوع، ولا حجم، ولا
عدد.

فنصّ الصيغة ليس تجميلاً للمخرَج — هو **الوسيلة الوحيدة** لإخبار الدالّة بما
أعطيتَها. وكل ما يبدو قبيحاً في `printf` نتيجةٌ لهذا القيد الواحد.

**ولذلك يقع الخطأ صامتاً:** إن كذبتَ في الصيغة صدّقتك، وقرأت البايتات بالعدسة
التي طلبتَها.

---

## `...` و`<stdarg.h>`

```c
#include <stdio.h>
#include <stdarg.h>

int sum(int n, ...)
{
	va_list ap;
	int     total = 0;

	va_start(ap, n);
	for (int i = 0; i < n; i++)
		total += va_arg(ap, int);
	va_end(ap);
	return total;
}

int main(void)
{
	printf("%d\n", sum(3, 10, 20, 30));
	printf("%d\n", sum(0));
	return 0;
}
```

<!-- out -->

```
60
0
```

أربعة أسماء، وكلّها **ماكروات** لا دوالّ (وهذا سبب مجيء هذا الإقليم بعد ١٩):

| | |
|---|---|
| `va_list ap` | مؤشّرٌ يمشي على الوسائط |
| `va_start(ap, n)` | ابدأ **بعد** آخر وسيطٍ مسمّى |
| `va_arg(ap, T)` | خذ الوسيط التالي **بافتراض** أن نوعه `T`، وتقدّم |
| `va_end(ap)` | انتهيت |

**و`va_arg` لا تفحص شيئاً.** أنت تقول لها النوع، فتقرأ بحجمه وتتقدّم بمقداره.
فإن أخطأتَ النوع اختلّ كل ما بعده — لا هذا الوسيط وحده.

**ولذلك تحتاج `...` إلى وسيطٍ مسمّى قبلها**: منه يبدأ `va_start`، ومنه غالباً
تعرف الدالّة كم وسيطاً تتوقّع. في `sum` هو العدد، وفي `printf` هو النصّ.

---

## والوسائط تُرقَّى قبل أن تصل

```c
#include <stdio.h>
#include <stdarg.h>

void show(int n, ...)
{
	va_list ap;

	va_start(ap, n);
	printf("%d %f\n", va_arg(ap, int), va_arg(ap, double));
	va_end(ap);
}

int main(void)
{
	char  c = 'A';
	float f = 1.5f;

	show(2, c, f);
	printf("%d\n", printf("abc\n"));
	return 0;
}
```

<!-- out -->

```
65 1.500000
abc
4
```

**مرّرتُ `char` وقرأتُ `int`، ومرّرتُ `float` وقرأتُ `double` — وصحّ الاثنان.**

لأن الوسائط التي تقع في موضع `...` تخضع لـ**الترقيات الافتراضية**: كل ما دون
`int` يصير `int`، و`float` يصير `double`. وهي قريبةٌ من الـpromotion الذي رأيتَه
في الإقليم ٠٦، وتزيد عليه بالعشريّ.

**وهذا يفسّر شيئين كانا يبدوان عشوائيين:**

- **لا `%f` للـ`float` و`%lf` للـ`double`** — لا يصل إلى `printf` سوى `double`
  أصلاً، فـ`%f` تكفيهما.
- **`%c` تأخذ `int`** — لأن `char` لا يصل بوصفه `char` أبداً.

**والسطر الأخير:** `printf` تُرجع **عدد ما كتبته**. أربعة: ثلاثة حروفٍ وسطرٌ جديد.

---

## حين تكذب في الصيغة

```c
#include <stdio.h>

int main(void)
{
	long n = 5;

	printf("%d\n", n);
	return 0;
}
```

<!-- warn @impl -->

```
warning: format specifies type 'int' but the argument has type 'long'
```

**والمترجم يعرف `printf` بالاسم.** هذا ليس فحصاً عاماً للغة: `-Wformat` قاعدةٌ
مخصوصة، والمترجم يقرأ نصّ الصيغة **إن كان حرفياً** ويطابقه بالوسائط.

**وحدّها أنها تسقط عند أوّل متغيّر:**

```c
printf(fmt, x);        /* لا أحد يفحص شيئاً */
```

**وهذه هي الثغرة المسمّاة format string** — إن كان `fmt` نصّاً يأتي من المستعمل،
فقد كتب هو الصيغة، وصار يقرأ من الـstack ما يشاء. **فلا تمرّر نصّاً خارجياً
صيغةً**؛ مرّره وسيطاً: `printf("%s", input)`.

**ولتُعلِم المترجم بدالّتك أنت**، فيفحص صيغتها كما يفحص `printf`:

```c
int my_log(const char *fmt, ...) __attribute__((format(printf, 1, 2)));
```

وهذا امتدادٌ من المترجم لا من المواصفة — والفرق يُعلَن.

---

## واكتبها بنفسك

كل ما سبق يكفي لكتابتها. والقلب حلقةٌ على النصّ:

<!-- part: 20-myprintf -->

```c
int my_printf(const char *fmt, ...)
{
	va_list ap;
	int     n = 0;

	va_start(ap, fmt);
	for (const char *p = fmt; *p != '\0'; p++) {
		if (*p != '%') {
			putchar(*p);
			n++;
			continue;
		}
		p++;
		switch (*p) {
		case 'd':
			n += put_int(va_arg(ap, int));
			break;
		case 'c':
			putchar(va_arg(ap, int));
			n++;
			break;
		case 's': {
			const char *s = va_arg(ap, const char *);

			while (*s != '\0') {
				putchar(*s++);
				n++;
			}
			break;
		}
		case '%':
			putchar('%');
			n++;
			break;
		default:
			putchar('%');
			putchar(*p);
			n += 2;
		}
	}
	va_end(ap);
	return n;
}
```

<!-- out -->

```
count = -42!
0 2147483647 -2147483648
100% و%q
طول أوّل سطر = 13
```

**لا سحر في السطور.** حلقةٌ تمشي على النصّ، وطباعةٌ حرفاً حرفاً، و`va_arg` عند كل
`%`. وهذا هو كل ما تفعله `printf` الحقيقية — عدا التنسيق والعرض والدقّة والأنواع
الباقية.

**ولاحظ ثلاثة قرارات في الكود:**

`case 'c'` تكتب `va_arg(ap, int)` لا `char` — لأن الترقية سبقتك، وطلبُ `char`
يقرأ حجماً خاطئاً.

و`default` تطبع `%` والحرف كما هما، فترى `%q` في المخرَج. والمواصفة تقول إن صيغةً
غير معروفة **سلوكٌ غير معرَّف** — واخترتُ سلوكاً معلوماً، وأعلنتُه.

و`%%` حالةٌ مستقلّة: النصّ لا يستهلك وسيطاً.

## و`put_int` فيها سطرٌ يستحقّ وقفة

```c
static int put_int(int v)
{
	if (v < 0) {
		putchar('-');
		return 1 + put_uint((unsigned int)-(v + 1) + 1u);
	}
	return put_uint((unsigned int)v);
}
```

الصيغة الطبيعية `put_uint((unsigned int)-v)`. **وهي تنهار عند `INT_MIN`** — لأن
`-INT_MIN` سلوكٌ غير معرَّف، ورأيتَه بعينك في الإقليم ٠٣.

فالمكتوب يزيد واحداً أوّلاً — فيصير في المدى — ثم ينفي، ثم يعيد الواحد **بعد**
التحويل إلى `unsigned` حيث الالتفاف معرَّف.

**والدليل في اللوحة:** `-2147483648` طُبعت صحيحة. وهذا السطر الواحد هو الفرق بين
`printf` تعمل و`printf` تنهار على قيمةٍ واحدة من أربعة مليارات.

## تمرير الصيغة إلى غيرها

يبقى نقصٌ واحد: كيف تكتب دالّةً تأخذ `...` وتسلّمها إلى `printf`؟

**لا تستطيع.** `...` لا تُمرَّر. ولذلك تُوجد نسخةٌ ثانية من كل دالّة صيغة، تأخذ
`va_list` جاهزة:

```c
#include <stdarg.h>

void log_msg(const char *fmt, ...)
{
	va_list ap;

	va_start(ap, fmt);
	vfprintf(stderr, fmt, ap);
	va_end(ap);
}
```

`vprintf` و`vfprintf` و`vsnprintf` — كلّها بحرف `v` في أوّلها. وهي السبب في وجود
عائلتين متوازيتين في `<stdio.h>` تبدوان تكراراً.

**وحدٌّ منصوص:** `va_list` قد تُستهلَك بالمرور، فلا تمرّرها مرّتين. وإن احتجتَ
تكرارها فـ`va_copy`.

---

## قبل أن تكمل

> **١.** أضِف `%x` إلى `my_printf`. ثم أضِف `%5d` — عرضاً أدنى. أيّهما غيّر بنية
> الحلقة، ولماذا؟
>
> **٢.** `my_printf("%d")` بلا وسيط — ماذا يحدث؟ شغّلها مع `-fsanitize=undefined`
> ثم اشرح: من أين قرأت `va_arg`، ولماذا لا يستطيع أحد أن يمنعها؟
>
> **٣.** في الإقليم ٠١، `printf("%-8s %s\n", …)` — أعِد كتابة `cmd_list`
> بـ`my_printf`. ما الذي ينقصك، وكم سطراً يكلّفك؟
