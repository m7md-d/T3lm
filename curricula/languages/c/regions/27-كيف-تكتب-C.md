# الإقليم ٢٧ — كيف تُكتب C

> ستّةٌ وعشرون إقليماً **فكّكت** اللغة. وهذا الإقليم يعكس الاتّجاه: كيف تبدو
> شِفرةُ C حقيقيةٌ يكتبها من يعرف كل ما عرفتَه.
>
> ومادّته جاهزة: **برنامج الإقليم ٠١ يُعاد كتابته** — والفرق بين النسختين هو
> الدرس كلّه.
>
> ولا قاعدة هنا بلا سبب. وكل ما ستقرؤه مردودٌ إلى إقليمٍ مضى، لا إلى ذوق.

---

## الاسم يحمل ما لا يحمله النوع

من الإقليم ١٠: لا `namespace` في C، ووحدة الإخفاء ملفّ، والاسم غير `static` يُرى
في البرنامج كلّه. **فالبادئة ليست عادةً، بل الأداة الوحيدة المتاحة.**

```c
Table *table_new(void);
void   table_free(Table *t);
int    table_set(Table *t, const char *key, const char *value);
```

| الاصطلاح | لماذا |
|---|---|
| `module_action` | البادئة تمنع اصطدام الـlinker (الإقليم ١٨) |
| **الوحدة أوّل وسيط** | متّسق، ويقرأ كما ينطق: `table_set(t, …)` |
| `_new` / `_free` **متقابلتان** | الاسم يقول من يحرّر — والإقليم ١٦ قال إن اللغة لا تحملها |
| `const` على ما لا يُكتَب | عقدٌ يفحصه المترجم (الإقليم ١١) |

**و`table_get` تُرجع `const char *` لا `char *`.** والفرق ليس تجميلاً: هو إعلانٌ
بأن الجدول ما زال يملك النصّ، وأن الكتابة عبره ممنوعة. **والنوع يفرضه.**

## الترويسة عقدٌ، لا ملفّ إعلانات

```c
#ifndef TABLE_H
#define TABLE_H

#include <stddef.h>

/* جدولُ مفاتيحَ وقيمٍ نصّية. النوع مُعتِم: أنشئه بـtable_new وحرّره بـtable_free. */
typedef struct Table Table;

/* يُرجع NULL عند نفاد الذاكرة. المِلكية للنادي. */
Table *table_new(void);
void   table_free(Table *t);

/* يُرجع 0 عند النجاح، و-1 عند الفشل. ينسخ key وvalue. */
int table_set(Table *t, const char *key, const char *value);

/* يُرجع NULL إن لم يوجد. المِلكية تبقى للجدول، وتبطل عند أوّل table_set. */
const char *table_get(const Table *t, const char *key);

int    table_del(Table *t, const char *key);
size_t table_len(const Table *t);

#endif /* TABLE_H */
```

**خمسة قرارات في عشرين سطراً:**

**١. النوع مُعتِم** (الإقليم ١٨): `struct Table` معلَنٌ بلا تعريف. فلا يستطيع
المستعمل أن يقرأ حقلاً، ولا أن ينشئ واحدةً على الـstack — ويصير تخطيطك الداخليّ
قابلاً للتغيير بلا إعادة ترجمته.

**٢. `#include <stddef.h>` وحده.** الترويسة تضمّ ما **تحتاجه هي** لتُترجَم —
`size_t` هنا — ولا شيء غيره. وترويسةٌ تضمّ `<stdio.h>` بلا حاجة تفرضه على كل
ملفٍّ يضمّها (الإقليم ١٨: النسخ واللصق).

**٣. التعليق يقول ما لا يقوله التوقيع**: من يملك، ومتى يبطل، وماذا يعني الإرجاع.
**وهذه هي المعلومة الوحيدة التي لا تحملها اللغة** (الإقليم ١٦) — فموضعها هنا، لا
في الـ`.c`.

**٤. اصطلاح إرجاعٍ واحد للوحدة كلّها**: صفرٌ نجاح، وسالبٌ فشل — إلا ما يُرجع
pointer فـ`NULL`. والخلط داخل وحدةٍ واحدة يجعل كل نداءٍ سؤالاً.

**٥. الحارس، والتعليق على `#endif`** — لأن الملفّ يطول والقوس يبعد.

## و`.c` يخفي كل ما عداه

```c
enum { TABLE_CAP = 64, KEY_MAX = 32 };

struct Entry {
	char  key[KEY_MAX];
	char *value;
};

struct Table {
	struct Entry entries[TABLE_CAP];
	size_t       len;
};

static struct Entry *find(const struct Table *t, const char *key)
{
	…
}

static char *dup_str(const char *s)
{
	…
}
```

**`static` على كل ما ليس في الترويسة** — رأيتَ أثره في `nm` في الإقليم ١٨:
`t` صغيرة لا `T`. وهو يمنع الاصطدام، ويأذن للمترجم بأن يدمج الدالّة في مكانها.

**و`enum` للثوابت لا `#define`** (الإقليم ١٩): لها نوع، ولها نطاق، ويراها المنقّح.

**و`KEY_MAX` داخل `.c` لا في الترويسة**، لأنه تفصيلٌ داخليّ. ولو ظهر لصار جزءاً
من العقد.

## والفرق بين النسختين

| الإقليم ٠١ | الآن | من أي إقليم |
|---|---|---|
| `struct Item table[64];` عامّة | داخل `struct Table` مُعتِمة | ١٠ · ١٨ |
| `strcpy(it->key, key)` | فحصُ الطول ثم `memcpy` | ١٢ · ١٣ |
| القديم يُدهَس فيُسرَّب | `free` قبل الإسناد | ١٦ |
| `void cmd_set(…)` بلا إرجاع | `int` تُفحَص | ٢٢ |
| `malloc` بلا فحص | يُفحَص، ويُرجَع `-1` | ١١ · ٢٢ |
| `int items` | `size_t len` | ٠٣ |
| لا حدّ على الجدول | `t->len == TABLE_CAP` | ١٢ |
| `char *` يُرجَع | `const char *` | ١١ |

**ثمانية أسطرٍ زادت.** وكلٌّ منها يغلق خطأً رأيتَه بعينك في إقليمٍ سابق.

## اختبارٌ بلا إطار

C لا تعطيك شيئاً للاختبار. **ولا تحتاج شيئاً**: `main` وassert وقيمةُ خروج.

<!-- part: 27-craft -->

```c
static int checks = 0;

#define CHECK(cond)                                          \
	do {                                                 \
		checks++;                                    \
		if (!(cond)) {                               \
			printf("فشل %s:%d: %s\n", __FILE__,  \
			       __LINE__, #cond);             \
			return 1;                            \
		}                                            \
	} while (0)

int main(void)
{
	Table *t = table_new();

	CHECK(t != NULL);
	CHECK(table_get(t, "x") == NULL);
	CHECK(table_set(t, "name", "ali") == 0);
	CHECK(table_set(t, "name", "sara") == 0);
	CHECK(table_len(t) == 1);
	CHECK(table_del(t, "name") == -1 + 1);
	…
}
```

```
نجح 13 فحصاً

```

**`CHECK` من الإقليم ١٩ كلّه:** `#cond` يطبع الشرط كما كُتب، و`__FILE__` و
`__LINE__` يقولان أين، و`do/while(0)` تجعله جملةً واحدة.

**ولا يستعمل `assert` هنا**، لثلاثة أسباب: `assert` تختفي مع `-DNDEBUG`، ولا تعدّ
شيئاً، وتُنهي البرنامج عند أوّل فشلٍ بلا رمز خروجٍ نظيف.

**وأهمّ سطرٍ في هذا كلّه في `Makefile`:**

```makefile
test: tests/test_table.c src/table.c include/table.h
	$(CC) $(CFLAGS) -fsanitize=address,undefined \
	      tests/test_table.c src/table.c -o test
	./test
```

**الاختبار يُبنى بالكاشفات دائماً.** لأن نصف ما يفحصه ليس القيمة المرجَعة، بل ألّا
يقع تسريبٌ ولا كتابةٌ خارج الحدّ أثناء الفحص — وذلك لا يظهر في `CHECK` أبداً.

## التخطيط، وحدّ الحاجة

```
project/
├── include/table.h        العقد — ما يراه غيرك
├── src/table.c            التنفيذ
├── src/main.c             نقطة الدخول
├── tests/test_table.c     الاختبار
└── Makefile
```

**والقاعدة التي تولّده:** `include/` لما يُنشَر، و`src/` لما لا يُنشَر. وفي مشروعٍ
صغيرٍ من ثلاثة ملفّات، مجلّدٌ واحد يكفي — **والبنية تتبع الحاجة**، ولا تُنسَخ من
مشروعٍ آخر.

**ووحدة التقسيم `struct` وعملياتها**، لا «طبقة» ولا «نوع ملفّ». وحين تتجاوز وحدةٌ
بضع مئاتٍ من الأسطر، اسأل: **أي `struct` فيها لها واجهةٌ مستقلّة؟**

## حلقة العمل

| | |
|---|---|
| `make test` | **قبل كل commit**، بالكاشفات |
| `make` بـ`-O2` | ثم أعِد الاختبار — الإقليم ٢٦ |
| `cc -E` | عند أي عطبٍ في ماكرو |
| `nm` · `objdump` | عند «undefined symbol» و«duplicate symbol» |
| `lldb ./test` | عند انهيارٍ لا يفسّره تقرير |

**والقاعدة التي تختصر الإقليم كلّه:** التحذير خطأ. اجعل `CFLAGS` تحمل
`-Wall -Wextra` من أوّل يوم، وأصلِح كل تحذيرٍ لحظةَ يظهر. **لأن التحذير الذي
يُترَك يخفي الذي بعده** — ومئةُ تحذيرٍ مألوفة تعني أن التحذير الحقيقيّ لن يُرى.

## ما لا تفعله

| | لماذا |
|---|---|
| `typedef` يخفي الـpointer — `typedef Item *ItemPtr` | يخفي النجمة، فلا يرى القارئ ما يُنسَخ ولا ما يُحرَّر |
| ماكرو يفعل ما تفعله دالّة | الإقليم ١٩: تقييمٌ مزدوج، وبلا نوع |
| متغيّرٌ عامّ غير `static` | الإقليم ١٠: يُرى في البرنامج كلّه |
| `strcpy` · `strcat` · `sprintf` | الإقليم ١٣: لا تعرف حجم الوجهة |
| `cast` يُسكت تحذيراً | الإقليم ٠٦: يشتري صمتاً بثمن الخطأ |
| ترويسةٌ تضمّ ما لا تحتاجه | الإقليم ١٨: تفرضه على كل من يضمّها |
| `int` لطولٍ أو فهرس | الإقليم ٠٣: `size_t` هو النوع |

## قبل أن تكمل

> **١.** أضِف `table_each` تمرّ على كل مدخلٍ وتنادي دالّةً تعطيها. ما توقيعها،
> وأين يقع `void *` للسياق، ولماذا؟
>
> **٢.** أضِف اختباراً يملأ الجدول إلى `TABLE_CAP` ثم يزيد. ماذا يجب أن يُرجَع؟
> وهل كتبتَ ذلك في تعليق الترويسة قبل أن تكتب الكود؟
>
> **٣.** اجعل `TABLE_CAP` يكبر بـ`realloc` بدل أن يكون ثابتاً. أي سطرٍ في العقد
> يتغيّر؟ وأي وعدٍ في تعليق `table_get` ينكسر؟ (الإقليم ١٦.)
