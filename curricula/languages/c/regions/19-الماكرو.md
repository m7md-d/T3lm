# الإقليم ١٩ — الماكرو

> رأيتَ في الإقليم السابق أن `#include` **نسخٌ ولصق**، وأن حارس الترويسة حيلةٌ
> فوق أداة استبدالٍ نصّيّ.
>
> هذه هي الأداة. وهي أبسط ممّا تتخيّل — **لا تعرف نوعاً ولا قيمةً ولا لغةً**،
> تستبدل نصّاً بنصّ ثم تمضي. ومن هذه البساطة بالذات تأتي مصائدها، ويأتي ما لا
> يستطيعه غيرها.

---

## استبدالٌ قبل أن يرى المترجم شيئاً

```c
#define MAX_ITEMS 64
```

هذا ليس متغيّراً ولا ثابتاً. هو أمرٌ للـpreprocessor: **حيثما رأيتَ `MAX_ITEMS`،
اكتب `64`**. وحين يصل الدور إلى المترجم، لا وجود للاسم أصلاً.

**ولذلك لا نوع له، ولا نطاق، ولا عنوان.** لا تستطيع أن تأخذ `&MAX_ITEMS`، ولا أن
تراه في `lldb`، ولا أن يحذّرك أحدٌ من إساءة استعماله.

**والبديل الذي يعرف نوعه:**

```c
enum { MAX_ITEMS = 64 };        /* ثابتٌ له نوع */
static const int limit = 64;    /* كائنٌ له عنوان */
```

فمتى الماكرو إذن؟ **حين تحتاج شيئاً لا يستطيعه المترجم**: طولَ array يُحسَم وقت
الترجمة، أو نصّاً يُلصَق بنصّ، أو كوداً يظهر ويختفي. وما عدا ذلك، النوع أفضل.

## المصيدة الأولى: الأقواس

```c
#include <stdio.h>

#define SQ_BAD(x)  x * x
#define SQ(x)     ((x) * (x))

int main(void)
{
	printf("%d\n", SQ_BAD(1 + 2));
	printf("%d\n", SQ(1 + 2));
	printf("%d\n", 100 / SQ_BAD(5));
	printf("%d\n", 100 / SQ(5));
	return 0;
}
```

<!-- out -->

```
5
9
100
4
```

**السطر الأول: `1 + 2 * 1 + 2`.** الاستبدال نصّيّ، فدخلت الأولوية على النتيجة.

**والسطر الثالث أخبث:** `100 / 5 * 5` — والقسمة والضرب متساويان في الأولوية،
فيُحسَبان من اليسار، فتخرج ١٠٠ بدل ٤.

**والقاعدة قاعدتان معاً:**

```c
#define SQ(x) ((x) * (x))
        ↑    ↑   ↑
        │    └───┴── قوسان حول كل وسيط
        └── وقوسان حول التعبير كلّه
```

الأولى تحمي من أولوية ما **بداخل** الوسيط، والثانية من أولوية ما **حوله**.
وإسقاط أيّهما يعطي خطأً لا يظهر إلا في استعمالٍ بعينه.

## المصيدة الثانية: الوسيط يُقيَّم مرّتين

الأقواس لا تنقذ من هذه:

```c
#include <stdio.h>

#define MAX(a, b) ((a) > (b) ? (a) : (b))

int main(void)
{
	int i = 5, j = 3;

	printf("%d\n", MAX(i++, j));
	printf("i = %d\n", i);
	return 0;
}
```

<!-- out -->

```
6
i = 7
```

**زادت `i` مرّتين، والجواب ٦ لا ٥.** لأن النصّ صار
`((i++) > (j) ? (i++) : (j))` — و`i++` مكتوبةٌ مرّتين، فتُنفَّذ مرّتين.

**والدالّة لا تفعل هذا أبداً.** الوسيط يُقيَّم مرّةً واحدة عند النداء، ثم تُنسخ
قيمته. **وهذا هو الفرق الجوهريّ بين الماكرو والدالّة**، لا الأداء.

**فالقاعدة:** ماكروٌ يذكر وسيطه أكثر من مرّةٍ **خطرٌ بالتصميم**. إمّا أن تكتبه
دالّةً، أو أن تحفظ الوسيط في متغيّرٍ داخليّ أوّلاً.

## أن تصنع نصّاً، وأن تلصق اسمين

معاملان لا يوجدان إلا هنا:

```c
#include <stdio.h>

#define STR(x)    #x
#define XSTR(x)   STR(x)
#define CAT(a, b) a##b

#define WIDTH 80

int main(void)
{
	int var1 = 7;

	printf("%s\n", STR(1 + 2));
	printf("%s\n", STR(WIDTH));
	printf("%s\n", XSTR(WIDTH));
	printf("%d\n", CAT(var, 1));
	return 0;
}
```

<!-- out -->

```
1 + 2
WIDTH
80
7
```

| | |
|---|---|
| `#x` | يحوّل الوسيط **كما كُتب** إلى نصّ |
| `a##b` | يلصق الرمزين فيصيران **اسماً واحداً** |

**والسطران الثاني والثالث هما الدرس:** `STR(WIDTH)` أعطت `"WIDTH"` لا `"80"`،
لأن `#` تمنع توسيع وسيطها. والحيلة المعروفة **طبقتان**: `XSTR` توسّع الوسيط ثم
تسلّمه إلى `STR`.

وهذه ليست طرفة — هي كيف تُطبَع قيمة ماكروٍ في رسالة خطأ أو في نصّ إصدار.

## سطرك ورقمه

الـpreprocessor يعرف أين هو، ويعطيك ذلك:

```c
#include <stdio.h>

#define LOG(fmt, ...) \
	printf("%s:%d: " fmt, __FILE__, __LINE__, __VA_ARGS__)

int main(void)
{
	int x = 42;

	printf("%s\n", __func__);
	LOG("%s = %d\n", "x", x);
	return 0;
}
```

<!-- out @impl: و`__FILE__` اسمُ الملفّ كما مرَّ على المترجم -->

```
main
main.c:11: x = 42
```

`__FILE__` و`__LINE__` يُستبدلان **في موضع الاستعمال** لا في موضع تعريف الماكرو —
ولذلك ظهر السطر ١١ لا السطر ٤. وهذا هو كل سرّ سجلّات الأخطاء في C.

**و`__func__` ليس ماكرو**، بل متغيّرٌ ساكن تضعه اللغة داخل كل دالّة (C99) — ولذلك
لا يعرفه الـpreprocessor ولا يظهر في `cc -E`.

**و`...` مع `__VA_ARGS__`** تمرّر ما بقي من الوسائط كما هي.

**ولاحظ `"%s:%d: " fmt`**: نصّان متجاوران في C **يلتحمان** في نصٍّ واحد وقت
الترجمة. وهذه ميزةٌ في اللغة لا في الماكرو، وهي التي تجعل هذه الصيغة ممكنة أصلاً.

## `assert` مبنيّةٌ من هذا كلّه

```c
#include <stdio.h>
#include <assert.h>

int main(void)
{
	int n = 3;

	printf("قبل\n");
	fflush(stdout);
	assert(n > 5);
	printf("بعد\n");
	return 0;
}
```

<!-- out @impl -->

```
قبل
Assertion failed: (n > 5), function main, file main.c, line 10.
```

**«بعد» لم تُطبَع.** و`assert` طبعت **نصّ الشرط كما كتبتَه** — هذا `#`؛
و**اسم الملفّ والسطر** — هذان `__FILE__` و`__LINE__`.

وترجم البرنامج نفسه بـ`-DNDEBUG`:

```c
//! cc: -DNDEBUG
#include <stdio.h>
#include <assert.h>

int main(void)
{
	int n = 3;

	printf("قبل\n");
	fflush(stdout);
	assert(n > 5);
	printf("بعد\n");
	return 0;
}
```

<!-- out: مع ‎-DNDEBUG -->

```
قبل
بعد
```

**اختفت `assert` تماماً**، لا مُلغاةً بل **محذوفة من النصّ**. لأن تعريفها في
`<assert.h>` مشروطٌ بـ`#ifndef NDEBUG`.

**ونتيجةٌ خطيرة تتساقط من هذا:** لا تضع في `assert` تعبيراً له **أثر**. سطرٌ مثل
`assert(next() == 0)` يعمل في التنقيح ويختفي في الإصدار — والدالّة لا تُنادى
أصلاً.

**و`assert` للمستحيل لا للمتوقّع:** الملفّ الذي لا يُفتح متوقَّع فيُفحَص ويُعالَج،
وpointer صفريّ داخل دالّتك بعد فحصك له مستحيلٌ إن لم تخطئ — فهو موضع `assert`.

## جملةٌ واحدة من عدّة جمل

```c
#define SWAP(a, b) do { int t = (a); (a) = (b); (b) = t; } while (0)
```

`do { ... } while (0)` تبدو حشواً — تدور مرّةً وتخرج. **وهي الحيلة الوحيدة** التي
تجعل عدّة جملٍ تتصرّف كجملةٍ واحدة.

```c
if (x < y)
	SWAP(x, y);
else
	puts("لا");
```

بلا `do/while`، تتوسّع الجمل الثلاث فيصير جسم `if` أوّلَها وحدها، وتلي الاثنتان
الأخريان خارج الشرط — ثم تجد `else` بلا `if` فيسقط البناء كلّه.

**والقوسان المعقوفان وحدهما لا يكفيان** — لأن الفاصلة المنقوطة بعد `SWAP(x, y)`
تصير جملةً فارغة بعد القوس، وهي أيضاً تكسر `else`.

## X-macro: تعريفٌ واحد، وثلاثة مخرجات

وهذا هو ما لا تستطيعه اللغة، ويستطيعه الاستبدال النصّيّ.

المشكلة: جدول أوامرٍ يحتاج **enum** و**array أسماء** و**array عددِ وسائط** — ثلاث
قوائم يجب أن تبقى متطابقة، ونسيان سطرٍ في إحداها خطأٌ صامت.

```c
#include <stdio.h>

#define COMMANDS       \
	X(SET,  "set",  3) \
	X(GET,  "get",  2) \
	X(LIST, "list", 1)

enum Cmd {
#define X(id, name, argc) CMD_##id,
	COMMANDS
#undef X
	CMD_COUNT
};

static const char *names[] = {
#define X(id, name, argc) name,
	COMMANDS
#undef X
};

static const int argcs[] = {
#define X(id, name, argc) argc,
	COMMANDS
#undef X
};

int main(void)
{
	for (int i = 0; i < CMD_COUNT; i++)
		printf("%d %-5s %d\n", i, names[i], argcs[i]);
	printf("العدد = %d\n", CMD_COUNT);
	return 0;
}
```

<!-- out -->

```
0 set   3
1 get   2
2 list  1
العدد = 3
```

**الفكرة كلّها في سطرين:** `COMMANDS` قائمةٌ تنادي ماكرو اسمه `X` **لم يُعرَّف
بعد**. ثم تعرّف `X` بمعنى، وتذكر `COMMANDS`، وتلغي التعريف — فتحصد شكلاً. ثم
تعرّفها بمعنىً آخر، فتحصد شكلاً آخر.

**والمكسب أن مصدر الحقيقة واحد.** إضافة أمرٍ سطرٌ واحد في `COMMANDS`، وتتحدّث
الثلاثة معاً. و`CMD_COUNT` تُحسَب وحدها لأنها آخر عنصرٍ في الـenum.

**وثمنه أن الكود الذي تقرؤه ليس الكود الذي يُترجَم.** ورسالة خطأٍ في ماكروٍ
متداخل تشير إلى سطر التوسيع لا إلى سطر الخطأ. و`cc -E` هو أوّل ما تفعله عند أي
عطبٍ فيه.

## `_Generic`: النوع يقرّر (C11)

آخر ما أضافته اللغة إلى هذا الباب — وليس ماكرو، لكنه لا يُستعمَل إلا معها:

```c
#include <stdio.h>

#define type_of(x) _Generic((x),  \
	int:     "int",               \
	long:    "long",              \
	float:   "float",             \
	double:  "double",            \
	char *:  "char *",            \
	default: "?")

int main(void)
{
	int    a = 1;
	double b = 2;
	char  *c = "x";

	printf("%s %s %s %s\n", type_of(a), type_of(b), type_of(c), type_of(1L));
	return 0;
}
```

<!-- out -->

```
int double char * long
```

**اختيارٌ بحسب نوع التعبير، ويُحسَم وقت الترجمة.** الفروع غير المختارة لا تُترجَم
أصلاً — فيجوز أن يكون فيها ما لا يصلح لغير نوعه.

وهذا ما تُبنى به `tgmath.h`: `sqrt` واحدةٌ في نظرك، وثلاث دوالٍّ في الحقيقة.

**وهو أقرب ما تملكه C إلى تعدّد الأسماء** — والبديهية الخامسة ما زالت قائمة: لا
شيء في اللغة، وكل شيء اتّفاقٌ فوق أدواتٍ بدائية.

## قبل أن تكمل

> **١.** اكتب `MIN(a, b)` صحيحاً، ثم جرّبه بـ`MIN(x++, y)` — لماذا لا يوجد حلٌّ
> بالماكرو وحده؟ وما الذي يعطيه `_Generic` هنا؟
>
> **٢.** حوّل جدول أوامر الإقليم ١٧ إلى X-macro: `COMMANDS` واحدة تولّد الـenum
> وarray الأسماء و**النماذج الأوّلية** للدوالّ. كم موضعاً كان يجب أن تحدّثه قبل،
> وكم صار؟
>
> **٣.** شغّل `cc -E` على ملفّ X-macro واقرأ ما خرج. ثم أضِف أمراً وقارن. أين
> ظهرت الأسطر الثلاثة الجديدة؟
