# C — اللغة الأولى

منهجٌ يبدأ من لا شيء وينتهي عند `shell` تكتبها بنفسك.

يفتح بفصلٍ نظريّ واحد: كيف صارت C لغة، وبديهياتها الخمس، ثم **كيف يُخزَّن كل
شيء** — bit bit. بعده تبني حلقة أوامرَ في مئةٍ وعشرين سطراً تعمل، وتقضي بقيّة
المنهج في تفكيكها: كل إقليمٍ يأخذ منها جزءاً ويسأل لماذا هكذا وأين يكسر، حتى
الإقليم الأخير حيث تصير الحلقة نفسها قادرةً على تشغيل أوامر النظام.

والسؤال الذي يتكرّر في كل إقليم: **ما الذي تعِد به المواصفة هنا، وما الذي تركته
للمترجم؟**

---

## لمن كُتب

لمن **لم يكتب سطر كودٍ قبل اليوم**.

لا يفترض المنهج عندك لغةً سابقة ولا مشروعاً ولا اصطلاحاً. ويفترض عندك شيئاً
واحداً: أن تكون مستعدّاً لأن تكتب برنامجاً يعمل قبل أن تفهم نصفه، ثم تقضي عشرين
إقليماً في فهم النصف الآخر.

**وإن كنتَ قد لمستَ لغةً عالية** — Python أو JavaScript — فأنت في الحالة الأخطر
لا الأسهل: تحمل عاداتٍ صحيحةً في لغةٍ تخفي عنك الذاكرة، وستجد هنا أن نصفها لا
معنى له. الأقاليم ٠٢–٠٦ مكتوبةٌ لتنقض ما تظنّ أنك تعرفه عن الأعداد والنصوص.

C هي مرساة هذا المستودع: كل منهج لغةٍ فيه يفترض أنك درست هذا أوّلاً.

## الأدوات المستهدفة

```
cc -std=c17 -Wall -Wextra
```

المنهج مثبَّت على **C17**، وما تغيّر في C23 مذكورٌ في موضعه. ورسائل المترجم في
اللوحات من `clang`؛ غيره يصوغها بكلماتٍ أخرى والمعنى واحد.

والأحجام في اللوحات لهدفٍ ٦٤-بت. وحيث يكون الرقم **مضموناً بالمواصفة** لا
مقيساً، يُقال ذلك صراحةً — والفرق بين الاثنين نصفُ ما يميّز من يكتب C عن غيره.

وكل مخرَجٍ في هذا المنهج مأخوذٌ من تشغيل، ويُعاد التحقّق منه مع كل تعديل:

```bash
python3 tools/verify.py          # كل الأقاليم
python3 tools/verify.py 03 04    # أقاليم بعينها
```

الأداة تترجم كل بلوكٍ وتقارن مخرَجه بلوحته، وتفشل عند أي اختلاف. واللوحة التي لا
يسبقها برنامجٌ قابل للترجمة تُعدّ **ثقباً** وتُفشِل الفحص كذلك.

## كيف تُدرَس

قاعدة واحدة، وكسرها يُبطل المنهج:

> حين يُطلب منك **توقّع** مخرَج، اكتبه قبل أن تشغّل. حرفياً، على ورقة أو في ملفّ.
> ثم شغّل.

ولا تقرأ إقليماً قبل ما قبله: كلٌّ يبدأ من بذرةٍ خلّفها الذي قبله.

ولك مَخرجٌ في كل موضع: لا قفل يمنعك من المضيّ، ولا تلميح يُدفع إليك بلا طلب.

**واكتب الكود بيدك.** النسخ يعطيك برنامجاً يعمل ولا يعطيك شيئاً غيره.

## البديهيات الخمس

كل ما سيبدو لك غريباً في C يعود إلى خمسة قرارات، ولكلٍّ منها في الفصل صفر دليلٌ
يعمل. وسأشير إليها بأرقامها عند استعمالها:

| # | البديهية | أوّل ما يتساقط منها |
|---|---|---|
| ١ | لا يبقى وقت التشغيل إلا البايتات | لا فحص حدود · لا جامع قمامة · لا سؤال عن نوع |
| ٢ | الذاكرة بايتاتٌ مسطّحة، والنوع عدسة | الـ`cast` · الـunion · الحساب على الـpointer |
| ٣ | كل تمريرٍ نسخ | الـpointer هو الطريقة الوحيدة للوصول إلى الأصل |
| ٤ | المترجم يفترض أنك لم تخطئ | السلوك غير المعرَّف رخصةُ تحسين، لا عقوبة |
| ٥ | اللغة صغيرة، والمكتبة دوالُّ عادية | لا نوع نصّ · و`printf` تستطيع كتابتها |

## أدواتك

لا يطلب منك هذا المنهج تصديق نصّ. مع كل ادّعاءٍ غير بديهيّ أمرٌ يكشفه:

| الأداة | ماذا ترى بها |
|---|---|
| `-Wall -Wextra` | ما يقبله المترجم وهو يعرف أنك تقصد غيره |
| `-fsanitize=address` | كل قراءةٍ أو كتابةٍ خارج ما تملك، بالسطر |
| `-fsanitize=undefined` | التجاوز والإزاحة الفاسدة وما لا تعد به المواصفة |
| `-pedantic` | «هل هذا C، أم لهجةُ مترجمي؟» |
| `-E` | نصّك بعد الـpreprocessor وقبل الترجمة |
| `-S` | لغة الآلة المولَّدة فعلاً |
| `nm` · `objdump` | الأسماء داخل الملفّ التنفيذيّ، ومحتواه |
| `lldb` | التنفيذ خطوةً خطوة، وقراءة الذاكرة بعنوانها |

## الطريق

فصلٌ نظريّ واحد، ثم ثمانيةٌ وعشرون إقليماً في `regions/`، في **ثماني حِزَم**:

| | | |
|---|---|---|
| `00–01` | **البداية** | برنامجٌ يعمل قبل أن تفهم نصفه، وفصلٌ نظريٌّ واحد قبله |
| `02–06` | **التمثيل** | ما الذي يجري للbits نفسها. أطول ما في المنهج عن قصد، لأن كل ما بعده يُبنى عليه |
| `07–10` | **ماذا تفعل بالقيمة** | التعبير وأثره · المسار · الدالّة · أين يُرى الاسم ومتى يموت |
| `11–17` | **العنوان** | الـpointer متغيّرٌ قيمتُه عنوان، ومنه الـarray والنصّ والـheap والـstruct |
| `18–20` | **تحت الأداة** | `cc` أربعةُ برامج، والماكرو استبدالٌ نصّيّ، و`printf` دالّةٌ كتبها إنسان |
| `21–22` | **الملفّ والفشل** | `stdout` ملفّ. وفي C لا يوجد استثناء، فالفشل قيمةٌ تُفحَص |
| `23–25` | **النظام** | `open` و`read` و`write` ليست من C. تحتاج هذه الحزمة نظاماً يتبع POSIX — macOS أو Linux |
| `26–28` | **العودة** | حساب السلوك غير المعرَّف كاملاً، ثم يُعاد بناء برنامج الإقليم ٠١ |

وتفصيلُها:

| | | |
|---|---|---|
| `00` | **الآلة والنصّ** | الفصل النظريّ الوحيد: القصّة · البديهيات · كيف يُخزَّن كل شيء |
| `01` | **حلقة الأوامر** | ١٢٠ سطراً تعمل، وفيها ثلاثة أخطاء لن تراها |
| `02` | **الـbit والبايت** | العنوان · السّت عشريّ · قراءة أي كائنٍ بايتاً بايتاً |
| `03` | **العدد الصحيح** | الـtwo’s complement · الالتفاف · المدى · `<stdint.h>` |
| `04` | **العدد العشريّ** | الحقول الثلاثة · الدقّة · متى يكذب التساوي |
| `05` | **الحرف** | ASCII · إشارة `char` · و UTF-8 بايتاتٍ لا حروفاً |
| `06` | **التحويل** | الـpromotion · الـusual arithmetic conversions · القصّ · الـ`cast` |
| `07` | **التعبير** | الأولوية · الأثر الجانبيّ · نقاط التتابع |
| `08` | **المسار** | الشرط · الحلقة · `switch` وسقوطها · `goto` ولماذا بقي |
| `09` | **الدالّة** | النسخة · الإرجاع · الـprototype · الـframe |
| `10` | **الاسم والمكان** | الـscope · العمر · `static` و`extern` |
| `11` | **الـpointer** | لماذا وُجد · `&` و`*` · الحساب عليه · `NULL` |
| `12` | **الـarray** | التحوّل · لماذا لا تُمرَّر · `sizeof` الذي يكذب |
| `13` | **النصّ** | البايت الصفريّ · الـliteral للقراءة فقط · الـoff-by-one |
| `14` | **pointer إلى pointer** | `char **` · array pointers · من يملك ماذا |
| `15` | **الـrecursion** | الـstack · شرط التوقّف · مطابقة النمط |
| `16` | **الـheap** | `malloc` · التسريب · الاستعمال بعد التحرير · الـsanitizer |
| `17` | **الـstruct** | الـoffset · الـpadding · الـalignment · الـunion · الـopaque type |
| `18` | **من النصّ إلى الملفّ التنفيذيّ** | أربع مراحل · ملفّ الـheader · الـtranslation unit · الـlinker |
| `19` | **الماكرو** | `#define` استبدالٌ نصّيّ · مصائده · ما يفتحه لك |
| `20` | **`printf`** | الوسائط المتغيّرة · قراءة الصيغة · ثم تكتبها بنفسك |
| `21` | **الملفّ** | `fopen` · ما هو `FILE` · الأنماط · `fread` و`fwrite` · `fseek` · نهاية الملفّ |
| `22` | **الفشل** | `NULL` قيمةَ خطأ · `errno` · `perror` · رمز الخروج · `assert` |
| `23` | **الـdescriptor** | الرقم تحت `FILE` · `open` و`read` و`write` · ٠ و١ و٢ · التوجيه |
| `24` | **الـbuffer** | لماذا وُجد · الأنماط الثلاثة · `fflush` · `setvbuf` |
| `25` | **الـprocess** | `fork` · `exec` · `wait` · الـpipe |
| `26` | **غير المعرَّف** | الفهرس الكامل · وكيف يستعمله المترجم ضدّك |
| `27` | **كيف تُكتب C** | الاصطلاح بأسبابه · حدود ملفّ الـheader · الاختبار |
| `28` | **`shell`** | حلقة الأوامر تعرف النظام أخيراً |

و`fork` و`exec` ليستا من اللغة، بل من النظام، والفرق يُشرح في موضعه.

## الأسئلة المعلّقة

ستمرّ عليك أسئلة أتركها بلا جواب عمداً، مثل:

> لماذا يعمل `strcmp(a, b) == 0` ولا يعمل `a == b`؟

ليست سهواً. لكل واحدٍ منها جواب في إقليمٍ لاحق أو في مشروع التخرّج. سجّلها عندك
حين تمرّ، وسترى متى تُغلق.
