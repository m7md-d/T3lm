# الإقليم ٣٢ — الثقة

> منذ الإقليم ٠٩ تثق ببصمة: `sha256:d9e853e…` تعني بايتاتٍ بعينها، لا غيرها.
> وهذا ثابت — رأيتَه يعمل عبر السلك في الإقليم ٣٠.
>
> **لكنّ البصمة لا تقول من صنع تلك البايتات، ولا ماذا بداخلها، ولا من يوافق
> عليها.** هذا الإقليم يبني الطبقة الثالثة فوق المحتوى: من يشهد، وماذا يشهد،
> وأين تنكسر الشهادة إن أُسيء استعمالها.

---

## ما تضمنه البصمة، مقروءاً لا مفترَضاً

<!-- host -->

```sh
mkdir -p .lab/trust32 && cd .lab/trust32
cat > Dockerfile <<'EOF'
FROM alpine:3.20@sha256:d9e853e87e55526f6b2917df91a2115c36dd7c696a35be12163d44e6e2a4b6bc
RUN apk add --no-cache curl
EOF
docker rm -f reg32 > /dev/null 2>&1
docker run -d --name reg32 -p 5556:5000 registry:2 > /dev/null
sleep 2
docker buildx build --sbom=true --provenance=true \
	-t localhost:5556/trusttest:v1 --push . > /dev/null 2>&1
docker buildx imagetools inspect localhost:5556/trusttest:v1 --raw \
	| python3 -c 'import json,sys
d = json.load(sys.stdin)
print("manifests in index :", len(d["manifests"]))
for m in d["manifests"]:
	kind = m.get("annotations", {}).get("vnd.docker.reference.type", "image")
	print(" -", kind, m["platform"])'
```

<!-- gate @machine -->

```
manifests in index : 2
 - image {'architecture': 'arm64', 'os': 'linux'}
 - attestation-manifest {'architecture': 'unknown', 'os': 'unknown'}
```

**تذكّر الإقليم ٠٩:** حين بنيتَ صورتك الأولى هناك رأيتَ فهرساً فيه مدخلان،
ونصحتُك أن تبنيَ بـ`--provenance=false` «لأنه ضجيج». هذا هو ذلك المدخل الثاني
بعينه — ولم يكن ضجيجاً؛ كان **موضوع هذا الإقليم**، مؤجَّلاً حتى صار عندك ما
يكفي لفتحه.

**والمدخل الأوّل وحده هو ما تحققتَ منه حتى الآن.** بصمتُه تضمن تطابق البايتات
— لا أكثر. من بناه؟ ما بداخله؟ هل يثق به أحد؟ ثلاثة أسئلةٍ لا تجيب عنها
البصمة، ويجيب عنها المدخل الثاني.

## SBOM: قائمة ما بداخل الصورة، بصيغةٍ موقَّعة لا نصّاً حرّاً

<!-- host -->

```sh
cd .lab/trust32
IDX=$(curl -s http://localhost:5556/v2/trusttest/manifests/v1 \
	-H "Accept: application/vnd.oci.image.index.v1+json")
ATT=$(echo "$IDX" | python3 -c 'import json,sys
d = json.load(sys.stdin)
print([m for m in d["manifests"] if m["platform"]["architecture"] == "unknown"][0]["digest"])')
AM=$(curl -s "http://localhost:5556/v2/trusttest/manifests/$ATT" \
	-H "Accept: application/vnd.oci.image.manifest.v1+json")
echo "$AM" | python3 -c 'import json,sys
d = json.load(sys.stdin)
print("subject digest :", d["subject"]["digest"])
for l in d["layers"]:
	print("predicate      :", l["annotations"]["in-toto.io/predicate-type"])'
```

<!-- gate -->

```
subject digest : sha256:70801072a1949486d235a271dc9445e297152102c751548296ca5913aa09db92
predicate      : https://spdx.dev/Document
predicate      : https://slsa.dev/provenance/v1
```

طبقتان في هذا «المدخل الغريب»، ولكلٍّ منهما اسمٌ ومعيار: **SPDX** لقائمة
المكوّنات (SBOM)، و**SLSA** لسجلّ البناء (المنشأ). وحقل `subject` يربطهما
**ببصمة الصورة بعينها** — لا باسمها ولا بوسمها.

<!-- host -->

```sh
cd .lab/trust32
IDX=$(curl -s http://localhost:5556/v2/trusttest/manifests/v1 \
	-H "Accept: application/vnd.oci.image.index.v1+json")
ATT=$(echo "$IDX" | python3 -c 'import json,sys
d = json.load(sys.stdin)
print([m for m in d["manifests"] if m["platform"]["architecture"] == "unknown"][0]["digest"])')
AM=$(curl -s "http://localhost:5556/v2/trusttest/manifests/$ATT" \
	-H "Accept: application/vnd.oci.image.manifest.v1+json")
SBOM=$(echo "$AM" | python3 -c 'import json,sys
d = json.load(sys.stdin)
for l in d["layers"]:
	if "spdx" in l["annotations"]["in-toto.io/predicate-type"]:
		print(l["digest"])')
curl -s "http://localhost:5556/v2/trusttest/blobs/$SBOM" | python3 -c 'import json,sys
d = json.load(sys.stdin)["predicate"]
pkgs = d["packages"]
print("packages :", len(pkgs))
curl_pkg = [p for p in pkgs if p["name"] == "curl"][0]
print("curl     :", curl_pkg["versionInfo"])'
```

<!-- gate -->

```
packages : 25
curl     : 8.14.1-r2
```

خمسةٌ وعشرون حزمة — **وفيها `curl` بعينه**، بالإصدار الذي ثبَّتَه سطرُ
`RUN` في Dockerfile. لم تسأل الصورة بنفسك، ولم تفتح الطبقات يدوياً كما فعلتَ
في الإقليم ٠٩: **الأداة التي بنت الصورة بنت أيضاً قائمة كل ما فيها**، في نفس
لحظة البناء، لا بفحصٍ لاحق قد يفوته شيء.

**والمكسب:** SBOM يجيب سؤالاً كان لا بدّ من تفكيك الصورة يدوياً للإجابة عنه —
«ما الحزم الموجودة، وبأي إصدار؟» — وهو السؤال الذي تسأله أداةٌ لفحص الثغرات
حين تقول لك «صورتك فيها إصدارٌ معطوب من `curl`».

## المنشأ: من بنى، ومن أي أساس

<!-- host -->

```sh
cd .lab/trust32
IDX=$(curl -s http://localhost:5556/v2/trusttest/manifests/v1 \
	-H "Accept: application/vnd.oci.image.index.v1+json")
ATT=$(echo "$IDX" | python3 -c 'import json,sys
d = json.load(sys.stdin)
print([m for m in d["manifests"] if m["platform"]["architecture"] == "unknown"][0]["digest"])')
AM=$(curl -s "http://localhost:5556/v2/trusttest/manifests/$ATT" \
	-H "Accept: application/vnd.oci.image.manifest.v1+json")
PROV=$(echo "$AM" | python3 -c 'import json,sys
d = json.load(sys.stdin)
for l in d["layers"]:
	if "slsa" in l["annotations"]["in-toto.io/predicate-type"]:
		print(l["digest"])')
curl -s "http://localhost:5556/v2/trusttest/blobs/$PROV" | python3 -c 'import json,sys
d = json.load(sys.stdin)["predicate"]
bd = d["buildDefinition"]
print("buildType :", bd["buildType"].split("/")[-1])
for r in bd["resolvedDependencies"]:
	if "alpine" in r["uri"]:
		print("base      :", r["uri"])'
```

<!-- gate -->

```
buildType : slsa-definitions.md
base      : pkg:docker/alpine@3.20?digest=sha256:d9e853e87e55526f6b2917df91a2115c36dd7c696a35be12163d44e6e2a4b6bc&platform=linux%2Farm64
```

اقرأ سطر `base`: **بصمة الأساس التي كتبتَها بيدك في `FROM`**، مسجَّلةً في وثيقة
منشأ مستقلّة. فمن يفحص هذه الصورة يعرف — بلا أن يملك Dockerfile أصلاً — من
أي بايتاتٍ بُنِيت، وبأيّ أداة (`buildkit`، كما رأيتَ اسمها في `docker
history` منذ الإقليم ٠٩).

**والمكسب:** SBOM يقول **ماذا** بداخل الصورة، والمنشأ يقول **كيف ومن أين**
جاءت. أحدهما جردٌ، والآخر سلسلة توريد.

## التوقيع: وما الذي يحميه بالضبط

**الاعتقاد، صريحاً:** صورةٌ موقَّعة تعني أن محتواها مأمون.

هذا خطأ من الأساس — التوقيع لا يفحص المحتوى؛ **يشهد بأن جهةً بعينها وافقت
على هذه البصمة بعينها**، لا أكثر ولا أقلّ:

<!-- host-setup -->

```sh
cd .lab/trust32
export COSIGN_PASSWORD=""
cosign generate-key-pair > /dev/null 2>&1
IMG_DIGEST=$(curl -s http://localhost:5556/v2/trusttest/manifests/v1 \
	-H "Accept: application/vnd.oci.image.index.v1+json" \
	| python3 -c 'import json,sys
d = json.load(sys.stdin)
print([m for m in d["manifests"] if m["platform"]["architecture"] != "unknown"][0]["digest"])')
echo "$IMG_DIGEST" > digest.txt
cosign sign --key cosign.key --tlog-upload=false --use-signing-config=false \
	-y "localhost:5556/trusttest@$IMG_DIGEST" > /dev/null 2>&1
```

<!-- host -->

```sh
cd .lab/trust32
D=$(cat digest.txt)
echo "--- بالمفتاح الصحيح ---"
cosign verify --key cosign.pub --insecure-ignore-tlog=true \
	"localhost:5556/trusttest@$D" 2>&1 | grep -c 'were verified'
echo "--- بمفتاحٍ آخر ---"
cosign generate-key-pair --output-key-prefix wrong > /dev/null 2>&1
cosign verify --key wrong.pub --insecure-ignore-tlog=true \
	"localhost:5556/trusttest@$D" 2>&1 | grep -c 'were verified' || true
```

<!-- gate -->

```
--- بالمفتاح الصحيح ---
1
--- بمفتاحٍ آخر ---
0
```

بالمفتاح الصحيح: تحقّقٌ ناجح. بمفتاحٍ آخر — ولو كان مفتاحاً حقيقياً صادراً
عن نفس الأداة — **فشلٌ تامّ**. لأن التوقيع لا يثبت شيئاً عن المحتوى نفسه؛
يثبت **مطابقةً رياضية** بين البصمة والمفتاح الخاصّ الذي وقَّعها. من يملك
مفتاحك يستطيع أن يوقّع أي بايتاتٍ يريدها بنفس «الصحّة».

**والمكسب:** «موقَّعة» تعني «جهةٌ أملك مفتاحها العامّ وافقت على هذه البصمة».
لا تعني خالية من الثغرات، ولا مبنيّةً بأمان، ولا حتى أن الموقِّع فحصها —
فقط أنه **اختار** أن يشهد لها.

## والتوقيع يتبع البصمة، لا الاسم

هنا تنعقد كل خيوط الإقليم: أعِد بناء الصورة **بنفس الوسم** بمحتوًى مختلف —
كما فعل أي CI حين يُعاد تشغيله على نفس الفرع:

<!-- host -->

```sh
cd .lab/trust32
echo "RUN echo unrelated-change >> /etc/motd" >> Dockerfile
docker buildx build --provenance=false -t localhost:5556/trusttest:v1 \
	--push . > /dev/null 2>&1
echo "--- تحقّقٌ بالاسم (وسمٌ متحرّك) ---"
cosign verify --key cosign.pub --insecure-ignore-tlog=true \
	localhost:5556/trusttest:v1 2>&1 | tail -1
echo "--- تحقّقٌ بالبصمة القديمة ذاتها ---"
D=$(cat digest.txt)
for i in 1 2 3 4 5; do
	R=$(cosign verify --key cosign.pub --insecure-ignore-tlog=true \
		"localhost:5556/trusttest@$D" 2>&1 | grep -c 'were verified')
	[ "$R" = "1" ] && break
	sleep 2
done
echo "$R"
```

<!-- gate -->

```
--- تحقّقٌ بالاسم (وسمٌ متحرّك) ---
error during command execution: no signatures found
--- تحقّقٌ بالبصمة القديمة ذاتها ---
1
```

الوسم `v1` يشير الآن إلى بايتاتٍ جديدة **لم تُوقَّع قطّ**، فالتحقّق بالاسم
يفشل بصدق. والبصمة القديمة — نفس البايتات التي وقَّعتَها فعلاً — **ما زالت
موقَّعةً كما كانت**، لأن التوقيع علِق ببصمتها لا باسمها.

```
"v1"  ──(كان يشير إلى)──►  70801072…  ✓ موقَّعة
      ──(صار يشير إلى)──►  ‹بصمةٌ جديدة›  ✗ بلا توقيع

البصمة 70801072… نفسها لم تتغيّر، ولن تتغيّر أبداً — والتوقيع باقٍ عليها
```

**والمكسب — خلاصة الإقليم:** الوسم مؤشِّرٌ متحرِّك (الإقليم ٠٩)، والتوقيع
شهادةٌ على نقطةٍ ثابتة. من يتحقّق بالاسم يتحقّق من **أيّاً كان الموجود الآن**
— ومن يتحقّق بالبصمة يتحقّق من **الشيء الذي وُقِّع عليه بعينه**. والفرق بين
العبارتين هو الفرق بين أمانٍ حقيقيّ ووهمٍ مريح.

<!-- host-setup -->

```sh
cd .lab/trust32
docker rm -f reg32 > /dev/null 2>&1
docker rmi -f localhost:5556/trusttest:v1 > /dev/null 2>&1
cd ../.. && rm -rf .lab/trust32
```

## التمرين — اثنان، ولا حلول

**١.** افحص وثيقة SLSA كاملةً، وابحث عن الحقل الذي يسمّي أداة SBOM نفسها
(`buildkit-syft-scanner`) بين الاعتماديّات المحلولة. **معيار القبول:** سطرٌ
يفسّر لماذا تُسجَّل أداةُ توليد الشهادة نفسها كاعتماديّةٍ في شهادةٍ أخرى —
وما الذي يمنع دورةً لا نهائية.

**٢ (الأصعب).** وقِّع صورةً بمفتاحك، ثم بدِّل حرفاً واحداً في `cosign.pub`
المحفوظ عندك (لا في السجلّ)، وأعد التحقّق. **معيار القبول:** رسالة الخطأ
حرفيّاً، وسطرٌ يقول أين تكمن نقطة الفشل الحقيقية في هذا النظام كلِّه — ليست
في الخوارزمية، بل فيما تسأله عن هذا الحرف.

## الخلاصة — أين نحن في الشجرة

| ما عرفتَه | العقدة التي يتعلّق بها |
|---|---|
| البصمة تضمن التطابق، لا الهويّة ولا الأمان | ثلاثة أسئلةٍ لا تجيب عنها وحدها |
| SBOM جردٌ حقيقيّ عند لحظة البناء | لا فحصٌ لاحق قد يفوته شيء |
| المنشأ يربط الصورة ببصمة أساسها | `FROM` مسجَّلٌ في شهادةٍ مستقلّة |
| التوقيع شهادةٌ على بصمةٍ لا على أمان | يثبت هويّة الموقِّع، لا سلامة المحتوى |
| التوقيع يعلق بالبصمة لا بالاسم | الوسم المُعاد بناؤه يفشل، والبصمة القديمة تنجح |

> **البذرة:** اكتملت السلسلة كلُّها — من نطاقٍ في C إلى بصمةٍ موقَّعة يفحصها
> `curl`. بقي إقليمٌ واحد، بلا كودٍ جاهز فيه: أن تبني شيئاً من الصفر، بمعايير
> قبولٍ لا حلول.
