# موقع «مَن يَنتظر؟» — جدول الاشتقاق

كل قرار في هذا الموقع، من البنية إلى اللون إلى المكوّن، مردود إلى شيء موجود في
ماركداون المنهج. وما لم أجد له سطراً في الجدول أدناه حذفته.

واختبار القبول: انقل هذا التصميم إلى منهج تشفير مثلاً فسيبدو غير منطقي، لأن
«محاور الإجهاد» التي تملأ البطاقة، و«البابين» في نهاية الفصل، والأحمال الأربعة
على آلة واحدة، وتقسيم الصفحة محطّات — لا معنى لها هناك.

## ١) جدول الاشتقاق

| القرار في الموقع | مصدره في المحتوى | لماذا هذا الشكل بالذات |
|---|---|---|
| **الصفحة = محطّات، لا نصٌّ متّصل** | README المنهج يعلن قالب الدرس صراحةً: نبذة → لغز → درس → تمرين → خلاصة | البنية موجودةٌ في النصّ قبل الموقع؛ عرضه كصفحةٍ واحدةٍ بطول ٣٠٠٠ كلمة يهدم قالبه |
| **محطّة «الدرس» تنقسم خطوات** | نصّ الدرس مرقّمٌ أصلاً: `### ١) …` `### ٢) …` | الترقيم قرارُ المؤلّف؛ الموقع يحترمه بدل أن يمرّره كعناوين |
| **بطاقة الإجهاد المثبّتة** | `> **محور الإجهاد:** …` + `> **السؤال:** …` في صدر كل إقليم | علامةٌ تتكرّر عشر مرّاتٍ بشكلٍ قابلٍ للتحليل ⇒ مكوّن لا تنسيق |
| **صندوق 🧨 بزرّ «أين انحرف المنطق؟»** | ٢٨ اقتباساً تبدأ بـ`> 🧨`، والمنهج يقول إنه يشرح **جذر الخطأ** لا الخطأ | الادّعاء ظاهرٌ دائماً؛ الانحراف خلف الزرّ — والزرّ يسأل السؤال نفسه بنصّه |
| **البابان في نهاية كل إقليم** | كل خلاصةٍ تنتهي بـ«**الباب الذي فتحتَه:**» + «**والباب المغلق/الجدار/السؤال:**» | الباب المغلق **هو** رابط الإقليم التالي: بنية النصّ صارت ملاحة |
| **بوّابة اللغز تقفل الدرس** | «لا تكمل قبل أن تكتب الجواب. ما ستقرأه يكون بلا قيمةٍ إن لم يكن عندك جوابٌ يُكسر» (٠٠) | تنفيذٌ حرفيٌّ لتعليمة المنهج لقارئه — أقوى أنواع الاشتقاق. والمخرج موجودٌ بتسميةٍ صادقة |
| **لا زرّ «اكشف الحلّ» في الموقع كلّه** | «لا توجد حلولٌ في هذا المنهج. لا في آخر الفصل ولا في ملحقٍ مخفيّ» | قيدٌ سالب: أي reveal كان سيكذب على القارئ |
| **حجب «شجرة المهارات»** | «⚠️ لا تفتح هذا قبل الإقليم ٠٩ — فيه حرقٌ متعمَّد» | يُفتح تلقائياً عند بلوغ ٠٩، أو بإذنٍ صريحٍ من القارئ |
| **الصفحة الأولى = مخطّط آلة** | مخطّط الإقليم ٠٩ («أربعة أحمالٍ على آلةٍ واحدة») ومخطّط README | الخريطة ليست قائمة فصول؛ المحتوى نفسه يقول إنه **آلة** |
| **الأحمال الأربعة كمحورٍ ثانٍ للملاحة** | الجدول الجامع (٠٩) أعمدته أربعة مشاريع تعبر كل الأقاليم | المحتوى شبكةٌ ذات محورين (إقليم × مشروع)، لا سلسلة |
| **صفحة «الأنماط الثمانية»** | قسم «الأنماط التي تكرّرت» في ٠٩، وكلٌّ منها يذكر أقاليمه بالأرقام | الروابط المتقاطعة كثيفة ⇒ ترسم الشبكة بدل أن تُترك ضمنيّة. **تُستخرَج من الماركداون لا تُكتب في الكود** |
| **صفحة «الجدول الجامع» تُقرأ عمودياً** | «اقرأ الصفّ الخامس عمودياً: سؤالٌ واحد وأربع إجاباتٍ صحيحة» (٠٩) | العمود صار وحدة الاختيار لأن النصّ يطلب ذلك صراحةً |
| **عائلات اللون** | README: «٠٠–٠٣ الجذع … ٠٤–٠٨ فروع … ٠٦ التحام» + أعمدة الجدول الجامع | فولاذيٌّ بارد للآلة، ولونٌ لكل حِمل. و**٠٦ مزيجٌ حرفيٌّ من لوني ٠٤ و٠٥** لأنه حاصل ضربهما |
| **لا دوّارة (spinner) في الموقع إطلاقاً** | الإقليم ٠٢: الاستقصاء النشط يحرق نواةً بلا تقدّم | الدوّارة انتظارٌ نشط. كل مؤشّرٍ هنا **شريط ميزانيّة** أفقيّ بدلها |
| **الانتقال «مسحٌ» لا تلاشٍ** | الرسم التفاضلي (٠٣): «لا ترسم ما لم يتغيّر» | الهيكل يبقى، وما تغيّر وحده يُمسَح إلى الظهور |
| **أحاديّ المسافة مسيطرٌ على الأرقام والمخطّطات** | المحتوى مليءٌ بمخطّطات ASCII وجداول أرقامٍ وحقول بايت | الأرقام جدوليّة (`tabular-nums`) لأن المنهج **يقيس** ولا يصف |
| **الملحقات تُقسَّم أجزاءً** (٧ · ٢٠ · ١٠ · ٤) | نفس السطر: «تُفتح أثناء العمل، لا تُقرأ مرّةً واحدة» | الورقة المرجعيّة عشرة أقسامٍ مستقلّة، والنماذج الذهنيّة عشرون نموذجاً مرقّماً — كلٌّ يُفتَح وحده |
| **لوحة أوامر (⌘K)** | ملحق «الورقة المرجعيّة» يقول: «تُفتح أثناء العمل، لا تُقرأ مرّة» | من يعمل يطارد مصطلحاً؛ الفهرس يشمل المحطّات والخطوات وصناديق 🧨 |
| **التقدّم محليٌّ بلا تلعيب** | `curriculum-architect`: «لا تلعيب — يحوّل الرحلة لسباق إنهاء» | يُحفَظ ثلاثة أشياء فقط: حاولتَ اللغز، وأين وصلت، وإذن الحرق. لا نقاط ولا شارات |

**ما حُذف لأنه بلا سطر:** شريطٌ جانبيٌّ دائم (المحطّات تغني عنه)، فهرس محتوياتٍ
لكل صفحة (المحطّة أقصر من أن تحتاجه)، وضعٌ فاتح، أي مكتبة رسومٍ أو حركة.

## ٢) المختبرات: من ادّعاءٍ إلى شيءٍ يُقلَب

سبعة، كلٌّ محقونٌ **بعد الخطوة التي يستحقّها** داخل إقليمه لا في صفحةٍ منفصلة.
`verify.mjs` يفرض أن يطابق كلٌّ منها خطوةً واحدةً بالضبط.

| المختبر | الادّعاء في النصّ | المُدخَل الذي تملكه | الحالة المفاجئة |
|---|---|---|---|
| **الحدود** (٠١) | «لا يمكن أن يظهر المحدِّد داخل البيانات» + المحلّل التزايدي | الاستراتيجية · حمولةٌ ثنائيّة · شكل وصول البايتات · نوع المحلّل | محلّلٌ ساذج ينجح تماماً مع «دفعةٍ لكل رسالة» ثم ينهار بمجرّد تقطيع البايتات |
| **الضغط العكسي** (٠٢) | «كل مخزنٍ غير محدودٍ قنبلة ذاكرة» + احجز/أسقِط/اقطع | معدّل الإنتاج والاستهلاك · السقف · السياسة | ما دام الاستهلاك يلحق، لا يظهر شيء — وهذا بالضبط ما يخدع في التطوير |
| **ميزانية الرسم** (٠٣) | «~٣٩ب/خليّة ⇒ ٧٥ك/إطار» و«الرسم التفاضلي ×١٠٠٠» | الأبعاد · عمق اللون · التفاضلي · نسبة التغيّر · الدمج · fps | ٨٠×٢٤ تمرّ بسهولة، و٢٠٠×٦٠ تكسر القناة عند نفس الإعدادات |
| **الحلقة** (٠٤) | خمس محاولاتٍ تنهار، والخطوة الثابتة تشتري أربعة أشياء معاً | شكل الحلقة · سرعة الجهاز · تجميد · سماكة الجدار | `dt` المتغيّر يبدو سليماً حتى تُدخِل تجميداً — عندها يقفز اللاعب **فوق وجود** الجدار |
| **إخفاء التأخير** (٠٦) | «كلٌّ يصلح شيئاً ويكلّف شيئاً، ولا واحدة تُلغي الفجوة» | RTT · ارتعاش · فقد · مخزن الاستيفاء · تنبّؤ · مصالحة | إصلاح الارتجاف يزيد ما تراه من الماضي — ومن هناك تولد شكوى «أصبتُه وما مات» |
| **السيّد** (٠٧) | «الصوت سيّد الوقت» وبلّورتان تنحرفان حتماً | انحراف الكاميرا والمايك (ppm) · السيّد · المدّة | ±٥٠ ppm «تافهة» تصير ثلث ثانيةٍ بعد ساعة إن كان السيّد ساعة النظام |
| **الوصفة الذرّيّة** (٠٨) | «`write` الناجحة ليست حفظاً» و«نسيان `fsync` المجلّد يُبطلها» | الخطوات الأربع (تشغيل/إطفاء) · نقطة انقطاع الطاقة | ثلاث خطواتٍ من أربع تنتج «قد يعود الاسم القديم» — الخطوة المنسيّة هي المهمّة |

## ٣) الفخاخ التقنية المعالَجة

- **مراسي GitHub:** `slugify` من محرّك المهارة كما هو — `\p{M}` تبقى (التنوين
  في «فعلاً» يغيّر المرساة)، وكل مسافةٍ تصير شرطةً **على حدة**.
- **HashRouter والمراسي:** كل `#anchor` يُبنى مساراً كاملاً؛ لا `<a href="#x">` خام.
- **ترتيب الـpager في RTL:** «السابق» أوّلاً في الـDOM ⇒ يُرسم يميناً، و
  `text-align: start/end` لا `right/left`.
- **عزل الاتجاه:** كل كودٍ ومخرَجٍ وحقلِ بايتٍ داخل `direction: ltr; unicode-bidi: isolate`.
- **نصّ SVG العربي:** `unicode-bidi` لا يعمل داخل `<svg>` ⇒ **كل `<text>` عربيٍّ
  له `textAnchor` صريح** (فحصٌ آليٌّ بـgrep).
- **الهوكس قبل الـreturn المبكر:** كل `useMemo`/`useEffect` قبل أي `Navigate`.
- **ملكيّة المحتوى:** الماركداون في `../regions` و`../appendix` هو المصدر الوحيد؛
  `src/content/md/` **مولَّدٌ عند كل بناء — لا تحرّره**.

## ٤) التشغيل والأرقام

```bash
npm install
npm run verify   # المحتوى: محطّات، خطوات، صناديق 🧨، أبواب، مطابقة المختبرات، الروابط
npm run smoke    # التصيير: كل مسار وكل مختبر بلا متصفح
npm run build    # الإنتاج
npm run dev      # التطوير
```

نتائج آخر تشغيل:

| الفحص | النتيجة |
|---|---|
| `verify` | ١٠ أقاليم · ٧٨ خطوة · ٢٨ صندوق 🧨 (مطابقة ١:١ للمصدر) · ٩ أبواب · ٧/٧ مختبرات بمطابقةٍ واحدة · ١٣ رابطاً داخلياً بلا كسر ✅ |
| `smoke` | ٢٢ مساراً + ٧ مختبراتٍ منفردة تُصيَّر بلا خطأ ✅ |
| `build` | `dist/` ≈ ٩٠٠ كيلوبايت · JS ٧٤٣ك (٢٨٢ك مضغوطاً) · CSS ٢٠٫٦ك · بلا أي أصلٍ خارجي ✅ |

**ما لم يُتحقَّق منه:** المظهر البصري الفعلي في متصفّح، والتفاعلات المدفوعة
بالنقر (البوّابة، حجب شجرة المهارات، لوحة `⌘K`، انتقال المحطّات، مزالج
المختبرات) — لا يغطّيها `verify` ولا `smoke`. شغّل `npm run dev` وافحصها بعينك.

### الرفع — من `dist/` إلى Cloudflare Pages

الأمر كاملاً، من الفحص إلى المضغوط:

```bash
node tools/release.mjs curricula/systems/who-waits/site   # من جذر المستودع
```

**الضغط من داخل `dist/`، لا من فوقه.** Cloudflare Pages يجعل جذر المضغوط جذر
الموقع؛ فإن حوى مجلّداً واحداً سكن الموقع تحت `/dist/` وأعطى الجذر ٤٠٤.

يُرفَع `who-waits.zip` في مشروع **`t3lm-who-waits`**:
Workers & Pages ← المشروع ← *Create deployment* ← *Upload assets*.
والعنوان `who-waits.nodeksa.com`.
