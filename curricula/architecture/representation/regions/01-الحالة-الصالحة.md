# الإقليم ٠١ — الحالة الصالحة

البديهية الثانية قالت إن الشكل يقبل `(n+1)²` والمعنى `n²`، وإن الفجوة تتّسع. وأوّل
ما يخطر: **افحص أكثر**. وهذا هو الطريق الذي ينتهي بنصف الكود تحقّقاً متناثراً،
وكلُّ دالّةٍ تعيد فحص ما فحصته سابقتُها.

الطريق الآخر أن تُغلَق الفجوة **من جهة البنية**: أن تكون الحالة الفاسدة غير
قابلةٍ للتمثيل أصلاً، فلا يبقى ما يُفحَص.

## اللغز

نفسُ التسعة مستنداتٍ من الإقليم `00` — صندوقان `a` و`b`، ووصلةٌ طرفاها من
`{a, b, c}` — وثلاثُ نسخٍ من الأداة تقرؤها:

<!-- part: 01-levels -->

```python
def draw(model):
    """المصبّ: يفترض الصحّة. وكلُّ ما يصله فاسداً ينفجر هنا."""
    return [(model["places"][s], model["places"][d]) for s, d in model["edges"]]
```

النسخة الأولى بلا تحقّق، والثانية تفحص عند القراءة، والثالثة تجعل الوصلة تحمل
**صندوقين لا اسمين**. كم يُرفَض في كلٍّ، وكم يبلغ `draw` فاسداً؟

المخرَج:

<!-- out -->

```
المستوى        رُفض عند القراءة   بلغ الرسمَ فاسداً
بلا تحقّق             0                5
عند الحدّ             5                0
في النوع              5                0

وتجاوزُ الحدّ باستدعاءٍ مباشر:
  المستوى ٢: KeyError 'c'
  المستوى ٣: TypeError طرفُ الوصلة 'c' ليس صندوقاً
```

## الفرق بين الثاني والثالث ليس في العدد

الصفّان متطابقان: خمسةٌ تُرفَض وصفرٌ يبلغ الرسم. **والفرق في السطرين الأخيرين.**

المستوى الثاني يفحص ثم يمرّر **قواميس**. وأيُّ سطرٍ في برنامجك يستطيع أن يبني
قاموساً جديداً لم يمرّ بالحدّ — فيصل إلى `draw` بلا مانع، وينفجر هناك بـ`KeyError`
لا يقول شيئاً عن ملفٍّ ولا عن وصلة. **الضمانة وعدٌ يُنقَض بسطر.**

والمستوى الثالث يمرّر `Link` يحمل `Box`. وبناءُ وصلةٍ إلى اسمٍ لا صندوقَ له
**ليس شيئاً يُكتَب**: ليس هناك ما تضعه في `src` إلا صندوقاً. والخطأ إن وقع وقع
عند البناء، بنوعِ الشيء الذي حاولتَ وضعه.

<!-- part: 01-levels -->

```python
@dataclass(frozen=True)
class Link:
    src: Box
    dst: Box
```

**والمقياس ليس «كم فحصاً كتبتَ» بل «كم دالّةً بعد الحدّ تحتاج أن تفحص».** في
الثاني: كلُّها، لأن أيّ قاموسٍ قد يصلها. وفي الثالث: ولا واحدة.

## ومن يفحص؟

«غير قابل للتمثيل» ليست صفةً مطلقة — هي إجابةٌ عن سؤال: **من يفحص، ومتى؟**
وفي Python الجواب ليس ما تظنّه من قراءة الكود.

<!-- part: 01-enum -->

```python
box = Box("a", align="sideways")
print("والصندوق:  ", box)
print("ونوعُ حقله: ", type(box.align).__name__)
```

<!-- out -->

```
الوسم يقبل: <Align.BOTTOM: 'bottom'>
ويرفض:     'sideways' is not a valid Align
والصندوق:   Box(name='a', align='sideways')
ونوعُ حقله:  str
```

`Align` نوعٌ **يفحص عند البناء** فيرفض. والحقل `align: Align` في الـ`dataclass`
**تعليقٌ توضيحيّ لا أكثر**: لا يُستشار وقت التشغيل، فالصندوق قَبِل سلسلةً وحملها.
وقارئُ الكود يرى نوعاً حيث لا نوع.

**والقاعدة:** ما يفحص هو **المُنشئ**، لا التعليق. فإمّا نوعٌ يرفض عند بنائه
(`Enum`، أو `__post_init__`)، وإمّا فاحصُ أنواعٍ ساكن يُشغَّل في خطّ عملك —
وثالثُهما العُرف، وهو `@convention` ودَينٌ يُسجَّل.

## والمرساة تقول الشيء نفسه

في C، الوصلة تحمل `Box *` لا سلسلة. فماذا يفعل المترجم بسلسلةٍ في موضع الصندوق؟

<!-- head: programs/01-anchor.c -->

```c
typedef struct { Box *src; Box *dst; } Link;

Link dangling(void) {
  Box a = {"a"};
  return (Link){.src = &a, .dst = "c"};   /* ← سلسلةٌ مكان الصندوق */
}
```

<!-- out -->

```
الافتراضيّ   خروج=0  7:35: warning: incompatible pointer types initializing 'Box *' with an expression of type 'char[2]' [-Wincompatible-pointer-types]
بالعلَم      خروج=1  7:35: error: incompatible pointer types initializing 'Box *' with an expression of type 'char[2]' [-Werror,-Wincompatible-pointer-types]
```

**حتى في اللغة المترجَمة، الرفضُ علَمٌ أشعلتَه.** بالافتراضيّ خرج بصفر، والملفّ
الكائنيّ يُبنى، والبرنامج يعمل حتى يقرأ `dst->name` من سلسلة. وبـ`-Werror` صار
الشيءُ نفسُه رفضاً.

فالسلطة ليست خاصّيةً في اللغة، **هي إعدادٌ في خطّ عملك**. وما لم تُشعله أنت فهو
`@convention` مهما بدا نوعاً.

## التمرين

خذ الـepitome، واجعل `width` غير قابلٍ لأن يكون سالباً أو صفراً — **بثلاث طرق**:
فحصاً في `layout`، وفحصاً عند القراءة، ونوعاً يرفض عند بنائه.

ثم لكلّ طريقةٍ أجب بسطرٍ واحد: **كم موضعاً في البرنامج ما زال يستطيع أن يُنتج
عرضاً سالباً؟** والعدد وحده هو الجواب، لا الوصف.

## الخلاصة

- الفجوة تُغلَق **من جهة البنية** لا بمزيد من الفحص: ما لا يُمثَّل لا يُفحَص.
- الفحصُ عند الحدّ يضمن **ما مرّ بالحدّ وحده**؛ والنوعُ يضمن كلَّ ما بعده.
- والمقياس: **كم دالّةً بعد الحدّ تحتاج أن تفحص**.
- و«النوع» في Python تعليقٌ حتى يفحصه مُنشئ أو فاحصٌ ساكن — وإلا فهو `@convention`.

**البابُ الذي فتحتَه:** تعرف أن الوصلة يجب أن تحمل الصندوق لا اسمَه.

**البابُ المغلق:** وحين تُحفَظ إلى ملفّ، لا يُحفَظ الصندوق مرّتين — يُحفَظ اسمُه.
**فمتى يكون الشيء في موضعين شيئاً واحداً؟** الإقليم `02`.
