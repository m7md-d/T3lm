# الفصل ٢٣ — النصّيّ والثنائيّ

سؤالان يُخلَط بينهما: بأيّ ترميزٍ تُكتَب البايتات، و**هل لكلّ بنيةٍ شكلٌ
واحد**. والثاني هو الذي يقرّر التسلسل، ويُنسى.

## الشكل القانونيّ

مستندان يعنيان الشيء نفسه، ويختلفان في ترتيب السطرين والمسافات:

<!-- part: 23-canonical -->

**مثال**

```python
A = 'box a "المصدر" { type: source }\nbox b "المصبّ" { type: sink }\n'
B = 'box b "المصبّ"  { type: sink }\nbox a "المصدر" { type: source }\n'
```

المستندان يعنيان الشيء نفسه. كم تجزيئةً مختلفة يعطيان قبل التقنين وبعده؟

المخرَج:

<!-- out -->

```
بايتاتٌ كما كُتبت: 563b4fd9242ac4d4 f2169b2e78263a99 · متساويان: False
وبعد التقنين:     563b4fd9242ac4d4 563b4fd9242ac4d4 · متساويان: True

وفرقُ النسخ على النصّ:
   -box b "المصبّ" { type: sink }
   +box b "المصرف" { type: sink }

نصّاً:   8101 بايت
ثنائياً: 3339 بايت · 0.41 من النصّ
وفرقُ النسخ على الثنائيّ: بايتاتٌ لا أسطر
```

بلا شكلٍ قانونيّ لا معنى لتساوي مستندين. وثلاثةٌ تتوقّف عليه كلُّها:

- **التجزئة** — تخزينٌ بمفتاح المحتوى، أو ذاكرةٌ مؤقّتة، أو توقيع.
- **المقارنة** — «هل تغيّر شيء؟» يصير سؤالاً عن بايتات.
- **فرقُ النسخ المفهوم** — وإلا ظهر إعادةُ ترتيبٍ تغييراً في كلّ سطر.

والتقنين يُبنى مع `dump` لا بعده: ترتيبٌ مثبَّت للعناصر والحقول، وتنسيقٌ واحد،
وتمثيلٌ واحد لكلّ قيمة. وأشهرُ ما يُنسى منها **الأرقام**: `2` و`2.0` و`2e0` بايتاتٌ
مختلفة لقيمةٍ واحدة، فيُختار شكلٌ ويُلتزَم.

## النصّ والثنائيّ — بأيّ رقم

| | نصّ | ثنائيّ |
|---|---|---|
| الحجم | المرجع | `0.41` منه في القياس أعلاه |
| القراءة بالعين | تُفتَح في أيّ محرّر | أداةٌ خاصّة أو لا شيء |
| فرقُ النسخ | أسطرٌ يقرؤها الإنسان | بايتاتٌ لا تُراجَع |
| الترميز الخاطئ | يظهر حرفاً مشوّهاً | يظهر بنيةً فاسدة أو لا يظهر |
| التوسّع | حقلٌ جديد يُقرأ بالعين | يحتاج مخطَّطاً وإصداراً |

والنسبة أقلُّ ممّا يُظنّ — أقلُّ من النصف هنا، وأقلُّ فرقاً بعد الضغط.
والحجمُ وحده لا يشتري ثنائياً في ملفّاتٍ يكتبها الإنسان.

**والثنائيّ يستحقّ ثمنه** حين يكون الملفّ مقروءاً بمقدارٍ يفوق تحريره بكثير،
أو حين تكون البنيةُ متجانسةً وضخمة — مصفوفةُ مليون عنصرٍ لا تُكتَب نصّاً. وذلك
موضوعٌ آخر: هذا المنهج عن **بنيةٍ يكتبها إنسان**.

## فرق النسخ يقيس الشكل القانونيّ

انظر الأسطر الوسطى: تغييرُ وسمٍ واحد ظهر سطرين. وهذا يعني أنّ مراجعةَ تغييرٍ في
مخطّطٍ فيه ألفُ صندوق **ممكنةٌ**، وأنّ الدمج بين فرعين يعمل، وأنّ سجلَّ المشروع
يقول من غيّر ماذا.

وهذا وحده يكفي لترجيح النصّ في كلّ ما يسكن مستودعاً — حتى لو كان يُكتَب
بأداة.

## التمرين

أضف إلى `dump` تقنينَ الأرقام: شكلٌ واحد لكلّ قيمةٍ عددية.

ثم اكتب اختباراً: لكلّ ملفٍّ في `examples/valid/`، اقرأه واكتبه، وقارن
`sha256` للناتج مع نفسه بعد إعادة ترتيب أسطر الأصل يدوياً.

وأجب بسطر: ما الحقل الذي كسر التقنين أوّلاً؟
