# الإقليم ٠٧ — التحليل النازل

القواعد أعطتك أسماء القواعد، والمقطِّع أعطاك مجرى رموز. **والنزول العوديّ
(`recursive descent`) هو أن تكتب لكلّ قاعدةٍ دالّةً باسمها، فتصير بنيةُ الكود
هي بنية القواعد.**

ولا مولِّد هنا. مولِّدُ المحلّلات يوفّر الوقت لمن يعرف ما يولّده، ويخفي الموضوع
كلَّه عن غيره. ويُقاس ما يوفّره في الإقليم `10`، بعد أن تكون قد كتبتَ ما يولّده.

## القاعدة دالّة

<!-- head: programs/dsl.py -->

```python
    def link(self):
        at = self.eat("LINK")
        src = self.port()
        self.eat("ARROW", "«->»")
        return Link(src, self.port(), at)

    def port(self):
        name = self.eat("IDENT", "اسمَ صندوق")
        self.eat("DOT", "«.»")
        return Port(name.text, self.eat("IDENT", "اسمَ منفذ").text, name)
```

قارنها بالقاعدتين في `grammar.ebnf`:

<!-- math -->

```
link = "link" , port , "->" , port ;
port = IDENT , "." , IDENT ;
```

**سطرٌ بسطر.** الحرفيّة تصير `eat`، وغيرُ الطرفيّ يصير نداءً، والتتابعُ يصير
تتابعاً. ولهذا لم يكن في المحلّل قرارُ بنيةٍ واحد: القرارات كلُّها اتُّخذت في
اثني عشر سطرَ قواعد.

## والنظرةُ الواحدة تكفي

كيف تعرف الدالّةُ `statement` أيَّ قاعدةٍ تنادي؟ **بالرمز الحاليّ وحده، بلا تراجع
وبلا تخمين:**

<!-- part: 07-parse -->

```python
parser = Parser(SRC)
while parser.peek.kind != "EOF":
    decide = parser.peek
    node = parser.statement()
    print(f"{decide.kind:<5} (سطر {decide.line}) ⇒ {type(node).__name__}")
```

<!-- out -->

```
BOX   (سطر 1) ⇒ Box
BOX   (سطر 2) ⇒ Box
LINK  (سطر 3) ⇒ Link

وثمنُ حجز الكلمة — `link` لا يصلح اسمَ خاصّية:
سطر 1، عمود 13: توقّعتُ «}» ووجدتُ «link»
    box a "x" { link: 3 }
                ^
```

اللغةُ التي يقرّر أوّلُ رمزٍ فيها أيَّ قاعدةٍ ننادي تُحلَّل بنظرةٍ واحدة —
وأكثرُ اللغات المصمَّمة تكون كذلك، **لأن مصمّمها أرادها كذلك**. والحاجة إلى
نظرتين علامةُ قاعدتين تبدآن بنفس الشيء، وهي دعوةٌ لإعادة كتابتهما لا لتوسيع
النظرة.

## وثمنُ الكلمة المحجوزة

`box` و`link` كلمتان محجوزتان: يعطيهما المقطِّع صنفاً خاصّاً. **والثمن** أنّهما
لا تصلحان اسمَ خاصّيةٍ ولا اسمَ صندوق — كما في السطور الأخيرة أعلاه.

وأمامك ثلاثة طرق، ولكلٍّ ثمنه:

| القرار | الثمن |
|---|---|
| كلماتٌ محجوزة | أسماءٌ ممنوعة على المستخدم، والقائمة تطول مع اللغة |
| كلماتٌ سياقية — `box` معرّفٌ عاديّ يُميَّز بموضعه | لا نظرةَ واحدة تكفي دائماً، والقواعد تعقّد |
| بادئةٌ صريحة — `@box` | لا حجز ولا التباس، وسطحٌ أثقل على العين |

**ولا واحد منها صحيح.** الصحيح أن يكون مكتوباً في القواعد فيراه من يقرأ لغتك،
بدل أن يكتشفه في رسالة خطأ.

## التمرين

أضف إلى اللغة صندوقاً يحوي صناديق:

<!-- math -->

```
box = "box" , IDENT , STRING , [ "{" , properties , "}" ] , [ "[" , { box } , "]" ] ;
```

اكتب القاعدة في `grammar.ebnf` أوّلاً، ثم الدالّة. ثم شغّلها على مستندٍ عمقُه
ثلاثةُ مستويات.

وأجب بسطرٍ واحد: **هل احتجتَ أكثر من نظرةٍ واحدة؟ ولماذا؟**

## الخلاصة

- **النزول العوديّ: لكلّ قاعدةٍ دالّةٌ باسمها**، فبنية الكود هي بنية القواعد.
- والحرفيّة `eat`، وغيرُ الطرفيّ نداء، والاختياريّ `if` على الرمز الحاليّ.
- **ونظرةٌ واحدة تكفي** حين لا تبدأ قاعدتان بنفس الشيء — وذلك قرارُ تصميم، لا حظّ.
- والكلمة المحجوزة قرارٌ له ثمنٌ يدفعه المستخدم، فيُكتَب في القواعد.

**البابُ الذي فتحتَه:** تستطيع أن تحوّل أيّ قواعدَ تكتبها إلى محلّلٍ بيدك.

**البابُ المغلق:** قلنا «ما لم تبدأ قاعدتان بنفس الشيء». **وإن بدأتا؟** الإقليم
`08` يُري ما يحدث حين تقبل قاعدتان النصَّ نفسه وتختلفان في معناه.
