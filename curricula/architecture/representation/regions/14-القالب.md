# الفصل ١٤ — القالب والنسخة

عشرون مرشّحاً متسلسلاً: تسعةٌ وثلاثون سطراً تكتبها بيدك، وكلُّها متطابقةٌ إلا
الرقم. والقالب أن تُعرَّف مرّةً وتُستعمَل مراراً.

وهو يوفّر أكثر ما توفّره هذه الحزمة، ويبدأ بمَعلمةٍ واحدة وينتهي بلغةٍ ثانية
لم تصمّمها.

## ما يوفّره

<!-- part: 14-template -->

**مثال**

```python
def expand(count):
    """قالبٌ بلا شرط: n مرشّحاتٍ متسلسلة."""
    out = [f'box f{i} "مرشّح {i}" {{ type: filter }}' for i in range(count)]
    out += [f"link f{i}.out -> f{i + 1}.in" for i in range(count - 1)]
    return out
```

**المخرَج**

```
n=2   أسطرٌ مولَّدة=3    أسطرٌ كتبتَها=1
n=5   أسطرٌ مولَّدة=9    أسطرٌ كتبتَها=1
n=20  أسطرٌ مولَّدة=39   أسطرٌ كتبتَها=1

والمثال الأخير، أوّلُ ثلاثة أسطرٍ منه:
  box f0 "مرشّح 0" { type: filter }
  box f1 "مرشّح 1" { type: filter }
  box f2 "مرشّح 2" { type: filter }

وبمَعلمةٍ شرطية واحدة:
  box f2 "عنصر 2" { type: sink }
  box f2 "عنصر 2" { type: filter }

والقالبُ الآن يحمل: تكراراً، وشرطاً، ومَعلمةً، وتوليدَ أسماء.
```

سطرٌ واحد مقابل تسعةٍ وثلاثين، والنسبةُ تكبر بلا حدّ. وهذا مكسبٌ حقيقيّ لا
يُنكَر.

## متى ينقلب القالب إلى لغة

انظر السطر الأخير: تكرارٌ، وشرطٌ، ومَعلمةٌ، وتوليدُ أسماء. أربعةٌ اجتمعت في
دالّةٍ من عشرة أسطر، وكلُّ واحدةٍ منها بنيةُ تحكّمٍ في لغة برمجة.

وهذا هو الانقلاب: بدأتَ بلغةٍ تصف مخطّطاً، فصار في يدك **لغةُ برمجةٍ ثانية** —
بلا قواعد مكتوبة، وبلا رسائل خطأ بمواضع، وبلا مصحِّح، وبلا أحدٍ صمّمها.

وثلاث علاماتٍ تقول إنّك عبرتَ الحدّ، وواحدةٌ تكفي:

| العلامة | ما يعنيه |
|---|---|
| **شرطٌ في القالب** | صار للقالب فروعٌ لا يراها من يقرأ الاستدعاء |
| **قالبٌ ينادي قالباً** | صار لك مكدّسُ نداءٍ بلا أثرٍ عند الخطأ |
| **تجاوزٌ فوق تجاوز** | صارت القيمة تُحسَب بترتيبٍ يجب حفظُه |

**والمخرج ليس المنع.** المخرج أن **تنتقل بوعي**: إمّا أن يُولَّد المستند بلغةٍ
حقيقيّةٍ خارج التمثيل — سكربتٌ يكتب `dsl` ويُحفَظ ناتجُه — وإمّا أن تُصمَّم لغة
القالب كما صمّمتَ لغة المخطّط، بقواعد ومواضع ورسائل.

والأوّل أرخص بكثير، ويكفي في أكثر الحالات. والفرق بينهما أنّ الأوّل يُبقي
الملفّ المولَّد هو المصدر الذي يُقرأ ويُراجَع.

## التجاوز وحدوده

القالب بلا تجاوزٍ يخدم الحالات المتطابقة وحدها. والتجاوزُ (`override`) أن تقول
«مثلَ القالب، إلا هذا الحقل».

**وطبقةٌ واحدة مفهومة**: قيمةُ الحقل من الاستدعاء إن ذُكر، وإلا فمن القالب.
والطبقة الثانية تُنتج سؤالاً بلا جوابٍ بديهيّ: قالبٌ يستدعي قالباً وكلاهما
يمرّر قيمة — أيُّهما يفوز؟

وهذه هي سلسلةُ الوراثة من الفصل `11` عائدةً بثوبٍ آخر، وحكمُها واحد: **القيمة
التي تحتاج ترتيباً محفوظاً لتُعرَف قيمةً لا يعرفها من يقرأ الملفّ.**

## التمرين

اكتب قالباً يولّد سلسلةً من `n` مرشّحاتٍ ينتهي بمصبّ، وشغّله على `n = 3` ثم
`n = 50`، ومرّر الناتج على `model.build`.

ثم أضف مَعلمةً ثانية: `metered` — إن كانت صحيحة يُوصَل مقياسٌ بكلّ مرشّح. اكتبها،
ثم عُدّ في قالبك: كم بنية تحكّمٍ فيه الآن؟

وأجب بسطرٍ واحد: أيَّ العلامات الثلاث عبرتَ؟
