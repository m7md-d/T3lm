# الإقليم ١١ — من يحرس الحدّ

> عشر هيكلاتٍ مرّت، وتسعٌ منها يحرسها سطرٌ واحد: **«المراجعة — لا شيء يمنع»**.
>
> والسؤال المؤجَّل منذ الفصل ٠٠: **أيّ حدٍّ يفرضه المترجم نفسه؟**
>
> والجواب يختلف اختلافاً حادّاً بين لغةٍ وأخرى. **وهذا يفسّر لماذا تحتاج بعض
> اللغات نصف هذه الهياكل ولا تحتاجها أخرى.**

## المبدأ الرابع، ودليله

قلنا في الفصل ٠٠: **الحدّ الذي لا يحرسه أحد ليس حدّاً**.

وهذا الفصل لا يقيس هيكلةً؛ يقيس **الحرّاس**. ولا يحتاج جهاز القياس — يحتاج أن
تكتب المخالفة وتضغط «ابنِ».

**والتجربة واحدة في اللغات كلّها:** وحدةٌ فيها `internal` مخفيّ، وملفٌّ من خارجها
يستورده مباشرةً. ثم نبني.

## Go — الحدّ اسمُ مجلّد

في Go، مجلّدٌ اسمه `internal` **لا يُستورَد إلا من داخل شجرته**. لا إعلان، ولا
إعداد، ولا أداة.

```bash
example.com/shop/internal/order   # وحدةٌ أخرى تستورده
go build ./...
```

<!-- shell -->

<!-- out: من وحدةٍ خارجية -->

```
package example.com/other
	main.go:6:2: use of internal package example.com/shop/internal/order not allowed
```

**والاسم هو القاعدة.** ما تحت `internal/` يراه إخوته وأبناؤهم، ولا يراه غيرهم.

**وهذا هو «الواجهة الواحدة» من الفصل السابق مفروضاً بالبناء** — بلا `index.ts`،
وبلا مُلزِمٍ للاستيراد، وبلا اتّفاق.

## و`import cycle not allowed`

وفي Go حارسٌ ثانٍ لا تملكه أكثر اللغات: **الدورة ممنوعة**.

```bash
go build ./...
```

<!-- shell -->

<!-- out: حزمتان تستورد كلٌّ منهما الأخرى -->

```
package example.com/cycle/a
	imports example.com/cycle/b from a.go
	imports example.com/cycle/a from b.go: import cycle not allowed
```

**وعمود «دورات» في جهاز القياس كان صفراً في كل هيكلٍ رأيتَه** — ولم أشرح لماذا
يستحقّ العدّ.

سببه أن الدورة **تُلغي الحدّ**: حزمتان تستورد كلٌّ منهما الأخرى ليستا حزمتين،
هما واحدةٌ بمجلّدين. **وفي لغةٍ تسمح بها، يقع ذلك بلا أن يلاحظه أحد.**

## Rust — الخصوصية هي الأصل

في Rust، الوحدة **خاصّةٌ حتى تُعلَن `pub`**. ولا يلزمك مجلّدٌ باسمٍ خاصّ:

```rust
mod internal;          // بلا pub — فلا يراها إلا من في هذا الملفّ
```

<!-- err: E0603 -->

```
error[E0603]: module `internal` is private
 --> src/lib.rs:4:12
  |
4 |     order::internal::secret()
  |            ^^^^^^^^  ------ function `secret` is not publicly re-exported
  |            |
  |            private module
```

**والفرق عن Go فرقُ افتراض:** في Go كل ما في الحزمة مرئيٌّ لها، والحدُّ عند المجلّد.
وفي Rust كل شيءٍ خاصٌّ حتى تفتحه، **والحدُّ عند كل سطر**.

**وفيها درجاتٌ بينهما**: `pub(crate)` مرئيٌّ في الحزمة وحدها، و`pub(super)` للأب.
فيصير الحدّ **متدرّجاً** لا مفتوحاً ولا مغلقاً.

## Java — الحدّ يُعلَن في ملفّ ويُفرَض في البناء

ومنذ ٢٠١٧ في Java ملفٌّ اسمه `module-info.java` يعلن ما تصدّره الوحدة:

```java
module com.example.shop {
    exports com.example.shop.api;      // ولا شيء غيرها
}
```

<!-- shell -->

<!-- out: وحدةٌ أخرى تستورد ما لم يُصدَّر -->

```
app/com/example/app/Main.java:3: error: package com.example.shop.internal is not visible
import com.example.shop.internal.Store;
                       ^
  (package com.example.shop.internal is declared in module com.example.shop, which does not export it)
1 error
```

**وهذا هو ملفّ الوحدة من الفصل ٠٩ بحرفه** — لكنه يُفرَض عند **التصريف** لا عند
الإقلاع.

**فالفرق بينه وبين وحدة `NestJS` ليس في الشكل؛ هو في الحارس.** ولهذا صار
`enforced: import` هنا و`runtime` هناك.

## TypeScript — لا شيء

نفس التجربة: ملفٌّ تحت `order/internal/` وملفٌّ في `api/` يستورده مباشرةً.

```bash
tsc -p .
```

<!-- shell -->

<!-- out: ولا سطر -->

```
[tsc exit 0]
```

**صفر.** لا خطأ، ولا تحذير، ولا علم يرفعه.

**و`private` في TypeScript لا تعنيك هنا:** هي داخل الصنف، لا بين الملفّات. ولا
يوجد في اللغة مفهوم «وحدةٌ لها سطحٌ عامّ» — **الملفّ هو الوحدة، وكل ما يُصدَّر منه
عامّ للجميع.**

**وهذا هو السبب البنيويّ** لأن يكون أكثر أدب المعمار الذي تقرؤه مكتوباً بهذه اللغة
وأخواتها: **الحدّ الذي لا تفرضه اللغة يجب أن يُكتب عنه.**

## Python — والاتّفاق وحده

```python
from shop.order._internal import secret   # اختراقٌ صريح للحدّ
```

<!-- shell -->

<!-- out -->

```
42
```

**يعمل.** والشرطة السفلية في `_internal` **عرفٌ** يقرؤه البشر و`linter`، ولا يمنع
شيئاً.

**و`__all__` كذلك عرف**: تحدّ ما يجلبه `import *` ولا تمنع الاستيراد المباشر.

## الجدول

| اللغة | ما يفرضه المترجم | الدورة | ما يبقى عليك |
|---|---|---|---|
| **Go** | `internal/` يمنع الاستيراد الخارجيّ | **ممنوعة** | اتّجاه الاعتماد بين حزمك |
| **Rust** | الخصوصية أصلٌ، و`pub(crate)` متدرّج | مسموحة داخل الحزمة | حدود الحزم إن قسمتَ |
| **Java** | `exports` في `module-info` | مسموحة | تفعيل الوحدات أصلاً |
| **TypeScript** | لا شيء | مسموحة | **كل شيء** — أداةٌ أو اتّفاق |
| **Python** | لا شيء | مسموحة | **كل شيء** |

**واقرأ العمود الأخير قراءةً عملية:** في Go تكتب `internal/` وتنتهي. وفي TypeScript
تكتب قاعدةً في `eslint-plugin-boundaries` أو `dependency-cruiser`، **وتضعها في
التكامل المستمرّ**، وإلا فالحدّ نصٌّ في `README`.

## وهذا يغيّر أي هيكلةٍ تحتاج

**والدرس الذي يخرج من هذا الفصل:** بعض ما تقرؤه من معمارٍ ليس حلّاً لمشكلةٍ في
التصميم — **هو تعويضٌ عن حارسٍ لا تملكه لغتك**.

| ما تكتبه | ولماذا | ومن لا يحتاجه |
|---|---|---|
| ملفّ `index` لكل مجلّد | لتصنع سطحاً عامّاً | من عنده `internal/` |
| فحصُ حدودٍ في `eslint` | لتمنع الاختراق | من يمنعه المترجم |
| ملفّ وحدةٍ يعلن الصادرات | ليُقرأ الحدّ في موضع | من يعلنه في `module-info` |

**ولا يعني هذا أن Hexagonal لا لزوم لها في Go.** الحارس يمنع **اختراق المجلّد**،
ولا يقلب **اتّجاه الاعتماد**: `internal/order` يستطيع أن يستورد `internal/postgres`
ولا يشتكي أحد.

**فالحارس يحرس ما أعلنتَه، ولا يقرّر عنك ما تُعلِن.**

## مشروعٌ يستفيد

**مكتبةٌ تُنشَر ويعتمد عليها آخرون** — بأي لغةٍ من الأولى ثلاث.

**لماذا:** السطح العامّ عقدٌ تدفع ثمن كسره في كل إصدار. وحارسٌ يفرضه عند البناء
يعني أن **تسريب نوعٍ داخليٍّ في توقيعٍ عامّ لا يقع أصلاً**.

**والرقم الذي يقرّر ليس في جدولنا:** كم من سطحك العامّ لم تقصد أن يكون عامّاً؟ وفي
لغةٍ بلا حارس، الجواب دائماً «لا أعرف».

## ومثالٌ مضادّ

**نموذجٌ أوّليّ تختبر به فكرة، عمره ثلاثة أسابيع.**

**ما ينهار:** لا شيء ينهار — **لكنك تدفع بلا مقابل**. `internal/` مجّانيّ في Go
فاكتبه؛ أمّا قواعد حدودٍ في `eslint` وملفّاتُ `index` وطبقةُ عقود، **فهي بنيةٌ
تحتيّة لمشروعٍ قد يُحذَف بعد شهر**.

**والفحص:** هل ستمرّ يدٌ ثانية على هذا الكود؟ **الحارس يحرس من النسيان ومن الغرباء.
ومن لا يوجد عنده أحدٌ منهما لا يحتاج حارساً.**

## بذرة

مرّ بك كل ما يمكن فرضه **داخل ملفٍّ تنفيذيٍّ واحد**: مجلّدٌ محميّ، وخصوصيةٌ متدرّجة،
وملفُّ صادرات، وقاعدةُ استيراد.

وبقي حارسٌ لم يُذكَر، **وهو أقساها**: أن يكون بين الوحدتين **سلك**.

فلا استيراد أصلاً، ولا ترجمةً مشتركة، ولا نوعاً يعبر. **والحدّ يصير مضموناً بالبنية
لا بالاتّفاق.**

والفصل القادم عنه — **وعن الأعمدة التي تنفجر في المقابل.**
