# مفردات الهيكلة

مرجعٌ يُفتح أثناء العمل. **وكلّه مصطلحاتٌ تسمعها في مراجعةٍ أو مقالٍ ثم لا تجد لها
تعريفاً يُفحَص.**

## الأدوار السبعة

هي مفردات جهاز القياس، والعمود الثاني في كل هيكل.

| الدور | التعريف الفاحص | إن اختلّ |
|---|---|---|
| `core` | لا يستورد `edge` ولا `io` | فليس قلباً — هو خدمة |
| `port` | **يملكه** القلب، ويحقّقه الخارج | إن ملكه الخارج فهو واجهةٌ في مكانٍ خاطئ |
| `app` | يرتّب خطواتٍ ولا يملك قاعدة | إن ملك قاعدةً فهو قلبٌ باسمٍ آخر |
| `edge` | يقود التطبيق من خارجه | `HTTP` · `CLI` · مستهلك رسائل |
| `io` | يُقاد: يحقّق عقداً أو يخاطب طرفاً | قاعدة بيانات · بريد · عميل خدمة |
| `wire` | يعرف الجميع، ولا يعرفه أحد | إن استورده منطقٌ فقد انقلب المعنى |
| `shared` | بلا اتّجاه: أدوات نصٍّ وزمن | إن حمل قاعدة عملٍ فهو قلبٌ مشترَك |

**والفحص الأقوى للقلب:** احذف مجلّد المهايئات كلّه — **هل يُترجَم القلب؟**

## القواعد الخمس

| القاعدة | نصّها | أين رأيتَها |
|---|---|---|
| `none` | لا وعد | `flat` · `slices` |
| `layer-downward` | الطبقة تعتمد على ما تحتها فقط | `layered` |
| `core-independent` | القلب والعقود لا يستوردان الخارج | `hexagonal` · `hex-lite` |
| `ring-inward` | الاعتماد يتّجه للداخل دائماً | `clean` · `ddd` |
| `feature-sealed` | الميزة لا تستورد ميزةً إلا عبر عقد | `by-feature` · `facade` · `modular` |

**و`ring-inward` هي `core-independent` مُعمَّمة** على كل الحلقات لا على القلب وحده.

## الحرّاس الثلاثة

| الحارس | متى يمسك | من يملكه |
|---|---|---|
| `import` | عند البناء، ولا ينسى | Go (`internal/`) · Rust · Java (`exports`) · أداةُ حدودٍ في غيرها |
| `runtime` | عند التركيب أو أوّل تشغيل | حاوي الحقن — `NestJS` وأخواتها |
| `review` | إن انتبه المراجع | اتّفاقٌ في `CONTRIBUTING.md` |

**والمبدأ الرابع:** الحدّ الذي لا يحرسه أحد ليس حدّاً.

## الاهتمامات الستّة

مفردات النظام في هذا المنهج، ولا تتغيّر بين هيكلةٍ وأخرى:

`http` · `ordering` · `pricing` · `customers` · `persistence` · `notification`

**والاهتمام شيءٌ يتغيّر لسببٍ واحد.** والملفّ وعاءٌ قد يحوي واحداً أو ستّة —
**والخلاف كلّه على التوزيع بينهما.**

## أنماطٌ تُذكَر ولم يُفرَد لها فصل

لأنها **تفاصيل داخل هيكلة**، لا هيكلةً بذاتها:

| النمط | موضعه |
|---|---|
| **Repository** | `port` يملكه القلب — أو `io` إن ملكه المخزن |
| **Service Layer** | `app` في الحلقات |
| **CQRS** | شريحتان لكل حالة: أمرٌ واستعلام. يظهر في `slices` |
| **Event Bus** | يحوّل حافّة استيرادٍ إلى حدث — انظر `modular-monolith` |
| **Screaming Architecture** | قرارُ تسميةٍ للمجلّد الأعلى — يُقاس بـ«حوافّ عابرة» |
| **BFF** | مهايئٌ `edge` ثانٍ لواجهةٍ بعينها |
