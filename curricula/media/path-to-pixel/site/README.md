# موقع «من المسار إلى البكسل» — جدول الاشتقاق

الموقع ليس ثيماً فوق المنهج. **كلُّ قرارٍ فيه مردودٌ إلى سطرٍ في ماركداون
المنهج أو إلى ملفٍّ من ملفّاته.** وما لا صفَّ له هنا حُذف.

**اختبار القبول:** انقل هذا التصميم إلى منهج شبكاتٍ أو منهج لغة. النتيجة
المطلوبة أن يبدو **غير منطقيّ**: صفحةٌ رماديةٌ عمداً لأن موضوعها التغطية،
وأربعةُ ألوانٍ تحمل أسماء سلطاتٍ لا وجود لها هناك، وشريطُ خلايا يقيس نصيباً من
مساحة. لا شيء من ذلك ينتقل.

## ١. جدول الاشتقاق

| القرار في الموقع | مصدره في المحتوى | لماذا هذا الشكل بالذات |
|---|---|---|
| **الصفحةُ رماديةٌ بالكامل** | البديهية الثالثة: «التنعيم تغطيةٌ لا ضبابة» | الرماديُّ **هو** الموضوع. وسلَّمُ الأسطح مأخوذٌ من سلَّم التغطية مارّاً بمنحنى `sRGB` الذي يبنيه الإقليم `21`: تغطيةٌ `0.004` ⇒ `#0d0d0d`، و`0.35` ⇒ `#a0a0a0`. فالصفحةُ عيّنةٌ ممّا تشرحه |
| **أربعُ فئاتٍ لونية، بأسماء السلطات** | الفصل صفر §الجزء الثالث: `@math` · `@rule` · `@precision` · `@colorspace` | تصنيفُ المنهج لمن يضمن الرقم صار تصنيفَ اللون. وأربعٌ هو الحدُّ الأعلى (أدلّة §٨) — وقد جاء العددُ من المحتوى لا من الحدّ |
| **اللونُ لا يظهر إلا حيث تُسمّى سلطة** | «لا يُسأل أيّهما صحيح قبل أيُّ سلطةٍ اختلفت» | رأسُ اللوحة رماديٌّ افتراضاً، ويُصبَغ حين تحمل اللوحة سطرَ `السلطة: @x`. فاللونُ معلومةٌ لا زينة |
| **العلامة: خليّةٌ وحافّةٌ ونقطة** | البديهيتان الأولى والثالثة | لا علامةَ رسميّةً لهذا الموضوع تُنتزَع. فالشكلُ بكسلٌ واحد، وحافّةٌ تقطعه، والجزءُ المغطّى مملوءٌ بقدره، ونقطةٌ في المركز عند نصف وحدة |
| **زوايا قائمةٌ تقريباً** (`--r: 3px`) | وحدةُ الموضوع خليّةٌ في شبكة | نصفُ قطرٍ كبير يناقض الشبكة التي يقوم عليها المنهج كلُّه |
| **الخطّ الأحاديّ للأرقام وحدها** | كلُّ لوحةٍ هنا جدولُ أرقام | `tabular-nums` حيث يقيس المنهج، والعربيةُ لا تدخله أبداً (يفحصه `tools/bidi.py`) |
| **الأرقامُ أسطعُ الرمادِ ولا لون لها** | «الصورة لا تُوصَف، تُقاس» | العددُ هو المحتوى في هذا المنهج، فيأخذ أعلى درجات النصّ — لا فئةً لونيةً خامسة |
| **الزمنُ أخفتُ الأرقام** (`--ink-3`) | الريدمي §أدواته: «الأرقام من جهازٍ واحد، والثابتُ هو النسبة» | أدنى الأرقام سلطةً يُعرَض أدناها سطوعاً. وهو الترميز الوحيد الذي يقول «لا تثق بهذا الرقم عندك» بلا كلمة |
| **`FAIL` بالأبيض التامّ وثقلٍ** | `10-edges` و`26-accept` يطبعان `ok`/`FAIL` | تغطيةٌ `1.0` = `#ffffff`، وهي أقصى السلَّم. تمييزٌ بالسطوع والوزن، بلا فتح فئةٍ لونية |
| **وسمُ اللوحة نصّاً** («مخرَجٌ حتميّ» · «قياسٌ ضدّ Skia» · …) | علاماتُ `tools/verify.py`: `out` · `ref` · `runs` · `err` · `shell` | **ما يفحصه الفاحص هو ما يُعرَض.** فلا يفترق ما يراه القارئ عمّا يُتحقَّق منه |
| **بلوكُ الصيغة (`math`) بلا تلوينٍ ولا وسم** | `<!-- math -->` في الماركداون | الصيغةُ ليست كوداً فلا تُلوَّن بمحلّل، وليست ادّعاءً فلا تُفحَص — فلا تُعطى وسمَ لوحة |
| **ترويسةُ البلوك تحمل مسار الملفّ** | `<!-- part: NAME -->` و`<!-- head: FILE -->` | القارئ يفتح `programs/NAME.c` عنده. والاسمُ يفرقُ بين المقتطع من برنامجٍ والمقتطع من رأسٍ مشترك |
| **البوّابةُ تقفل اللوحةَ وما بعدها** | `المخرَج:` في الماركداون، ٢٩ موضعاً | الشرحُ بعد اللوحة يقول الجواب، **والمختبرُ يعرضه بشكلٍ آخر** — فتقفلهما معاً وإلا صارت زينة |
| **لقطةٌ واحدةٌ في الصفحة** | حدُّ اللقطة في الأسلوب: ادّعاءٌ + دليلٌ + مكسب | ١١١ لقطةً، ١٣٩ مساراً. والانتقالُ بضغطةٍ في موضعٍ ثابت، ولا تقدّمَ تلقائيّ |
| **زرُّ التالي يسمّي ما بعده بثلاث كلمات** | عناوين اللقطات | خطوةٌ محدّدةٌ رخيصة المظهر، لا قفزةٌ في المجهول |
| **الملاحةُ من بنية النصّ** | كلُّ إقليمٍ يختم بـ«البابُ المغلق» يسمّي التالي | البابُ المغلق **هو** رابط الإقليم التالي، فلا `pager` عامٌّ بجانبه |
| **حِزَمُ الطريق الخمس** | جدول `README.md` §الطريق | تُقرأ من الجدول ولا تُكتَب رقماً؛ وفحصُ الدخان يقارنها بـ`regions/` ١:١ |
| **البديهيات الخمس على الواجهة** | عناوين لقطات الجزء الثاني من الفصل صفر | تُستخرَج من العناوين، فإن غُيّر عنوانٌ تغيّرت الواجهة |
| **سلّمُ التشخيص `0 → 6 → 105`** | لوحاتُ `ref` الثلاث في الفصل صفر | أقوى فكرةٍ في المنهج في ثلاثة أرقام: التطابقُ ممكن، والاختلافُ له سلطة |

## ٢. المكوّنات التفاعلية

**ثلاثةُ مختبرات، ولحظةُ تفاعلٍ واحدةٍ على الواجهة.** ولكلٍّ ادّعاءٌ من نصّ
المنهج يقلبه، ومُدخَلٌ حقيقيٌّ يغيّر النتيجة، **وحالةٌ مفاجئة**.

| المكوّن | الإقليم | الادّعاء المقلوب | الحالة المفاجئة |
|---|---|---|---|
| `EdgeStrip` (الواجهة) | — | «البكسلُ مربّعٌ يُضاء أو يُطفأ» | خليّةٌ واحدةٌ رماديةٌ دائماً بين المضاء والمطفأ، ومجموعُ الأرقام يساوي المسافة |
| `FillRuleLab` | `05` | «الشكلُ يقرّر ما بداخله» | `ring` و`ring-same` **شكلان متطابقان على الورق**، وأحدُهما يفقد ثقبَه تحت `nonzero` |
| `SamplesLab` | `08` | «عيّناتٌ أكثرُ تعني جواباً أصحّ» | شريطٌ بعُشر بكسل **غيرُ موجودٍ أصلاً** تحت `4×4`، و`0.125` تحت `16×16` — والصواب `0.100` |
| `HairlineLab` | `15` | «خطٌّ عرضُه بكسل هو صفٌّ واحدٌ أسود» | نصفُ بكسلٍ من الإزاحة يحوّل صفّاً أسودَ إلى صفَّين رماديَّين، **والحبرُ لا يتغيّر** |

**ومسارُ `FillRuleLab` هو ملفُّ الشكل نفسُه** (`shapes/*.path`) الذي يقرؤه C
ويقرؤه `tools/ref.py` — يُرسَم بـ`fill-rule` في مصيّر متصفّحك. فما تراه ليس
محاكاةً للقاعدة؛ **هو القاعدة نفسُها في مصيّرٍ ثالث**.

**وحسابُ `HairlineLab` حيٌّ ومربوطٌ بالمنهج:** التغطية تُحسَب في المتصفّح،
و`scripts/ssr-check.tsx` يقارن ناتجَها بالحالات الستّ المقيسة في لوحة
`15-hairline` ويفشل عند أي فرقٍ فوق `0.0005`. فالحسابُ في المتصفّح **ادّعاءٌ
مفحوص**، لا تنفيذٌ موازٍ يُصدَّق.

## ٣. مقابلة الأدلّة

| الرقم | ما يقرّره | الحال |
|---|---|---|
| **d = 0.86 / 0.17** | التلاعب النشط بالمخطّط مقابل مشاهدته | ⚠ **جزئيّ.** ثلاثةُ مختبرات ولحظةٌ على الواجهة — ٣ من ٢٧ إقليماً. والمواضع الثلاثة الأولى بالاستحقاق مذكورةٌ في §٥ |
| **d ≈ 0.80** | التقارب المكانيّ: تشريحُ السطر إلى سطره | ⚠ **غير مستوفًى.** التشريحُ نثرٌ بعد البلوك، ولا مراسٍ سطرية في الماركداون. يحتاج علامةً في **المصدر أوّلاً**، لا في الموقع |
| **d ≈ 0.86** | التماسك: حذفُ كلّ عنصرٍ زخرفيّ | ✔ لا حركةَ دخول، ولا رسمَ لا يعلّم، ولا لونَ بلا سلطة. والحركةُ الوحيدة انتقالُ عتامةٍ في المختبرات، وهي **الكمّية المعروضة نفسُها**، وتُلغى تحت `prefers-reduced-motion` |
| **d = 0.50–0.70** | التقطيع بتحكّم المتعلّم | ✔ لقطةٌ في الصفحة، ١٣٩ مساراً، والانتقالُ بيد القارئ. ولا تقدّمَ تلقائيّ ولا تمريرَ لا نهائيّ |
| **§٥ الآلة التصوّرية عند دفن الاعتقاد** | مخطّطٌ يُظهر السبب بين الكود الفاشل والبديل | ⚠ **في ثلاثة مواضع من عشرة.** المختبراتُ الثلاثة هي الآلة التصوّرية بخلايا مفهرسة وقيمٍ مقيسة. وثلاثةُ مواضعَ أخرى — `13` التوسيع، و`16` الخيط الأبيض، و`20` القصُّ المتداخل — تدفن اعتقاداً **بالأرقام والنثر وحدهما** |
| **§٧ لا تلعيب** | ما يُحفَظ وما لا يُحفَظ | ✔ يُحفَظ التوقّعُ وموضعُ الوقوف فقط، ويُعرَضان عند أرضية الإقليم. ولا نقاطَ ولا شاراتٍ ولا سلاسل، ولا مؤقّتَ يحكم |
| **§٨ ≤ ٤ فئاتٍ لونية + قناةٌ ثانية** | حدُّ المعالجة قبل-الانتباهية | ✔ أربعٌ بالضبط، **ولكلٍّ وسمٌ نصّيّ** (`@math · رياضيات`). ولا ثالثةَ: بلا أيقوناتٍ وبلا حدودٍ ملوّنة |

## ٤. القيود السالبة — ما مُنع، ومن أين جاء المنع

| المنع | مصدره |
|---|---|
| **لا زرَّ تشغيلٍ لأي بلوك** | الكودُ كلُّه C يُترجَم ويُشغَّل محلياً، ولا منفّذَ له في المتصفّح يطابق `cc`. وزرٌّ يعطي جواباً مختلفاً أسوأ من لا زرّ |
| **لا صورَ ناتجةً معروضةً** | «الصورة لا تُوصَف، تُقاس» (الريدمي). عرضُ `PGM` صورةً يدعو إلى الحكم بالنظر، والمنهج يرفضه — فتُعرَض **أرقامُ الفرق** وحدها |
| **لا زرَّ «اكشف الحلّ»** | «ولا حلول في المنهج» (الريدمي §كيف يُدرَس) |
| **لا حركةَ دخولٍ ولا انتقالاتِ صفحة** | أثر التماسك، وحظرُ الحركة التلقائية في الأسلوب |
| **لا دوّارة (spinner)** | لا شيء ينتظر: الموقع ساكنٌ بالكامل ومُصيَّرٌ مسبقاً |
| **لا شريطَ تقدّمٍ للمنهج ولا نسبةَ إنجاز** | ركيزةُ «التقدّم يُعرَض مقلوباً»: شريطُ اللقطة نفسِها فقط |
| **لا لونَ لبطاقةٍ ولا أيقونةَ لفصل** | تمييزٌ بلا معلومة — وهو القالبُ بثوبٍ آخر |

**وما حُذف بعد أن كُتب:** لوحُ ألوانٍ مأخوذٌ من «هوية بصرية» — لا مصدر له في
المحتوى فسقط باختبار القبول؛ وشارةُ إصدارٍ في الترويسة — تُقرأ قديمةً بعد سنة
ولا تضيف للقارئ شيئاً؛ وتلوينُ صفٍّ بعينه في سلّم التشخيص — كان يعني نقلَ
ادّعاءٍ من النثر إلى الكود (خرقُ الثابت ٤).

| الناقص | موضعُه بالاسم |
|---|---|
| مختبرٌ رابع: **مخزنُ التراكم** | `09` — يُظهر المجموع الجاري وهو يعبر الصفّ، ولماذا يلزم عمودا الهامش |
| مختبرٌ خامس: **المفصل وحدُّ الـmiter** | `12` — مزلاجُ زاويةٍ يُظهر لحظة سقوط الشوكة إلى `bevel` عند النسبة المحسوبة |
| مختبرٌ سادس: **الترميز مقابل الضوء** | `21` — حافّةٌ تُدمَج بالطريقتين جنباً إلى جنب |
| مراسٍ سطريةٌ داخل البلوك | يحتاج علامةً في **الماركداون** أوّلاً (`<!-- line: 3 -->` أو ما يقوم مقامها)، ثم يستخرجها الموقع |

## ٦. مصائد تقنية وقعت فعلاً

1. **البوّابةُ سرّبت جوابَها مرّتين.** أوّلاً حين كان الشرحُ بعد اللوحة ظاهراً
   وهي مقفلة، وثانياً حين كان **المختبرُ** خارج نطاقها فعرض الرقم نفسه. العلاج:
   `Blocks` تلفّ بقيّة اللقطة **ومعها ذيلُها** داخل البوّابة.
2. **وذيلٌ مضاعف:** بعد إدخال الذيل، كان يُضاف داخل البوّابة ومرّةً بعد الحلقة —
   فظهر المختبر مرّتين. العلاج رايةُ `gated`.
3. **العربيةُ داخل عنصرٍ بصنف مونو** (`الصفّ 7`): يمسكها `tools/bidi.py`، ولا
   يراها فحصُ الدخان ولا المترجم. وقد وُسّعت قائمةُ الأصناف في الفاحص لتشمل
   أصناف هذا المنهج.
4. **مصطلحٌ لاتينيّ بين قوسين في فقرةٍ عربية** (`(hairline)`): يقفز القوسُ في
   الخوارزمية الثنائية. حُوّلت أحدَ عشرَ موضعاً إلى علامتَي شفرة، فصارت معزولةَ
   الاتّجاه.
5. **شريطُ الحافّة محورُ إحداثيّ**، فيبقى `ltr` كما تبقى مخطّطات الذاكرة — وقد
   ظهر معكوساً في أوّل لقطةِ متصفّح.
6. **العتامةُ على الخليّة تُخفي إطارَها**: خليّةُ العيّنات ذات القيمة صفر
   اختفت تماماً بدل أن تُرى فارغة. العلاج: الإطارُ على الحاوية، والعتامةُ على
   المِلء وحده.
7. **مسارات `HashRouter`** لا تُلتقَط بـ`/r/00/8` بل بـ`/#/r/00/8` — وإلا التقط
   الفاحصُ صفحةً بلا أصولٍ ولا تركيب.

## ٧. الفحوص وأرقامُها

```bash
npm run outputs   # ٧٠ لوحةً · صفر ثقوب · ٢٩ بوّابة — ومنها ٦ قياساً ضدّ Skia
npm run bidi      # ١٦ ملفّاً: لا عربيةَ في مونو، والكودُ معزول
npm run smoke     # ١٣٩ مساراً · ٢٧ إقليماً · ١١١ لقطة · ٣ مختبرات
npm run typecheck
npm run build     # dist/ بلا أصلٍ خارجيّ، ثم sw.js
npm run swcheck   # ثلاثُ زياراتٍ تحت سيطرة عامل الخدمة
node ../../../../tools/doctor.mjs   # البنية والتوثيق
```

**و`outputs` هو الفحص الذي يحمل المنهج:** يترجم كلَّ برنامجٍ في `programs/`،
ويقارن مخرَجه بلوحته، **ويشغّل `tools/ref.py` لكلّ صورةٍ فيقارنها بـSkia**
ويقارن أرقام الفرق باللوحة. فلا لوحةَ في هذا الموقع لم تخرج من تشغيلٍ حقيقيّ.

## ٨. النشر

```bash
npm run build
cd dist && zip -r ../path-to-pixel.zip . && cd ..
```

المشروع `t3lm-path-to-pixel`، والعنوان `path-to-pixel.nodeksa.com` — يكتبه
`doctor` في `curriculum.json` ولا يُكتَب بيد.
