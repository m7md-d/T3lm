# الإقليم ٠٦ — الملء الساذج

> هذا هو الـepitome بصورته الكاملة: صحيحٌ، ومقيسُ الكلفة. وهذا الإقليم يقيسه
> لا ليمدحه — بل ليجعل ما بعده **مقارنةً برقم**، لا ادّعاءَ سرعة.

---

## الحلقة كما هي

<!-- head: fill_naive.h -->

```c
static void fill_naive(image *im, const poly *g, rgba color, fillrule rule) {
  for (int y = 0; y < im->h; y++)
    for (int x = 0; x < im->w; x++)
      if (inside(g, (float)x + 0.5f, (float)y + 0.5f, rule)) img_set(im, x, y, color);
}
```

ثلاث حلقاتٍ متداخلة: صفٌّ، فعمود، ثمّ `inside` تمرّ على **كلّ حافّةٍ في الشكل**.
فالكلفة `O(w · h · n)` حيث `n` عددُ الحوافّ بعد التسطيح.

والمهمّ في هذه الصيغة أنّ الحدَّين الأولين **لا علاقة لهما بالشكل**: صورةٌ
`512×512` فيها نقطةٌ سوداءُ واحدة تدفع الثمنَ كاملاً.

## القياس

<!-- part: 06-cost -->

```c
for (int n = 64; n <= 512; n *= 2) {
  flatten(&q, xf_scale(n / 256.0f, n / 256.0f), 0.1f, &g);
  fill_naive(&im, &g, (rgba){0, 0, 0, 255}, PX_EVENODD);
}
```

ثمانيةٌ وستّون مليوناً أم ثمانيةٌ وستّون ألفاً؟ خمّن رتبةَ العدد في العمود
الأخير قبل أن تنظر.

المخرَج:

<!-- runs: 06-cost -->

```
 الحجم   حوافّ   الزمن      اختباراتُ حافّة
  64×64     100      0.4 ms           0.4 مليون
 128×128    132      2.0 ms           2.2 مليون
 256×256    196     12.0 ms          12.8 مليون
 512×512    260     63.7 ms          68.2 مليون
```

**الأرقام من جهازٍ واحد، والثابتُ هو النسبة.** ضاعِف الضلع، فتصير الصورة أربعة
أضعاف والحوافُّ نحو الثلث زيادةً (لأن حدَّ الاستواء يُقاس بعد التكبير — الإقليم
`04`) — والزمنُ خمسةَ أضعافٍ ونيّف. وهو حاصلُ ضربهما بالضبط.

وعمودُ «اختبارات حافّة» هو الرقم الذي يهمّ: ثمانيةٌ وستّون مليون اختبارٍ لرسم
حلقةٍ واحدة، أكثرُها لبكسلاتٍ فارغةٍ في أركان الصورة.

## أين يذهب العمل

للحلقة عند `512×512` مساحةٌ نحو ٨٧ ألف بكسل من ٢٦٢ ألفاً. فثلثا العمل يُنفَق على
بكسلاتٍ لا تُكتَب — **وهي تُمسَح كاملةً كما تُمسَح المملوءة**، لأن `inside` لا
تعرف أنها بعيدة.

وهذا يقترح إصلاحين مختلفَين تماماً:

1. **قلّل البكسلات**: لا تمرّ إلا على ما يمكن أن يُملأ (المستطيل المحيط، ثمّ
   المدَيات على السطر). وذلك الإقليم `07`.
2. **قلّل الحوافّ لكلّ بكسل**: لا تمرّ على كلّ حافّةٍ لكلّ نقطة، بل رتّبها مرّةً
   واعبرها. وذلك الإقليم `07` أيضاً — الإصلاحان واحد.

**والثالث لا يظهر إلا بعد ذلك:** لا تسأل عن البكسل أصلاً، بل دع الحوافَّ تكتب
أثرَها. وذلك الإقليم `09`.

---

## التمرين

أضِف إلى `fill_naive` تقليماً بالمستطيل المحيط: احسب حدود المضلَّع مرّةً، ثم
اقصر الحلقتين عليه.

قِس الحلقة، ثمّ قِس **نجمةً**. الأولى ستتحسّن كثيراً، والثانية أقلّ. قل لماذا في
سطر — والجواب في نسبة المساحة إلى المستطيل المحيط.

## الخلاصة

- الملء الساذج `O(w · h · n)`، **وحدّاه الأولان لا يعرفان الشكل**.
- الأرقام من جهازٍ واحد، والثابتُ هو النسبة.
- ثلثا العمل يُنفَق على بكسلاتٍ لا تُكتَب.
- إصلاحان: قلّل البكسلات المزارة، ورتّب الحوافَّ مرّةً بدل مسحِها لكلّ بكسل.

**البابُ الذي فتحتَه:** صار عندك رقمٌ تقارن به، لا انطباع.

**البابُ المغلق:** كيف تعرف مدَيات السطر بلا أن تسأل كلَّ بكسلٍ فيه؟ ذلك
الإقليم `07`.
