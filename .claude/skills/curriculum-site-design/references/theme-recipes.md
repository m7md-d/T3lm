# وصفات الثيم — الاشتقاق من جوّ الموضوع

الثيم دالّة في جوّ الموضوع. هذه وصفات محلولة + طريقة لاشتقاق ثيم لموضوع جديد.
البنية ومفردات المكوّنات تبقى ثابتة (انظر design-dna و component-library)؛ هنا
يتغيّر **الجلد** فقط: لوحة، خطوط، نسيج، موتيف، شدّة حركة، نصف قطر.

> قيد حاكم: **كل الثيمات داكنة، بلا استثناء.** التمييز بين المواضيع يكون عبر
> درجة حرارة الظلام واللون المهيمن والخطّ والنسيج — لا عبر فاتح مقابل داكن.

---

## ١) هاكينج / بروتوكولات / أمن — "سايبربانك طرفية"

(الثيم المرفق كمثال محقّق: `assets/example-cyberpunk.css`)
- **الجوّ:** تسلّل، خطر، استكشاف خفيّ، توتّر.
- **اللوحة:** أسود عميق + أخضر حمضي مهيمن + cyan ثانوي + كهرماني/أحمر دلالي.
- **الخطوط:** mono ثقيل الحضور (JetBrains Mono) + عربي تقني.
- **النسيج:** scanlines + توهّج شعاعي خافت.
- **الموتيف:** glitch في الـ hero، مؤشر وامض، نقطة حالة نابضة، أضواء مرور للطرفية.
- **الحركة:** متوسطة، تخدم حسّ "النظام الحيّ".
- **الزوايا:** حادّة تماماً.

## ٢) CSS / تصميم / فرونت‑إند — "استوديو داكن تحريري"

- **الجوّ:** صنعة، ذوق، تعبير بصري، انفتاح. **عكس روح الهاكر — لكن داكن.**
- **اللوحة:** **داكنة دافئة** — خلفية فحم/حبر شبه أسود (لا أسود طرفية بارد)، نص
  كريمي فاتح، لون مهيمن **حيوي معبّر** (برتقالي محروق، مرجاني كهربائي، أو وردي
  مغبّر) + لمسة ثانية. تباين عالٍ وجريء داخل الظلام.
- **الخطوط:** display تحريري ذو شخصية للعناوين (serif معبّر أو grotesque مميّز) +
  عربي أنيق للجسم. mono للكود فقط.
- **النسيج:** مساحات سخية، خطوط شبكة طباعية خفيفة جداً، لا scanlines.
- **الموتيف:** بلا glitch؛ بدله انتقالات لونية ناعمة وإبراز تايبوغرافي.
- **الحركة:** ناعمة منحنية (ease)، تكشف عند التمرير.
- **الزوايا:** قد تكون أنعم قليلاً إن خدم الإحساس التحريري.

> الفرق عن الهاكر: دفء اللوحة، اللون المعبّر، الحضور التايبوغرافي، نعومة الحركة،
> غياب الطرفية والـ scanlines. كلاهما داكن، لكن الروح مختلفة تماماً.

## ٣) لغة وظيفية / نظرية أنواع / رياضيات — "سبّورة داكنة"

- **الجوّ:** صرامة، تجريد، هدوء تأمّلي، بناء برهاني.
- **اللوحة:** سبّورة داكنة مخضرّة/مزرقّة عميقة + طباشير فاتح للنص + لمسة باستيل
  واحدة (طباشير ملوّن) للتأكيد. هادئة، رصينة.
- **الخطوط:** serif للعناوين/الجسم (حسّ رصين) + mono للرموز والكود. عربي رصين.
- **النسيج:** نقش سبّورة خفيف جداً، احترام كبير للفراغ.
- **الموتيف:** بلا تأثيرات صاخبة؛ ربما إبراز معادلات/براهين.
- **الحركة:** أدنى ما يمكن. السكون يخدم التأمّل.
- **الزوايا:** حادّة، رصينة.

## ٤) أنظمة / C / ذاكرة / OS — "مخطّط هندسي / CRT كهرماني"

- **الجوّ:** هندسة منخفضة المستوى، دقّة آلية، صلابة.
- **اللوحة:** خياران: (أ) blueprint أزرق داكن + خطوط بيضاء/سماوية رفيعة؛ (ب) CRT
  أسود + كهرماني مهيمن (فوسفور قديم) + أخضر باهت.
- **الخطوط:** mono مهيمن (حسّ آلة) + عربي تقني.
- **النسيج:** شبكة مخطّطات هندسية دقيقة، أو توهّج فوسفور CRT.
- **الموتيف:** مخططات ascii/figure كثيفة، جداول عناوين الذاكرة.
- **الحركة:** قليلة وميكانيكية.
- **الزوايا:** حادّة.

## ٥) تشفير — "شيفرة / خزنة"

- **الجوّ:** سرّية، صرامة، طبقات إخفاء.
- **اللوحة:** داكن معدني + لون مهيمن بارد (فضي/بنفسجي عميق) + لمسة ذهبية للمفاتيح.
- **الخطوط:** mono للشيفرات + عربي رصين.
- **النسيج:** نقش متكرّر دقيق (حسّ تعمية)، توهّج خافت.
- **الموتيف:** تحوّلات نص مُعمّى عند الكشف، badges للمفاتيح.
- **الحركة:** محسوبة، تكشف تدريجياً.

## اشتقاق ثيم لموضوع جديد (الطريقة)

1. **صف الجوّ بكلمتين أو ثلاث.** (مثلاً: "بيانات، تدفّق، سيولة" لقواعد البيانات →
   قد يوحي بثيم تدفّق سائل/شبكي.)
2. **اختر درجة حرارة الظلام:** بارد أم دافئ؟ أزرق/أخضر/فحم/معدني؟ (الخلفية
   داكنة دائماً — يبقى أن تحدّد *نوع* الظلام الذي يجسّد الجوّ.)
3. **عيّن لوناً مهيمناً واحداً** يجسّد الجوّ + ثانوي + مجموعة دلالية ثابتة المعنى.
4. **اختر اقتران خطّين:** display بشخصية تناسب الجوّ + عربي مريح للجسم + mono للكود.
5. **اختر النسيج والموتيف** من جوهر الموضوع (لا زخرفة عشوائية): ما الذي يجسّد
   توتّره بصرياً؟
6. **اضبط شدّة الحركة ونصف القطر** على المزاج (صاخب/هادئ، دقيق/ودّي).
7. **طبّقها على نفس الـ tokens والمكوّنات** — لا تلمس البنية.

اختبار القبول: لو نقلت هذا الثيم لموضوع مختلف الجوّ، هل يبدو خاطئاً؟ إن كان نعم،
فقد نجحت في جعله مشتقّاً من الموضوع لا عاماً.
