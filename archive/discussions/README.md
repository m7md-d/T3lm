# النقاشات والأفكار القائمة

**ما يسكن هنا:** المسائل التي **لم تُحسَم بعد** وتحتاج قرارك — تدقيقُ حالة،
اقتراحٌ ينتظر ردّاً، خيطٌ مفتوح يمتدّ عبر جلسات. ملفٌّ هنا حيٌّ: يُحدَّث حتى
يُحسَم، ثم **يُنقَل ما قرّرته إلى موضعه** ويُشطَب من هنا.

**ما لا يسكن هنا:**

| النوع | موضعه |
|---|---|
| قرارٌ تربويّ حُسِم | `.claude/profiles/<name>.md` |
| اجتهادٌ بلا دليل، أو فجوةٌ تنتظر دراسة | `.claude/evidence/open.md` |
| ما أثبته بحث | `.claude/evidence/findings.md` |
| قاعدةٌ تنفيذية | `.claude/skills/*/SKILL.md` |
| **تقرير بحثٍ خام** | **لا يُحفَظ** — يُستخرَج منه ما يقرّر ثم يُحذَف (قانون ٨) |
| منهجٌ قديم أو مادّةٌ ليست منهجاً | `archive/<name>/` بجوار هذا المجلد |

**والفرق بين هذا و`evidence/open.md` فرقُ سؤال:** هناك «ما الذي لا نعرفه عن
التعلّم؟»، وهنا «ما الذي لم نقرّره بعد في هذا المستودع؟».
